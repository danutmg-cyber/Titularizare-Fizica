13.2 Experiența Michelson–Morley

Interferometrul Michelson, două drumuri luminoase perpendiculare, predicția cinematicii newtoniene, diferența timpilor de propagare, detecția prin interferență și rezultatul nul al experienței.

Context

Problema experimentală

Bunget prezintă experiența Michelson–Morley în contextul încercărilor istorice de a detecta efectele presupusei mișcări față de eter.

Analiza din §13.2 pornește de la cinematica newtoniană și de la legea clasică de compunere a vitezelor, apoi compară predicția astfel obținută cu rezultatul experimental.

Figura I.13.1

Schema interferometrului

O sursă monocromatică \(S\) trimite lumină către o oglindă semitransparentă \(O\).

Fasciculul este separat în două fascicule care parcurg două brațe perpendiculare.

Fasciculul 1

Este trimis spre oglinda \(O_1\), se reflectă și revine la \(O\).

Fasciculul 2

Este trimis spre oglinda \(O_2\), se reflectă și revine la \(O\).

Reunirea

Cele două fascicule ajung apoi la luneta \(L\), unde pot interfera.

Ipoteza de calcul

Predicția newtoniană

Se presupune, în calculul lui Bunget, că aparatul se deplasează cu viteza \(v\) și că vitezele luminii se compun după regula cinematicii clasice.

Lungimea fiecărui braț este notată cu \(l\), iar viteza luminii cu \(c\).

\[ \boxed{ v\ll c } \]
Brațul paralel

Timpul dus–întors

Pentru brațul paralel cu direcția vitezei \(v\), în modelul clasic apar vitezele relative:

\[ c+v \qquad\text{și}\qquad c-v. \]

Timpii celor două porțiuni ale drumului sunt deci:

\[ t_1' = \frac{l}{c+v}, \]
\[ t_1'' = \frac{l}{c-v}. \]

Timpul total este:

\[ t_1 = t_1'+t_1''. \]
Relația (13.1)

Timpul pe brațul paralel

\[ t_1 = \frac{l}{c+v} + \frac{l}{c-v}. \]

Prin aducere la același numitor:

\[ \boxed{ t_1 = \frac{2lc}{ c^2-v^2 } } \]

sau:

\[ \boxed{ t_1 = \frac{2l}{c} \frac{1}{ 1-\dfrac{v^2}{c^2} } } \]
Figura I.13.2

Brațul perpendicular

Pentru fasciculul care se propagă pe brațul perpendicular, în timpul propagării aparatul se deplasează lateral.

În construcția geometrică utilizată de Bunget, pentru o jumătate de drum apare un triunghi dreptunghic:

\[ \boxed{ (ct_2')^2 = l^2 + (vt_2')^2 } \]
Calcul

Timpul pentru o jumătate de drum

Din relația geometrică:

\[ (c^2-v^2) (t_2')^2 = l^2. \]

Rezultă:

\[ \boxed{ t_2' = \frac{l}{ \sqrt{c^2-v^2} } } \]

Drumul de întoarcere necesită același timp.

Relația (13.2)

Timpul total pe brațul perpendicular

\[ \boxed{ t_2 = \frac{2l}{ \sqrt{c^2-v^2} } } \]

sau:

\[ \boxed{ t_2 = \frac{2l}{c} \frac{1}{ \sqrt{ 1-\dfrac{v^2}{c^2} } } } \]
Compararea timpilor

Predicția unei întârzieri

În cinematica newtoniană folosită în calcul, timpii \(t_1\) și \(t_2\) nu sunt egali.

\[ \boxed{ \Delta t = t_1-t_2 } \]

Înlocuind relațiile (13.1) și (13.2):

\[ \Delta t = \frac{2l}{c} \left[ \frac{1}{ 1-\dfrac{v^2}{c^2} } - \frac{1}{ \sqrt{ 1-\dfrac{v^2}{c^2} } } \right]. \]
Relația (13.3)

Aproximația pentru \(v\ll c\)

Bunget folosește faptul că viteza orbitală considerată pentru Pământ este mult mai mică decât viteza luminii.

\[ \frac{v}{c}\ll1. \]

Dezvoltarea aproximativă conduce la:

\[ \boxed{ \Delta t \approx \frac{l}{c} \frac{v^2}{c^2} } \]

echivalent:

\[ \boxed{ \Delta t \approx \frac{lv^2}{c^3} } \]
Ordin de mărime

O diferență extrem de mică

Compendiul ia în considerare viteza orbitală a Pământului de ordinul:

\[ v \approx 30\,\mathrm{km/s}. \]

Pentru un braț de ordinul metrului, diferența de timp prevăzută clasic este de ordinul:

\[ \boxed{ \Delta t \sim 10^{-16}\,\mathrm s } \]

O astfel de diferență nu poate fi pusă în evidență cu un cronometru obișnuit.

A doua orientare

Brațele la \(45^\circ\) față de direcția mișcării

Bunget consideră apoi orientarea în care cele două brațe ale aparatului fac același unghi de \(45^\circ\) cu direcția vitezei \(v\).

Prin simetrie, în modelul analizat, timpii de propagare pe cele două brațe devin egali.

\[ \boxed{ t_1=t_2 \Rightarrow \Delta t=0 } \]
Metoda de măsurare

Interferența în locul măsurării directe a timpului

Michelson utilizează interferența luminii pentru a detecta diferența foarte mică dintre timpii de propagare.

Dacă cele două fascicule ajung simultan, diferența temporală datorată celor două brațe este nulă. Dacă timpii sunt diferiți, între fascicule apare un defazaj.

\[ \boxed{ \Delta t\neq0 \Rightarrow \Delta\varphi\neq0 } \]

Modificarea defazajului produce o modificare observabilă a figurii de interferență.

Rezultatul experienței

Rezultat nul

Bunget arată că diferența de timp prezisă de calculul clasic nu a fost observată la schimbarea orientării aparatului.

\[ \boxed{ \Delta t_{\text{observat}} \approx 0 } \]

În interpretarea paragrafului, acest rezultat indică faptul că legea newtoniană de compunere a vitezelor nu poate fi aplicată luminii în modul presupus de calcul.

Sinteză

De reținut din §13.2

Interferometru

Separă un fascicul în două fascicule care parcurg brațe perpendiculare și apoi interferează.

Braț paralel

\[ \boxed{ t_1 = \frac{2l}{c} \frac{1}{ 1-\dfrac{v^2}{c^2} } } \]

Braț perpendicular

\[ \boxed{ t_2 = \frac{2l}{c} \frac{1}{ \sqrt{ 1-\dfrac{v^2}{c^2} } } } \]

Predicția clasică

\[ \boxed{ \Delta t \approx \frac{lv^2}{c^3} } \]

Metoda de detecție

Interferența permite evidențierea unor diferențe de timp extrem de mici.

Rezultat

\[ \boxed{ \text{diferența prevăzută de modelul clasic nu este observată} } \]
Titularizare

Precizări pentru examen

Această secțiune este separată de corpul §13.2 al Compendiului. Reperul oficial utilizat este programa Titularizare Fizică 2026.

Statut: cerință directă a programei 2026

Spre deosebire de capitolul de acustică, această lecție intră direct în tematica obligatorie.

Punctul 14 cere:

Bazele experimentale ale teoriei relativității restrânse. Postulatele lui Einstein. Transformările Lorentz; consecințe.

Experiența Michelson–Morley trebuie deci înțeleasă ca una dintre bazele experimentale relevante pentru trecerea de la cinematica galileiană la relativitatea restrânsă.

La examen trebuie să poți reconstrui logic experiența:

ipoteza cinematicii clasice;
două brațe perpendiculare;
calculul celor doi timpi;
predicția: \[ t_{\parallel}\neq t_{\perp}; \]
detecția prin interferență;
rezultatul experimental nul;
concluzia privind limitele compunerii galileiene pentru lumină.
Notație utilă: \[ \boxed{ \beta = \frac{v}{c} } \] este adimensională. Pentru viteza orbitală a Pământului: \[ \beta \sim 10^{-4}, \] deci: \[ \beta^2 \sim 10^{-8}. \]
Braț paralel — formă de reținut: independent de denumirea „dus” sau „întors” asociată semnelor, \[ t_{\parallel} = \frac{l}{c-v} + \frac{l}{c+v}. \] De aici: \[ \boxed{ t_{\parallel} = \frac{2l}{c} \frac{1}{ 1-\beta^2 } } \]
Braț perpendicular: din triunghiul vitezelor: \[ c^2t^2 = l^2+v^2t^2. \] Rezultă pentru dus–întors: \[ \boxed{ t_{\perp} = \frac{2l}{c} \frac{1}{ \sqrt{1-\beta^2} } } \]
Pentru: \[ \beta\ll1, \] folosim: \[ \frac{1}{ 1-\beta^2 } \approx 1+\beta^2 \] și: \[ \frac{1}{ \sqrt{1-\beta^2} } \approx 1+\frac{\beta^2}{2}. \]
Prin scădere: \[ \Delta t = t_{\parallel} - t_{\perp} \] devine: \[ \boxed{ \Delta t \approx \frac{l}{c}\beta^2 = \frac{lv^2}{c^3} } \]
Eroare algebrică frecventă: efectul prezis este de ordinul: \[ \boxed{ \left( \frac{v}{c} \right)^2 } \] nu de ordinul: \[ \frac{v}{c}. \]
De ce interferența este suficient de sensibilă: o diferență temporală produce diferență de fază: \[ \boxed{ \Delta\varphi = \omega\Delta t } \] Pentru lumină monocromatică: \[ \omega=2\pi\nu \] și: \[ \nu=\frac{c}{\lambda}. \] Prin urmare: \[ \boxed{ \Delta\varphi = \frac{ 2\pi c\Delta t }{ \lambda } } \]
O schimbare a diferenței de fază deplasează franjele de interferență. De aceea nu este necesară măsurarea directă a unui timp de ordinul: \[ 10^{-16}\,\mathrm s. \]
Formulare modernă riguroasă: rezultatul Michelson–Morley este numit rezultat nul deoarece nu a fost observată deplasarea franjelor de mărimea și cu dependența de orientare prevăzute de modelul clasic al unui „vânt de eter” staționar.
Nu formula: „Michelson–Morley a demonstrat singur inexistența oricărei forme posibile de eter.” Aceasta este prea puternică din punct de vedere istoric și logic. Experiența a infirmat predicția simplă a modelului de eter folosit în calcul și a fost una dintre bazele experimentale importante ale noii teorii.
Altă precizare importantă: interferometrul compară timpii de propagare pe trasee dus–întors. Nu este o măsurare directă independentă a vitezei luminii pe un singur sens.
Legătura cu §13.1: în cinematica galileiană: \[ u'_x=u_x-V. \] Aplicată naiv luminii, această regulă conduce la viteze relative de tip: \[ c+v \qquad\text{și}\qquad c-v. \] Tocmai această ipoteză conduce la diferența de timp calculată în §13.2.
Legătura cu §13.3: rezultatul experimental pregătește formularea celor două principii ale relativității restrânse:

principiul relativității;
constanța vitezei luminii în vid pentru sistemele de referință inerțiale.
Nu introduce încă transformările Lorentz în corpul §13.2. În Compendiu, ele sunt dezvoltate abia în §13.4. §13.2 trebuie să rămână lecția experimentală care motivează schimbarea cadrului cinematic.
Verificare de limită: dacă: \[ v\rightarrow0, \] atunci: \[ t_{\parallel} \rightarrow \frac{2l}{c} \] și: \[ t_{\perp} \rightarrow \frac{2l}{c}. \] Deci: \[ \boxed{ \Delta t\rightarrow0 } \] așa cum trebuie.
Verificare dimensională: pentru: \[ \Delta t = \frac{lv^2}{c^3}, \] avem: \[ [\Delta t] = \frac{ \mathrm m \cdot \mathrm{m^2/s^2} }{ \mathrm{m^3/s^3} } = \boxed{ \mathrm s }. \]
Estimare de ordin de mărime: pentru: \[ l=1\,\mathrm m, \] \[ v = 3{,}0\times10^4 \,\mathrm{m/s}, \] \[ c \approx 3{,}0\times10^8 \,\mathrm{m/s}, \] avem: \[ \frac{v}{c} \approx 10^{-4}. \] Astfel: \[ \Delta t \sim \frac{1}{ 3\times10^8 } 10^{-8} \,\mathrm s, \] adică un timp extrem de mic, de ordinul \(10^{-17}\)–\(10^{-16}\,\mathrm s\), în funcție de lungimea optică efectivă.
Abordare didactică potrivită: experiența se pretează foarte bine unei situații-problemă:

„Dacă vitezele se compun galileian, ce diferență ar trebui să apară între timpii de propagare pe cele două brațe?”

Elevii pot deduce separat \(t_{\parallel}\) și \(t_{\perp}\), apoi compara predicția cu rezultatul experimental.
Avantaj metodic: teoria relativității nu este introdusă ca o colecție de formule noi. Ea apare ca răspuns la o incompatibilitate între predicția unui model clasic și rezultatele experimentale.
Șase erori de evitat:

1. confundarea celor doi timpi: \[ t_{\parallel} \quad\text{și}\quad t_{\perp}; \]

2. folosirea aceleiași viteze relative \(c-v\) pe ambele sensuri ale brațului paralel;

3. ignorarea deplasării laterale a aparatului pentru brațul perpendicular;

4. pierderea termenului de ordin: \[ \left(\frac{v}{c}\right)^2; \]

5. afirmația că experimentul măsoară pur și simplu „viteza luminii într-o direcție”;

6. formularea rezultatului nul drept demonstrație izolată a întregii teorii a relativității restrânse.
Nucleul de memorat: braț paralel: \[ \boxed{ t_{\parallel} = \frac{2l}{c} \frac{1}{ 1-v^2/c^2 } } \] braț perpendicular: \[ \boxed{ t_{\perp} = \frac{2l}{c} \frac{1}{ \sqrt{ 1-v^2/c^2 } } } \] predicție clasică: \[ \boxed{ \Delta t \approx \frac{lv^2}{c^3} } \] detecție: \[ \boxed{ \Delta t \Rightarrow \Delta\varphi \Rightarrow \text{deplasare a franjelor} } \] rezultat experimental: \[ \boxed{ \text{deplasarea clasic prevăzută nu apare} } \]
