Suprapunerea undelor

Mai multe unde în același mediu

Bunget pornește de la situația în care prin același mediu se propagă simultan mai multe unde, provenite de la surse diferite.

O particulă a mediului poate fi astfel supusă concomitent mai multor mișcări oscilatorii.

Mișcarea efectivă a particulei este rezultanta mișcărilor pe care fiecare undă le-ar produce separat.

\[ \boxed{ y = y_1+y_2+\cdots } \]
Principiu

Compunerea oscilațiilor

În fiecare punct în care ajung două sau mai multe unde, trebuie compuse oscilațiile produse de acestea.

\[ \boxed{ \text{unde suprapuse} \Rightarrow \text{compunerea oscilațiilor} } \]

§11.5 se concentrează asupra unui caz deosebit de important: sursele coerente.

Definiție

Surse coerente

Bunget consideră surse ale căror oscilații au aceeași frecvență și o diferență de fază constantă.

Oscilații coerente

Oscilații cu frecvențe egale și cu diferență de fază constantă în timp.

\[ \boxed{ \nu_1=\nu_2 } \]
\[ \boxed{ \Delta\varphi_0 = \text{constantă} } \]
Fenomen

Interferența

Interferență

În prezentarea Compendiului, este fenomenul de suprapunere a două sau mai multor unde de aceeași frecvență.

Bunget studiază în continuare cazul surselor coerente, pentru care relațiile de fază dintre unde rămân stabile.

Surse coerente

Două orificii alimentate de aceeași sursă

Compendiul prezintă o modalitate de obținere a două surse coerente.

O sursă \(O\) produce o undă sferică. În fața ei este plasat un ecran cu două orificii punctiforme:

\[ O_1, \qquad O_2. \]

Cele două orificii sunt așezate simetric față de sursa \(O\).

Conform principiului lui Huygens, ele se comportă ca două surse secundare.

Proprietate

Aceeași frecvență și aceeași fază

Deoarece \(O_1\) și \(O_2\) se află la aceeași distanță de sursa inițială, oscilațiile lor au aceeași frecvență și sunt în fază în configurația aleasă de Bunget.

\[ \boxed{ \nu_1=\nu_2=\nu } \]
\[ \boxed{ \Delta\varphi_0=0 } \]

În spatele ecranului se propagă astfel două unde sferice provenite de la surse coerente.

Un punct al mediului

Două unde ajung în același punct

Se consideră un punct al mediului în care sosesc undele produse de sursele coerente \(O_1\) și \(O_2\).

Distanțele parcurse de cele două unde sunt notate:

\[ x_1, \qquad x_2. \]

Amplitudinile celor două oscilații sunt:

\[ A_1, \qquad A_2. \]
Relația (11.9)

Cele două oscilații

Folosind ecuația undei plane din §11.2, Bunget scrie oscilațiile care ajung în punctul considerat:

\[ \boxed{ y_1 = A_1 \sin 2\pi \left( \nu t - \frac{x_1}{\lambda} \right) } \]
\[ \boxed{ y_2 = A_2 \sin 2\pi \left( \nu t - \frac{x_2}{\lambda} \right) } \]
Relațiile (11.10)–(11.11)

Diferența de fază

Faza fiecărei oscilații depinde de distanța parcursă de undă de la sursa respectivă până la punctul de observație.

Diferența de fază asociată diferenței de drum este:

\[ \boxed{ \Delta\varphi = \frac{ 2\pi(x_1-x_2) }{ \lambda } } \]

Semnul depinde de ordinea în care sunt scăzute cele două faze.

Mărime geometrică

Diferența de drum

Bunget subliniază că diferența de fază depinde de diferența dintre distanțele parcurse de cele două unde.

\[ \boxed{ \Delta x = x_1-x_2 } \]
\[ \boxed{ \Delta\varphi = \frac{ 2\pi\Delta x }{ \lambda } } \]
Compunerea oscilațiilor

Amplitudinea rezultantă

Bunget folosește rezultatele stabilite anterior pentru compunerea a două oscilații paralele.

Amplitudinea mișcării rezultante depinde de diferența de fază dintre oscilațiile componente.

\[ \boxed{ A = A(\Delta\varphi) } \]
Maxim

Oscilațiile ajung în fază

Amplitudinea rezultantă este maximă atunci când diferența de fază este un multiplu întreg de \(2\pi\).

\[ \boxed{ \Delta\varphi = \pm2k\pi } \]

cu:

\[ k=0,1,2,\ldots \]

Valoarea amplitudinii maxime este:

\[ \boxed{ A_{\max} = A_1+A_2 } \]
Relația (11.12)

Condiția de maxim prin diferența de drum

Din:

\[ \Delta\varphi = \frac{ 2\pi(x_1-x_2) }{ \lambda }, \]

condiția de maxim devine:

\[ \boxed{ x_1-x_2 = \pm k\lambda } \]

adică diferența de drum este zero sau un număr întreg de lungimi de undă.

Formularea sursei

Număr par de semiunde

O lungime de undă conține două semiunde.

De aceea, condiția:

\[ \Delta x=k\lambda \]

poate fi exprimată și prin faptul că diferența de drum conține un număr par de semiunde.

Minim

Oscilații în opoziție de fază

Amplitudinea rezultantă este minimă atunci când diferența de fază este un multiplu impar de \(\pi\).

\[ \boxed{ \Delta\varphi = \pm(2k+1)\pi } \]

Amplitudinea minimă este:

\[ \boxed{ A_{\min} = |A_1-A_2| } \]
Relația (11.13)

Condiția de minim prin diferența de drum

Condiția corespunzătoare diferenței de drum este:

\[ \boxed{ x_1-x_2 = \pm (2k+1) \frac{\lambda}{2} } \]

Diferența de drum este deci un număr impar de semiunde.

Caz particular

Amplitudini componente egale

Dacă:

\[ A_1=A_2=A_0, \]

atunci la maxim:

\[ \boxed{ A_{\max} = 2A_0 } \]

iar la minim:

\[ \boxed{ A_{\min}=0 } \]
Interferență destructivă

Anularea mișcării

Bunget precizează că, atunci când amplitudinile celor două oscilații componente sunt egale și condiția de minim este îndeplinită, mișcarea punctului respectiv încetează.

\[ \boxed{ A_1=A_2, \qquad \Delta x = (2k+1) \frac{\lambda}{2} \Rightarrow A=0 } \]

Compendiul caracterizează această situație drept interferență destructivă.

Legătura logică

Firul §11.5

Mai multe unde

Se propagă simultan prin același mediu.

Suprapunere

\[ y=y_1+y_2 \]

Coerență

\[ \nu_1=\nu_2, \qquad \Delta\varphi_0 = \text{constantă} \]

Diferență de fază

\[ \boxed{ \Delta\varphi = \frac{ 2\pi\Delta x }{ \lambda } } \]

Maxim

\[ \boxed{ \Delta x = k\lambda } \]

Minim

\[ \boxed{ \Delta x = (2k+1) \frac{\lambda}{2} } \]
Sinteză

De reținut din §11.5

Surse coerente

Au aceeași frecvență și diferență de fază constantă.

Oscilațiile în punct

\[ y_1 = A_1 \sin 2\pi \left( \nu t-\frac{x_1}{\lambda} \right) \]
\[ y_2 = A_2 \sin 2\pi \left( \nu t-\frac{x_2}{\lambda} \right) \]

Diferență de fază

\[ \boxed{ \Delta\varphi = \frac{ 2\pi(x_1-x_2) }{ \lambda } } \]

Maxim

\[ \boxed{ x_1-x_2 = \pm k\lambda } \]
\[ A_{\max} = A_1+A_2 \]

Minim

\[ \boxed{ x_1-x_2 = \pm (2k+1) \frac{\lambda}{2} } \]
\[ A_{\min} = |A_1-A_2| \]
Titularizare

Precizări pentru examen

Această secțiune este separată de corpul §11.5 al Compendiului. Reperul oficial utilizat este programa Titularizare Fizică 2026.

Statut în programa 2026

Interferența undelor elastice nu este nominalizată separat la punctul 11.

Programa cere explicit:

Unde elastice plane în medii omogene și izotrope: unde longitudinale și transversale, viteza undelor. Ecuația undei plane.

§11.5 este însă legat direct de ecuația undei plane și pregătește §11.6 Unde staționare.

Principiul superpoziției: într-un mediu liniar, elongația rezultantă este suma algebrică a elongațiilor produse separat: \[ \boxed{ y=y_1+y_2 } \]
Atenție: undele nu se „distrug” definitiv atunci când apare un minim. Ele se suprapun, iar după regiunea de suprapunere își continuă propagarea în modelul liniar.
Coerența: pentru o figură de interferență stabilă sunt necesare: \[ \boxed{ \nu_1=\nu_2 } \] și: \[ \boxed{ \Delta\varphi_0 = \text{constantă} } \]
Aceeași frecvență nu este singură suficientă pentru o figură de interferență stabilă. Relația de fază trebuie să rămână stabilă în timp.
Diferența de drum: este util să o definim pozitiv: \[ \boxed{ \delta = |x_2-x_1| } \] cu unitatea SI: \[ \boxed{ [\delta]=\mathrm m } \]
Diferența de fază produsă de diferența de drum: \[ \boxed{ |\Delta\varphi| = \frac{ 2\pi\delta }{ \lambda } } \]
Maxim de interferență: \[ \boxed{ \delta = k\lambda } \] echivalent cu: \[ \boxed{ \Delta\varphi = 2k\pi } \]
Minim de interferență: \[ \boxed{ \delta = (2k+1) \frac{\lambda}{2} } \] echivalent cu: \[ \boxed{ \Delta\varphi = (2k+1)\pi } \]
Dacă sursele nu pornesc în fază: diferența de fază totală nu mai provine numai din diferența de drum. În general: \[ \boxed{ \Delta\varphi = \Delta\varphi_0 + \frac{ 2\pi\Delta x }{ \lambda } } \] cu semnul termenului spațial stabilit după convenția de fază aleasă.
Delimitare de sursă: în exemplul lui Bunget, sursele secundare \(O_1\) și \(O_2\) sunt în fază. De aceea: \[ \Delta\varphi_0=0. \] Forma generală de mai sus este o completare modernă.
Amplitudinea rezultantă — forma generală: pentru două oscilații armonice de aceeași frecvență: \[ \boxed{ A^2 = A_1^2 + A_2^2 + 2A_1A_2 \cos\Delta\varphi } \]
Verificarea maximului: dacă: \[ \Delta\varphi = 2k\pi, \] atunci: \[ \cos\Delta\varphi=1 \] și: \[ \boxed{ A=A_1+A_2 } \]
Verificarea minimului: dacă: \[ \Delta\varphi = (2k+1)\pi, \] atunci: \[ \cos\Delta\varphi=-1 \] și: \[ \boxed{ A=|A_1-A_2| } \]
Pentru amplitudini egale: dacă: \[ A_1=A_2=A_0, \] atunci: \[ \boxed{ A = 2A_0 \left| \cos \frac{\Delta\varphi}{2} \right| } \]
Interferență constructivă: pentru amplitudini egale: \[ \Delta\varphi=2k\pi \] conduce la: \[ \boxed{ A_{\max}=2A_0 } \]
Interferență destructivă: pentru: \[ \Delta\varphi = (2k+1)\pi, \] rezultă: \[ \boxed{ A_{\min}=0 } \] dacă amplitudinile componente sunt egale.
Dacă: \[ A_1\neq A_2, \] minimul nu este în general nul. Corect: \[ \boxed{ A_{\min} = |A_1-A_2| } \]
Intensitatea — extensie utilă: în situațiile în care intensitatea este proporțională cu pătratul amplitudinii, pentru două unde coerente: \[ \boxed{ I = I_1+I_2 + 2\sqrt{I_1I_2} \cos\Delta\varphi } \]
Pentru intensități egale: dacă: \[ I_1=I_2=I_0, \] atunci la maxim: \[ \boxed{ I_{\max}=4I_0 } \] iar la minim: \[ \boxed{ I_{\min}=0 } \]
Nu confunda amplitudinea cu intensitatea. Dacă amplitudinea se dublează: \[ A\rightarrow2A, \] atunci, în modelul în care: \[ I\propto A^2, \] intensitatea devine: \[ I\rightarrow4I. \]
Legătura cu §11.6: unda staționară este un caz particular de interferență a două unde de aceeași frecvență și amplitudine, care se propagă în sensuri opuse.
Legătura cu optica: aceleași idei de coerență, diferență de drum și diferență de fază vor reapărea la interferența luminii.
Schema de rezolvare:

1. identifică sursele și verifică dacă sunt coerente;
2. determină drumurile: \[ x_1,\quad x_2; \]
3. calculează: \[ \delta = |x_2-x_1|; \]
4. compară \(\delta\) cu \(\lambda\);
5. pentru maxim verifică: \[ \delta=k\lambda; \]
6. pentru minim verifică: \[ \delta = (2k+1) \frac{\lambda}{2}; \]
7. dacă este necesar, calculează amplitudinea rezultantă;
8. verifică unitățile și faza.
Cinci erori de evitat:

1. confundarea diferenței de drum cu diferența de fază;

2. folosirea condiției de maxim pentru minim;

3. presupunerea că orice două unde produc o figură stabilă de interferență;

4. afirmația că la minim amplitudinea este mereu zero;

5. confundarea amplitudinii rezultante cu intensitatea.
Nucleul de memorat: coerență: \[ \boxed{ \nu_1=\nu_2, \qquad \Delta\varphi_0 = \text{constantă} } \] diferență de fază: \[ \boxed{ |\Delta\varphi| = \frac{ 2\pi\delta }{ \lambda } } \] maxim: \[ \boxed{ \delta=k\lambda } \] minim: \[ \boxed{ \delta = (2k+1) \frac{\lambda}{2} } \] amplitudini: \[ \boxed{ A_{\max} = A_1+A_2 } \] \[ \boxed{ A_{\min} = |A_1-A_2| } \]
Prioritate pentru concurs: interferența undelor elastice nu este nominalizată ca temă autonomă în punctul 11 al programei 2026. Trebuie însă înțeleasă pentru continuitatea capitolului, în special pentru undele staționare.
Titularizare 2027: această încadrare este realizată după programa oficială 2026. Programa oficială pentru sesiunea 2027 trebuie reverificată după publicare.
