11.8 Efectul Doppler-Fizeau

Modificarea frecvenței percepute atunci când sursa și observatorul se deplasează unul față de celălalt, sursă mobilă, observator mobil, cazul general și rolul componentei radiale a vitezei.

Punct de plecare

Sursa și observatorul în repaus

Bunget reamintește că particulele mediului prin care se propagă unda oscilează cu frecvența impusă de sursă.

Dacă sursa și observatorul sunt în repaus unul față de celălalt, observatorul înregistrează același număr de oscilații în unitatea de timp ca frecvența sursei.

\[ \boxed{ \nu'=\nu } \]
Definiție

Efectul Doppler-Fizeau

Situația se modifică atunci când sursa sau observatorul se deplasează.

Efect Doppler-Fizeau

Modificarea frecvenței percepute de observator față de frecvența proprie a sursei, ca urmare a mișcării sursei sau observatorului.

Compendiul amintește contribuțiile istorice ale lui Doppler, Buys-Ballot și Fizeau.

Ipoteza inițială

Mișcare pe direcția sursă–observator

Bunget studiază mai întâi cazurile în care mișcarea are loc de-a lungul dreptei care unește sursa cu observatorul.

\(v\)

viteza de propagare a undei în mediu;

\(u_1\)

viteza sursei;

\(u_2\)

viteza observatorului;

\(\nu\)

frecvența proprie a sursei;

\(\nu'\)

frecvența percepută de observator.

Primul caz

Sursa se apropie de observator

Se consideră sursa \(O\) deplasându-se spre observatorul \(A\) cu viteza constantă \(u_1\).

O primă oscilație pleacă de la sursă la momentul \(t\). Ea ajunge la observator la:

\[ t_1 = t + \frac{OA}{v}. \]

Următoarea oscilație este emisă după o perioadă \(T\).

În acest timp, sursa s-a apropiat de observator cu distanța:

\[ \boxed{ OO_1=u_1T } \]
Relația (11.29)

Perioada percepută pentru sursa mobilă

A doua oscilație are de parcurs o distanță mai mică până la observator.

Intervalul dintre sosirea celor două oscilații reprezintă perioada aparentă \(T'\).

\[ \boxed{ T' = \frac{v-u_1}{v} T } \]

Pentru:

\[ u_1>0, \]

sursa se apropie de observator.

Relația (11.29')

Frecvența percepută

Deoarece:

\[ \nu=\frac{1}{T}, \qquad \nu'=\frac{1}{T'}, \]

rezultă:

\[ \boxed{ \nu' = \frac{v}{ v-u_1 } \nu } \]

În aceeași scriere, Compendiul asociază lungimea de undă:

\[ \boxed{ \lambda' = \frac{ v-u_1 }{ v } \lambda } \]
Consecință

Sursa care se apropie

Pentru:

\[ u_1>0, \]

avem:

\[ \boxed{ \nu'>\nu } \]

și lungimea de undă din fața sursei mobile este mai mică.

Convenția de semn

Sursa se depărtează

Bunget păstrează aceeași formulă, dar ia:

\[ \boxed{ u_1<0 } \]

când sursa se depărtează.

Atunci:

\[ \boxed{ \nu'<\nu } \]
Al doilea caz

Observatorul se deplasează spre sursă

Bunget consideră apoi sursa în repaus și observatorul \(A\) deplasându-se spre sursă cu viteza constantă \(u_2\).

Observatorul înaintează către fronturile de undă, astfel încât întâlnește oscilațiile la intervale de timp mai mici.

Relația (11.30)

Perioada aparentă pentru observatorul mobil

În intervalul dintre două recepții succesive, observatorul se deplasează cu distanța:

\[ AA_1 = u_2T'. \]

Din construcția temporală rezultă:

\[ \boxed{ T' = \frac{v}{ v+u_2 } T } \]
Relația (11.30')

Frecvența percepută de observatorul mobil

Din relația precedentă:

\[ \boxed{ \nu' = \frac{ v+u_2 }{ v } \nu } \]

Pentru observatorul care se apropie, Compendiul folosește:

\[ u_2>0. \]

În consecință:

\[ \boxed{ \nu'>\nu } \]
Notația Compendiului

Mărimea \(\lambda'\)

În relația (11.30'), Compendiul asociază perioadei aparente și mărimea:

\[ \boxed{ \lambda' = \frac{ v }{ v+u_2 } \lambda } \]

Interpretarea modernă a lungimii de undă pentru observatorul mobil este precizată separat în secțiunea „Titularizare”.

Convenția de semn

Observatorul se depărtează

Pentru observatorul care se depărtează de sursă, Bunget utilizează:

\[ \boxed{ u_2<0 } \]

și aceeași relație:

\[ \nu' = \frac{ v+u_2 }{ v } \nu. \]

Rezultă:

\[ \boxed{ \nu'<\nu } \]
Caz general

Sursa și observatorul se deplasează

Bunget tratează în final situația în care atât sursa \(O\), cât și observatorul \(A\) se deplasează unul spre celălalt.

Sursa are viteza \(u_1\), iar observatorul viteza \(u_2\).

În timpul unei perioade a sursei, aceasta înaintează cu:

\[ u_1T, \]

iar în timpul perioadei aparente observatorul înaintează cu:

\[ u_2T'. \]
Relația (11.31)

Perioada aparentă — cazul general

Din relația temporală dintre două recepții succesive, Bunget obține:

\[ \boxed{ T' = \frac{ v-u_1 }{ v+u_2 } T } \]
Relația (11.31')

Formula generală pentru frecvență

Cum:

\[ \nu=\frac{1}{T}, \qquad \nu'=\frac{1}{T'}, \]

rezultă:

\[ \boxed{ \nu' = \frac{ v+u_2 }{ v-u_1 } \nu } \]

Aceasta conține drept cazuri particulare situațiile studiate anterior.

Notația sursei

Relația pentru \(\lambda'\)

În aceeași prezentare, Compendiul scrie:

\[ \boxed{ \lambda' = \frac{ v-u_1 }{ v+u_2 } \lambda } \]
Simbolurile din relațiile (11.29')–(11.31') sunt deformate în OCR. Formele de mai sus sunt reconstruite din relațiile pentru \(T'\), din relația \(\nu=1/T\) și din succesiunea algebrică a textului.
Convenții de semn

Apropiere și depărtare

Bunget utilizează aceleași relații pentru apropiere și depărtare, prin alegerea semnelor vitezelor.

Sursa

\[ \boxed{ u_1>0 \quad \text{la apropiere} } \]
\[ \boxed{ u_1<0 \quad \text{la depărtare} } \]

Observatorul

\[ \boxed{ u_2>0 \quad \text{la apropiere} } \]
\[ \boxed{ u_2<0 \quad \text{la depărtare} } \]
Consecință

Frecvența crește la apropiere

Apropiere

\[ \boxed{ \nu'>\nu } \]

Depărtare

\[ \boxed{ \nu'<\nu } \]
Mișcare necoliniară

Contează componenta pe direcția sursă–observator

La finalul §11.8, Bunget precizează că vitezele nu trebuie să fie neapărat orientate chiar pe dreapta care unește sursa cu observatorul.

În formule trebuie introduse componentele vitezelor de-a lungul acestei drepte.

\[ \boxed{ u \longrightarrow u_{\parallel} } \]
Caz particular

Mișcare perpendiculară

Dacă observatorul se deplasează astfel încât distanța față de sursă rămâne constantă, componenta vitezei pe direcția radială este nulă.

În modelul mecanic clasic utilizat de Compendiu:

\[ \boxed{ u_{\parallel}=0 \Rightarrow \nu'=\nu } \]

Bunget dă ca exemplu mișcarea pe o circumferință având centrul în poziția sursei.

Sinteză

De reținut din §11.8

Efect Doppler-Fizeau

Sursă mobilă

\[ \boxed{ \nu' = \frac{v}{ v-u_1 } \nu } \]

\[ \boxed{ \nu' = \frac{ v+u_2 }{ v } \nu } \]

\[ \boxed{ \nu' = \frac{ v+u_2 }{ v-u_1 } \nu } \]

Titularizare

Precizări pentru examen

Această secțiune este separată de corpul §11.8 al Compendiului. Reperul oficial utilizat este programa pentru Titularizare Fizică 2026.

Statut în programa 2026

Efectul Doppler-Fizeau nu este nominalizat separat la punctul 11.

Programa cere explicit:

unde elastice plane în medii omogene și izotrope: unde longitudinale și transversale, viteza undelor și ecuația undei plane.

§11.8 este deci o aplicație și aprofundare a propagării undelor, nu un punct autonom al tematicii 2026.

Formula clasică pentru undele mecanice: dacă folosim aceeași convenție ca Bunget:

\(u_S>0\) când sursa se deplasează spre observator;
\(u_O>0\) când observatorul se deplasează spre sursă, atunci: \[ \boxed{ \nu_O = \nu_S \frac{ v+u_O }{ v-u_S } } \]
Unități SI: frecvență: \[ \boxed{ [\nu] = \mathrm{Hz} } \] viteza undei: \[ \boxed{ [v] = \mathrm{m/s} } \] viteza sursei: \[ \boxed{ [u_S] = \mathrm{m/s} } \] viteza observatorului: \[ \boxed{ [u_O] = \mathrm{m/s} } \]
Testul de sens fizic trebuie făcut înainte de calcul: apropiere: \[ \boxed{ \nu_O>\nu_S } \] depărtare: \[ \boxed{ \nu_O<\nu_S } \] Dacă rezultatul tău nu respectă această regulă, verifică semnele.
De ce sursa mobilă modifică lungimea de undă: într-o perioadă \(T\), primul front înaintează: \[ vT, \] dar sursa înaintează și ea: \[ u_ST. \] În fața sursei: \[ \boxed{ \lambda_{\text{față}} = (v-u_S)T = \frac{ v-u_S }{ \nu_S } } \]
În spatele unei surse care se deplasează: fronturile sunt mai depărtate. \[ \boxed{ \lambda_{\text{spate}} = (v+u_S)T } \] pentru modulul vitezei sursei și geometria corespunzătoare.
Sursa mobilă și observatorul mobil nu produc efectul în același mecanism. Sursa mobilă modifică distanța dintre fronturile succesive în mediu. Observatorul mobil modifică ritmul în care întâlnește fronturile deja existente.
Corecție modernă importantă privind \(\lambda'\) din prezentarea istorică: dacă sursa este în repaus față de mediu și numai observatorul se deplasează, distribuția spațială a fronturilor în mediu nu se modifică. Lungimea de undă măsurată în sistemul de repaus al mediului rămâne: \[ \boxed{ \lambda = \frac{v}{\nu_S} } \]
Mărimea \(\lambda'\) scrisă de Compendiu pentru observatorul mobil este legată de perioada aparentă prin convenția utilizată acolo. Nu trebuie interpretată automat drept distanța fizică dintre fronturile de undă în sistemul de repaus al mediului.
Numai componenta radială produce efectul Doppler clasic instantaneu. Dacă \(\hat n\) este direcția sursă–observator: \[ \boxed{ u_r = \vec u\cdot\hat n } \]
Pentru o viteză care face unghiul \(\theta\) cu direcția radială: \[ \boxed{ u_r = u\cos\theta } \]
Dacă: \[ \theta=90^\circ, \] atunci: \[ u_r=0. \] În modelul clasic al undelor mecanice: \[ \boxed{ \nu_O=\nu_S } \] la acel moment.
Exemplu conceptual: o sursă sonoră trece pe lângă un observator. Înainte de apropierea maximă: \[ \nu_O>\nu_S. \] După trecere: \[ \nu_O<\nu_S. \] Schimbarea percepută este consecința schimbării componentei radiale a vitezei.
Nu folosi direct viteza totală dacă mișcarea nu este coliniară. Trebuie determinată: \[ \boxed{ u_r } \] componenta pe direcția sursă–observator.
Deosebire importantă: undele mecanice. Formula: \[ \nu_O = \nu_S \frac{ v+u_O }{ v-u_S } \] presupune existența unui mediu în raport cu care este definită viteza \(v\) de propagare.
Nu aplica această formulă luminii în vid. Efectul Doppler pentru radiația electromagnetică trebuie tratat relativist. Nu există pentru lumină în vid un mediu material privilegiat de propagare analog aerului pentru sunet.
De aceea, afirmația clasică „mișcare transversală \(\Rightarrow\) niciun efect Doppler” nu trebuie extinsă automat la lumină. În relativitatea restrânsă există și efect Doppler transversal.
Limită a formulei pentru sursa mobilă: forma elementară: \[ \nu' = \frac{v}{ v-u_S } \nu \] descrie regimul obișnuit în care sursa se deplasează mai lent decât unda în direcția considerată: \[ \boxed{ |u_S|
Când viteza sursei se apropie de viteza de propagare sau o depășește, geometria fronturilor se schimbă esențial. Regimul undelor de șoc este discutat ulterior în capitolul de acustică, nu în corpul §11.8.
Aproximație pentru viteze mici: dacă observatorul este în repaus și: \[ |u_S|\ll v, \] pentru sursa care se apropie: \[ \nu' = \frac{ \nu }{ 1-u_S/v }. \] Aproximativ: \[ \boxed{ \frac{ \Delta\nu }{ \nu } \approx \frac{ u_S }{ v } } \]
Delimitare de sursă: aproximația liniară pentru \(\Delta\nu/\nu\) nu este prezentată în §11.8 al lui Bunget. Este o dezvoltare modernă utilă pentru estimări.
Schema de rezolvare:

1. stabilește mediul și viteza undei \(v\);
2. identifică frecvența sursei \(\nu_S\);
3. stabilește cine se deplasează: sursa, observatorul sau amândoi;
4. determină componentele radiale ale vitezelor;
5. fixează convenția de semn;
6. înainte de calcul, decide dacă trebuie: \[ \nu_O>\nu_S \] sau: \[ \nu_O<\nu_S; \]
7. aplică relația;
8. verifică rezultatul cu sensul fizic.
Cinci erori de evitat:

1. folosirea aceleiași formule pentru sursa mobilă și observatorul mobil fără identificarea numărătorului și numitorului;

2. alegerea greșită a semnelor la apropiere și depărtare;

3. folosirea vitezei totale în locul componentei radiale;

4. afirmația că observatorul mobil modifică distanța fizică dintre fronturile existente în mediul aflat în repaus;

5. aplicarea formulei clasice pentru undele mecanice efectului Doppler relativist al luminii.
Nucleul de memorat: sursa mobilă: \[ \boxed{ \nu' = \frac{v}{ v-u_S } \nu } \] observator mobil: \[ \boxed{ \nu' = \frac{ v+u_O }{ v } \nu } \] amândoi mobili: \[ \boxed{ \nu' = \frac{ v+u_O }{ v-u_S } \nu } \] apropiere: \[ \boxed{ \nu'>\nu } \] depărtare: \[ \boxed{ \nu'<\nu } \] mișcare necoliniară: \[ \boxed{ u_r=u\cos\theta } \]
