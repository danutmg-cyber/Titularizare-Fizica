11.6 Unde staționare

Interferența a două unde de amplitudini egale și sensuri opuse, unda incidentă și unda reflectată, noduri și ventre, amplitudinea dependentă de poziție, reflexia cu și fără pierdere de semiundă și distribuția fazei.

Ion Bunget Compendiu de Fizică §11.6

Definiția centrală

Cum apare o undă staționară

Bunget prezintă unda staționară ca un caz particular de compunere a undelor.

Se suprapun două unde cu amplitudini egale, care se propagă pe aceeași direcție, dar în sensuri contrare.

Undă staționară

Rezultatul interferenței a două unde de amplitudini egale, care se propagă în sensuri opuse.

\[ \boxed{ a_1=a_2=a, \qquad \vec v_1=-\vec v_2 } \]
Situația obișnuită

Unda incidentă și unda reflectată

Bunget arată că undele staționare apar în mod obișnuit prin suprapunerea unei unde incidente cu unda reflectată.

Este analizat cazul incidenței normale pe suprafața reflectătoare.

\[ \boxed{ \text{undă incidentă} + \text{undă reflectată} \Rightarrow \text{undă staționară} } \]
Figura I.11.8

Punctul de reflexie

Unda plană pornește de la sursa \(O\) și se propagă către suprafața reflectătoare, pe care o întâlnește în punctul \(M\).

Se consideră un punct oarecare \(N\) situat între sursă și suprafața reflectătoare.

În punctul \(N\) sosesc simultan:

unda directă, provenită de la \(O\);

unda reflectată în punctul \(M\).

Undele componente

Elongațiile în punctul \(N\)

Pentru unda directă, Bunget utilizează forma undei progresive:

\[ y_1 = a \sin 2\pi \left( \nu t - \frac{x_1}{\lambda} \right). \]

Pentru reflexie fără pierdere de semiundă, unda reflectată are aceeași amplitudine și aceeași regulă de fază:

\[ y_2 = a \sin 2\pi \left( \nu t - \frac{x_2}{\lambda} \right). \]

Aici \(x_1\) și \(x_2\) sunt drumurile parcurse de cele două unde până la punctul \(N\).

Diferența de drum

Distanța față de suprafața reflectătoare

Dacă notăm cu \(x\) distanța dintre punctul \(N\) și punctul de reflexie \(M\), atunci diferența dintre drumurile celor două unde este de două ori această distanță.

\[ \boxed{ |x_2-x_1| = 2x } \]

Suma drumurilor este constantă pentru configurația considerată de Bunget.

Relația (11.14)

Ecuația undei staționare fără schimbare de fază la reflexie

Adunând cele două elongații și folosind relațiile trigonometrice de compunere, Bunget obține o expresie în care dependența de poziție și dependența de timp apar în factori separați.

\[ \boxed{ y(x,t) = 2a \cos \left( \frac{2\pi x}{\lambda} \right) \sin \left[ 2\pi \left( \nu t - \frac{d}{\lambda} \right) \right] } \]

unde \(d\) este o distanță constantă stabilită de geometria dintre sursă și suprafața reflectătoare.

Relația (11.15)

Amplitudinea depinde de poziție

Toate punctele oscilează cu frecvența sursei, însă amplitudinea nu este aceeași în toate punctele.

Din relația precedentă:

\[ \boxed{ A(x) = 2a \left| \cos \left( \frac{2\pi x}{\lambda} \right) \right| } \]
\[ \boxed{ 0 \leq A(x) \leq 2a } \]
Relația (11.16)

Ventrele

Ventru

Punct al undei staționare în care amplitudinea oscilației este maximă.

Pentru reflexia fără pierdere de semiundă:

\[ A_{\max}=2a. \]

Maximul apare pentru:

\[ \boxed{ x = k\frac{\lambda}{2}, \qquad k=0,1,2,\ldots } \]
Relația (11.17)

Distanța dintre două ventre vecine

Două valori succesive sunt:

\[ x_k = k\frac{\lambda}{2} \]

și:

\[ x_{k+1} = (k+1) \frac{\lambda}{2}. \]

Diferența este:

\[ \boxed{ \Delta x_{\text{ventru-ventru}} = \frac{\lambda}{2} } \]
Relația (11.18)

Nodurile

Nod

Punct al undei staționare în care amplitudinea oscilației este nulă.

\[ \boxed{ A_{\min}=0 } \]

Pentru cazul analizat:

\[ \boxed{ x = (2k+1) \frac{\lambda}{4}, \qquad k=0,1,2,\ldots } \]
Relația (11.19)

Distanțele caracteristice

Bunget obține două distanțe fundamentale.

Două noduri consecutive

\[ \boxed{ \Delta x_{\text{nod-nod}} = \frac{\lambda}{2} } \]

Nod și ventru vecine

\[ \boxed{ \Delta x_{\text{nod-ventru}} = \frac{\lambda}{4} } \]
Suprafața reflectătoare

Reflexie fără pierdere de semiundă

În coordonata aleasă de Bunget, suprafața reflectătoare corespunde:

\[ x=0. \]

Din expresia amplitudinii:

\[ A(0) = 2a. \]

Prin urmare, pentru reflexia fără pierdere de semiundă, pe suprafața reflectătoare se formează un ventru.

\[ \boxed{ x=0 \Rightarrow \text{ventru} } \]
Relația (11.20)

Reflexie cu pierdere de semiundă

Bunget analizează apoi cazul în care reflexia produce schimbarea semnului elongației, adică o diferență de fază de \(\pi\).

\[ \boxed{ \Delta\varphi = \pi } \]

Unda reflectată este atunci în opoziție de fază față de cazul reflexiei fără pierdere.

Ecuația rezultantă

Distribuția spațială se inversează

Prin compunerea undei incidente cu unda reflectată având faza schimbată, Bunget obține o undă staționară în care factorul spațial este sinusoidal.

\[ \boxed{ y(x,t) = 2a \sin \left( \frac{2\pi x}{\lambda} \right) \cos \left[ 2\pi \left( \nu t - \frac{d}{\lambda} \right) \right] } \]
Amplitudinea

Reflexie cu schimbare de fază

Amplitudinea depinde acum de poziție conform:

\[ \boxed{ A(x) = 2a \left| \sin \left( \frac{2\pi x}{\lambda} \right) \right| } \]
Consecință

Nodurile și ventrele își schimbă pozițiile

Bunget observă că maximele sinusului apar acolo unde cosinusul avea minime, și invers.

Astfel, în cazul reflexiei cu pierdere de semiundă:

Noduri

\[ \boxed{ x = k \frac{\lambda}{2} } \]

Ventre

\[ \boxed{ x = (2k+1) \frac{\lambda}{4} } \]
Suprafață rigidă

Pe suprafață apare un nod

Pentru:

\[ x=0, \]

amplitudinea devine:

\[ A(0)=0. \]

În cazul unei suprafețe rigide în modelul analizat de Bunget, punctul de la suprafață nu poate oscila.

\[ \boxed{ x=0 \Rightarrow \text{nod} } \]
Interpretarea sursei

De ce apare schimbarea de fază

Bunget folosește condiția de amplitudine nulă la un perete rigid pentru a explica de ce unda reflectată trebuie să apară cu schimbarea fazei.

Pentru ca punctul suprafeței rigide să rămână nemișcat, unda incidentă și cea reflectată trebuie să se anuleze acolo.

\[ \boxed{ y_{\text{incident}} + y_{\text{reflectat}} = 0 \quad \text{la peretele rigid} } \]
Încheierea §11.6

Faza nu este aceeași în toate punctele

Bunget atrage atenția că factorul spațial din ecuația undei staționare își poate schimba semnul.

Schimbarea semnului are loc la traversarea unui nod.

De aceea, două puncte aflate de o parte și de alta a aceluiași nod au elongații de semne opuse în același moment.

\[ \boxed{ \text{traversarea unui nod} \Rightarrow \Delta\varphi=\pi } \]
Sinteză

De reținut din §11.6

Unda staționară

Apare prin interferența a două unde egale care se propagă în sensuri opuse.

Amplitudinea

Depinde de poziție.

Ventru

\[ \boxed{ A_{\max}=2a } \]

Nod

\[ \boxed{ A_{\min}=0 } \]

Două noduri vecine

\[ \boxed{ \Delta x = \frac{\lambda}{2} } \]

Două ventre vecine

\[ \boxed{ \Delta x = \frac{\lambda}{2} } \]

Nod și ventru vecine

\[ \boxed{ \Delta x = \frac{\lambda}{4} } \]

Reflexie fără schimbare de fază

La suprafață se formează un ventru.

Reflexie cu schimbare de fază \(\pi\)

La suprafața rigidă se formează un nod.

Titularizare

Precizări pentru examen

Această secțiune este separată de corpul §11.6 al Compendiului. Reperul oficial utilizat este programa pentru Titularizare Fizică 2026.

Statut în programa 2026

„Undele staționare” nu sunt nominalizate ca temă autonomă la punctul 11.

Programa cere explicit:

unde elastice plane în medii omogene și izotrope, unde longitudinale și transversale, viteza undelor și ecuația undei plane.

Undele staționare reprezintă însă o aplicație directă a ecuației undei plane și a principiului superpoziției.

Forma modernă standard: se pot considera două unde: \[ y_1 = a \sin ( \omega t-kx ) \] și: \[ y_2 = a \sin ( \omega t+kx ). \] Ele au: \[ \boxed{ \text{aceeași amplitudine} } \] și: \[ \boxed{ \text{sensuri opuse de propagare} } \]
Prin superpoziție: \[ y = y_1+y_2. \] Rezultă: \[ \boxed{ y(x,t) = 2a \sin(\omega t) \cos(kx) } \]
Numărul de undă: \[ \boxed{ k = \frac{2\pi}{\lambda} } \]
Ideea-cheie: într-o undă progresivă, expresia are forma: \[ f(\omega t-kx), \] iar spațiul și timpul apar în aceeași fază. Într-o undă staționară: \[ \boxed{ y(x,t) = f(x)\,g(t) } \] iar dependența spațială și cea temporală sunt separate.
Nu confunda „undă staționară” cu „particule staționare”. Majoritatea particulelor mediului oscilează. Numai nodurile ideale au permanent: \[ \boxed{ y=0 } \]
Amplitudinea locală: pentru: \[ y = 2a \sin(\omega t) \cos(kx), \] amplitudinea este: \[ \boxed{ A(x) = 2a|\cos(kx)| } \]
De aceea amplitudinea unei unde staționare nu este o constantă pentru întregul mediu. Ea depinde de coordonata \(x\).
Pentru forma cu cosinus: ventrele satisfac: \[ |\cos(kx)|=1. \] Deci: \[ \boxed{ x_n = n\frac{\lambda}{2} } \]
Nodurile satisfac: \[ \cos(kx)=0. \] Deci: \[ \boxed{ x_n = (2n+1) \frac{\lambda}{4} } \]
Pentru forma: \[ y = 2a \sin(kx) \cos(\omega t), \] pozițiile se inversează. Nodurile sunt: \[ \boxed{ x_n = n\frac{\lambda}{2} } \] iar ventrele: \[ \boxed{ x_n = (2n+1) \frac{\lambda}{4} } \]
Nu memora două seturi de formule fără să verifici condiția la limită. Mai sigur este să identifici mai întâi:

nod sau ventru la suprafață;
apoi să construiești șirul punctelor la distanțe de: \[ \frac{\lambda}{4}. \]
Distanțe universale în modelul ideal: nod–nod: \[ \boxed{ \frac{\lambda}{2} } \] ventru–ventru: \[ \boxed{ \frac{\lambda}{2} } \] nod–ventru vecin: \[ \boxed{ \frac{\lambda}{4} } \]
Eroare frecventă: distanța dintre două noduri consecutive nu este \(\lambda\). Corect: \[ \boxed{ d_{\mathrm{nod-nod}} = \frac{\lambda}{2} } \]
Faza particulelor: între două noduri consecutive, factorul spațial păstrează același semn. Punctele din aceeași regiune oscilează în fază.
La traversarea unui nod: factorul spațial își schimbă semnul. Prin urmare, două regiuni vecine sunt în opoziție de fază: \[ \boxed{ \Delta\varphi = \pi } \]
Nodul nu are o fază de oscilație bine definită în același sens ca un punct care oscilează. În nod: \[ A=0. \]
Coardă cu două capete fixe: la ambele capete trebuie să existe noduri. Dacă lungimea corzii este \(L\): \[ \boxed{ L = n \frac{\lambda_n}{2} } \] unde: \[ n=1,2,3,\ldots \]
Lungimile de undă permise: \[ \boxed{ \lambda_n = \frac{2L}{n} } \]
Frecvențele proprii: folosind: \[ v = \lambda_n\nu_n, \] rezultă: \[ \boxed{ \nu_n = n \frac{v}{2L} } \]
Delimitare de sursă: cuantificarea frecvențelor unei corzi cu două capete fixe nu este dezvoltată în §11.6 al lui Bunget. Este o aplicație modernă directă a condițiilor de nod.
Frecvența fundamentală: pentru \(n=1\): \[ \boxed{ \nu_1 = \frac{v}{2L} } \] iar: \[ \boxed{ \lambda_1 = 2L } \]
Armonicile: \[ \boxed{ \nu_n=n\nu_1 } \] pentru modelul corzii ideale fixate la ambele capete.
Un capăt fix și un capăt liber: la capătul fix avem nod, iar la capătul liber ideal avem ventru. Condiția geometrică devine: \[ \boxed{ L = (2n-1) \frac{\lambda_n}{4} } \] cu: \[ n=1,2,3,\ldots \]
Frecvențele corespunzătoare: \[ \boxed{ \nu_n = (2n-1) \frac{v}{4L} } \] apar numai armonicile impare în modelul ideal fix–liber.
Delimitare de sursă: relațiile pentru sistemele fix–fix și fix–liber sunt completări de sistematizare actuală. Corpul §11.6 se concentrează pe interferența undei incidente cu cea reflectată și pe poziția nodurilor și ventrelor.
Transportul de energie: într-o undă progresivă există transport net de energie în sensul propagării. Într-o undă staționară ideală produsă de două unde de amplitudini egale și sensuri opuse, fluxurile medii de energie sunt egale și opuse.
Consecință: \[ \boxed{ \langle P_{\mathrm{net}}\rangle = 0 } \] pentru unda staționară ideală.
Asta nu înseamnă că energia este zero. Mediul oscilează și posedă energie. Afirmația se referă la lipsa unui transport mediu net într-o direcție.
Cum recunoști o undă staționară din ecuație: dacă ecuația poate fi adusă la forma: \[ \boxed{ y(x,t) = X(x)T(t) } \] cu noduri aflate permanent în aceleași poziții, avem forma caracteristică unei unde staționare.
Compară: undă progresivă: \[ y = A \sin(\omega t-kx); \] undă staționară: \[ y = 2a \sin(\omega t) \cos(kx). \] În primul caz, profilul se deplasează. În al doilea, nodurile și ventrele rămân în poziții fixe.
Verificare rapidă: dacă: \[ \lambda = 0{,}80\,\mathrm m, \] atunci distanța dintre două noduri consecutive este: \[ \frac{\lambda}{2} = 0{,}40\,\mathrm m, \] iar dintre un nod și ventrul vecin: \[ \frac{\lambda}{4} = 0{,}20\,\mathrm m. \]
Activitate didactică potrivită: o coardă elastică poate fi pusă în oscilație periodică, având celălalt capăt fix sau reflectător. Elevii urmăresc pozițiile care rămân permanent nemișcate și regiunile cu amplitudine maximă.
Întrebări de investigare:

Unde se află nodurile?
Ce distanță există între două noduri?
Cum se modifică configurația dacă se schimbă frecvența?
Ce se întâmplă dacă se schimbă viteza de propagare în coardă?
Cinci erori de evitat:

1. undă staționară = mediu nemișcat;

2. distanța nod–nod = \(\lambda\);

3. nodul are amplitudine maximă;

4. toate punctele undei staționare oscilează în aceeași fază;

5. alegerea formulelor pentru noduri și ventre fără verificarea condiției la suprafața reflectătoare.
Nucleul de memorat: undă staționară: \[ \boxed{ \text{două unde egale în sensuri opuse} } \] amplitudine: \[ \boxed{ A=A(x) } \] ventru: \[ \boxed{ A_{\max}=2a } \] nod: \[ \boxed{ A_{\min}=0 } \] nod–nod: \[ \boxed{ \frac{\lambda}{2} } \] ventru–ventru: \[ \boxed{ \frac{\lambda}{2} } \] nod–ventru: \[ \boxed{ \frac{\lambda}{4} } \] schimbare de fază la traversarea unui nod: \[ \boxed{ \pi } \]
Prioritate pentru concurs: undele staționare nu sunt nominalizate separat în punctul 11 al programei 2026. Prioritatea explicită rămâne:

unde elastice plane;
unde longitudinale și transversale;
viteza undelor;
ecuația undei plane. §11.6 este însă o aplicație foarte utilă a acestor concepte.
