11.7 Energia undelor

Transportul energiei prin unde elastice, energia cinetică și potențială a unui element de mediu, densitatea de energie, densitatea medie de energie, absorbția undelor și atenuarea amplitudinii.

Ion Bunget Compendiu de Fizică §11.7
Sursa

Compendiu de Fizică

11.7 Energia undelor

Pagini: 240–241.
§11.8 Efectul Doppler-Fizeau începe la p. 242.
Ideea centrală

Unda transportă energie

Bunget pornește de la faptul că unda elastică reprezintă propagarea unei mișcări prin mediu.

Odată cu această mișcare se transmite și energie de la o regiune a mediului la alta.

\[ \boxed{ \text{propagarea undei} \Rightarrow \text{transport de energie} } \]

Particulele mediului oscilează local, dar energia mișcării poate avansa prin mediu.

Modelul analizat

Undă plană longitudinală

Pentru calcul, Compendiul consideră o undă plană longitudinală care se propagă de-a lungul axei \(Ox\).

Este aleasă o porțiune mică a mediului, de forma unui paralelipiped, cu lungimea \(\ell\) pe direcția propagării și secțiunea transversală \(\Delta S\).

\[ \boxed{ \Delta V = \ell\,\Delta S } \]
Bilanț energetic

Două forme de energie

Energia elementului de volum \(\Delta V\) este suma dintre energia cinetică a particulelor sale și energia potențială elastică asociată deformării.

\[ \boxed{ \Delta W = \Delta W_c + \Delta W_p } \]
Relația (11.21)

Energia cinetică

Masa elementului de mediu este:

\[ \Delta m = \rho\Delta V, \]

unde \(\rho\) este densitatea mediului.

Energia cinetică este:

\[ \Delta W_c = \frac{1}{2} \Delta m\,u^2, \]

unde \(u\) este viteza de oscilație a particulelor mediului.

Pentru unda:

\[ y = A \sin \omega \left( t-\frac{x}{v} \right), \]

viteza particulelor este:

\[ u = \frac{\partial y}{\partial t} = A\omega \cos \omega \left( t-\frac{x}{v} \right). \]

Rezultă:

\[ \boxed{ \Delta W_c = \frac{1}{2} \rho\Delta V A^2\omega^2 \cos^2 \omega \left( t-\frac{x}{v} \right) } \]
Relația (11.22)

Energia potențială elastică

Energia potențială este energia deformării elastice a porțiunii de mediu.

Deformația longitudinală este legată de variația deplasării particulelor cu poziția.

\[ \frac{\partial y}{\partial x} = - \frac{A\omega}{v} \cos \omega \left( t-\frac{x}{v} \right). \]

Pentru modelul elastic utilizat de Bunget:

\[ v^2 = \frac{E}{\rho}, \]

unde \(E\) este modulul lui Young.

După înlocuire, energia potențială devine:

\[ \boxed{ \Delta W_p = \frac{1}{2} \rho\Delta V A^2\omega^2 \cos^2 \omega \left( t-\frac{x}{v} \right) } \]
Rezultat important

Energia cinetică și cea potențială sunt egale

În modelul undei plane longitudinale analizate, Bunget obține:

\[ \boxed{ \Delta W_c = \Delta W_p } \]

Cele două energii ating simultan valorile maxime și simultan valorile minime.

Relația (11.23)

Energia totală a elementului de mediu

Adunând cele două contribuții:

\[ \boxed{ \Delta W = \rho\Delta V A^2\omega^2 \cos^2 \omega \left( t-\frac{x}{v} \right) } \]

Compendiul evidențiază astfel dependența energiei de:

densitatea mediului;

pătratul amplitudinii;

pătratul pulsației, deci și al frecvenței.

\[ \boxed{ \Delta W \propto \rho A^2\omega^2 } \]
Observație fizică

Element de mediu versus oscilator izolat

Bunget compară energia unei porțiuni dintr-un mediu ondulatoriu cu energia unui punct material care oscilează izolat.

Pentru oscilatorul izolat, energia mecanică totală rămâne constantă, iar energia cinetică și cea potențială se transformă reciproc.

Pentru un element al mediului prin care trece unda, energia totală a acelui element nu rămâne constantă.

Elementul poate primi energie de la vecini și poate transmite energie către alte regiuni ale mediului.

\[ \boxed{ \text{energia poate trece dintr-un element de mediu în altul} } \]
Relația (11.24)

Densitatea de energie

Densitate de energie

Energia undei conținută în unitatea de volum a mediului.

\[ w = \frac{\Delta W}{\Delta V}. \]

Pentru unda analizată:

\[ \boxed{ w(x,t) = \rho A^2\omega^2 \cos^2 \omega \left( t-\frac{x}{v} \right) } \]
Relația (11.25)

Densitatea medie de energie

Densitatea de energie variază în timp.

Bunget introduce valoarea medie pe durata unei perioade.

Deoarece:

\[ \left\langle \cos^2 \right\rangle = \frac{1}{2}, \]

rezultă:

\[ \boxed{ \overline{w} = \frac{1}{2} \rho A^2\omega^2 } \]

În modelul unui mediu omogen fără absorbție, această valoare medie este aceeași în diferite puncte ale mediului.

Mediul real

Absorbția undei

Bunget trece apoi de la modelul ideal la un mediu mecanic real.

Din cauza proprietăților disipative ale mediului, o parte din energia mecanică a oscilațiilor se transformă în alte forme de energie.

Absorbție

Pierderea treptată a energiei mecanice a undei în cursul propagării prin mediu.

\[ \boxed{ \text{absorbție} \Rightarrow A\downarrow \Rightarrow \overline{w}\downarrow } \]
Relația (11.26)

Scăderea amplitudinii

Compendiul presupune că micșorarea relativă a amplitudinii, la traversarea unui strat foarte subțire de grosime \(dx\), este proporțională cu grosimea stratului.

\[ -\frac{dA}{A} \propto dx. \]
Notă de transcriere: simbolul coeficientului din scanul OCR este degradat. În această pagină îl notăm convențional cu \(\chi\), fără a atribui această notație ediției originale.
\[ -\frac{dA}{A} = \chi\,dx. \]

Pentru:

\[ A(0)=A_0, \]

integrarea conduce la:

\[ \boxed{ A(x) = A_0 e^{-\chi x} } \]
Relația (11.27)

Ecuația undei într-un mediu absorbant

Amplitudinea nu mai este constantă cu distanța.

În notația de lucru folosită mai sus:

\[ \boxed{ y(x,t) = A_0 e^{-\chi x} \sin \omega \left( t-\frac{x}{v} \right) } \]
Relația (11.28)

Energia scade mai repede decât amplitudinea

Din relația:

\[ \overline{w} \propto A^2, \]

și din scăderea exponențială a amplitudinii rezultă:

\[ \boxed{ \overline{w}(x) = \overline{w}_0 e^{-2\chi x} } \]

Compendiul introduce pentru această scădere un coeficient de absorbție.

Simbolurile coeficienților din relațiile (11.26)–(11.28) sunt deformate în OCR. Relația exponențială și factorul 2 dintre exponentul amplitudinii și cel al energiei rezultă însă neechivoc din relațiile succesive ale sursei.

Titularizare

Precizări pentru examen

Această secțiune este separată de corpul §11.7 al Compendiului. Reperul oficial utilizat este programa pentru Titularizare Fizică 2026.

Statut în programa 2026

Energia undelor nu este nominalizată ca punct autonom.

Programa cere explicit la punctul 11:

unde elastice plane în medii omogene și izotrope, unde longitudinale și transversale, viteza undelor și ecuația undei plane.

§11.7 este deci o aprofundare a modelului undei plane și a semnificației sale energetice.

Mărimile principale și unitățile SI: energie: \[ \boxed{ [W] = \mathrm J } \] densitate de energie: \[ \boxed{ [w] = \mathrm{J/m^3} } \] densitatea mediului: \[ \boxed{ [\rho] = \mathrm{kg/m^3} } \] amplitudine: \[ \boxed{ [A] = \mathrm m } \] pulsație: \[ \boxed{ [\omega] = \mathrm{rad/s} } \]
Verificare dimensională: pentru: \[ \overline{w} = \frac{1}{2} \rho A^2\omega^2, \] avem: \[ [\rho A^2\omega^2] = \frac{\mathrm{kg}}{\mathrm{m^3}} \cdot \mathrm{m^2} \cdot \frac{1}{\mathrm{s^2}} \] \[ = \frac{\mathrm{kg}}{ \mathrm{m\,s^2} } = \frac{\mathrm J}{ \mathrm{m^3} }. \]
Dependența de amplitudine: \[ \boxed{ \overline{w} \propto A^2 } \] pentru același mediu și aceeași frecvență.
Dacă amplitudinea se dublează: \[ A_2=2A_1, \] atunci: \[ \boxed{ \overline{w}_2 = 4\overline{w}_1 } \] nu de două ori.
Dependența de frecvență: deoarece: \[ \omega=2\pi\nu, \] rezultă, la amplitudine și mediu fixate: \[ \boxed{ \overline{w} \propto \nu^2 } \]
Această proporționalitate presupune amplitudine constantă. Nu este o afirmație că orice sursă reală emite automat de patru ori mai multă energie când frecvența se dublează.
Intensitatea unei unde: în formularea modernă, intensitatea reprezintă puterea medie transportată prin unitatea de suprafață perpendiculară pe direcția propagării. \[ \boxed{ I = \frac{P}{S} } \] cu: \[ \boxed{ [I] = \mathrm{W/m^2} } \]
Pentru unda plană din modelul §11.7: energia medie conținută în unitatea de volum este: \[ \overline{w} = \frac{1}{2} \rho A^2\omega^2. \] În timpul unei secunde, unda avansează cu distanța \(v\). De aici: \[ \boxed{ I = \overline{w}\,v } \]
Rezultă: \[ \boxed{ I = \frac{1}{2} \rho v A^2\omega^2 } \] pentru modelul undei plane longitudinale armonice analizate.
Delimitare de sursă: relația explicită: \[ I = \overline{w}\,v \] și forma: \[ I = \frac{1}{2} \rho vA^2\omega^2 \] sunt completări moderne construite din densitatea medie de energie dedusă în §11.7.
Energia care traversează o suprafață \(S\) în timpul \(\Delta t\): \[ \boxed{ \Delta E = IS\Delta t } \] pentru intensitate uniformă pe suprafața considerată.
Nu confunda: densitatea de energie: \[ w \quad [\mathrm{J/m^3}] \] cu intensitatea: \[ I \quad [\mathrm{W/m^2}]. \] Sunt mărimi diferite.
De ce energia locală poate varia: o porțiune fixă de mediu nu este un sistem mecanic izolat. Energia intră și iese prin interacțiunile cu regiunile vecine.
Eroare conceptuală: faptul că energia unui element mic de mediu variază nu încalcă legea conservării energiei. Energia este transferată prin undă.
Pentru unda progresivă armonică din model: \[ \boxed{ w_c=w_p } \] instantaneu. În consecință: \[ w = w_c+w_p = 2w_c. \]
Nu transfera automat această egalitate oricărui tip de undă sau oricărei configurații. Ea rezultă aici pentru unda progresivă plană din modelul elastic utilizat.
Absorbția: dacă amplitudinea scade după: \[ \boxed{ A(x) = A_0e^{-\alpha x} } \] atunci energia medie și intensitatea, fiind proporționale cu \(A^2\), scad după: \[ \boxed{ \overline{w}(x) = \overline{w}_0 e^{-2\alpha x} } \] și: \[ \boxed{ I(x) = I_0 e^{-2\alpha x} } \]
Convenția coeficientului de absorbție diferă între surse. Uneori se definește direct coeficientul pentru intensitate: \[ \mu=2\alpha. \] Atunci: \[ \boxed{ I(x) = I_0e^{-\mu x} } \] De aceea trebuie verificată definiția simbolului înainte de aplicarea formulei.
Unitatea coeficientului de atenuare: deoarece exponentul trebuie să fie adimensional: \[ [\alpha x]=1. \] Prin urmare: \[ \boxed{ [\alpha] = \mathrm{m^{-1}} } \]
Distanța caracteristică de atenuare a amplitudinii: pentru: \[ A=A_0e^{-\alpha x}, \] la: \[ x=\frac{1}{\alpha}, \] avem: \[ \boxed{ A = \frac{A_0}{e} } \]
În același punct: intensitatea devine: \[ \boxed{ I = \frac{I_0}{e^2} } \] dacă \(\alpha\) este coeficientul de atenuare al amplitudinii.
Absorbție și împrăștiere geometrică nu sunt același lucru. Pentru o undă plană ideală, amplitudinea poate rămâne constantă în lipsa absorbției. Pentru o undă sferică, amplitudinea poate scădea cu distanța chiar fără absorbție, deoarece energia se distribuie pe suprafețe tot mai mari.
Undă sferică ideală: dacă: \[ A(r) \propto \frac{1}{r}, \] atunci: \[ \boxed{ I(r) \propto \frac{1}{r^2} } \] în absența absorbției.
Două mecanisme diferite: răspândire geometrică: \[ I \propto \frac{1}{r^2}; \] absorbție: \[ I \propto e^{-\mu r}. \] Într-o situație reală pot apărea simultan.
Schema de rezolvare pentru o problemă energetică:

1. identifică tipul undei;
2. transformă datele în SI;
3. notează: \[ \rho,\quad A,\quad \nu \] sau \(\omega\);
4. folosește: \[ \omega=2\pi\nu; \]
5. pentru densitatea medie de energie: \[ \overline{w} = \frac{1}{2} \rho A^2\omega^2; \]
6. pentru intensitate, dacă modelul o permite: \[ I=\overline{w}v; \]
7. dacă există absorbție, identifică exact definiția coeficientului;
8. verifică unitățile și dependențele de ordinul \(A^2\).
Cinci erori de evitat:

1. confundarea energiei cu densitatea de energie;

2. confundarea densității de energie cu intensitatea;

3. presupunerea că energia este proporțională cu amplitudinea, nu cu pătratul ei;

4. folosirea aceluiași exponent pentru amplitudine și energie fără verificarea definiției;

5. interpretarea scăderii geometrice a unei unde sferice drept absorbție.
Nucleul de memorat: energie totală: \[ \boxed{ \Delta W = \Delta W_c+\Delta W_p } \] în modelul Bunget: \[ \boxed{ \Delta W_c=\Delta W_p } \] densitate medie: \[ \boxed{ \overline{w} = \frac{1}{2} \rho A^2\omega^2 } \] intensitate: \[ \boxed{ I = \overline{w}v } \] atenuarea amplitudinii: \[ \boxed{ A = A_0e^{-\alpha x} } \] atenuarea intensității: \[ \boxed{ I = I_0e^{-2\alpha x} } \] dacă \(\alpha\) este definit pentru amplitudine.
Legătură didactică: o întrebare bună de problematizare este:

„Dacă amplitudinea unei unde se reduce la jumătate, de câte ori se reduce energia medie transportată, în aceleași condiții?”

Relația-cheie este: \[ \overline{w} \propto A^2. \]
