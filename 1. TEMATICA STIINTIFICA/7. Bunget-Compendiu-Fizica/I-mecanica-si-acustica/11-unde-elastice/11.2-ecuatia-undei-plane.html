11.2 Ecuația undei plane

Oscilația sursei, întârzierea propagării, elongația unui punct al mediului, ecuația undei plane, faza, concordanța și opoziția de fază și forma undei sferice.

Ion Bunget Compendiu de Fizică §11.2
Sursa

Compendiu de Fizică

Partea I. Mecanică și acustică
11. Unde elastice
11.2 Ecuația undei plane

Pagina: 230.
§11.3 Principiul lui Huygens începe la p. 231.
Obiectiv

Cum descriem matematic unda?

Bunget urmărește determinarea ecuației unei unde plane care se propagă de-a lungul unei direcții.

Ca exemplu, se poate considera propagarea de-a lungul unui fir.

Mișcarea ondulatorie este cunoscută dacă putem determina elongația \(y\) a oricărui punct al mediului, pentru orice poziție și orice moment.

\[ \boxed{ y=y(x,t) } \]
Sursa oscilațiilor

Punctul \(O\)

Originea coordonatelor este aleasă chiar în punctul \(O\), care constituie sursa oscilațiilor.

Sursa execută o mișcare oscilatorie armonică.

Relația (11.3)

Ecuația sursei

Bunget scrie elongația sursei:

\[ \boxed{ y_O = A\sin\omega t } \]

unde:

\(A\)

amplitudinea oscilației;

\(\omega\)

pulsația;

\(t\)

timpul.

Punct al mediului

Punctul \(P\)

Se consideră un punct oarecare \(P\) situat la distanța:

\[ \boxed{ OP=x } \]

față de sursa \(O\).

Deoarece unda se propagă cu viteză finită, punctul \(P\) nu începe să oscileze simultan cu sursa.

Relația (11.4)

Timpul de propagare

Dacă viteza de propagare a undei este \(v\), intervalul necesar pentru parcurgerea distanței \(x\) este:

\[ \boxed{ t_1 = \frac{x}{v} } \]
Ideea centrală

Punctul \(P\) repetă mișcarea sursei cu întârziere

La momentul \(t\), punctul \(P\) se află în starea pe care sursa \(O\) o avea cu intervalul \(t_1\) mai devreme.

\[ \boxed{ y_P(t) = y_O(t-t_1) } \]
Substituție

Elongația punctului \(P\)

Înlocuind timpul prin \(t-t_1\) în ecuația sursei, rezultă:

\[ y_P = A \sin \omega (t-t_1). \]

Cu:

\[ t_1 = \frac{x}{v}, \]

obținem:

\[ \boxed{ y(x,t) = A \sin \omega \left( t-\frac{x}{v} \right) } \]
Relații cunoscute

\(\omega\), \(T\), \(\nu\), \(\lambda\)

Din studiul oscilațiilor și din §11.1 avem:

\[ \omega = 2\pi\nu = \frac{2\pi}{T}, \]

iar:

\[ \lambda = vT = \frac{v}{\nu}. \]
Relația (11.5)

Ecuația undei plane

Folosind relațiile precedente, ecuația poate fi scrisă:

\[ \boxed{ y(x,t) = A \sin \omega \left( t-\frac{x}{v} \right) } \]

sau:

\[ \boxed{ y(x,t) = A \sin 2\pi \left( \nu t - \frac{x}{\lambda} \right) } \]

echivalent:

\[ \boxed{ y(x,t) = A \sin 2\pi \left( \frac{t}{T} - \frac{x}{\lambda} \right) } \]
Semnificație

De ce aceasta este ecuația undei plane

Relația determină elongația unui punct al mediului în funcție atât de poziția \(x\), cât și de timpul \(t\).

\[ \boxed{ y=y(x,t) } \]

În cazul undei plane, punctele aceluiași front plan au, la un moment dat, aceeași fază și aceeași elongație în modelul analizat.

Faza oscilației

Dependența de poziție

Pentru un punct fix situat la coordonata \(x=x_0\), Bunget identifică termenul spațial:

\[ \boxed{ \varphi = \frac{\omega x_0}{v} = \frac{2\pi x_0}{\lambda} } \]

iar mișcarea punctului poate fi scrisă:

\[ \boxed{ y = A \sin (\omega t-\varphi) } \]
Concordanță de fază

Două puncte separate printr-o lungime de undă

Se consideră un al doilea punct aflat la:

\[ x' = x_0+\lambda. \]

Faza spațială a acestuia diferă cu:

\[ \boxed{ \Delta\varphi = 2\pi } \]

față de punctul de la \(x_0\).

Cele două puncte oscilează astfel în concordanță de fază.

Opoziție de fază

Două puncte separate prin jumătate de lungime de undă

Pentru punctul:

\[ x'' = x_0 + \frac{\lambda}{2}, \]

diferența de fază este:

\[ \boxed{ \Delta\varphi = \pi } \]

Cele două puncte sunt în opoziție de fază.

Concluzie

Distanța și diferența de fază

Ecuația undei plane permite astfel interpretarea directă a noțiunilor introduse în §11.1.

Distanța \(\lambda\)

\[ \boxed{ \Delta\varphi=2\pi } \]

concordanță de fază;

Distanța \(\lambda/2\)

\[ \boxed{ \Delta\varphi=\pi } \]

opoziție de fază.

Încheierea §11.2

Unda sferică

Bunget menționează la sfârșitul paragrafului și cazul unei unde sferice.

Amplitudinea oscilației scade invers proporțional cu distanța \(r\) față de centrul de oscilație.

\[ \boxed{ A(r) \propto \frac{1}{r} } \]
Relația (11.6)

Ecuația undei sferice

Cu o constantă de amplitudine \(A\), forma indicată de Compendiu este:

\[ \boxed{ y(r,t) = \frac{A}{r} \sin \omega \left( t-\frac{r}{v} \right) } \]

sau, folosind \(\omega=2\pi\nu\) și \(\lambda=v/\nu\):

\[ \boxed{ y(r,t) = \frac{A}{r} \sin 2\pi \left( \nu t - \frac{r}{\lambda} \right) } \]
Observația sursei

Scăderea amplitudinii

Bunget nu demonstrează în §11.2 dependența:

\[ A(r) \propto \frac{1}{r}. \]

Compendiul precizează că justificarea va fi dată ulterior, în capitolul de acustică.

Legătura logică

Firul §11.2

Sursa

\[ y_O = A\sin\omega t \]

Punct la distanța \(x\)

\[ t_1 = \frac{x}{v} \]

Întârzierea

\[ y_P(t) = y_O \left( t-\frac{x}{v} \right) \]

Unda plană

\[ \boxed{ y = A \sin 2\pi \left( \nu t - \frac{x}{\lambda} \right) } \]

Distanță \(\lambda\)

\[ \Delta\varphi = 2\pi \]

Distanță \(\lambda/2\)

\[ \Delta\varphi = \pi \]

Undă sferică

\[ \boxed{ A(r) \propto \frac{1}{r} } \]
Sinteză

De reținut din §11.2

Oscilația sursei

\[ \boxed{ y_O=A\sin\omega t } \]

Întârzierea la distanța \(x\)

\[ \boxed{ t_1=\frac{x}{v} } \]

Ecuația undei plane

\[ \boxed{ y(x,t) = A \sin \omega \left( t-\frac{x}{v} \right) } \]
\[ \boxed{ y(x,t) = A \sin 2\pi \left( \nu t - \frac{x}{\lambda} \right) } \]

Concordanță de fază

\[ \boxed{ \Delta x=\lambda \Rightarrow \Delta\varphi=2\pi } \]

Opoziție de fază

\[ \boxed{ \Delta x = \frac{\lambda}{2} \Rightarrow \Delta\varphi=\pi } \]

Undă sferică

\[ \boxed{ y(r,t) = \frac{A}{r} \sin \omega \left( t-\frac{r}{v} \right) } \]
Titularizare

Precizări pentru examen

Această secțiune este separată de corpul §11.2 al Compendiului. Reperul oficial utilizat este programa pentru Titularizare Fizică 2026.

Prioritate maximă

Programa 2026 cere explicit:

Unde elastice plane în medii omogene și izotrope: unde longitudinale și transversale, viteza undelor. Ecuația undei plane.

§11.2 corespunde direct ultimei cerințe.

Forma modernă standard pentru propagare spre \(+x\): \[ \boxed{ y(x,t) = A \sin ( \omega t - kx + \varphi_0 ) } \] unde \(\varphi_0\) este faza inițială.
Numărul de undă: \[ \boxed{ k = \frac{2\pi}{\lambda} } \] cu unitatea SI: \[ \boxed{ [k] = \mathrm{rad/m} } \] sau, dimensional, \(\mathrm{m^{-1}}\).
Pulsația: \[ \boxed{ \omega = 2\pi\nu = \frac{2\pi}{T} } \] cu: \[ \boxed{ [\omega] = \mathrm{rad/s} } \]
Viteza de fază: din: \[ k = \frac{2\pi}{\lambda} \] și: \[ \omega = 2\pi\nu, \] rezultă: \[ \boxed{ v = \frac{\omega}{k} = \lambda\nu } \]
Nu confunda \(v\) cu \(\nu\). În tipar, litera latină: \[ v \] pentru viteză și litera grecească: \[ \nu \] pentru frecvență pot arăta foarte asemănător. Unitățile le separă: \[ [v] = \mathrm{m/s}, \] \[ [\nu] = \mathrm{Hz}. \]
Faza undei: \[ \boxed{ \Phi(x,t) = \omega t - kx + \varphi_0 } \]
La același moment: pentru două puncte separate prin: \[ \Delta x, \] diferența de fază în modul este: \[ \boxed{ |\Delta\Phi| = k|\Delta x| = \frac{ 2\pi|\Delta x| }{ \lambda } } \]
Pentru același punct: între două momente separate prin: \[ \Delta t, \] diferența de fază este: \[ \boxed{ \Delta\Phi = \omega\Delta t = \frac{ 2\pi\Delta t }{ T } } \]
Concordanță de fază: \[ \boxed{ \Delta\Phi = 2\pi n } \] unde: \[ n\in\mathbb Z. \] Spațial: \[ \boxed{ \Delta x = n\lambda } \]
Opoziție de fază: \[ \boxed{ \Delta\Phi = (2n+1)\pi } \] și: \[ \boxed{ \Delta x = (2n+1) \frac{\lambda}{2} } \]
Eroare frecventă: pentru puncte în aceeași fază, distanța nu trebuie să fie numai \(\lambda\). General: \[ \boxed{ \Delta x=n\lambda } \]
Sensul propagării: forma: \[ \boxed{ \omega t-kx } \] descrie propagarea spre \(+x\). Forma: \[ \boxed{ \omega t+kx } \] descrie propagarea spre \(-x\).
Cum verifici sensul fără să memorezi mecanic: urmărește un punct de fază constantă. Pentru: \[ \omega t-kx = \text{constant}, \] rezultă: \[ x = \frac{\omega}{k}t + \text{constant}, \] deci \(x\) crește în timp.
Periodicitate temporală: pentru \(x\) fix: \[ \boxed{ y(x,t+T) = y(x,t) } \]
Periodicitate spațială: pentru \(t\) fix: \[ \boxed{ y(x+\lambda,t) = y(x,t) } \]
Aceasta este dubla periodicitate a undei armonice:

periodicitate în timp: \[ T; \] periodicitate în spațiu: \[ \lambda. \]
Nu confunda: \[ T \] cu: \[ \lambda. \] \(T\) este interval de timp și se măsoară în secunde. \(\lambda\) este distanță și se măsoară în metri.
Întârzierea de propagare: un punct aflat la distanța \(x\) față de sursă primește perturbația după: \[ \boxed{ \tau = \frac{x}{v} } \]
Forma cea mai intuitivă: \[ \boxed{ y(x,t) = y_O \left( t-\frac{x}{v} \right) } \] spune direct:

„punctul de la \(x\) reproduce mai târziu mișcarea sursei”.

Aceasta este cheia demonstrației. Dacă o înțelegi, nu mai este nevoie să memorezi mecanic semnul din ecuația undei progresive.
Amplitudinea undei plane: în modelul Bunget al undei plane fără atenuare: \[ \boxed{ A=\text{constant} } \] pe direcția propagării.
Într-un mediu real absorbant, amplitudinea poate scădea cu distanța. Acest efect va fi discutat ulterior în Compendiu.
Unda sferică: în modelul ideal fără absorbție: \[ \boxed{ A(r) \propto \frac{1}{r} } \]
Consecință energetică modernă: dacă amplitudinea scade ca: \[ \frac{1}{r}, \] iar intensitatea este proporțională cu pătratul amplitudinii, atunci: \[ \boxed{ I(r) \propto \frac{1}{r^2} } \] pentru propagare sferică fără absorbție.
Delimitare de sursă: relația explicită: \[ I\propto\frac{1}{r^2} \] nu este dedusă în §11.2. Bunget menționează aici doar scăderea amplitudinii ca \(1/r\).
Ecuația diferențială a undei: funcția ideală de undă plană satisface: \[ \boxed{ \frac{ \partial^2 y }{ \partial x^2 } = \frac{1}{v^2} \frac{ \partial^2 y }{ \partial t^2 } } \] în modelul unidimensional.
Delimitare importantă: ecuația diferențială a undelor de mai sus nu este introdusă în §11.2 al lui Bunget. Compendiul numește „ecuația undei plane” relația care dă elongația: \[ y(x,t). \]
Cum identifici mărimile dintr-o ecuație dată: dacă ai: \[ y = A \sin ( at-bx+\varphi_0 ), \] compară cu: \[ y = A \sin ( \omega t-kx+\varphi_0 ). \] Atunci: \[ \boxed{ \omega=a } \] și: \[ \boxed{ k=b } \]
De aici: \[ T = \frac{2\pi}{\omega}, \] \[ \nu = \frac{\omega}{2\pi}, \] \[ \lambda = \frac{2\pi}{k}, \] \[ \boxed{ v = \frac{\omega}{k} } \]
Verificare dimensională: argumentul funcției sinus trebuie să fie adimensional. În: \[ \omega t-kx, \] avem: \[ [\omega t] = 1 \] și: \[ [kx] = 1. \]
Dacă într-o ecuație termenii din sinus nu sunt adimensionali, ecuația este scrisă greșit sau unitățile nu sunt introduse coerent.
Exemplu de citire fără rezolvare numerică: din: \[ y = 0{,}02 \sin ( 20\pi t - 4\pi x ) \] se citesc direct: \[ A = 0{,}02\,\mathrm m, \] \[ \omega = 20\pi\,\mathrm{rad/s}, \] \[ k = 4\pi\,\mathrm{rad/m}. \]
Apoi metoda este: \[ \nu = \frac{\omega}{2\pi}, \] \[ \lambda = \frac{2\pi}{k}, \] \[ v = \frac{\omega}{k}. \] Acest tip de identificare este foarte important în problemele de concurs.
Patru erori de evitat:

1. confundarea lui \(k\) cu \(\lambda\);

2. confundarea lui \(\omega\) cu frecvența \(\nu\);

3. inversarea semnului și deci a sensului de propagare;

4. confundarea vitezei de propagare cu viteza de oscilație a unei particule.
Schema de rezolvare pentru o ecuație de undă:

1. adu ecuația la forma: \[ y = A \sin ( \omega t \mp kx + \varphi_0 ); \]
2. identifică \(A\);
3. identifică \(\omega\);
4. identifică \(k\);
5. calculează: \[ T=\frac{2\pi}{\omega}; \]
6. calculează: \[ \nu=\frac{\omega}{2\pi}; \]
7. calculează: \[ \lambda=\frac{2\pi}{k}; \]
8. determină: \[ v=\frac{\omega}{k}; \]
9. stabilește sensul propagării;
10. verifică unitățile și argumentul funcției trigonometrice.
Nucleul de memorat: propagare spre \(+x\): \[ \boxed{ y = A \sin ( \omega t - kx + \varphi_0 ) } \] propagare spre \(-x\): \[ \boxed{ y = A \sin ( \omega t + kx + \varphi_0 ) } \] număr de undă: \[ \boxed{ k=\frac{2\pi}{\lambda} } \] pulsație: \[ \boxed{ \omega=2\pi\nu } \] viteză: \[ \boxed{ v = \frac{\omega}{k} = \lambda\nu } \] diferență de fază: \[ \boxed{ |\Delta\Phi| = \frac{ 2\pi|\Delta x| }{ \lambda } } \]
Pentru Titularizare: ecuația undei plane nu trebuie doar memorată. Trebuie să poți reconstrui formula pornind de la: \[ \boxed{ \text{întârzierea} = \frac{x}{v} } \] și să poți extrage dintr-o ecuație dată: \[ A,\; T,\; \nu,\; \omega,\; \lambda,\; k,\; v \] precum și sensul propagării.
