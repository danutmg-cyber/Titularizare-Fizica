5.6 Efectul giroscopic

Momentul cinetic al unui corp aflat în rotație rapidă, modificarea direcției axei de rotație, efectul giroscopic și mișcarea de precesie.

Ion Bunget Compendiu de Fizică §5.6
Sursa

Compendiu de Fizică

Partea I. Mecanică și acustică
5. Mișcarea corpului rigid
5.6 Efectul giroscopic
Pagini: 150–153
Definiție

Giroscopul

Compendiul consideră drept giroscop un disc cu moment de inerție mare, care se rotește rapid în jurul axei sale de simetrie.

Giroscop

Disc cu moment de inerție mare, aflat în rotație rapidă în jurul axei sale de simetrie.

Proprietățile giroscopului sunt legate direct de momentul său cinetic.

Rotația proprie

Rotație rapidă în jurul axei \(Oy\)

În figura I.5.11, giroscopul se rotește în jurul axei orizontale \(Oy\).

Viteza unghiulară a acestei rotații este:

\[ \omega_0. \]

Rotației îi corespunde un moment cinetic:

\[ \vec L_0, \]

orientat după aceeași axă \(Oy\).

\[ \boxed{ \vec L_0 \parallel \vec\omega_0 } \]
Moment cinetic

Relația din §5.3

Pentru rotația în jurul axei de simetrie, se utilizează relația:

\[ \boxed{ L_0 = J\omega_0 } \]

unde \(J\) este momentul de inerție al discului față de axa sa de rotație.

Modificarea axei

Rotație suplimentară în jurul axei \(Ox\)

Compendiul presupune apoi că giroscopului i se imprimă o rotație suplimentară în jurul axei \(Ox\).

Viteza unghiulară a acestei mișcări este notată:

\[ \Omega. \]

Ea este considerată mult mai mică decât viteza rotației proprii:

\[ \boxed{ \Omega\ll\omega_0 } \]
Interval mic de timp

Schimbarea orientării axei

Într-un interval mic de timp:

\[ \Delta t, \]

axa giroscopului se rotește cu un unghi mic:

\[ \Delta\theta. \]

Viteza unghiulară asociată acestei rotații este:

\[ \boxed{ \Omega = \frac{ \Delta\theta }{ \Delta t } } \]
Momentul cinetic

Se schimbă direcția, nu modulul

Prin rotirea axei, se modifică direcția vectorului viteză unghiulară.

Se modifică în același mod și direcția vectorului moment cinetic.

În construcția analizată, turația proprie a giroscopului nu se modifică.

Prin urmare, modulul momentului cinetic rămâne constant:

\[ \boxed{ L_1=L_0=L } \]
Variația vectorului

\(\Delta\vec L\)

Momentul cinetic inițial este \(\vec L_0\), iar după rotirea axei devine \(\vec L_1\).

Variația momentului cinetic este:

\[ \boxed{ \Delta\vec L = \vec L_1-\vec L_0 } \]

Pentru un unghi mic \(\Delta\theta\), Compendiul aproximează coarda corespunzătoare variației vectorului prin arcul asociat.

\[ \boxed{ \Delta L \simeq L_0\Delta\theta } \]
Teorema momentului cinetic

Pentru schimbarea direcției lui \(\vec L\) este necesar un moment

Din relația dintre momentul forței și variația momentului cinetic:

\[ M = \frac{\Delta L}{\Delta t}, \]

și din:

\[ \Delta L \simeq L_0\Delta\theta, \]

rezultă:

\[ M = L_0 \frac{ \Delta\theta }{ \Delta t }. \]

Deoarece:

\[ \Omega = \frac{ \Delta\theta }{ \Delta t }, \]

se obține relația (5.30):

\[ \boxed{ M=L_0\Omega } \]
Direcție

Momentul este orientat după \(\Delta\vec L\)

Momentul forțelor care produce schimbarea orientării giroscopului are direcția variației momentului cinetic.

\[ \boxed{ \vec M \parallel \Delta\vec L } \]

În configurația din figura I.5.11, această direcție este perpendiculară pe planul determinat de pozițiile succesive ale axei momentului cinetic.

Cuplu de forțe

Realizarea momentului necesar

Compendiul produce momentul necesar prin două forțe paralele, egale ca modul și de sensuri contrare.

\[ \vec F \qquad\text{și}\qquad -\vec F. \]

Dacă fiecare forță este aplicată la distanța \(l\) față de centrul giroscopului, distanța dintre liniile lor de acțiune este \(2l\).

Relațiile (5.31)–(5.32)

Momentul cuplului

Pentru forțele perpendiculare pe brațele corespunzătoare, momentul cuplului este:

\[ \boxed{ M=2Fl } \]

Acest moment trebuie să fie egal cu momentul necesar pentru modificarea direcției lui \(\vec L\).

\[ 2Fl=L_0\Omega. \]
Relația (5.33)

Modulul forțelor

Din relația precedentă:

\[ \boxed{ F = \frac{ L_0\Omega }{ 2l } } \]
Relația (5.34)

Legătura cu momentul de inerție

Din §5.3:

\[ L_0=J\omega_0. \]

Înlocuind în expresia forței, se obține:

\[ \boxed{ F = \frac{ J\omega_0\Omega }{ 2l } } \]

Forțele necesare pentru modificarea orientării giroscopului cresc odată cu momentul său de inerție și cu viteza rotației proprii.

Fenomen

Efectul giroscopic

Bunget subliniază o proprietate caracteristică a corpului aflat în rotație rapidă.

Dacă unui giroscop care se rotește în jurul unei axe i se aplică un cuplu care tinde să-i modifice orientarea în jurul unei axe perpendiculare, răspunsul mișcării apare în jurul celei de-a treia axe, perpendiculară pe primele două.

Efect giroscopic

Comportarea caracteristică a unui corp aflat în rotație rapidă atunci când asupra lui acționează un cuplu care modifică direcția momentului său cinetic.

Geometrie

Trei direcții perpendiculare

În construcția Compendiului apar trei axe reciproc perpendiculare:

\(Oy\)

axa rotației rapide proprii a giroscopului;

\(Ox\)

una dintre axele rotației suplimentare;

\(Oz\)

cea de-a treia direcție, perpendiculară pe primele două.

Efectul este în esență tridimensional și este legat de caracterul vectorial al momentului cinetic.

Experiența din Compendiu

Om, roată și disc turnant

Pentru evidențierea efectului giroscopic, Compendiul descrie o experiență în care un om stă pe un disc care se poate roti.

Omul ține în mâini o roată aflată în rotație în jurul unei axe orizontale.

Inițial, omul și discul turnant sunt în repaus.

Schimbarea orientării

Axa roții este adusă din poziție orizontală în poziție verticală

Omul modifică orientarea axei roții printr-o rotație de aproximativ:

\[ 90^\circ. \]

În urma acestei mișcări, omul împreună cu discul turnant încep să se rotească.

Sensul rotației lor este opus efectului asociat schimbării orientării momentului cinetic al roții.

Explicația mecanică

Principiul acțiunii și reacțiunii

Pentru schimbarea orientării axei roții, omul exercită asupra acesteia un cuplu de forțe.

Conform principiului al treilea al mecanicii, roata exercită asupra omului forțe de reacțiune egale și opuse.

Momentul acestor forțe determină rotația omului și a discului turnant.

Explicație energetic-dinamică

Conservarea momentului cinetic

Bunget oferă și o explicație bazată direct pe legea conservării momentului cinetic.

În poziția inițială, momentul cinetic total al sistemului:

\[ \text{roată} + \text{om} + \text{disc} \]

este determinat de rotația roții în jurul axei orizontale.

Componenta momentului cinetic total pe verticală este inițial nulă.

După rotirea roții

Apare o componentă verticală a momentului cinetic al roții

După aducerea axei roții în poziție verticală, momentul cinetic al roții este orientat pe verticală.

Pentru ca momentul cinetic total al sistemului să respecte condiția inițială, omul și discul trebuie să capete un moment cinetic în sens opus.

\[ \boxed{ L_{z,\mathrm{total}} = \text{constant} } \]
A doua aplicație

Mișcarea titirezului

Efectul giroscopic este folosit de Compendiu și pentru explicarea comportării unui titirez.

Axa de rotație a titirezului este înclinată față de verticală.

Greutatea produce un moment care tinde să modifice orientarea axei sale.

Mișcare de precesie

Axa titirezului se rotește în jurul verticalei

Datorită efectului giroscopic, acțiunea momentului greutății nu produce pur și simplu răsturnarea imediată a titirezului.

Axa sa capătă o mișcare suplimentară în jurul verticalei.

Precesie

Mișcarea în care axa de rotație a titirezului se rotește în jurul unei alte axe.

Geometria precesiei

Axa descrie o suprafață conică

În timpul mișcării de precesie, axa de rotație a titirezului își schimbă continuu orientarea.

Ea descrie o suprafață conică.

Axa de simetrie a acestui con coincide cu verticala locului.

\[ \boxed{ \text{axa titirezului} \longrightarrow \text{suprafață conică} } \]
Consecință

Stabilitatea titirezului

Compendiul explică faptul că, datorită mișcării de precesie, titirezul aflat în rotație rapidă nu se răstoarnă în modul în care ar face-o un corp lipsit de rotația proprie.

Comportarea este determinată de variația vectorială a momentului cinetic.

Aplicații

Utilizarea efectului giroscopic

Bunget precizează că efectul giroscopic are aplicații tehnice importante.

Un exemplu prezentat în Compendiu este stabilizarea prin rotație rapidă a unui corp aflat în mișcare.

Rotația îi conferă un moment cinetic propriu mare, iar momentele perturbatoare tind să producă în principal modificarea orientării axei prin precesie.

Exemplu istoric din sursă

Stabilizarea prin rotație

Compendiul menționează, ca exemplu tehnic, imprimarea unei rotații rapide unui proiectil în jurul axei sale.

Prin această rotație, corpul capătă un moment cinetic propriu mare.

Momentele produse de rezistența aerului determină în principal o modificare prin precesie a orientării, în locul unei răsturnări simple a corpului.

Efect tehnic nedorit

Mașini cu piese rotitoare rapide

Bunget atrage atenția că efectul giroscopic nu este întotdeauna util.

El poate produce solicitări importante în sistemele mecanice care conțin corpuri masive, cu moment de inerție mare, aflate în rotație rapidă.

Exemplul din Compendiu

Turbina unei nave în timpul virajului

Compendiul consideră cazul unei turbine care se rotește rapid în interiorul unei nave.

Atunci când nava execută un viraj în jurul axei sale verticale, se modifică orientarea axei de rotație a turbinei.

Efectul giroscopic generează un cuplu care poate produce solicitări importante asupra lagărelor turbinei.

Relația finală

De ce cresc solicitările

Relația (5.34):

\[ \boxed{ F = \frac{ J\omega_0\Omega }{ 2l } } \]

arată în modelul analizat că efectul este mai pronunțat atunci când cresc:

momentul de inerție \(J\);

viteza unghiulară proprie \(\omega_0\);

viteza unghiulară de modificare a orientării \(\Omega\).

Sinteză

De reținut din §5.6

Giroscop

Corp cu moment de inerție mare aflat în rotație rapidă în jurul unei axe.

Momentul cinetic

\[ \boxed{ L=J\omega } \]

Variația momentului cinetic

\[ \boxed{ \Delta\vec L = \vec L_1-\vec L_0 } \]

Momentul forțelor

\[ \boxed{ M=L\Omega } \]

Cuplul de forțe

\[ \boxed{ M=2Fl } \]

Forțele din modelul Compendiului

\[ \boxed{ F = \frac{ J\omega\Omega }{ 2l } } \]

Precesie

Mișcare de rotație a axei corpului în jurul unei alte axe.

Ideea fundamentală

Un moment exterior aplicat unui corp aflat în rotație rapidă modifică direcția vectorului său moment cinetic.

Titularizare

Precizări pentru examen

Această secțiune este separată de conținutul §5.6 al Compendiului. Reperul oficial utilizat este programa pentru Titularizare Fizică 2026.

Statut în programa 2026

„Efectul giroscopic” nu apare ca punct autonom în lista tematicii științifice.

Sunt însă cerute explicit:

la punctul 5: momentul cinetic și legile de conservare;

la punctul 6: mișcarea solidului rigid cu axă fixă și momentele de inerție.

Relația fundamentală, mai generală decât formula particulară din §5.6: \[ \boxed{ \vec M_{\mathrm{ext}} = \frac{ d\vec L }{ dt } } \] Momentul exterior rezultant determină variația vectorului moment cinetic.
Pentru rotație în jurul unei axe principale în situațiile simple tratate aici: \[ \boxed{ \vec L = I\vec\omega } \] unde: \[ [I]_{\mathrm{SI}} = \mathrm{kg\,m^2}. \]
Atenție la relația \(M=L\Omega\): aceasta nu trebuie memorată ca o formulă scalară universală pentru orice mișcare a corpului rigid. În §5.6 ea rezultă pentru configurația particulară în care modulul lui \(\vec L\) rămâne constant, iar direcția sa se rotește cu viteza unghiulară \(\Omega\).
Ideea sigură pentru examen: pornești de la: \[ \boxed{ \vec M_{\mathrm{ext}} = \frac{d\vec L}{dt} } \] și analizezi vectorial schimbarea lui \(\vec L\).
Greșeală frecventă: dacă modulul momentului cinetic rămâne constant, aceasta nu înseamnă că: \[ \Delta\vec L=\vec0. \] Un vector se poate modifica numai prin schimbarea direcției sale.
În §5.6: \[ |\vec L| = \text{constant} \] dar: \[ \boxed{ \frac{ d\vec L }{ dt } \neq \vec0 } \] deoarece direcția lui \(\vec L\) se modifică.
Nu confunda: rotația proprie a giroscopului este caracterizată prin: \[ \omega, \] iar rotația lentă a axei sale poate fi caracterizată prin: \[ \Omega. \] Cele două viteze unghiulare descriu mișcări diferite.
Precesia: trebuie înțeleasă geometric drept schimbarea continuă a orientării axei de rotație. Pentru titirezul discutat de Bunget, axa înclinată descrie o suprafață conică în jurul verticalei.
Unități SI: moment cinetic: \[ \boxed{ [L] = \mathrm{kg\,m^2/s} } \] momentul forței: \[ \boxed{ [M] = \mathrm{N\,m} } \] viteză unghiulară: \[ \boxed{ [\omega] = [\Omega] = \mathrm{rad/s} } \]
Verificarea dimensională pentru \(M=L\Omega\): \[ [L\Omega] = \mathrm{ \frac{kg\,m^2}{s} } \cdot \mathrm{ \frac1s } \] \[ = \mathrm{ \frac{kg\,m^2}{s^2} } \] \[ = \boxed{ \mathrm{N\,m} }. \]
Efect giroscopic și conservarea momentului cinetic: sunt strâns legate, dar nu trebuie confundate două situații. Dacă: \[ \vec M_{\mathrm{ext}}=\vec0, \] atunci: \[ \vec L=\text{constant}. \] Dacă există un moment exterior nenul: \[ \vec M_{\mathrm{ext}} = \frac{d\vec L}{dt}, \] vectorul \(\vec L\) își modifică direcția și/sau modulul.
Schema conceptuală:

rotație rapidă \[ \longrightarrow \] moment cinetic mare \[ \longrightarrow \] moment exterior \[ \longrightarrow \] schimbarea direcției lui \(\vec L\) \[ \longrightarrow \] precesie / efect giroscopic.
Prioritatea pentru Titularizare: trebuie stăpânite înainte de toate relațiile: \[ \boxed{ \vec L = \vec r \times \vec p } \] \[ \boxed{ \vec M = \frac{d\vec L}{dt} } \] \[ \boxed{ L=I\omega } \] și condiția: \[ \boxed{ \vec M_{\mathrm{ext}}=0 \Rightarrow \vec L=\text{constant} } \]
