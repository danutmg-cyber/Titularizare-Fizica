5.3 Momentul cinetic și momentul de inerție. Legea conservării momentului cinetic

Momentul cinetic al unui corp rigid în rotație, definirea momentului de inerție, dependența acestuia de distribuția masei și conservarea momentului cinetic.

Ion Bunget Compendiu de Fizică §5.3

Compendiu de Fizică

5.3 Momentul cinetic și momentul de inerție. Legea conservării momentului cinetic
Pagini: 144–147
Sistemul analizat

Corp rigid în rotație în jurul unei axe fixe

Compendiul consideră un corp rigid care se rotește uniform în jurul unei axe \(OO'\), a cărei direcție nu se modifică în timp.

Corpul este privit ca un sistem alcătuit din puncte materiale de mase:

\[ m_1,\, m_2,\, \ldots,\, m_N. \]
Punct material

Mișcarea unui punct al rigidului

Se consideră punctul material de masă \(m_i\), situat la distanța \(r_i\) față de axa de rotație.

Acesta descrie un cerc de rază \(r_i\), aflat într-un plan perpendicular pe axa de rotație.

Viteza sa:

\[ \vec v_i \]

este tangentă la cercul descris.

Din §5.1:

\[ \boxed{ v_i=\omega r_i } \]
Impuls

Impulsul punctului material

Impulsul punctului material de masă \(m_i\) este:

\[ \boxed{ \vec p_i = m_i\vec v_i } \]
Moment cinetic

Momentul cinetic al punctului material

Momentul cinetic față de axa de rotație se exprimă prin produsul vectorial:

\[ \boxed{ \vec L_i = \vec r_i \times \vec p_i } \]

Deoarece:

\[ \vec p_i = m_i\vec v_i, \]

se poate scrie:

\[ \boxed{ \vec L_i = m_i \vec r_i \times \vec v_i } \]
Direcție și sens

\(\vec L_i\) este paralel cu \(\vec\omega\)

Vectorii \(\vec r_i\) și \(\vec v_i\) se află în planul cercului descris de punct.

Momentul cinetic este perpendicular pe acest plan.

În situația analizată, direcția sa coincide cu direcția axei de rotație.

Sensul este stabilit prin regula burghiului, asemenea sensului vectorului viteză unghiulară.

\[ \boxed{ \vec L_i \parallel \vec\omega } \]
Modul

Modulul momentului cinetic

Deoarece în mișcarea circulară:

\[ \vec r_i \perp \vec v_i, \]

modulul momentului cinetic este:

\[ L_i = m_i r_i v_i. \]

Folosind:

\[ v_i=\omega r_i, \]

se obține:

\[ \boxed{ L_i = m_i r_i^2\omega } \]
Corpul rigid

Momentul cinetic total

Momentul cinetic total al rigidului este suma momentelor cinetice ale tuturor punctelor materiale componente.

\[ \boxed{ \vec L = \sum_{i=1}^{N} \vec L_i } \]

Aceasta este relația (5.14) din Compendiu.

În cazul rotației în jurul aceleiași axe, toate momentele cinetice individuale au aceeași direcție.

Pentru module se poate scrie:

\[ \boxed{ L = \sum_{i=1}^{N} L_i } \]
Prelucrare

Introducerea vitezei unghiulare

Pentru fiecare punct:

\[ L_i = m_i r_i^2\omega. \]

Prin urmare:

\[ L = \sum_{i=1}^{N} m_i r_i^2\omega. \]

Viteza unghiulară este aceeași pentru toate punctele corpului rigid și poate fi scoasă în afara sumei.

\[ \boxed{ L = \omega \sum_{i=1}^{N} m_i r_i^2 } \]

Aceasta corespunde relației (5.16).

Definiție

Momentul de inerție

Compendiul introduce mărimea:

\[ \boxed{ J = \sum_{i=1}^{N} m_i r_i^2 } \]
Momentul de inerție față de o axă

Suma produselor dintre masa fiecărui punct material al corpului și pătratul distanței acestuia până la axa de rotație.

Aceasta reprezintă relația (5.17) din Compendiu.

Interpretare

Distribuția masei contează

Momentul de inerție nu depinde numai de masa totală a corpului.

El depinde și de modul în care masa este distribuită față de axa de rotație.

Din:

\[ J = \sum_i m_i r_i^2 \]

rezultă că o masă aflată mai departe de axă contribuie mai mult la momentul de inerție, deoarece distanța apare la pătrat.

Relația fundamentală

Moment cinetic și moment de inerție

Introducând definiția momentului de inerție în expresia momentului cinetic total:

\[ \boxed{ L=J\omega } \]

În situația de rotație în jurul axei fixe analizată de Compendiu, relația poate fi exprimată vectorial prin:

\[ \boxed{ \vec L = J\vec\omega } \]

Aceasta este relația (5.18).

Dinamica momentului cinetic

Legătura cu momentul forțelor

Compendiul reamintește rezultatul stabilit în §3.7:

\[ \boxed{ \frac{d\vec L}{dt} = \vec M_{\mathrm{ext}} } \]

Variația în timp a momentului cinetic total este determinată de momentul rezultant al forțelor exterioare.

Conservare

Moment exterior rezultant nul

În situația analizată, dacă momentul rezultant al forțelor externe este nul:

\[ \vec M_{\mathrm{ext}} = \vec0, \]

atunci:

\[ \frac{d\vec L}{dt} = \vec0. \]

Rezultă:

\[ \boxed{ \vec L = \text{constant} } \]
Legea

Legea conservării momentului cinetic

Legea conservării momentului cinetic

Dacă momentul rezultant al forțelor exterioare este nul, momentul cinetic total al sistemului rămâne constant.

\[ \boxed{ \vec M_{\mathrm{ext}} = \vec0 \quad\Longrightarrow\quad \vec L = \text{constant} } \]
Rigid cu axă fixă

Conservarea produsului \(J\omega\)

Pentru rotația în jurul aceleiași axe:

\[ L=J\omega. \]

Dacă momentul cinetic se conservă:

\[ \boxed{ J\omega = \text{constant} } \]

Pentru două stări ale corpului:

\[ \boxed{ J_1\omega_1 = J_2\omega_2 } \]
Exemplul din Compendiu

Persoană pe o platformă rotitoare

Compendiul consideră o persoană aflată pe o platformă care se poate roti cu frecare neglijabilă.

Persoana ține în mâini două corpuri de masă \(M\), având inițial brațele întinse.

Sistemul se rotește cu viteza unghiulară:

\[ \omega_1. \]

Momentul de inerție inițial este:

\[ J_1. \]

Momentul cinetic este:

\[ \boxed{ L=J_1\omega_1 } \]
Modificarea distribuției masei

Aducerea brațelor lângă corp

Persoana aduce brațele și greutățile mai aproape de axa de rotație.

Distanțele maselor față de axă scad.

Din definiția:

\[ J = \sum_i m_i r_i^2, \]

rezultă că noul moment de inerție este mai mic:

\[ \boxed{ J_2
Consecință

Viteza unghiulară crește

Deoarece momentul cinetic se conservă:

\[ J_1\omega_1 = J_2\omega_2. \]

Dacă:

\[ J_2

atunci:

\[ \boxed{ \omega_2>\omega_1 } \]

Persoana se rotește mai repede atunci când masele sunt aduse mai aproape de axa de rotație.

Momentul de inerție

De ce depinde \(J\)

Din relația de definiție rezultă că momentul de inerție depinde de mai multe elemente.

Masa corpului

Creșterea maselor componente mărește, în general, momentul de inerție.

Distribuția masei

Contează distanțele punctelor materiale față de axa de rotație.

Forma geometrică

Corpuri cu aceeași masă pot avea momente de inerție diferite.

Poziția axei

Același corp are, în general, momente de inerție diferite față de axe diferite.

Corpuri omogene

Momente de inerție prezentate în Compendiu

Bunget prezintă în figurile I.5.7 și I.5.8 valorile momentului de inerție pentru câteva corpuri de formă geometrică simplă.

Relațiile sunt considerate pentru corpuri cu masa uniform distribuită, adică densitate constantă.

Bară omogenă

Axă perpendiculară pe bară

Pentru o bară omogenă de masă \(M\) și lungime \(l\), față de axa perpendiculară pe bară și care trece prin centrul său de masă:

\[ \boxed{ J_C = \frac{1}{12} Ml^2 } \]

Pentru axa paralelă care trece printr-un capăt:

\[ \boxed{ J_{\mathrm{capăt}} = \frac13Ml^2 } \]
Sferă plină

Axă prin centrul sferei

Pentru o sferă plină omogenă de masă \(M\) și rază \(R\):

\[ \boxed{ J = \frac25MR^2 } \]
Cilindru plin

Axă de simetrie

Pentru un cilindru plin omogen, în raport cu axa sa longitudinală de simetrie:

\[ \boxed{ J = \frac12MR^2 } \]
Cilindru inelar

Rază interioară și rază exterioară

Pentru un cilindru omogen cu razele \(R_1\) și \(R_2\), față de axa de simetrie:

\[ \boxed{ J = \frac12 M \left( R_1^2+R_2^2 \right) } \]
Cilindru gol

Perete subțire

Pentru cazul limită în care masa cilindrului este distribuită practic la aceeași distanță \(R\) față de axă:

\[ \boxed{ J=MR^2 } \]
Axe paralele

Momentul de inerție față de o altă axă

Compendiul consideră o axă care trece prin centrul de masă al corpului și o a doua axă paralelă cu aceasta.

Distanța dintre cele două axe este:

\[ a. \]

Se notează cu \(J\) momentul de inerție față de axa care trece prin centrul de masă și cu \(J'\) momentul de inerție față de axa paralelă.

Deducere

Relația dintre \(J'\) și \(J\)

Pentru fiecare punct material, schimbarea axei introduce în pătratul distanței termeni care conțin distanța \(a\).

La însumare apare un termen proporțional cu:

\[ \sum_i m_i\vec r_i. \]

Dacă originea este aleasă în centrul de masă, din §5.2:

\[ \boxed{ \sum_i m_i\vec r_i = \vec0 } \]

iar termenul respectiv dispare.

Relația (5.20)

Teorema axelor paralele

Compendiul obține:

\[ \boxed{ J' = J+Ma^2 } \]

unde:

\(J\) — momentul de inerție față de axa paralelă care trece prin centrul de masă;

\(J'\) — momentul de inerție față de noua axă;

\(M\) — masa totală a corpului;

\(a\) — distanța dintre cele două axe paralele.

Consecință

Axa prin centrul de masă

Deoarece:

\[ Ma^2\geq0, \]

relația:

\[ J'=J+Ma^2 \]

arată că:

\[ \boxed{ J'\geq J } \]

Pentru familia de axe paralele considerată, momentul de inerție este minim pentru axa care trece prin centrul de masă.

Verificare

Bara omogenă

Pentru bara de lungime \(l\), axa prin capăt este paralelă cu axa prin centru și se află la distanța:

\[ a=\frac l2. \]

Din relația axelor paralele:

\[ J_{\mathrm{capăt}} = J_C + M \left( \frac l2 \right)^2. \]

Folosind:

\[ J_C = \frac1{12}Ml^2, \]

rezultă:

\[ J_{\mathrm{capăt}} = \frac1{12}Ml^2 + \frac14Ml^2 \]
\[ \boxed{ J_{\mathrm{capăt}} = \frac13Ml^2 } \]
Legătura logică

De la punct material la corp rigid

Impulsul unui punct

\[ \vec p_i = m_i\vec v_i \]

Momentul cinetic

\[ \vec L_i = \vec r_i \times \vec p_i \]

Rotația rigidului

\[ v_i=\omega r_i \]

Momentul cinetic total

\[ L = \omega \sum_i m_i r_i^2 \]

Momentul de inerție

\[ \boxed{ J = \sum_i m_i r_i^2 } \]

Relația rigidului

\[ \boxed{ L=J\omega } \]

Conservarea

\[ \boxed{ J\omega = \text{constant} } \]
Sinteză

\[ \boxed{ \vec L_i = \vec r_i \times \vec p_i } \]

\[ \boxed{ \vec L = \sum_i \vec L_i } \]

\[ \boxed{ J = \sum_i m_i r_i^2 } \]

Cerință explicită în programa 2026

§5.3 se suprapune direct peste două puncte importante ale tematicii oficiale.

5. Teoremele mecanicii clasice (energie cinetică, impuls, moment cinetic). Legi de conservare.

6. Mișcarea solidului rigid cu axă fixă. Momente de inerție. Pendulul fizic.

Momentul cinetic al unui punct material: \[ \boxed{ \vec L_O = \vec r \times \vec p } \] unde: \[ \vec p=m\vec v. \] Unitatea SI este: \[ \boxed{ [L] = \mathrm{kg\,m^2/s} } \]
Teorema momentului cinetic: \[ \boxed{ \frac{d\vec L_O}{dt} = \vec M_O^{\,\mathrm{ext}} } \] Condiția de conservare este: \[ \boxed{ \vec M_O^{\,\mathrm{ext}} = \vec0 } \] de unde: \[ \boxed{ \vec L_O = \text{constant} } \]
Pentru rotația rigidului în jurul unei axe fixe: \[ \boxed{ L=I\omega } \] În Compendiu și în această lecție s-a folosit \(J\) pentru momentul de inerție. În literatura actuală se întâlnesc frecvent ambele notații: \[ I \quad\text{sau}\quad J. \]
Definiția momentului de inerție pentru un sistem discret: \[ \boxed{ I = \sum_i m_i r_i^2 } \] unde \(r_i\) este distanța perpendiculară dintre masa \(m_i\) și axa de rotație.
Pentru distribuție continuă de masă: \[ \boxed{ I = \int r^2\,dm } \] Aceasta este forma continuă actuală a definiției.
Unitatea SI a momentului de inerție: \[ \boxed{ [I] = \mathrm{kg\,m^2} } \] Verificare: \[ [mr^2] = \mathrm{kg\,m^2}. \]
Greșeală foarte frecventă: momentul de inerție nu este o proprietate determinată numai de masa corpului. Este obligatoriu să precizezi axa față de care îl calculezi. Același corp poate avea momente de inerție diferite față de axe diferite.
Nu confunda masa cu momentul de inerție: pentru translație, inerția este caracterizată de masă: \[ F=ma. \] Pentru rotația în jurul unei axe fixe, rolul analog este jucat de momentul de inerție. Legătura dinamică va fi tratată în §5.4.
Teorema axelor paralele — Steiner: \[ \boxed{ I = I_C+Md^2 } \] unde:

\(I_C\) este momentul de inerție față de axa paralelă care trece prin centrul de masă;
\(d\) este distanța dintre cele două axe.
Condiția teoremei Steiner: cele două axe trebuie să fie paralele. Nu se poate aplica relația: \[ I=I_C+Md^2 \] unor două axe arbitrare.
Momente de inerție utile de recunoscut: bară omogenă, axă perpendiculară prin centru: \[ \boxed{ I_C = \frac1{12}Ml^2 } \] bară omogenă, axă perpendiculară prin capăt: \[ \boxed{ I = \frac13Ml^2 } \] disc sau cilindru plin, axă de simetrie: \[ \boxed{ I = \frac12MR^2 } \] inel subțire: \[ \boxed{ I=MR^2 } \] sferă plină, axă prin centru: \[ \boxed{ I = \frac25MR^2 } \]
Conservarea lui \(I\omega\) nu este automată: relația: \[ I_1\omega_1 = I_2\omega_2 \] rezultă din conservarea momentului cinetic numai atunci când momentul extern rezultant este nul în condițiile problemei.
Exemplu conceptual esențial: dacă: \[ I_2\omega_1 } \] Apropierea masei de axă determină creșterea vitezei unghiulare.
Schema de rezolvare pentru conservarea momentului cinetic:

1. alegi sistemul;
2. alegi axa sau punctul față de care calculezi momentele;
3. verifici momentul forțelor exterioare;
4. dacă: \[ M_{\mathrm{ext}}=0, \] scrii: \[ L_i=L_f; \]
5. pentru rotație cu axă fixă folosești: \[ L=I\omega; \]
6. calculezi momentele de inerție față de aceeași axă ;
7. verifici unitățile și sensul fizic.
Observație pentru nivelul de concurs: relația simplă: \[ \vec L=I\vec\omega \] este folosită aici pentru rotația rigidului în jurul unei axe fixe în situațiile analizate. Pentru mișcarea generală tridimensională a rigidului, relația dintre \(\vec L\) și \(\vec\omega\) este mai generală. Această extensie nu este conținutul §5.3 din Compendiu și nu este introdusă aici în corpul lecției.
