5.5 Energia cinetică de rotație

Energia cinetică a punctelor unui corp rigid în rotație, energia cinetică totală de rotație și aplicațiile la rostogolirea cilindrului și a sferei.

Ion Bunget Compendiu de Fizică §5.5
Sursa

Compendiu de Fizică

Partea I. Mecanică și acustică
5. Mișcarea corpului rigid
5.5 Energia cinetică de rotație
Pagina: 149
Punct material

Energia cinetică a unui punct al rigidului

Se consideră un punct material de masă \(m_i\), aparținând unui corp rigid aflat în mișcare de rotație.

Punctul se află la distanța:

\[ r_i \]

față de axa de rotație.

Corpul se rotește cu viteza unghiulară:

\[ \omega. \]
Cinematică

Viteza liniară

Din cinematica rotației:

\[ \boxed{ v_i=\omega r_i } \]

Viteza liniară a punctului depinde de distanța acestuia față de axa de rotație.

Energia cinetică

Aplicarea relației \(W_c=\frac12mv^2\)

Energia cinetică a punctului material este:

\[ W_{c_i} = \frac12m_i v_i^2. \]

Folosind:

\[ v_i=\omega r_i, \]

rezultă relația (5.24):

\[ \boxed{ W_{c_i} = \frac12 m_i r_i^2\omega^2 } \]
Corpul rigid

Energia cinetică totală

Energia cinetică de rotație a întregului corp rigid este suma energiilor cinetice ale tuturor punctelor materiale care îl alcătuiesc.

\[ \boxed{ W_c = \sum_i W_{c_i} } \]

Introducând expresia energiei fiecărui punct:

\[ W_c = \sum_i \frac12 m_i r_i^2\omega^2. \]
Proprietatea rigidului

Aceeași viteză unghiulară

Toate punctele corpului rigid au aceeași viteză unghiulară \(\omega\).

Prin urmare:

\[ W_c = \frac12 \omega^2 \sum_i m_i r_i^2. \]
Momentul de inerție

Introducerea lui \(J\)

Din §5.3:

\[ \boxed{ J = \sum_i m_i r_i^2 } \]

unde \(J\) este momentul de inerție al corpului față de axa de rotație.

Relația (5.25)

Energia cinetică de rotație

Introducând momentul de inerție în suma energiilor cinetice, Compendiul obține:

\[ \boxed{ W_c = \frac12J\omega^2 } \]
Energia cinetică de rotație

Energia cinetică totală a punctelor materiale care alcătuiesc corpul rigid aflat în rotație în jurul axei considerate.

Analogie

Translație și rotație

Translație

\[ W_c = \frac12mv^2 \]

mărimea inerțială este masa:

\[ m. \]

Mărimea cinematică este:

\[ v. \]

Rotație

\[ W_c = \frac12J\omega^2 \]

mărimea inerțială este momentul de inerție:

\[ J. \]

Mărimea cinematică este:

\[ \omega. \]
Axa de rotație

Axa nu trece prin centrul de masă

Compendiul analizează apoi cazul în care axa de rotație nu trece prin centrul de masă al corpului.

Se consideră o axă paralelă cu axa care trece prin centrul de masă.

Distanța dintre cele două axe este:

\[ a. \]
Relația din §5.3

Teorema axelor paralele

Momentul de inerție față de axa de rotație este:

\[ \boxed{ J = J_C+Ma^2 } \]

unde:

\(J_C\) — momentul de inerție față de axa paralelă care trece prin centrul de masă;

\(M\) — masa totală a corpului;

\(a\) — distanța dintre cele două axe.

Relația (5.26)

Energia exprimată prin \(J_C\)

Din:

\[ W_c = \frac12J\omega^2 \]

și:

\[ J = J_C+Ma^2, \]

rezultă:

\[ \boxed{ W_c = \frac12 \left( J_C+Ma^2 \right) \omega^2 } \]

sau:

\[ \boxed{ W_c = \frac12J_C\omega^2 + \frac12Ma^2\omega^2 } \]
Interpretarea relației

Mișcarea centrului de masă

Dacă centrul de masă se află la distanța \(a\) față de axa de rotație, viteza sa este:

\[ v_C=a\omega. \]

Termenul:

\[ \frac12Ma^2\omega^2 \]

poate fi scris:

\[ \boxed{ \frac12Mv_C^2 } \]

Astfel, expresia (5.26) separă contribuția asociată centrului de masă de contribuția rotației în jurul unei axe paralele care trece prin acesta.

Formă echivalentă

Energia exprimată prin centrul de masă

\[ \boxed{ W_c = \frac12Mv_C^2 + \frac12J_C\omega^2 } \]

Relația permite utilizarea momentului de inerție față de o axă care trece prin centrul de masă.

Aplicație

Rostogolirea unui cilindru

Compendiul aplică rezultatul mișcării de rostogolire a unui cilindru pe un plan orizontal.

Mișcarea poate fi privită ca o succesiune de rotații instantanee în jurul generatoarelor de contact dintre cilindru și plan.

Acestea joacă rolul unor axe instantanee de rotație.

Axa instantanee

Poziția axei de rotație

Axa instantanee este perpendiculară pe planul secțiunii reprezentate în figura I.5.10.

Ea trece prin zona de contact dintre cilindru și plan.

Pe măsură ce cilindrul se rostogolește, axa instantanee se deplasează de-a lungul suprafeței.

Geometria cilindrului

Distanța până la centrul de masă

Pentru cilindrul omogen, centrul de masă coincide cu centrul său geometric.

Distanța dintre axa instantanee de rotație și axa paralelă care trece prin centrul cilindrului este:

\[ \boxed{ a=R } \]

unde \(R\) este raza cilindrului.

Relația (5.27)

Energia cilindrului

Aplicând relația (5.26) pentru:

\[ a=R, \]

rezultă:

\[ \boxed{ W_c = \frac12MR^2\omega^2 + \frac12J_C\omega^2 } \]
Cilindru plin omogen

Momentul de inerție față de axa centrală

Pentru cilindrul plin și omogen:

\[ \boxed{ J_C = \frac12MR^2 } \]
Relația (5.28)

Energia cinetică a cilindrului care se rostogolește

Introducând:

\[ J_C = \frac12MR^2, \]

se obține:

\[ W_c = \frac12MR^2\omega^2 + \frac14MR^2\omega^2. \]

Prin urmare:

\[ \boxed{ W_c = \frac34MR^2\omega^2 } \]
A doua aplicație

Rostogolirea unei sfere

Compendiul aplică în mod asemănător metoda unei sfere omogene care se rostogolește.

Pentru sfera plină, momentul de inerție față de o axă care trece prin centrul său este:

\[ \boxed{ J_C = \frac25MR^2 } \]
Relația (5.29)

Energia cinetică a sferei care se rostogolește

Pentru axa instantanee situată la distanța \(R\) de centrul sferei:

\[ W_c = \frac12MR^2\omega^2 + \frac12 \left( \frac25MR^2 \right) \omega^2. \]

Rezultă:

\[ W_c = \frac12MR^2\omega^2 + \frac15MR^2\omega^2. \]
\[ \boxed{ W_c = \frac7{10} MR^2\omega^2 } \]
Comparație

Cilindru și sferă

Cilindru plin omogen

\[ J_C = \frac12MR^2 \]
\[ \boxed{ W_c = \frac34MR^2\omega^2 } \]

Sferă plină omogenă

\[ J_C = \frac25MR^2 \]
\[ \boxed{ W_c = \frac7{10} MR^2\omega^2 } \]
Legătura logică

De la energia punctului la energia rigidului

\[ W_{c_i} = \frac12m_iv_i^2 \]

\[ v_i=\omega r_i \]

\[ W_{c_i} = \frac12 m_i r_i^2\omega^2 \]

Însumarea

\[ W_c = \frac12 \omega^2 \sum_i m_i r_i^2 \]

Momentul de inerție

\[ J = \sum_i m_i r_i^2 \]

Energia de rotație

\[ \boxed{ W_c = \frac12J\omega^2 } \]

Titularizare

Precizări pentru examen

Această secțiune este separată de conținutul §5.5 al Compendiului. Reperul oficial utilizat este programa pentru Titularizare Fizică 2026.

Legătura cu programa 2026

Punctul 5 include energia cinetică și legile de conservare.

Punctul 6 cere explicit:

Mișcarea solidului rigid cu axă fixă. Momente de inerție. Pendulul fizic.

Energia cinetică de rotație constituie una dintre relațiile fundamentale necesare în problemele de dinamică și energie ale rigidului.

Notație actuală: Compendiul utilizează: \[ W_c \] pentru energia cinetică și: \[ J \] pentru momentul de inerție. În notația actuală sunt frecvente: \[ E_c \] și: \[ I. \] Formula devine: \[ \boxed{ E_{c,\mathrm{rot}} = \frac12I\omega^2 } \]
Condiția formulei: \[ E_{c,\mathrm{rot}} = \frac12I\omega^2 \] este energia cinetică asociată rotației rigidului în jurul axei față de care este calculat momentul de inerție \(I\).
Greșeală frecventă: momentul de inerție trebuie calculat față de aceeași axă de rotație care apare în problema energetică. Nu se folosește automat momentul de inerție față de centrul de masă.
Teorema Steiner: pentru două axe paralele, dintre care una trece prin centrul de masă: \[ \boxed{ I=I_C+Md^2 } \] și atunci: \[ E_c = \frac12 \left( I_C+Md^2 \right) \omega^2. \]
Descompunerea energiei: dacă centrul de masă are viteza \(v_C\): \[ \boxed{ E_c = \frac12Mv_C^2 + \frac12I_C\omega^2 } \] Primul termen este asociat mișcării centrului de masă, iar al doilea rotației în jurul centrului de masă.
Atenție: formula: \[ E_c = \frac12Mv_C^2 + \frac12I_C\omega^2 \] nu înseamnă că alegem două corpuri diferite. Sunt două contribuții la energia cinetică a aceluiași corp rigid.
Rostogolire fără alunecare: condiția cinematică este: \[ \boxed{ v_C=R\omega } \] Prin urmare: \[ \boxed{ E_c = \frac12Mv_C^2 + \frac12I_C \frac{v_C^2}{R^2} } \]
Cilindru plin omogen: \[ I_C = \frac12MR^2. \] Pentru rostogolire fără alunecare: \[ E_c = \frac12Mv_C^2 + \frac14Mv_C^2, \] deci: \[ \boxed{ E_c = \frac34Mv_C^2 } \] Echivalent, deoarece: \[ v_C=R\omega, \] \[ \boxed{ E_c = \frac34MR^2\omega^2 } \]
Sferă plină omogenă: \[ I_C = \frac25MR^2. \] Pentru rostogolire fără alunecare: \[ E_c = \frac12Mv_C^2 + \frac15Mv_C^2, \] deci: \[ \boxed{ E_c = \frac7{10}Mv_C^2 } \] sau: \[ \boxed{ E_c = \frac7{10} MR^2\omega^2 } \]
Greșeală importantă la rostogolire: pentru un corp care se rostogolește, nu se ia numai: \[ \frac12Mv_C^2 \] și nici numai: \[ \frac12I_C\omega^2. \] Energia cinetică totală este: \[ \boxed{ E_c = \frac12Mv_C^2 + \frac12I_C\omega^2 } \]
Altă greșeală: relația: \[ v_C=R\omega \] este condiția rostogolirii fără alunecare. Dacă există alunecare, \(v_C\) și \(\omega\) trebuie determinate separat din condițiile problemei.
Unitatea SI: \[ \boxed{ [E_c] = \mathrm J } \] deoarece: \[ [I\omega^2] = \mathrm{kg\,m^2} \cdot \frac{1}{\mathrm{s^2}} \] \[ = \mathrm{kg\,m^2/s^2} = \mathrm J. \]
Analogia utilă: pentru translație: \[ E_c = \frac12mv^2, \] iar pentru rotație: \[ E_{c,\mathrm{rot}} = \frac12I\omega^2. \] Corespondențele sunt: \[ \boxed{ m \longleftrightarrow I } \] și: \[ \boxed{ v \longleftrightarrow \omega } \]
Legătura cu lecțiile precedente: §5.3: \[ L=I\omega; \] §5.4: \[ M=I\alpha; \] §5.5: \[ \boxed{ E_{c,\mathrm{rot}} = \frac12I\omega^2 } \] Aceste trei relații formează nucleul mecanicii rotației în jurul unei axe fixe.
Schema de rezolvare pentru probleme energetice cu rigid:

1. identifici corpul și tipul mișcării;
2. precizezi axa de rotație;
3. calculezi momentul de inerție față de acea axă;
4. stabilești dacă există și translația centrului de masă;
5. pentru rotație scrii: \[ E_{c,\mathrm{rot}} = \frac12I\omega^2; \]
6. pentru mișcarea generală de tip translație + rotație: \[ E_c = \frac12Mv_C^2 + \frac12I_C\omega^2; \]
7. la rostogolire fără alunecare folosești: \[ v_C=R\omega; \]
8. verifici unitățile, condițiile și sensul fizic al rezultatului.
Pendulul fizic: programa 2026 îl cere explicit la punctul 6, dar el nu este tratat în §5.5 al Compendiului. Va trebui adăugat separat ca o completare pentru pregătirea Titularizării.
