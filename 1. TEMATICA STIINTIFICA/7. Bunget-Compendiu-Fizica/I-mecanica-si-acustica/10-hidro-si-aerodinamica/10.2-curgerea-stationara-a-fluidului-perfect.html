Definiție

Linia de curent

Bunget introduce mai întâi traiectoria unei particule de fluid.

Linie de curent

Traiectoria descrisă de o particulă de fluid în mișcarea considerată.

Viteza particulei este tangentă la linia de curent în fiecare punct.

\[ \boxed{ \vec v \text{ este tangentă la linia de curent} } \]
Interpretare

Liniile de curent și direcția vitezei

Cunoașterea liniilor de curent permite, în prezentarea Compendiului, determinarea direcției vitezei fluidului în diferite puncte ale spațiului.

\[ \boxed{ \text{linie de curent} \longrightarrow \text{direcția lui } \vec v } \]
Convenție grafică

Desimea liniilor de curent

Bunget precizează o convenție de reprezentare: liniile de curent sunt desenate mai dese în regiunile în care viteza fluidului este mai mare.

În zonele în care fluidul curge mai lent, liniile sunt reprezentate mai rare.

\[ \boxed{ \text{linii mai dese} \Rightarrow v \text{ mai mare} } \]
Evidențiere experimentală

Particule introduse în fluid

Configurația liniilor de curent poate fi evidențiată experimental prin introducerea unor particule fine în fluid.

Urmărirea traiectoriilor acestora permite vizualizarea mișcării fluidului.

Definiție

Tubul de curent

Tub de curent

Un mănunchi de linii de curent formează un tub de curent.

\[ \boxed{ \text{mănunchi de linii de curent} \Rightarrow \text{tub de curent} } \]
Proprietate

Fluidul rămâne în tubul de curent

Pe suprafața laterală a tubului de curent, viteza fluidului este tangentă.

Componenta vitezei normală pe această suprafață este nulă.

\[ \boxed{ v_n=0 } \]

În modelul descris, particulele nu traversează lateral suprafața tubului de curent.

Definiție

Curgerea staționară

Bunget definește regimul staționar prin constanța în timp a vitezei fluidului într-un punct dat al spațiului.

Mișcare staționară sau regim permanent

În fiecare punct fix al fluidului, viteza rămâne constantă în timp.

\[ \boxed{ \vec v(\vec r) \text{ nu se modifică în timp} } \]
Mărime caracteristică

Debitul

Cantitatea de fluid care traversează o secțiune transversală a tubului de curent în unitatea de timp este numită debit.

Debit

Cantitatea de fluid care trece printr-o secțiune în unitatea de timp.

Pentru curgerea staționară, Bunget consideră debitul constant în timp.

Relațiile (10.1)

Debit masic și debit volumic

Cantitatea de fluid poate fi exprimată prin masă sau prin volum.

Compendiul introduce astfel două debite.

Debit masic

\[ \boxed{ Q_m = \frac{\Delta m}{\Delta t} } \]

Debit volumic

\[ \boxed{ Q_V = \frac{\Delta V}{\Delta t} } \]
Relația (10.2)

Legătura dintre debite

Deoarece:

\[ m=\rho V, \]

debitul masic și debitul volumic sunt legate prin:

\[ \boxed{ Q_m = \rho Q_V } \]
Conservarea masei

Aceeași masă intră și iese

Bunget aplică legea conservării masei unui tub de curent.

În regim staționar, masa care traversează o secțiune într-o secundă trebuie să fie egală cu masa care traversează orice altă secțiune a aceluiași tub.

\[ \boxed{ Q_m = \text{constant} } \]
Relația (10.3)

Masa transportată printr-o secțiune

Pentru o secțiune transversală \(S\), viteza \(v\) și densitatea \(\rho\), masa transportată în unitatea de timp este proporțională cu:

\[ \rho Sv. \]

Pentru două secțiuni:

\[ \boxed{ \rho S_1v_1 = \rho S_2v_2 } \]
Relația (10.4)

Ecuația de continuitate

Pentru fluidul perfect incompresibil, densitatea este aceeași în cele două secțiuni.

Ea se simplifică din relația precedentă.

\[ \boxed{ S_1v_1 = S_2v_2 = \text{constant} } \]
Ecuația de continuitate

Pentru curgerea staționară a fluidului perfect incompresibil, produsul dintre aria secțiunii tubului de curent și viteza fluidului este constant.

Consecință

Viteza și secțiunea

Din ecuația de continuitate:

\[ Sv = \text{constant}, \]

rezultă că viteza este invers proporțională cu aria secțiunii.

\[ \boxed{ v \propto \frac{1}{S} } \]
Conductă cu secțiune variabilă

În porțiunea îngustă viteza crește

Dacă:

\[ \boxed{ v_2>v_1 } \]

Fluidul accelerează atunci când intră într-o regiune mai îngustă a conductei.

Interpretare dinamică

De ce accelerează fluidul

Bunget observă că accelerarea fluidului necesită existența unei forțe.

În interiorul fluidului, această forță este legată de diferența de presiune dintre regiunile conductei.

În situația orizontală analizată conceptual, presiunea este mai mare în regiunea mai largă și mai mică în regiunea îngustată.

\[ \boxed{ S\downarrow \Rightarrow v\uparrow \Rightarrow p\downarrow } \]
Conductă înclinată

Rolul greutății

Pentru o conductă care nu este orizontală, Bunget arată că trebuie luată în considerare și greutatea fluidului.

În analiza energetică vor apărea astfel:

energia cinetică;

energia potențială gravitațională;

lucrul forțelor de presiune.

Masa \(\Delta m\) transportată prin tub

Bunget urmărește deplasarea unei mase:

\[ \boxed{ \Delta m } \]

între două secțiuni ale tubului de curent.

În prima secțiune fluidul are:

\[ v_1,\quad p_1,\quad h_1, \]

iar în cea de-a doua:

\[ v_2,\quad p_2,\quad h_2. \]
Relația (10.5)

Teorema variației energiei cinetice

Bunget aplică teorema energiei cinetice masei de fluid considerate.

\[ \boxed{ \frac{ \Delta m\,v_2^2 }{2} - \frac{ \Delta m\,v_1^2 }{2} = L_{\mathrm{ext}} } \]
Relația (10.6)

Separarea lucrului greutății

Lucrul forțelor exterioare este separat în contribuția greutății și contribuția celorlalte forțe care deplasează masa de fluid.

Regruparea termenilor conduce la compararea energiilor mecanice la cele două secțiuni.

\[ \frac{\Delta m\,v_1^2}{2} + \Delta m\,gh_1 + L_p = \frac{\Delta m\,v_2^2}{2} + \Delta m\,gh_2 \]

unde termenul de lucru datorat presiunilor este analizat separat.

Relația (10.7)

Incompresibilitatea

Masa \(\Delta m\) ocupă la cele două secțiuni volume egale, deoarece fluidul este incompresibil.

\[ \boxed{ \Delta V_1 = \Delta V_2 = \Delta V } \]

Geometric:

\[ S_1\Delta l_1 = S_2\Delta l_2. \]
Relația (10.8)

Lucrul forțelor de presiune

La intrarea în porțiunea analizată, presiunea \(p_1\) efectuează lucru pozitiv.

La ieșire, presiunea \(p_2\) contribuie cu semn opus.

Pentru același volum transportat \(\Delta V\):

\[ \boxed{ L_p = p_1\Delta V - p_2\Delta V } \]
Relația (10.9)

Ecuația lui Bernoulli

Introducând lucrul presiunilor în bilanțul energetic și folosind:

\[ \Delta m = \rho\Delta V, \]

Bunget obține:

\[ \boxed{ p_1 + \rho gh_1 + \frac{\rho v_1^2}{2} = p_2 + \rho gh_2 + \frac{\rho v_2^2}{2} } \]
Forma constantă

Bernoulli de-a lungul curgerii

\[ \boxed{ p + \rho gh + \frac{\rho v^2}{2} = \text{constant} } \]
Ecuația lui Bernoulli

În modelul fluidului perfect studiat de Compendiu, suma termenului de presiune, a termenului gravitațional și a termenului asociat vitezei rămâne constantă de-a lungul tubului de curent analizat.

Interpretare

Toți termenii au dimensiunea unei presiuni

\[ p \]
\[ \rho gh \]
\[ \frac{\rho v^2}{2} \]

apar în aceeași relație și au aceeași dimensiune fizică.

Relația (10.10)

Conductă orizontală

Dacă cele două secțiuni se află la aceeași înălțime:

\[ h_1=h_2, \]

termenul gravitațional se simplifică.

\[ \boxed{ p + \frac{\rho v^2}{2} = \text{constant} } \]
Definiție

Presiunea statică

Bunget numește presiune statică presiunea asociată fluidului în direcțiile normale pe suprafețele conductei.

O notează:

\[ \boxed{ p_s } \]

Presiunea exercitată pe peretele conductei, paralel cu direcția curgerii, este presiunea statică.

Definiție

Presiunea dinamică

Bunget introduce mărimea:

\[ \boxed{ p_d = \frac{\rho v^2}{2} } \]

și o numește presiune dinamică.

Paradoxul hidrodinamic

Viteză mare, presiune statică mai mică

Pentru o conductă orizontală:

\[ p_s + \frac{\rho v^2}{2} = \text{constant}. \]

De aceea, acolo unde viteza este mai mare, presiunea statică este mai mică.

\[ \boxed{ v\uparrow \Rightarrow p_s\downarrow } \]

Bunget numește această manifestare:

\[ \boxed{ \text{paradox hidrodinamic} } \]

Tubul Pitot

Compendiul introduce apoi un tub al cărui orificiu este orientat contra curentului.

Tub Pitot

Tub cu deschiderea orientată spre curent, utilizat pentru punerea în evidență a presiunii totale.

La intrarea în tub

Viteza se anulează

La orificiul orientat contra curentului, fluidul este adus la repaus în punctul de măsurare.

\[ \boxed{ v=0 } \]

Termenul de presiune dinamică se transformă astfel în creștere de presiune statică.

Relația (10.11)

Presiunea totală

Pentru conducta orizontală, relația lui Bernoulli conduce la:

\[ \boxed{ p_t = p_s + \frac{\rho v^2}{2} } \]

Diferența dintre presiunea totală și presiunea statică este presiunea dinamică:

\[ \boxed{ p_t-p_s = p_d = \frac{\rho v^2}{2} } \]
Consecință

Determinarea vitezei

Dacă se măsoară diferența:

\[ p_t-p_s, \]

viteza poate fi obținută din:

\[ \boxed{ v = \sqrt{ \frac{ 2(p_t-p_s) }{ \rho } } } \]
Figura I.10.7

Curgerea printr-un orificiu

Bunget aplică ecuația lui Bernoulli unui vas mare din care lichidul se scurge printr-un orificiu mic.

Diametrul orificiului este considerat mic în comparație cu diametrul vasului.

\[ \boxed{ d\ll D } \]
Consecința geometriei

Viteza suprafeței libere este mică

Deoarece secțiunea vasului este mult mai mare decât cea a orificiului, nivelul lichidului coboară lent.

Viteza suprafeței libere poate fi astfel neglijată în aproximația utilizată de Bunget.

\[ \boxed{ v_1\approx0 } \]
Vas deschis

Presiunile se simplifică

Atât suprafața liberă, cât și jetul de la ieșire se află la presiunea atmosferică.

\[ p_1=p_2=p_{\mathrm{atm}}. \]

Termenii de presiune se simplifică din ecuația Bernoulli.

Relațiile (10.12)–(10.13)

Legătura dintre viteze și diferența de nivel

Pentru cele două puncte, Bunget obține relația:

\[ \boxed{ v_2^2 = v_1^2 + 2g(h_1-h_2) } \]
Relația (10.14)

Teorema lui Torricelli

Dacă viteza suprafeței libere este neglijabilă și diferența verticală dintre suprafața lichidului și orificiu este \(h\):

\[ \boxed{ v = \sqrt{2gh} } \]

Bunget observă că această viteză este egală cu viteza dobândită de un corp în cădere liberă de la aceeași înălțime, în modelul ideal.

Aplicații tehnice

Dispozitive bazate pe efectul Bernoulli

Dintre acestea, Bunget descrie în detaliu pulverizatorul.

Figura I.10.8

Pulverizatorul

Printr-un tub orizontal circulă un curent de aer.

Tubul se îngustează către extremitate, astfel încât viteza aerului crește.

\[ S\downarrow \Rightarrow v\uparrow. \]

Din relația Bernoulli, presiunea statică din regiunea îngustată scade.

\[ \boxed{ p_s < p_{\mathrm{atm}} } \]
Funcționare

Aspirarea lichidului

Diferența dintre presiunea atmosferică din vasul cu lichid și presiunea redusă din zona curentului de aer determină urcarea lichidului prin tubul vertical.

Jetul de aer antrenează apoi lichidul și îl pulverizează.

\[ \boxed{ v_{\mathrm{aer}}\uparrow \Rightarrow p_s\downarrow \Rightarrow \text{lichid aspirat} } \]

Titularizare

Precizări pentru examen

Această secțiune este separată de corpul §10.2 al Compendiului. Reperul oficial utilizat este programa pentru Titularizare Fizică 2026.

Prioritate maximă în capitol

Programa oficială 2026 cere nominal la punctul 13:

Noțiuni de dinamica fluidelor. Ecuația de continuitate. Legea lui Bernoulli.

§10.2 acoperă direct exact aceste două relații fundamentale.

Notație modernă: pentru aria unei secțiuni vom utiliza frecvent: \[ A \] în loc de \(S\). Debitul volumic este: \[ \boxed{ Q = \frac{dV}{dt} } \] iar unitatea SI: \[ \boxed{ [Q] = \mathrm{m^3/s} } \]
Debitul masic: \[ \boxed{ \dot m = \frac{dm}{dt} } \] cu unitatea: \[ \boxed{ [\dot m] = \mathrm{kg/s} } \]
Pentru curgere uniformă pe o secțiune: \[ \boxed{ Q=Av } \] și: \[ \boxed{ \dot m = \rho Av } \]
\(Q=Av\) presupune că viteza utilizată este reprezentativă pentru secțiunea considerată. Pentru un profil neuniform de viteze, forma generală este: \[ Q = \int_A \vec v \cdot d\vec A. \]
Delimitare de sursă: forma integrală a debitului nu este dezvoltată în §10.2 al Compendiului. Este o completare modernă.
Continuitatea — forma generală pentru două secțiuni: \[ \boxed{ \rho_1A_1v_1 = \rho_2A_2v_2 } \] pentru curgere staționară într-un tub de curent, în modelul unidimensional.
Pentru fluid incompresibil: \[ \rho_1=\rho_2. \] Deci: \[ \boxed{ A_1v_1 = A_2v_2 } \]
Nu scrie automat: \[ A_1v_1=A_2v_2 \] pentru un gaz cu variații importante de densitate. Forma sigură este: \[ \boxed{ \rho_1A_1v_1 = \rho_2A_2v_2 } \] atunci când densitățile nu se pot simplifica.
Verificare dimensională pentru debit: \[ [Av] = \mathrm{m^2} \cdot \mathrm{m/s} \] \[ = \boxed{ \mathrm{m^3/s} }. \]
Verificare intuitivă: dacă: \[ A_2 = \frac{A_1}{4}, \] atunci pentru fluid incompresibil: \[ A_1v_1 = A_2v_2. \] Deci: \[ \boxed{ v_2=4v_1 } \]
Dacă sunt date diametre: nu folosi direct raportul diametrelor. Pentru conducte circulare: \[ A = \frac{\pi d^2}{4}. \] Prin urmare: \[ \boxed{ \frac{v_2}{v_1} = \frac{A_1}{A_2} = \frac{d_1^2}{d_2^2} } \]
Ecuația Bernoulli — forma de presiuni: \[ \boxed{ p + \rho gz + \frac{1}{2}\rho v^2 = \text{constant} } \] de-a lungul aceleiași linii de curent, în condițiile modelului.
Între două puncte: \[ \boxed{ p_1 + \rho gz_1 + \frac{\rho v_1^2}{2} = p_2 + \rho gz_2 + \frac{\rho v_2^2}{2} } \]
Condițiile trebuie spuse. Forma elementară utilizată aici presupune:

curgere staționară;
fluid nevâscos;
fluid incompresibil;
aplicare de-a lungul aceleiași linii de curent;
câmp gravitațional considerat uniform;
absența dispozitivelor care introduc sau extrag energie mecanică între punctele analizate.
„Bernoulli” nu înseamnă pur și simplu „viteză mare = presiune mică” în orice situație. Trebuie comparate toate cele trei contribuții: \[ p, \qquad \rho gz, \qquad \frac{\rho v^2}{2}. \]
Conductă orizontală: dacă: \[ z_1=z_2, \] atunci: \[ \boxed{ p_1 + \frac{\rho v_1^2}{2} = p_2 + \frac{\rho v_2^2}{2} } \]
Continuitate + Bernoulli: dacă într-o conductă orizontală: \[ A_2v_1 \] și: \[ \boxed{ p_2
Eroare frecventă: afirmația că presiunea scade „pentru că tubul este mai îngust”. Raționamentul complet este: \[ A\downarrow \Rightarrow v\uparrow \] prin continuitate, apoi: \[ v\uparrow \Rightarrow p\downarrow \] prin Bernoulli, pentru aceeași cotă și în condițiile modelului.
Ce reprezintă termenii lui Bernoulli: presiunea statică: \[ \boxed{ p } \] contribuția gravitațională: \[ \boxed{ \rho gz } \] presiunea dinamică: \[ \boxed{ q = \frac{1}{2}\rho v^2 } \]
Notație modernă: presiunea dinamică este notată frecvent: \[ q \] pentru a evita confuzia cu presiunea statică \(p\). Bunget utilizează notația \(p_d\).
Verificare dimensională: \[ \left[ \frac{1}{2}\rho v^2 \right] = \frac{\mathrm{kg}}{\mathrm{m^3}} \cdot \frac{\mathrm{m^2}}{\mathrm{s^2}} \] \[ = \frac{ \mathrm{kg} }{ \mathrm{m\,s^2} } \] \[ = \boxed{ \mathrm{Pa} }. \]
Și termenul gravitațional: \[ [\rho gz] = \frac{\mathrm{kg}}{\mathrm{m^3}} \cdot \frac{\mathrm m}{\mathrm{s^2}} \cdot \mathrm m \] \[ = \boxed{ \mathrm{Pa} }. \]
Forma energetică pe unitatea de masă: împărțind Bernoulli prin \(\rho\): \[ \boxed{ \frac{p}{\rho} + gz + \frac{v^2}{2} = \text{constant} } \]
Forma pe unitatea de greutate: împărțind prin \(\rho g\): \[ \boxed{ \frac{p}{\rho g} + z + \frac{v^2}{2g} = \text{constant} } \]
Delimitare de sursă: Bunget lucrează în §10.2 cu forma având dimensiune de presiune: \[ p+\rho gh+\frac{\rho v^2}{2}. \] Formele pe unitatea de masă și de greutate sunt completări moderne echivalente algebric.
Tubul Pitot: la punctul de stagnare: \[ v=0. \] Pentru aceeași cotă: \[ p_t = p_s + \frac{\rho v^2}{2}. \] Deci: \[ \boxed{ v = \sqrt{ \frac{ 2(p_t-p_s) }{ \rho } } } \]
Presiune totală ≠ presiune dinamică. Pentru aceeași cotă: \[ p_t = p_s+p_d. \] Prin urmare: \[ \boxed{ p_d = p_t-p_s } \]
Teorema lui Torricelli: pentru un rezervor mare, deschis, cu orificiu mic și fluid perfect: \[ \boxed{ v = \sqrt{2gh} } \]
Condițiile lui Torricelli:

vas suficient de larg față de orificiu;
viteza suprafeței libere neglijabilă;
aceeași presiune la suprafață și la ieșire;
fluid practic incompresibil;
pierderi vâscoase neglijate.
\(h\) este diferența verticală de nivel. Nu este distanța parcursă de lichid în interiorul vasului.
Interpretarea energetică a lui Torricelli: scăderea energiei potențiale gravitaționale pe unitatea de masă: \[ gh \] se transformă în: \[ \frac{v^2}{2}. \] Deci: \[ gh = \frac{v^2}{2}. \]
Nu confunda legea lui Torricelli din dinamica fluidelor cu experimentul lui Torricelli privind presiunea atmosferică. Sunt două contexte fizice diferite.
Pulverizatorul: explicația corectă este construită în doi pași: \[ A\downarrow \Rightarrow v_{\mathrm{aer}}\uparrow \] apoi: \[ p_s\downarrow. \] Presiunea atmosferică mai mare asupra lichidului din rezervor îl împinge în sus prin tubul vertical.
Formulare de evitat: „aerul rapid trage lichidul în sus”. Mai precis, viteza mare a aerului este asociată unei presiuni statice mai mici în regiunea respectivă, iar diferența de presiune produce urcarea lichidului.
Schema de rezolvare — continuitate:

1. transformă datele în SI;
2. identifică secțiunile;
3. calculează ariile;
4. verifică dacă densitatea este constantă;
5. scrie: \[ \rho_1A_1v_1 = \rho_2A_2v_2; \]
6. pentru fluid incompresibil: \[ A_1v_1 = A_2v_2; \]
7. verifică dacă în secțiunea mai mică ai obținut viteza mai mare.
Schema de rezolvare — Bernoulli:

1. alege punctele 1 și 2;
2. notează: \[ p_1,\; v_1,\; z_1; \]
3. notează: \[ p_2,\; v_2,\; z_2; \]
4. verifică ipotezele;
5. scrie: \[ p_1 + \rho gz_1 + \frac{\rho v_1^2}{2} = p_2 + \rho gz_2 + \frac{\rho v_2^2}{2}; \]
6. folosește continuitatea dacă vitezele sunt necunoscute;
7. simplifică numai termenii justificați;
8. calculează simbolic;
9. introdu datele numerice;
10. verifică unitățile și sensul fizic.
Cinci erori de evitat la concurs:

1. inversarea raportului ariilor în continuitate;

2. folosirea diametrelor în locul pătratelor diametrelor;

3. aplicarea lui Bernoulli fără verificarea ipotezelor;

4. uitarea termenului \(\rho gz\) când punctele sunt la cote diferite;

5. confundarea presiunii statice, dinamice și totale.
Nucleul de memorat pentru Titularizare: debit: \[ \boxed{ Q=Av } \] continuitate generală: \[ \boxed{ \rho_1A_1v_1 = \rho_2A_2v_2 } \] fluid incompresibil: \[ \boxed{ A_1v_1 = A_2v_2 } \] Bernoulli: \[ \boxed{ p + \rho gz + \frac{\rho v^2}{2} = \text{constant} } \] presiune dinamică: \[ \boxed{ p_d = \frac{\rho v^2}{2} } \] Pitot: \[ \boxed{ p_t-p_s = \frac{\rho v^2}{2} } \] Torricelli: \[ \boxed{ v=\sqrt{2gh} } \]
Legătura didactică: această lecție este foarte potrivită pentru problematizare și investigație. Întrebarea:

„De ce într-o conductă mai îngustă apa curge mai repede?”

conduce natural la conservarea masei. Întrebarea:

„Ce se întâmplă cu presiunea?”

conduce apoi la ecuația Bernoulli.
Ordinea pedagogică recomandată: nu începe prin memorarea simultană a celor două formule. Construiește:

tub de curent;
conservarea masei;
continuitatea;
necesitatea unei diferențe de presiune;
bilanțul energetic;
Bernoulli;
aplicațiile.
