Sursă de energie

Apa în cădere

Bunget prezintă energia apei în cădere ca sursă naturală de energie mecanică.

Căderea apei poate fi utilizată pentru punerea în mișcare a unei roți hidraulice.

\[ \boxed{ \text{energia potențială a apei} \longrightarrow \text{lucru mecanic} } \]
Dispozitiv

Roata hidraulică

Roată hidraulică

Dispozitiv pus în mișcare prin energia mecanică furnizată de apa aflată în cădere.

Relația (10.22)

Lucrul mecanic disponibil

Se consideră o masă \(m\) de apă care cade de la înălțimea \(h\), măsurată față de nivelul roții hidraulice.

Lucrul mecanic pe care apa îl poate efectua este egal cu scăderea energiei sale potențiale gravitaționale.

\[ \boxed{ L=mgh } \]
Mărimile din relație

\(m\), \(g\) și \(h\)

\(m\)

masa apei;

\(g\)

accelerația gravitațională;

\(h\)

diferența de nivel față de roata hidraulică în modelul considerat.

Relația (10.23)

Puterea apei

Puterea este raportul dintre lucrul mecanic și intervalul de timp:

\[ P = \frac{L}{\Delta t}. \]

Folosind:

\[ L=mgh, \]

rezultă:

\[ P = \frac{m}{\Delta t} gh. \]

Cum raportul:

\[ Q_m = \frac{m}{\Delta t} \]

reprezintă debitul masic, Bunget obține:

\[ \boxed{ P = Q_mgh } \]
Debit

Rolul debitului masic

Puterea disponibilă crește atunci când prin instalație trece o masă mai mare de apă în unitatea de timp.

\[ \boxed{ Q_m\uparrow \Rightarrow P\uparrow } \]

pentru aceleași valori ale lui \(g\) și \(h\).

Căderea de apă

Rolul înălțimii

Pentru același debit masic, o diferență mai mare de nivel înseamnă o energie potențială mai mare disponibilă pentru fiecare unitate de masă.

\[ \boxed{ h\uparrow \Rightarrow P\uparrow } \]
Puterea utilă

Arborele roții hidraulice

Nu întreaga putere asociată apei este transmisă arborelui roții.

Relația (10.24)

Randamentul

Raportul dintre puterea utilă și puterea disponibilă este randamentul dispozitivului.

\[ \boxed{ \eta = \frac{P_u}{P} } \]
Valoarea indicată de sursă

Roata hidraulică

Pentru roata hidraulică discutată în Compendiu, Bunget indică un randament aproximativ:

\[ \boxed{ \eta \approx 0{,}75 } \]

Din punct de vedere tehnic, se urmărește obținerea unui randament cât mai mare.

Dispozitive perfecționate

Turbinele

Bunget arată că roata hidraulică simplă a fost înlocuită, în aplicații tehnice, de dispozitive mai perfecționate.

Acestea sunt turbinele, concepute pentru valorificarea mai eficientă a energiei apei.

Turbină hidraulică

Dispozitiv care transformă o parte din energia mecanică a apei în energie mecanică de rotație a rotorului.

Figura I.10.14

Turbina Pelton

Ca exemplu, Bunget prezintă turbina Pelton.

Ea este acționată de un jet de apă cu viteză mare, obținut printr-o conductă care se îngustează treptat către ieșire.

Partea terminală a conductei este numită:

\[ \boxed{ \text{ajutaj} } \]
Ajutajul

Obținerea jetului

Secțiunea conductei scade către ieșire, astfel încât apa este evacuată sub forma unui jet cu viteză mare.

\[ \boxed{ S\downarrow \Rightarrow v\uparrow } \]

conform principiului de continuitate discutat în §10.2.

Figura I.10.15 a

Cupele rotorului

Rotorul turbinei Pelton este prevăzut cu cupe concave.

În mijlocul unei cupe există o muchie care împarte jetul în două părți.

Geometria cupei determină schimbarea puternică a direcției de curgere a apei.

Variația vitezei

Inversarea jetului

În modelul idealizat prezentat de Bunget, viteza jetului își inversează sensul.

Dacă viteza inițială este \(v\), iar cea finală este aproximată prin \(-v\), modulul variației este:

\[ \boxed{ |\Delta v| = |(-v)-v| = 2v } \]
Impuls

Variația impulsului în unitatea de timp

Dacă debitul masic al jetului este:

\[ Q_m, \]

atunci variația impulsului fluidului în unitatea de timp are modulul:

\[ \boxed{ \frac{|\Delta p|}{\Delta t} = 2Q_mv } \]
Forța asupra fluidului

Relația dintre forță și variația impulsului

Din teorema impulsului, Bunget obține pentru modulul forței exercitate asupra jetului:

\[ \boxed{ F = 2Q_mv } \]
Principiul al treilea

Forța asupra cupei

Cupa modifică impulsul jetului.

Jetul exercită, la rândul său, asupra cupei o forță egală în modul și de sens opus.

\[ \boxed{ F_{\text{apă asupra cupei}} = 2Q_mv } \]

în modelul idealizat al inversării complete a vitezei jetului.

Figura I.10.15 b

De ce este utilă schimbarea mare a direcției

Bunget compară cupa Pelton cu o paletă care ar reduce viteza finală a apei aproximativ la zero, fără inversarea sensului.

În acest al doilea caz:

\[ |\Delta v| \approx v. \]

Forța ar avea modulul:

\[ F \approx Q_mv. \]
Concluzia comparației

Inversarea jetului mărește transferul de impuls

Pentru același debit masic și aceeași viteză inițială, inversarea ideală a vitezei produce o variație de impuls de două ori mai mare decât simpla oprire a jetului.

\[ \boxed{ 2Q_mv = 2(Q_mv) } \]

De aceea, geometria cupelor Pelton permite obținerea unei forțe mai mari asupra rotorului în modelul descris.

Titularizare

Precizări pentru examen

Această secțiune este separată de corpul §10.5 al Compendiului. Reperul oficial utilizat este programa pentru Titularizare Fizică 2026.

Statut în programa 2026

„Energia hidraulică” și „turbina Pelton” nu sunt nominalizate ca teme științifice independente.

Programa cere însă explicit:

Noțiuni de dinamica fluidelor. Ecuația de continuitate. Legea lui Bernoulli.

§10.5 este deci o aplicație integratoare a energiei mecanice, debitului, continuității și variației impulsului.

Debit masic: în notație modernă: \[ \boxed{ \dot m = \frac{dm}{dt} } \] cu unitatea SI: \[ \boxed{ [\dot m] = \mathrm{kg/s} } \]
Debit volumic: \[ \boxed{ Q = \frac{dV}{dt} } \] cu: \[ \boxed{ [Q] = \mathrm{m^3/s} } \]
Legătura dintre debite: pentru densitate uniformă: \[ \boxed{ \dot m = \rho Q } \]
Puterea hidraulică asociată unei căderi \(H\): din relația Bunget: \[ P = Q_mgh \] și: \[ Q_m = \rho Q, \] rezultă: \[ \boxed{ P_h = \rho gQH } \]
Notația modernă \(H\): este utilizată aici pentru diferența de nivel sau „căderea” hidraulică, pentru a nu o confunda cu alte înălțimi din problemă. Bunget utilizează direct \(h\).
Unități SI: \[ [\rho] = \mathrm{kg/m^3}, \] \[ [g] = \mathrm{m/s^2}, \] \[ [Q] = \mathrm{m^3/s}, \] \[ [H] = \mathrm m. \] Rezultă: \[ \boxed{ [P_h]=\mathrm W } \]
Verificare dimensională: \[ [\rho gQH] = \frac{\mathrm{kg}}{\mathrm{m^3}} \cdot \frac{\mathrm m}{\mathrm{s^2}} \cdot \frac{\mathrm{m^3}}{\mathrm s} \cdot \mathrm m \] \[ = \frac{ \mathrm{kg\,m^2} }{ \mathrm{s^3} } \] \[ = \boxed{ \mathrm W }. \]
Puterea utilă a turbinei: \[ \eta = \frac{P_u}{P_h}. \] Prin urmare: \[ \boxed{ P_u = \eta \rho gQH } \]
Randamentul este adimensional: \[ \boxed{ 0<\eta<1 } \] pentru o instalație reală pasivă, în condițiile definiției uzuale.
Valoarea: \[ \eta\approx0{,}75 \] din corpul lecției este valoarea aproximativă dată de Bunget pentru roata hidraulică discutată în sursa din 1972. Nu trebuie tratată drept randament universal al turbinelor hidraulice.
Legătura cu Bernoulli: termenul: \[ \rho gH \] are dimensiunea unei presiuni: \[ [\rho gH] = \mathrm{Pa}. \] Înmulțind cu debitul volumic: \[ Q, \] obținem putere: \[ \boxed{ P = \Delta p\,Q } \] în cazul în care diferența de presiune este cea care furnizează transferul de energie.
Interpretare energetică: \[ \rho gQH \] reprezintă energia potențială gravitațională transportată de apă în unitatea de timp, în modelul simplificat.
Turbina Pelton — ideea centrală: forța asupra rotorului provine din modificarea impulsului jetului. Forma generală este: \[ \boxed{ \vec F = \frac{d\vec p}{dt} } \]
Pentru curgere staționară și un singur jet: forma vectorială utilă este: \[ \boxed{ \vec F_{\text{asupra fluidului}} = \dot m \left( \vec v_{\mathrm{ieșire}} - \vec v_{\mathrm{intrare}} \right) } \]
Forța asupra cupei are sens opus: prin principiul al treilea al mecanicii: \[ \boxed{ \vec F_{\text{fluid asupra cupei}} = - \vec F_{\text{cupă asupra fluidului}} } \]
Caz idealizat Bunget: dacă: \[ \vec v_i = v\hat x \] și: \[ \vec v_f = -v\hat x, \] atunci: \[ \Delta\vec v = -2v\hat x. \] Modulul forței este: \[ \boxed{ F = 2\dot mv } \]
Dacă jetul este numai oprit: \[ \vec v_f \approx \vec0. \] Atunci: \[ |\Delta\vec v| \approx v \] și: \[ \boxed{ F \approx \dot mv } \]
De aceea, schimbarea direcției contează. Forța nu depinde numai de cât de mult încetinește apa, ci de variația vectorului viteză.
Eroare frecventă: dacă viteza trece de la \(+v\) la \(-v\), variația nu este zero. Corect: \[ \Delta v = -v-v = -2v. \] Prin urmare: \[ \boxed{ |\Delta v|=2v } \]
Legătura cu continuitatea: pentru un jet de secțiune \(A\): \[ Q=Av \] și: \[ \dot m = \rho Av. \] În modelul idealizat cu inversarea jetului: \[ F = 2\dot mv. \] Deci: \[ \boxed{ F = 2\rho Av^2 } \] pentru aceleași ipoteze.
Delimitare de sursă: relația: \[ F=2\rho Av^2 \] este o combinație modernă între continuitate și rezultatul Pelton din §10.5. Nu este scrisă explicit de Bunget în această formă.
Transferul de energie și transferul de impuls sunt două analize complementare: pentru energia apei: \[ L=mgh, \] iar pentru acțiunea jetului asupra paletei: \[ \vec F = \frac{d\vec p}{dt}. \]
Nu confunda: impulsul: \[ \vec p=m\vec v \] cu presiunea: \[ p. \] Au aceeași literă în multe notații, dar sunt mărimi fizice complet diferite.
Unități: impuls: \[ [\vec p] = \mathrm{kg\,m/s}; \] presiune: \[ [p] = \mathrm{Pa}. \]
Schema de rezolvare — putere hidraulică:

1. transformă datele în SI;
2. identifică debitul volumic \(Q\) sau debitul masic \(\dot m\);
3. identifică diferența de nivel \(H\);
4. scrie: \[ P_h = \rho gQH \] sau: \[ P_h = \dot mgH; \]
5. dacă există randament: \[ P_u = \eta P_h; \]
6. verifică unitatea: \[ \mathrm W. \]
Schema de rezolvare — jet pe paletă:

1. stabilește axa și sensul pozitiv;
2. scrie viteza inițială vectorial;
3. scrie viteza finală vectorial;
4. calculează: \[ \Delta\vec v = \vec v_f-\vec v_i; \]
5. folosește: \[ \vec F_{\text{asupra fluidului}} = \dot m\Delta\vec v; \]
6. aplică principiul acțiunii și reacțiunii pentru forța asupra paletei;
7. verifică unitatea: \[ \mathrm N. \]
Cinci erori de evitat:

1. confundarea debitului masic cu debitul volumic;

2. omiterea densității când treci de la \(Q\) la \(\dot m\);

3. folosirea lui \(P_h=\eta\rho gQH\) drept putere disponibilă înaintea turbinei;

4. tratarea vitezei ca scalar atunci când jetul își schimbă direcția;

5. considerarea valorii \(\eta\approx0{,}75\) drept constantă universală.
Nucleul de memorat: energie: \[ \boxed{ L=mgh } \] debit masic: \[ \boxed{ \dot m=\rho Q } \] putere hidraulică: \[ \boxed{ P_h = \rho gQH } \] putere utilă: \[ \boxed{ P_u = \eta\rho gQH } \] forța jetului: \[ \boxed{ \vec F = \dot m \Delta\vec v } \] inversare ideală: \[ \boxed{ F=2\dot mv } \]
