9.3 Presiunea hidrostatică

Presiunea produsă de greutatea lichidului, dependența de adâncime, diferența de presiune între două niveluri, independența de forma vasului, presiunea asupra pereților, butoiul lui Pascal și vasele comunicante cu lichide de densități diferite.

Ion Bunget Compendiu de Fizică §9.3

Modelul de calcul

Coloana de lichid

Bunget consideră un vas cilindric care conține un lichid.

În interiorul lichidului se consideră un strat orizontal \(A'B'\), cu aria:

\[ \boxed{ S } \]

aflat la adâncimea:

\[ \boxed{ h } \]

față de suprafața liberă.

Relația (9.9)

Greutatea coloanei de lichid

Asupra stratului \(A'B'\) apasă coloana de lichid situată deasupra sa.

Volumul acestei coloane este:

\[ V=Sh. \]

Dacă densitatea lichidului este \(\rho\), masa coloanei este:

\[ m=\rho V. \]

Prin urmare:

\[ m=\rho Sh. \]

Greutatea coloanei de lichid este:

\[ \boxed{ G = mg = \rho Shg } \]
Relația (9.10)

Presiunea hidrostatică

Din definiția presiunii:

\[ p=\frac GS. \]

Introducând greutatea:

\[ G=\rho Shg, \]

se obține:

\[ \boxed{ p=\rho gh } \]
Presiune hidrostatică

Presiunea produsă, în modelul considerat, de greutatea coloanei de lichid situate deasupra nivelului analizat.

Mărimile din relație

\(\rho\), \(g\) și \(h\)

\(\rho\)

densitatea lichidului;

\(g\)

accelerația gravitațională;

\(h\)

adâncimea punctului față de suprafața liberă.

\[ \boxed{ p=\rho gh } \]
Consecință

Presiunea crește cu adâncimea

Pentru același lichid și aceeași accelerație gravitațională:

\[ \rho=\text{constant}, \qquad g=\text{constant}. \]

Din:

\[ p=\rho gh \]

rezultă:

\[ \boxed{ p\propto h } \]

Cu cât adâncimea este mai mare, cu atât presiunea hidrostatică este mai mare.

Altă dependență

Rolul densității

Pentru aceeași adâncime și aceeași valoare a accelerației gravitaționale:

\[ \boxed{ p\propto\rho } \]

Un lichid mai dens produce o presiune hidrostatică mai mare la aceeași adâncime.

Relația (9.10 a)

Două puncte la adâncimi diferite

Bunget consideră două puncte din același lichid situate la adâncimile:

\[ h_1 \qquad\text{și}\qquad h_2. \]

Presiunile hidrostatice sunt:

\[ p_1=\rho gh_1, \]
\[ p_2=\rho gh_2. \]

Diferența este:

\[ \boxed{ \Delta p = p_1-p_2 = \rho g \left( h_1-h_2 \right) } \]
Caz particular

Puncte aflate la aceeași adâncime

Dacă:

\[ h_1=h_2, \]

atunci:

\[ \Delta p=0. \]

Prin urmare:

\[ \boxed{ p_1=p_2 } \]

Presiunea hidrostatică are aceeași valoare în punctele situate în același plan orizontal, pentru același lichid aflat în echilibru.

Figura I.9.3

Independența de forma vasului

Bunget subliniază că presiunea hidrostatică nu depinde de forma vasului.

Pentru un lichid dat, valoarea ei este determinată de adâncimea punctului considerat.

\[ \boxed{ p=\rho gh } \]
\[ \boxed{ p \text{ nu depinde de forma vasului} } \]
Argument

Coloana de lichid relevantă

Pentru o porțiune de suprafață aflată la adâncimea \(h\), Bunget consideră coloana de lichid corespunzătoare acelei porțiuni.

Greutatea ei este proporțională cu:

\[ \rho Shg. \]

Împărțirea prin aria \(S\) conduce din nou la:

\[ \boxed{ p=\rho gh } \]
Echilibrul stratului

Acțiunea de jos în sus

Stratul de lichid analizat se află în repaus.

De aceea, acțiunea datorată presiunii exercitate de coloana de deasupra trebuie compensată de o acțiune de sens opus.

\[ \boxed{ \text{echilibru} \Rightarrow \text{forțe de presiune care se compensează} } \]
Suprafețe solide

Presiunea asupra unui corp aflat în lichid

Compendiul precizează că suprafețele solide aflate în contact cu lichidul suportă acțiunea presiunii hidrostatice.

Forța exercitată de lichid este orientată normal pe suprafața corpului.

\[ \boxed{ \vec F_p \perp \text{suprafața} } \]
Orientarea suprafeței

Presiunea este exercitată pe orice suprafață udată

Acțiunea normală a lichidului apare indiferent de orientarea suprafeței solide.

Astfel, nu numai fundul vasului, ci și pereții laterali sunt supuși presiunii hidrostatice.

Fundul vasului

Presiunea la adâncimea \(h\)

Pentru un vas în care lichidul are înălțimea \(h\), fundul vasului este supus presiunii:

\[ \boxed{ p=\rho gh } \]

în raport cu nivelul suprafeței libere ales în analiza Compendiului.

Pereții laterali

Presiunea și legea lui Pascal

Bunget leagă acțiunea pe pereții laterali de transmiterea presiunii în toate direcțiile.

La o anumită adâncime \(h\), presiunea hidrostatică are valoarea:

\[ \boxed{ p=\rho gh } \]

iar forța exercitată asupra peretelui este normală pe suprafața acestuia.

Observație experimentală

Jetul printr-un orificiu lateral

Compendiul arată că dacă peretele vasului este perforat, lichidul este împins spre exterior.

Direcția inițială a jetului este normală pe suprafața laterală a vasului.

\[ \boxed{ \text{jet inițial} \perp \text{perete} } \]
Figura I.9.4

Butoiul lui Pascal

Bunget descrie o experiență cunoscută sub numele de butoiul lui Pascal.

Un butoi este umplut cu apă, iar în partea superioară este montat un tub subțire și foarte înalt.

Tubul este umplut la rândul său cu apă.

Efectul experienței

O coloană înaltă, presiune mare

Presiunea hidrostatică în interiorul butoiului crește deoarece înălțimea coloanei de lichid crește.

\[ \boxed{ p=\rho gh } \]

Chiar dacă tubul are o secțiune mică, înălțimea mare a coloanei poate produce o presiune considerabilă.

Consecință

Forțe mari pe pereții butoiului

Presiunea se exercită asupra pereților interiori ai butoiului.

Pentru o suprafață asupra căreia presiunea poate fi considerată uniformă:

\[ F=pS. \]

O presiune mare aplicată unei suprafețe suficient de mari poate produce forțe foarte mari.

Ideea experimentului

Presiunea nu este determinată de cantitatea totală de lichid

Experiența ilustrează proprietatea deja stabilită:

\[ \boxed{ p=\rho gh } \]

Pentru presiunea la un anumit nivel, contează înălțimea coloanei de lichid și densitatea sa, nu forma vasului.

Figura I.9.5

Două lichide în vase comunicante

Bunget aplică apoi presiunea hidrostatică la vase comunicante care conțin două lichide cu densități diferite.

Lichidele sunt considerate:

fără reacție chimică între ele;

nemiscibile.

Exemplul Compendiului

Mercur și apă

Bunget consideră mai întâi mercur în cele două ramuri.

Inițial, mercurul se găsește la același nivel în cele două ramuri.

Apoi se toarnă apă într-una dintre ramuri.

Nivelul mercurului coboară în acea ramură și urcă în cealaltă, până la stabilirea unui nou echilibru.

Condiția de echilibru

Egalitatea presiunilor la același nivel

În starea de echilibru, presiunile produse de cele două coloane se compensează la nivelul comun ales.

\[ \rho_1gh_1 = \rho_2gh_2. \]

Factorul \(g\) se simplifică:

\[ \boxed{ \rho_1h_1 = \rho_2h_2 } \]
Relația (9.11)

Înălțimi și densități

Din:

\[ \rho_1h_1 = \rho_2h_2 \]

rezultă:

\[ \boxed{ \frac{h_1}{h_2} = \frac{\rho_2}{\rho_1} } \]

Bunget concluzionează că denivelările sunt invers proporționale cu densitățile celor două lichide.

Interpretare

Lichidul mai dens

Dacă:

\[ \rho_1>\rho_2, \]

atunci:

\[ h_1

Coloana lichidului mai dens trebuie să fie mai mică pentru a produce aceeași presiune hidrostatică.

\[ \boxed{ \rho\uparrow \Rightarrow h\downarrow } \]

în condiția de echilibru dintre cele două coloane.

Titularizare

Precizări pentru examen

Această secțiune este separată de corpul §9.3 al Compendiului. Reperul oficial utilizat este programa pentru Titularizare Fizică 2026.

Prioritate directă

Programa oficială 2026 cere explicit:

Noțiuni de statica fluidelor. Legile hidrostaticii.

§9.3 este, prin urmare, conținut de prioritate ridicată pentru concurs.

Relația fundamentală: pentru un lichid omogen, practic incompresibil, în repaus, într-un câmp gravitațional uniform: \[ \boxed{ p_h=\rho gh } \] unde \(p_h\) este creșterea hidrostatică a presiunii față de suprafața de referință.
Precizare foarte importantă: formula: \[ p=\rho gh \] din §9.3 exprimă presiunea hidrostatică datorată coloanei de lichid. Dacă asupra suprafeței libere există o presiune \(p_0\), presiunea totală la adâncimea \(h\) este: \[ \boxed{ p_{\mathrm{total}} = p_0+\rho gh } \]
Pentru un vas deschis: la suprafața liberă: \[ p_0=p_{\mathrm{atm}}. \] Atunci: \[ \boxed{ p_{\mathrm{abs}} = p_{\mathrm{atm}} + \rho gh } \]
Presiunea manometrică: dacă luăm presiunea atmosferică drept referință: \[ \boxed{ p_{\mathrm{man}} = \rho gh } \]
Nu confunda: presiunea absolută: \[ p_{\mathrm{abs}} \] cu presiunea față de atmosferă: \[ p_{\mathrm{man}}. \] Într-un vas deschis: \[ p_{\mathrm{abs}} = p_{\mathrm{atm}} + p_{\mathrm{man}}. \]
Unități SI: \[ [\rho] = \mathrm{kg/m^3} \] \[ [g] = \mathrm{m/s^2} \] \[ [h] = \mathrm m \] \[ \boxed{ [p] = \mathrm{Pa} } \]
Verificare dimensională: \[ [\rho gh] = \frac{\mathrm{kg}}{\mathrm{m^3}} \cdot \frac{\mathrm m}{\mathrm{s^2}} \cdot \mathrm m \] \[ = \frac{ \mathrm{kg} }{ \mathrm{m\,s^2} } \] \[ = \frac{\mathrm N}{\mathrm{m^2}} \] \[ = \boxed{ \mathrm{Pa} }. \]
Adâncimea \(h\): este distanța verticală față de suprafața de referință. Nu este lungimea unui traseu oblic prin lichid.
Test de sens fizic: dacă: \[ h=0, \] atunci: \[ p_h=0. \] Dacă: \[ h \] se dublează, pentru \(\rho\) și \(g\) constante: \[ \boxed{ p_h \text{ se dublează} } \]
Între două niveluri: forma cea mai sigură este: \[ \boxed{ p_2-p_1 = \rho g (h_2-h_1) } \] dacă \(h\) este măsurată pozitiv în jos de la aceeași suprafață de referință.
Semnul depinde de convenția pentru \(h\). Fizic, punctul aflat mai jos într-un lichid în repaus are presiunea mai mare.
Forma generală pe verticală: dacă axa \(z\) este orientată în sus: \[ \boxed{ \frac{dp}{dz} = -\rho g } \] pentru densitate constantă și câmp gravitațional uniform.
Delimitare de sursă: forma diferențială: \[ \frac{dp}{dz} = -\rho g \] este o completare modernă. Bunget formulează §9.3 prin relațiile finite dintre presiune și adâncime.
Din forma diferențială: pentru \(\rho\) constant: \[ dp=-\rho g\,dz. \] Integrarea între suprafață și punctul aflat la adâncimea \(h\) conduce la: \[ \boxed{ p-p_0 = \rho gh } \]
Forma vasului nu intră în formulă: \[ p_h=\rho gh. \] Nu apar:

volumul total al lichidului;
aria fundului;
forma pereților;
masa totală a lichidului din vas.
Paradoxul hidrostatic: vase cu forme diferite pot avea aceeași presiune la fund dacă au: \[ \boxed{ \rho \text{ și } h \text{ identice} } \] chiar dacă volumele de lichid sunt diferite.
Dar presiune egală nu înseamnă automat forță totală egală. Pentru o suprafață plană orizontală pe care presiunea este uniformă: \[ F=pA. \] Dacă ariile diferă, forțele pot diferi.
La aceeași adâncime: într-un fluid omogen aflat în repaus: \[ \boxed{ p_A=p_B } \] dacă punctele \(A\) și \(B\) se află la același nivel și fac parte din aceeași regiune fluidă conectată.
Această proprietate este extrem de utilă în manometre și vase comunicante. Alegerea unui nivel orizontal comun simplifică ecuațiile de presiune.
Două lichide nemiscibile: alegem un nivel orizontal comun în zona de echilibru. Egalitatea presiunilor conduce la: \[ \rho_1gh_1 = \rho_2gh_2. \] Deci: \[ \boxed{ \rho_1h_1 = \rho_2h_2 } \]
Raportul înălțimilor: \[ \boxed{ \frac{h_1}{h_2} = \frac{\rho_2}{\rho_1} } \] Înălțimile sunt invers proporționale cu densitățile.
Greșeală frecventă: scrierea: \[ \frac{h_1}{h_2} = \frac{\rho_1}{\rho_2}. \] Raportul corect este invers: \[ \boxed{ \frac{h_1}{h_2} = \frac{\rho_2}{\rho_1} } \]
Verificare intuitivă: lichidul mai dens are nevoie de o coloană mai scurtă pentru a produce aceeași presiune. Dacă: \[ \rho_1>\rho_2, \] trebuie să rezulte: \[ \boxed{ h_1
Forța exercitată de lichid: în hidrostatică, forța locală de presiune este normală la suprafață. Pentru un element de arie \(dA\): \[ \boxed{ dF=p\,dA } \] ca modul.
Pe un perete vertical, presiunea nu este uniformă pe toată înălțimea. Deoarece: \[ p=\rho gh, \] presiunea crește de sus în jos. De aceea nu se poate utiliza automat: \[ F=pA \] cu o singură valoare arbitrară a presiunii.
Pentru o suprafață pe care presiunea variază: forța rezultantă se obține prin: \[ \boxed{ F = \int_A p\,dA } \]
Delimitare de sursă: integrarea distribuției presiunii pe suprafețe este o completare formală modernă. §9.3 al lui Bunget pune accentul pe dependența presiunii de adâncime și pe direcția normală a forțelor de presiune.
Butoiul lui Pascal: ideea-cheie este: \[ \boxed{ p=\rho gh } \] și nu: \[ p \propto \text{cantitatea totală de apă}. \] O coloană îngustă, dar foarte înaltă, poate produce o presiune mare.
Atenție: experiența butoiului lui Pascal implică presiuni și forțe care pot deteriora recipientul. Pentru activități didactice este preferabilă o demonstrație sigură la scară redusă sau o simulare.
Legătura cu experimentul didactic: un vas transparent cu orificii la adâncimi diferite permite evidențierea calitativă a faptului că: \[ \boxed{ p_h \text{ crește cu } h } \] Jetul asociat unui orificiu mai adânc indică o presiune hidrostatică mai mare în punctul respectiv.
Interpretarea jetului: observația este o evidențiere calitativă a variației presiunii cu adâncimea. Studiul exact al vitezei jetului aparține dinamicii fluidelor și nu trebuie confundat cu demonstrația strict hidrostatică.
Schema de rezolvare pentru presiunea hidrostatică:

1. transformă toate datele în SI;
2. identifică densitatea: \[ \rho; \]
3. identifică adâncimea verticală: \[ h; \]
4. stabilește dacă se cere presiune hidrostatică sau presiune absolută;
5. pentru presiunea hidrostatică folosește: \[ p_h=\rho gh; \]
6. pentru presiunea absolută într-un vas deschis: \[ p_{\mathrm{abs}} = p_{\mathrm{atm}} + \rho gh; \]
7. verifică unitatea: \[ \mathrm{Pa}; \]
8. verifică dacă presiunea obținută crește corect cu adâncimea.
Patru erori de evitat:

1. folosirea adâncimii oblice în locul diferenței verticale de nivel;

2. introducerea formei vasului în formula: \[ p=\rho gh; \]

3. confundarea presiunii hidrostatice cu presiunea absolută;

4. folosirea aceleiași densități pentru două lichide diferite.
Relațiile de memorat: presiunea hidrostatică: \[ \boxed{ p_h=\rho gh } \] presiunea totală: \[ \boxed{ p=p_0+\rho gh } \] diferența de presiune: \[ \boxed{ \Delta p = \rho g\Delta h } \] două lichide: \[ \boxed{ \rho_1h_1 = \rho_2h_2 } \]
Relevanță metodică directă: într-un material de Titularizare 2021 este utilizată exact investigarea variației presiunii hidrostatice cu adâncimea, printr-un vas cu orificii situate la niveluri diferite. Aceasta face §9.3 important atât științific, cât și didactic.
Pentru un răspuns de examen: nu este suficient să scrii numai: \[ p=\rho gh. \] Precizează:

ce reprezintă fiecare mărime;
unitățile SI;
condițiile de aplicare;
nivelul de referință;
dacă \(p\) este presiune hidrostatică, manometrică sau absolută.
