9.7 Legea lui Arhimede pentru gaze

Extinderea legii lui Arhimede la gaze, forța arhimedică în aer, baroscopul, greutatea aparentă și efectul volumului de gaz dezlocuit.

Extinderea legii

Gazele au greutate

Bunget pornește de la faptul stabilit în paragraful precedent: gazele au greutate.

Din acest motiv, legea lui Arhimede se aplică și corpurilor cufundate într-un gaz.

Legea lui Arhimede

Forța exercitată de gaz

Legea lui Arhimede pentru gaze

Un corp cufundat într-un gaz este supus unei forțe orientate vertical de jos în sus, egală cu greutatea volumului de gaz dezlocuit de corp.

\[ \boxed{ F_A = G_{\text{gaz dezlocuit}} } \]
Formă matematică

Forța arhimedică în gaz

Dacă densitatea gazului este \(\rho\), iar corpul dezlocuiește volumul \(V\), greutatea acelui volum de gaz este:

\[ G_{\text{gaz}} = \rho Vg. \]

Prin urmare:

\[ \boxed{ F_A = \rho Vg } \]
Comparație

Gaze și lichide

Compendiul subliniază că densitatea gazelor este mult mai mică decât densitatea lichidelor.

În consecință, pentru același volum dezlocuit, forța arhimedică produsă de un gaz este sensibil mai mică decât cea produsă de un lichid.

\[ F_A = \rho Vg \]
\[ \boxed{ \rho\downarrow \Rightarrow F_A\downarrow } \]
Evidențiere experimentală

Forța nu este nulă

Deși forța arhimedică în aer este mică, Bunget arată că ea poate fi pusă experimental în evidență.

În acest scop este utilizat un dispozitiv numit:

\[ \boxed{ \text{baroscop} } \]
Figura I.9.12

Baroscopul

Baroscop

Dispozitiv format, în experiența prezentată de Bunget, dintr-o balanță la capetele căreia sunt suspendate două sfere cu volume foarte diferite.

Sferele sunt notate:

\[ \boxed{ S_1 \qquad\text{și}\qquad S_2 } \]
Prima etapă

Echilibrul în aer

Cele două sfere sunt astfel alese încât balanța să se afle în echilibru cât timp sub clopotul de sticlă există aer.

\[ \boxed{ F_1=F_2 } \]

Volumele celor două sfere sunt însă foarte diferite.

Notații

Masele și volumele sferelor

Bunget notează masele celor două sfere:

\[ m_1, \qquad m_2 \]

și volumele lor:

\[ V_1, \qquad V_2. \]

Densitatea aerului este notată:

\[ \boxed{ \rho } \]
Relația (9.17)

Greutatea aparentă a sferei \(S_1\)

Greutatea gravitațională a sferei este:

\[ m_1g. \]

Forța arhimedică exercitată de aer este:

\[ \rho V_1g. \]

Bunget scrie pentru forța totală corespunzătoare greutății aparente în aer:

\[ \boxed{ F_1 = m_1g - \rho V_1g } \]
Relația (9.18)

Greutatea aparentă a sferei \(S_2\)

În mod analog, pentru a doua sferă:

\[ \boxed{ F_2 = m_2g - \rho V_2g } \]
Interpretarea echilibrului

Volume diferite, forțe arhimedice diferite

Deoarece volumele sferelor sunt diferite, ele dezlocuiesc volume diferite de aer.

Prin urmare, forțele arhimedice exercitate asupra lor sunt diferite:

\[ F_{A1} = \rho V_1g, \]
\[ F_{A2} = \rho V_2g. \]

Astfel, sfere cu mase diferite pot avea aceeași greutate aparentă în aer.

A doua etapă

Evacuarea aerului

Aerul este apoi scos din interiorul clopotului în care se află baroscopul.

Pe măsură ce aerul este evacuat, efectul forței arhimedice asupra celor două sfere devine neglijabil în experiența descrisă.

\[ \boxed{ \rho_{\text{aer}} \rightarrow \text{foarte mică} \Rightarrow F_A \rightarrow \text{foarte mică} } \]
Observația

Balanța se dezechilibrează

După evacuarea aerului, balanța nu mai rămâne în echilibrul inițial.

Ea se înclină spre sfera mai grea, care în configurația descrisă de Bunget este și sfera mai voluminoasă.

\[ \boxed{ \text{eliminarea aerului} \Rightarrow \text{dispare compensarea arhimedică inițială} } \]
Echilibrul inițial

Egalitatea forțelor aparente

În aer, înainte de evacuare:

\[ F_1=F_2. \]

Introducând relațiile (9.17) și (9.18):

\[ m_1g-\rho V_1g = m_2g-\rho V_2g. \]

Factorul \(g\) se simplifică:

\[ \boxed{ m_1-\rho V_1 = m_2-\rho V_2 } \]
Relația (9.19)

Diferența maselor

Regrupând termenii:

\[ \boxed{ m_1-m_2 = \rho \left( V_1-V_2 \right) } \]
Concluzia Compendiului

Masa aerului dezlocuit

Mărimea:

\[ \rho V_1 \]

reprezintă masa aerului dezlocuit de prima sferă, iar:

\[ \rho V_2 \]

reprezintă masa aerului dezlocuit de a doua sferă.

Astfel, relația (9.19) arată că diferența maselor celor două sfere care se echilibrează în aer este egală cu diferența maselor de aer dezlocuite.

\[ \boxed{ m_1-m_2 = m_{\text{aer},1} - m_{\text{aer},2} } \]
Legătura logică

Firul §9.7

Gazele au greutate

Legea lui Arhimede se aplică și gazelor.

Forța arhimedică

\[ \boxed{ F_A=\rho Vg } \]

În gaze

Efectul este mai mic decât în lichide datorită densității mai mici.

Baroscopul

Evidențiază experimental forța arhimedică exercitată de aer.

Sfera \(S_1\)

\[ \boxed{ F_1 = m_1g - \rho V_1g } \]

Sfera \(S_2\)

\[ \boxed{ F_2 = m_2g - \rho V_2g } \]

Echilibrul în aer

\[ F_1=F_2 \]

Relația finală

\[ \boxed{ m_1-m_2 = \rho (V_1-V_2) } \]
Sinteză

De reținut din §9.7

Arhimede pentru gaze

\[ \boxed{ F_A = G_{\text{gaz dezlocuit}} } \]

Formă matematică

\[ \boxed{ F_A = \rho Vg } \]

Greutate aparentă

\[ \boxed{ F = mg-\rho Vg } \]

Baroscop

Balanță cu două sfere de volume diferite, introdusă sub un clopot din care aerul poate fi evacuat.

Relația (9.19)

\[ \boxed{ m_1-m_2 = \rho (V_1-V_2) } \]
Titularizare

Precizări pentru examen

Această secțiune este separată de corpul §9.7 al Compendiului. Reperul oficial utilizat este programa pentru Titularizare Fizică 2026.

Statut în programa 2026

Programa oficială cere explicit la punctul 12:

Noțiuni de statica fluidelor. Legile hidrostaticii.

Legea lui Arhimede aplicată gazelor aparține direct acestui cadru conceptual.

Formula de bază: \[ \boxed{ F_A = \rho_g V_d g } \] unde: \[ \rho_g \] este densitatea gazului, \[ V_d \] este volumul de gaz dezlocuit, iar: \[ g \] este accelerația gravitațională.
Unități SI: \[ [\rho_g] = \mathrm{kg/m^3} \] \[ [V_d] = \mathrm{m^3} \] \[ [g] = \mathrm{m/s^2} \] și: \[ \boxed{ [F_A] = \mathrm N } \]
Verificare dimensională: \[ [\rho_gV_dg] = \frac{\mathrm{kg}}{\mathrm{m^3}} \cdot \mathrm{m^3} \cdot \frac{\mathrm m}{\mathrm{s^2}} \] \[ = \mathrm{kg\,m/s^2} \] \[ = \boxed{ \mathrm N }. \]
Nu folosi densitatea corpului în formula forței arhimedice. Corect: \[ \boxed{ F_A = \rho_{\text{gaz}} V_dg } \] Densitatea este cea a fluidului exterior.
Pentru un corp complet înconjurat de aer: dacă volumul exterior al corpului este \(V\), atunci: \[ \boxed{ V_d=V } \] în modelul simplificat.
Greutatea gravitațională: \[ G=mg. \] Forța arhimedică: \[ F_A = \rho_gVg. \] Rezultanta verticală asociată celor două este: \[ \boxed{ G-F_A = mg-\rho_gVg } \] în sens descendent dacă \(G>F_A\).
Greutatea corpului nu se modifică. Rămâne: \[ \boxed{ G=mg } \] Ceea ce se modifică în prezența aerului este rezultanta forțelor și, în anumite montaje de măsurare, greutatea aparentă.
Greutatea aparentă în modelul Bunget: \[ \boxed{ F_{\mathrm{ap}} = mg-\rho_gVg } \]
Termenul „greutate aparentă” trebuie folosit atent. Într-o problemă cu dinamometru, mărimea citită este de regulă forța de tensiune sau reacțiunea aparatului, nu o nouă „greutate gravitațională”.
Baroscopul — ideea fizică: două corpuri de volume diferite primesc forțe arhimedice diferite: \[ F_{A1} = \rho_gV_1g, \] \[ F_{A2} = \rho_gV_2g. \] Dacă: \[ V_1>V_2, \] atunci: \[ \boxed{ F_{A1}>F_{A2} } \] pentru același gaz și aceleași condiții.
Echilibrul în aer: \[ m_1g-\rho_gV_1g = m_2g-\rho_gV_2g. \] După simplificarea lui \(g\): \[ m_1-\rho_gV_1 = m_2-\rho_gV_2. \] Deci: \[ \boxed{ m_1-m_2 = \rho_g (V_1-V_2) } \]
Interpretare dimensională: termenul: \[ \rho_gV \] are unitatea: \[ \frac{\mathrm{kg}}{\mathrm{m^3}} \cdot \mathrm{m^3} = \mathrm{kg}. \] El reprezintă masa gazului dezlocuit.
Ce se întâmplă când aerul este evacuat: nu apare o nouă forță care trage sfera mai mare în jos. Scade forța arhimedică pe care aerul o exercita anterior asupra sferelor.
În limita unui vid foarte bun: \[ \rho_g \rightarrow0 \] și: \[ \boxed{ F_A = \rho_gVg \rightarrow0 } \]
„Vid” experimental nu înseamnă automat densitate exact zero. Într-o incintă reală poate rămâne gaz rezidual. Pentru analiza elementară efectul său poate fi considerat neglijabil dacă problema o permite.
Densitatea aerului nu este universal constantă. Ea depinde, între altele, de presiune, temperatură și compoziția gazului.
Legătură cu gazul ideal: pentru un gaz ideal de masă molară \(M\): \[ pV=nRT. \] Deoarece: \[ n=\frac{m}{M}, \] rezultă: \[ pV = \frac{m}{M}RT. \] Cum: \[ \rho_g = \frac{m}{V}, \] obținem: \[ \boxed{ \rho_g = \frac{pM}{RT} } \]
Atunci forța arhimedică poate fi scrisă: \[ \boxed{ F_A = \frac{pM}{RT} V_dg } \] în condițiile modelului de gaz ideal.
Delimitare de sursă: relația: \[ \rho_g = \frac{pM}{RT} \] și forma rezultată pentru \(F_A\) sunt completări moderne. Ele nu fac parte din §9.7 al Compendiului.
Legătura cu programa: programa 2026 include separat și:

teoria cinetico-moleculară a gazului ideal și ecuațiile de stare ale gazului ideal.

De aceea, legătura dintre: \[ F_A=\rho_gVg \] și: \[ \rho_g=\frac{pM}{RT} \] este utilă ca integrare între două teme.
Aplicație: corp mai ușor decât aerul pentru un sistem de volum exterior \(V\), forța arhimedică este: \[ F_A = \rho_{\mathrm{aer}}Vg. \] Pentru urcare, în absența altor forțe verticale importante: \[ \boxed{ F_A > G_{\mathrm{total}} } \]
Pentru un balon care conține un gaz: dacă masa învelișului și a sarcinii este \(m_s\), iar densitatea gazului interior este \(\rho_i\), masa totală este: \[ m_{\mathrm{tot}} = m_s+\rho_iV. \] Condiția de urcare este: \[ \rho_{\mathrm{aer}}Vg > (m_s+\rho_iV)g. \] Adică: \[ \boxed{ (\rho_{\mathrm{aer}}-\rho_i)V > m_s } \]
Nu compara numai densitatea gazului interior cu densitatea aerului. Pentru un balon real, trebuie inclusă și masa învelișului, a nacelului, a sarcinii și a celorlalte componente.
De ce forța arhimedică apare și în aer: presiunea atmosferică scade cu altitudinea. Prin urmare, partea inferioară a unui corp este supusă unei presiuni puțin mai mari decât partea superioară. Rezultanta acestor forțe de presiune este orientată în sus.
Nu spune: „aerul nu are forță arhimedică deoarece este foarte ușor”. Forța este: \[ F_A = \rho_{\mathrm{aer}}Vg. \] Poate fi mică, dar nu este în general identic nulă.
Pentru corpuri mici și dense: în multe probleme școlare, forța arhimedică a aerului poate fi neglijată dacă efectul ei este foarte mic față de greutatea corpului.
„Neglijabil” nu înseamnă „inexistent”. Este o ipoteză de modelare care trebuie justificată prin scara problemei.
Raport util: pentru un corp omogen cu densitatea \(\rho_c\) și complet înconjurat de un gaz de densitate \(\rho_g\): \[ G = \rho_cVg \] și: \[ F_A = \rho_gVg. \] Prin urmare: \[ \boxed{ \frac{F_A}{G} = \frac{\rho_g}{\rho_c} } \]
Această relație explică de ce efectul aerului este adesea foarte mic pentru corpuri dense. Dacă: \[ \rho_c \gg \rho_g, \] atunci: \[ \boxed{ F_A \ll G } \]
Schema de rezolvare pentru o problemă:

1. identifică gazul;
2. stabilește densitatea: \[ \rho_g; \]
3. determină volumul de gaz dezlocuit: \[ V_d; \]
4. calculează: \[ F_A = \rho_gV_dg; \]
5. calculează greutatea: \[ G=mg; \]
6. reprezintă toate forțele;
7. scrie condiția de echilibru sau ecuația de mișcare;
8. verifică unitățile;
9. verifică dacă \(F_A\) poate fi sau nu neglijată;
10. precizează ipotezele folosite.
Patru erori de evitat:

1. afirmația că legea lui Arhimede este valabilă numai pentru lichide;

2. utilizarea densității corpului în: \[ F_A=\rho_gV_dg; \]

3. afirmația că masa sau greutatea corpului scad în prezența aerului;

4. interpretarea evacuării aerului ca apariție a unei forțe noi orientate în jos.
Relațiile de memorat: Arhimede pentru gaze: \[ \boxed{ F_A = \rho_gV_dg } \] greutate aparentă: \[ \boxed{ F_{\mathrm{ap}} = mg-\rho_gVg } \] baroscop: \[ \boxed{ m_1-m_2 = \rho_g (V_1-V_2) } \]
Demers didactic posibil: baroscopul permite formularea unei întrebări investigative:

„Dacă două corpuri sunt în echilibru în aer, vor rămâne în echilibru și atunci când aerul din jur este evacuat?”

Observația conduce direct la rolul forței arhimedice în gaze.
Siguranță experimentală: o incintă de sticlă supusă vidului poate prezenta risc de implozie. Demonstrația nu trebuie improvizată cu recipiente neproiectate pentru vid. În laborator se utilizează echipament adecvat, protecție și proceduri aprobate sau, alternativ, o demonstrație simulată.
