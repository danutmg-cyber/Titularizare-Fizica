9.2 Presiunea

Definiția presiunii, unitățile de măsură, transmiterea presiunii într-un lichid închis, legea lui Pascal și presa hidraulică.

Ion Bunget Compendiu de Fizică §9.2
Sursa

Compendiu de Fizică

Partea I. Mecanică și acustică
9. Hidro- și aerostatica
9.2 Presiunea

Pagina: 200.
§9.3 Presiunea hidrostatică începe la p. 201.
Definiție

Presiunea

Bunget introduce presiunea prin raportarea forței care acționează perpendicular pe o suprafață la aria acelei suprafețe.

Presiune

Mărime fizică ce caracterizează acțiunea normală a unei forțe asupra unei suprafețe, raportată la aria suprafeței.

Relația (9.4)

Formula presiunii

Dacă forța normală \(F\) este repartizată pe suprafața \(S\), Compendiul scrie:

\[ \boxed{ p=\frac{F}{S} } \]

unde:

\(p\)

presiunea;

\(F\)

forța perpendiculară pe suprafață;

\(S\)

aria suprafeței asupra căreia este repartizată forța.

Interpretare

Aceeași forță, suprafețe diferite

Relația:

\[ p=\frac FS \]

arată că, pentru aceeași forță, presiunea este mai mare dacă suprafața pe care acționează forța este mai mică.

\[ \boxed{ F=\text{constant}, \quad S\downarrow \Rightarrow p\uparrow } \]
Formă echivalentă

Forța exercitată pe o suprafață

Din relația (9.4) se poate scrie:

\[ \boxed{ F=pS } \]

Relația va fi utilizată imediat în analiza sistemului hidraulic.

Unități

Unitățile prezentate de Compendiu

Bunget prezintă, conform practicii epocii, atât unități SI, cât și unități din sistemul CGS sau unități tehnice.

Sistemul CGS

Unitatea utilizată este barye:

\[ 1\,\mathrm{Ba} = 1\,\mathrm{dyn/cm^2}. \]

Sistemul Internațional

\[ \boxed{ 1\,\mathrm{N/m^2} } \]
Conversie

SI și barye

Relația dintre unitățile menționate de Compendiu este:

\[ \boxed{ 1\,\mathrm{N/m^2} = 10\,\mathrm{Ba} } \]
Unitate tehnică istorică

Atmosfera tehnică

Bunget menționează și atmosfera tehnică, unitate folosită frecvent în tehnică în perioada apariției Compendiului.

Ea corespunde presiunii unei forțe de un kilogram-forță repartizate uniform pe un centimetru pătrat.

\[ 1\,\mathrm{at} = 1\,\mathrm{kgf/cm^2} \]
\[ 1\,\mathrm{at} \approx 9{,}8\times10^4 \,\mathrm{N/m^2}. \]
Figura I.9.2

Vas în formă de U cu două pistoane

Pentru demonstrarea modului în care se transmite presiunea, Bunget consideră un vas cu lichid în formă de U.

Cele două ramuri au secțiuni diferite și sunt prevăzute cu pistoane.

\[ S_1 \qquad\text{și}\qquad S_2 \]

reprezintă ariile celor două pistoane.

Deplasările pistoanelor

\(l_1\) și \(l_2\)

Prin acționarea primului piston, acesta se deplasează cu distanța:

\[ l_1. \]

Lichidul determină deplasarea celui de-al doilea piston cu distanța:

\[ l_2. \]
Lichid practic incompresibil

Conservarea volumului

Bunget utilizează proprietatea discutată în §9.1: lichidul este considerat practic incompresibil.

Volumul deplasat de primul piston trebuie să fie egal cu volumul corespunzător deplasării celui de-al doilea.

Relația (9.5)

Egalitatea volumelor

\[ \boxed{ S_1l_1 = S_2l_2 } \]

Din această relație:

\[ \boxed{ \frac{l_1}{l_2} = \frac{S_2}{S_1} } \]

Pistonul cu suprafață mai mică parcurge o distanță mai mare decât pistonul cu suprafață mare, pentru același volum de lichid deplasat.

Forțele

\(F_1\) și \(F_2\)

Notăm forța aplicată primului piston cu:

\[ F_1 \]

și forța exercitată asupra celui de-al doilea piston cu:

\[ F_2. \]
Conservarea energiei

Egalitatea lucrurilor mecanice

Bunget aplică apoi legea conservării energiei sistemului ideal.

Lucrul mecanic efectuat asupra primului piston este egal cu lucrul efectuat de lichid asupra celui de-al doilea.

Relația (9.6)

Lucrul mecanic

\[ \boxed{ F_1l_1 = F_2l_2 } \]
Presiunile celor două pistoane

\(p_1\) și \(p_2\)

Din definiția presiunii:

\[ p_1 = \frac{F_1}{S_1}, \]
\[ p_2 = \frac{F_2}{S_2}. \]

Utilizând relațiile de conservare a volumului și a lucrului mecanic, se obține egalitatea presiunilor transmise.

Deducție

Eliminarea deplasărilor

Din:

\[ S_1l_1 = S_2l_2 \]

avem:

\[ \frac{l_1}{l_2} = \frac{S_2}{S_1}. \]

Iar din:

\[ F_1l_1 = F_2l_2 \]

rezultă:

\[ \frac{F_2}{F_1} = \frac{l_1}{l_2}. \]

Prin urmare:

\[ \boxed{ \frac{F_1}{S_1} = \frac{F_2}{S_2} } \]
Relația (9.7)

Presiunile sunt egale

\[ \boxed{ p_1=p_2 } \]

Din această egalitate, Bunget formulează proprietatea fundamentală cunoscută drept legea lui Pascal.

Legea lui Pascal

Transmiterea presiunii

Legea lui Pascal

Presiunea exercitată din exterior asupra unei porțiuni din suprafața unui lichid aflat într-un vas închis se transmite integral în lichid și în toate direcțiile către suprafețele interioare ale vasului.

\[ \boxed{ p_1=p_2 } \]
Observație

Orientarea suprafețelor

Bunget subliniază că transmiterea presiunii nu depinde de orientarea pereților interiori asupra cărora acționează lichidul.

\[ \boxed{ \text{presiunea se transmite în toate direcțiile} } \]
Aplicație

Presa hidraulică

O aplicație importantă a legii lui Pascal este presa hidraulică.

Se consideră:

Pistonul mic

\[ S_1, \qquad F_1 \]

Pistonul mare

\[ S_2, \qquad F_2 \]
Pistonul mic

Presiunea introdusă în lichid

Forța \(F_1\) aplicată pistonului mic produce presiunea:

\[ \boxed{ p_1 = \frac{F_1}{S_1} } \]
Pistonul mare

Forța obținută

Potrivit legii lui Pascal:

\[ p_2=p_1. \]

Asupra pistonului mare acționează astfel:

\[ F_2=p_2S_2. \]

Înlocuind:

\[ p_2 = \frac{F_1}{S_1}, \]

rezultă:

\[ \boxed{ F_2 = F_1 \frac{S_2}{S_1} } \]
Relația (9.8)

Amplificarea forței

\[ \boxed{ \frac{F_2}{F_1} = \frac{S_2}{S_1} } \]

Forța obținută pe pistonul mare este de atâtea ori mai mare decât forța aplicată pistonului mic, de câte ori aria pistonului mare este mai mare decât aria pistonului mic.

Consecință

Forță și deplasare

Relațiile utilizate de Bunget arată simultan:

\[ \frac{F_2}{F_1} = \frac{S_2}{S_1} \]

și:

\[ \frac{l_1}{l_2} = \frac{S_2}{S_1}. \]

Prin urmare:

\[ \boxed{ \frac{F_2}{F_1} = \frac{l_1}{l_2} } \]
Conservarea energiei

Nu se obține energie gratuită

Creșterea forței pe pistonul mare este compensată de deplasarea mai mare a pistonului mic.

\[ \boxed{ F_1l_1 = F_2l_2 } \]

Aceasta este relația energetică folosită de Compendiu în demonstrația legii lui Pascal.

Sinteză

De reținut din §9.2

Presiune

\[ \boxed{ p=\frac FS } \]

Conservarea volumului

\[ \boxed{ S_1l_1 = S_2l_2 } \]

Conservarea lucrului

\[ \boxed{ F_1l_1 = F_2l_2 } \]

Legea lui Pascal

\[ \boxed{ p_1=p_2 } \]

Presa hidraulică

\[ \boxed{ \frac{F_2}{F_1} = \frac{S_2}{S_1} } \]
Titularizare

Precizări pentru examen

Această secțiune este separată de corpul §9.2 al Compendiului. Reperul oficial utilizat este programa pentru Titularizare Fizică 2026.

Prioritate ridicată

Programa oficială 2026 cere explicit:

Noțiuni de statica fluidelor. Legile hidrostaticii.

Presiunea și legea lui Pascal sunt noțiuni fundamentale pentru acest punct al programei.

Definiția de lucru pentru o presiune uniformă: \[ \boxed{ p=\frac{F_n}{A} } \] unde: \[ F_n \] este componenta normală a forței, iar: \[ A \] este aria suprafeței.
De ce scriem \(F_n\): presiunea este asociată acțiunii normale asupra suprafeței. O componentă pur tangențială nu intră în definiția presiunii statice.
Forma locală: pentru o suprafață foarte mică: \[ \boxed{ p = \frac{dF_n}{dA} } \] iar pentru presiune uniformă se recuperează: \[ p=\frac{F_n}{A}. \]
Unitatea SI: \[ \boxed{ 1\,\mathrm{Pa} = 1\,\mathrm{N/m^2} } \] Presiunea se măsoară în pascali.
Multipli uzuali: \[ 1\,\mathrm{kPa} = 10^3\,\mathrm{Pa} \] \[ 1\,\mathrm{MPa} = 10^6\,\mathrm{Pa}. \]
Atmosfera tehnică din Compendiu este o unitate istorică de tehnică. În SI: \[ 1\,\mathrm{at} = 98\,066{,}5\,\mathrm{Pa} \approx 9{,}8\times10^4\,\mathrm{Pa}. \] Ea nu trebuie confundată cu atmosfera standard: \[ 1\,\mathrm{atm} = 101\,325\,\mathrm{Pa}. \]
Greșeală de unități: dacă aria este dată în \(\mathrm{cm^2}\), trebuie convertită corect în SI: \[ \boxed{ 1\,\mathrm{cm^2} = 10^{-4}\,\mathrm{m^2} } \]
Exemplu de verificare: pentru: \[ F=100\,\mathrm N \] și: \[ A=10\,\mathrm{cm^2} = 10^{-3}\,\mathrm{m^2}, \] presiunea este: \[ p = \frac{100}{10^{-3}} = 10^5\,\mathrm{Pa}. \]
Presiunea este scalară. Forța exercitată de presiune asupra unei suprafețe are însă direcție normală pe acea suprafață.
Pentru presiune uniformă: modulul forței este: \[ \boxed{ F=pA } \]
Relația \(F=pA\) are o condiție: presiunea trebuie să fie uniformă pe suprafața considerată. Dacă presiunea variază, trebuie însumate contribuțiile locale.
Legea lui Pascal — formulare de reținut: o variație de presiune aplicată unui fluid închis se transmite nediminuată în fluid și către pereții recipientului, în modelul hidrostatic considerat.
Atenție la formularea \(p_1=p_2\): aceasta descrie presiunea transmisă în modelul presei hidraulice din §9.2. Nu înseamnă că presiunea totală este aceeași în orice două puncte aflate la adâncimi diferite. Variația cu adâncimea va fi tratată în §9.3.
Presa hidraulică ideală: folosind notația modernă \(A_1\), \(A_2\): \[ p_1 = \frac{F_1}{A_1} \] și: \[ p_2 = \frac{F_2}{A_2}. \] Din legea lui Pascal: \[ p_1=p_2. \] Deci: \[ \boxed{ \frac{F_1}{A_1} = \frac{F_2}{A_2} } \]
Formula centrală: \[ \boxed{ F_2 = F_1 \frac{A_2}{A_1} } \]
Avantajul mecanic ideal: \[ A_m = \frac{F_2}{F_1}. \] Pentru presa hidraulică: \[ \boxed{ A_m = \frac{A_2}{A_1} } \]
Nu spune: „presa hidraulică produce forță”. Sistemul permite obținerea unei forțe mai mari la pistonul mare, în schimbul unei deplasări mai mici a acestuia.
Conservarea volumului: pentru lichid ideal incompresibil: \[ \boxed{ A_1x_1 = A_2x_2 } \] de unde: \[ \boxed{ \frac{x_1}{x_2} = \frac{A_2}{A_1} } \]
Combinând cele două relații: \[ \frac{F_2}{F_1} = \frac{A_2}{A_1} \] și: \[ \frac{x_1}{x_2} = \frac{A_2}{A_1}, \] rezultă: \[ \boxed{ F_1x_1 = F_2x_2 } \]
Câștig de forță ≠ câștig de energie. În modelul ideal: \[ \boxed{ L_{\mathrm{intrare}} = L_{\mathrm{ieșire}} } \] Forța mai mare este compensată de deplasarea mai mică.
Verificare fizică: dacă: \[ A_2=10A_1, \] atunci: \[ F_2=10F_1. \] Dar: \[ x_2=\frac{x_1}{10}. \]
Eroare tipică 1: inversarea raportului ariilor. Pentru pistonul mare: \[ \boxed{ F_2 = F_1 \frac{A_2}{A_1} } \] dacă: \[ A_2>A_1. \]
Eroare tipică 2: utilizarea diametrelor direct în locul ariilor. Pentru un piston circular: \[ A=\frac{\pi d^2}{4}. \] Astfel: \[ \boxed{ \frac{A_2}{A_1} = \frac{d_2^2}{d_1^2} } \] și nu: \[ \frac{d_2}{d_1}. \]
Dacă sunt date razele: \[ A=\pi r^2. \] Prin urmare: \[ \boxed{ \frac{F_2}{F_1} = \frac{r_2^2}{r_1^2} } \]
Eroare tipică 3: confundarea presiunii cu forța. Presiunea: \[ p \] se măsoară în: \[ \mathrm{Pa}, \] iar forța: \[ F \] se măsoară în: \[ \mathrm N. \]
Verificare dimensională: \[ p=\frac FA. \] Atunci: \[ [p] = \frac{ \mathrm N }{ \mathrm{m^2} } = \mathrm{Pa}. \]
Schema de rezolvare pentru presa hidraulică:

1. scrie datele în SI;
2. identifică pistonul 1 și pistonul 2;
3. calculează ariile, dacă sunt date razele sau diametrele;
4. scrie: \[ p_1=p_2; \]
5. înlocuiește: \[ \frac{F_1}{A_1} = \frac{F_2}{A_2}; \]
6. izolează mărimea cerută;
7. verifică raportul ariilor;
8. verifică unitatea rezultatului;
9. dacă sunt cerute deplasările, folosește: \[ A_1x_1=A_2x_2; \]
10. verifică bilanțul energetic.
Relevanță metodică: un material oficial încărcat pentru Titularizare 2022 utilizează explicit un cric hidraulic ca situație-problemă. Relația fizică utilizată este: \[ \boxed{ \frac{F_1}{A_1} = \frac{F_2}{A_2} } \] Elevii trebuie să lege această relație de legea lui Pascal și de amplificarea efectului forței.
Prioritate pentru concurs: trebuie să poți:

defini presiunea;
utiliza corect unitatea Pa;
enunța legea lui Pascal;
deduce relația presei hidraulice;
explica schimbul forță–deplasare;
rezolva probleme cu arii, raze sau diametre.
