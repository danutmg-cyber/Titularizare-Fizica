9.4 Legea lui Arhimede

Figura I.9.6

Experiența pentru evidențierea forței arhimedice

Bunget pornește de la o experiență realizată cu o balanță.

De unul dintre talere este suspendat un cilindru gol \(A\), cu pereți foarte subțiri.

Sub acesta este suspendat un cilindru plin \(A'\), al cărui volum este egal cu volumul interior al cilindrului gol.

\[ \boxed{ V_A=V_{A'} } \]
Prima etapă

Echilibrarea balanței

Sistemul format din cei doi cilindri este mai întâi echilibrat cu ajutorul unor greutăți introduse în celălalt taler.

\[ \boxed{ \text{balanță în echilibru} } \]
A doua etapă

Cilindrul plin este introdus în apă

Cilindrul plin \(A'\) este introdus într-un vas cu apă.

Balanța nu mai rămâne în echilibru.

Brațul de care sunt suspendați cilindrii se deplasează în sus.

\[ \boxed{ A' \text{ introdus în apă} \Rightarrow \text{apare o acțiune orientată în sus} } \]
Concluzie experimentală

Forța arhimedică

Din dezechilibrarea balanței, Bunget concluzionează că lichidul exercită asupra cilindrului \(A'\) o forță orientată vertical, de jos în sus.

Forță arhimedică

Forța exercitată de lichid asupra corpului cufundat, orientată vertical de jos în sus în situația analizată.

\[ \boxed{ \vec F_A \text{ este orientată de jos în sus} } \]
A treia etapă

Umplerea cilindrului gol

Echilibrul balanței poate fi restabilit dacă cilindrul gol \(A\) este umplut complet cu apă.

Greutatea apei introduse în \(A\) compensează efectul forței arhimedice asupra cilindrului \(A'\).

Rezultatul experienței

Greutatea lichidului dezlocuit

Cum volumul interior al cilindrului gol este egal cu volumul cilindrului plin, apa necesară restabilirii echilibrului are tocmai volumul dezlocuit de \(A'\).

Rezultă că modulul forței arhimedice este egal cu greutatea volumului de lichid dezlocuit.

\[ \boxed{ F_A = G_{\text{lichid dezlocuit}} } \]
Legea lui Arhimede

Enunțul fizic

Legea lui Arhimede

Un corp cufundat într-un lichid este supus unei forțe orientate de jos în sus, al cărei modul este egal cu greutatea lichidului dezlocuit de corp.

\[ \boxed{ F_A = G_{\text{lichid dezlocuit}} } \]
Figura I.9.7

Demonstrația teoretică

Bunget consideră apoi, în interiorul unui lichid aflat în repaus, un cilindru imaginar de lichid.

Se notează:

\(S\)

aria bazei cilindrului;

\(h\)

înălțimea cilindrului.

Baza superioară

Forța de presiune \(F_1\)

Asupra bazei superioare acționează presiunea lichidului de deasupra.

Forța corespunzătoare este orientată de sus în jos.

\[ \boxed{ F_1=p_1S } \]
Greutatea cilindrului

Forța \(G\)

Cilindrul imaginar conține lichid de densitate \(\rho\).

Volumul său este:

\[ V=Sh. \]

Greutatea lichidului din cilindru este:

\[ \boxed{ G = \rho Vg = \rho Shg } \]

Această greutate este orientată vertical în jos.

Baza inferioară

Forța de presiune \(F_2\)

Presiunea la baza inferioară este mai mare decât la baza superioară, deoarece baza inferioară se află la o adâncime mai mare.

Asupra bazei inferioare acționează o forță orientată de jos în sus:

\[ \boxed{ F_2=p_2S } \]
Relația (9.13)

Echilibrul cilindrului de lichid

Cilindrul imaginar de lichid se află în repaus.

Forța orientată de jos în sus trebuie să echilibreze atât forța de presiune de la baza superioară, cât și greutatea cilindrului.

\[ F_2=F_1+G. \]

Prin urmare:

\[ \boxed{ F_2-F_1=G } \]
Rezultanta presiunilor

Diferența forțelor de presiune

Diferența dintre forța de presiune de la baza inferioară și cea de la baza superioară este orientată vertical în sus.

Modulul său este:

\[ \boxed{ F_2-F_1 = G } \]

adică egal cu greutatea lichidului din volumul considerat.

Pasul esențial

Înlocuirea lichidului cu un corp solid

Bunget imaginează apoi că cilindrul de lichid este înlocuit cu un corp solid având același volum.

Lichidul exterior exercită asupra suprafeței noului corp aceleași acțiuni de presiune corespunzătoare poziției ocupate în lichid.

Rezultanta lor este aceeași forță orientată în sus.

Relația (9.14)

Formula forței arhimedice

Dacă \(V\) este volumul de lichid dezlocuit, greutatea acelui volum de lichid este:

\[ G_{\ell} = \rho Vg. \]

Prin urmare:

\[ \boxed{ F_A = \rho Vg } \]

\(\rho'<\rho\)

\[ \rho'<\rho, \]

La suprafață

Corpul iese parțial din lichid

După ajungerea la suprafață, o parte a corpului iese din lichid.

Volumul de lichid dezlocuit scade.

În consecință, scade și forța arhimedică:

\[ F_A = \rho Vg. \]

\[ \boxed{ G'>F_A } \]

Rezultanta este orientată vertical în jos, iar corpul coboară în lichid până când intervine fundul vasului sau o altă acțiune mecanică.

Prioritate directă

Programa oficială 2026 include explicit:

Noțiuni de statica fluidelor. Legile hidrostaticii.

Legea lui Arhimede este una dintre relațiile fundamentale care trebuie stăpânite în această zonă.

Formula modernă: \[ \boxed{ F_A = \rho_f g V_d } \] unde: \[ \rho_f \] este densitatea fluidului, \[ V_d \] este volumul de fluid dezlocuit, iar: \[ g \] este accelerația gravitațională.
Unitatea SI: \[ \boxed{ [F_A]=\mathrm N } \]
Verificare dimensională: \[ [\rho_f g V_d] = \frac{\mathrm{kg}}{\mathrm{m^3}} \cdot \frac{\mathrm m}{\mathrm{s^2}} \cdot \mathrm{m^3} \] \[ = \mathrm{kg\,m/s^2} = \boxed{ \mathrm N }. \]
Densitatea din formula lui Arhimede este densitatea fluidului. Formula este: \[ \boxed{ F_A = \rho_f gV_d } \] și nu: \[ F_A = \rho_{\text{corp}} gV_d. \]
Volumul din formulă este volumul dezlocuit. Dacă un corp este complet cufundat: \[ \boxed{ V_d=V_{\text{corp}} } \] Dacă este numai parțial cufundat: \[ \boxed{ V_d=V_{\text{cufundat}} } \]
Originea forței: presiunea hidrostatică crește cu adâncimea. De aceea, pentru un corp cufundat, acțiunile de presiune din zona inferioară sunt mai mari decât cele din zona superioară. Rezultanta are componenta verticală orientată în sus.
Pentru cilindrul din demonstrație: \[ F_1=p_1S \] acționează în jos, iar: \[ F_2=p_2S \] acționează în sus. Cum: \[ p_2>p_1, \] rezultă: \[ F_2>F_1. \]
Diferența: dacă distanța verticală dintre baze este \(h\): \[ p_2-p_1 = \rho_f gh. \] Atunci: \[ F_A = (p_2-p_1)S \] \[ = \rho_f ghS. \] Cum: \[ V=Sh, \] rezultă: \[ \boxed{ F_A=\rho_f gV } \]
Punctul de aplicație — terminologie actuală: pentru un corp cufundat, rezultanta arhimedică trece prin centrul geometric al volumului de fluid dezlocuit, pentru densitate uniformă. Acest punct este numit uzual: \[ \boxed{ \text{centrul de împingere} } \] sau centrul de flotabilitate.
Delimitare față de Bunget: Compendiul folosește în demonstrația cilindrului expresia „centru de presiune”. În terminologia modernă, „centrul de presiune” este utilizat în mod obișnuit pentru punctul de aplicație al rezultantei presiunii pe o suprafață. Pentru forța arhimedică este mai precis să folosim centrul volumului de fluid dezlocuit.
Corp omogen, complet cufundat: greutatea este: \[ G = \rho_c Vg. \] Forța arhimedică este: \[ F_A = \rho_f Vg. \]
Rezultanta verticală: alegând sensul pozitiv în sus: \[ F_{\mathrm{rez}} = F_A-G. \] Deci: \[ \boxed{ F_{\mathrm{rez}} = (\rho_f-\rho_c)Vg } \] pentru corpul complet cufundat și fără alte forțe.
Dacă: \[ \rho_c=\rho_f, \] atunci: \[ F_A=G \] și: \[ \boxed{ F_{\mathrm{rez}}=0 } \]
Dacă: \[ \rho_c<\rho_f, \] atunci: \[ F_A>G \] și rezultanta, în absența altor forțe, este orientată în sus.
Dacă: \[ \rho_c>\rho_f, \] atunci: \[ F_A
Precizare asupra textului istoric: Bunget descrie, pentru cazurile \(\rho'<\rho\) și \(\rho'>\rho\), mișcarea corpului drept uniform accelerată. Această concluzie corespunde unei idealizări în care rezistența fluidului este neglijată și forțele relevante rămân constante.
Pentru un corp real în mișcare prin lichid: apare de regulă și o forță de rezistență dependentă de mișcare. În aceste condiții, accelerația nu este în general constantă. Nu transforma formularea istorică din Compendiu într-o regulă universală.
Independența de adâncime: pentru un corp rigid, complet cufundat, într-un lichid omogen și practic incompresibil: \[ F_A = \rho_f gV \] nu conține adâncimea \(h\). Prin urmare: \[ \boxed{ F_A \text{ nu depinde de adâncime} } \] în aceste condiții.
Nu confunda: presiunea hidrostatică: \[ p=\rho gh \] crește cu adâncimea, dar forța arhimedică asupra unui corp rigid complet cufundat poate rămâne constantă. Contează diferența presiunilor dintre partea inferioară și cea superioară.
Greutatea aparentă: dacă un corp mai dens decât lichidul este suspendat de un dinamometru și se află în repaus: \[ T+F_A-G=0. \] Deci: \[ \boxed{ T=G-F_A } \]
Prin urmare: scăderea indicației dinamometrului la introducerea corpului în lichid este: \[ \boxed{ G-T=F_A } \] în modelul ideal.
Greșeală frecventă: corpul introdus în lichid nu își schimbă masa și nici greutatea gravitațională. Se modifică rezultanta forțelor asupra lui, deoarece apare forța arhimedică.
Corp plutitor, echilibru: când corpul plutește fără alte forțe verticale: \[ F_A=G. \] Deci: \[ \rho_f V_{\mathrm{cuf}} g = \rho_c V_c g. \]
Pentru un corp omogen: \[ \boxed{ \frac{ V_{\mathrm{cuf}} }{ V_c } = \frac{ \rho_c }{ \rho_f } } \] Această relație va fi dezvoltată în §9.5, „Plutirea corpurilor”.
Verificare intuitivă: dacă un corp care plutește are densitatea egală cu jumătate din densitatea lichidului: \[ \rho_c = \frac{1}{2}\rho_f, \] atunci în modelul ideal: \[ \boxed{ V_{\mathrm{cuf}} = \frac{1}{2}V_c } \]
Legea lui Arhimede este o consecință a presiunii hidrostatice. Succesiunea logică este: \[ p \text{ crește cu adâncimea} \] \[ \Downarrow \] \[ F_{\mathrm{jos}} > F_{\mathrm{sus}} \] \[ \Downarrow \] \[ \boxed{ F_A = \rho_f gV_d } \]
Schema de rezolvare pentru probleme:

1. scrie datele în unități SI;
2. identifică fluidul și densitatea: \[ \rho_f; \]
3. determină volumul efectiv dezlocuit: \[ V_d; \]
4. calculează: \[ F_A = \rho_f gV_d; \]
5. calculează greutatea: \[ G=mg; \]
6. reprezintă toate forțele asupra corpului;
7. scrie ecuația lui Newton sau condiția de echilibru;
8. verifică sensul rezultatului;
9. verifică unitatea: \[ \mathrm N; \]
10. compară, dacă este relevant, \(\rho_c\) cu \(\rho_f\).
Patru erori de evitat:

1. utilizarea densității corpului în formula lui \(F_A\);

2. folosirea volumului total al corpului când corpul este numai parțial cufundat;

3. afirmarea că greutatea corpului scade în lichid;

4. concluzia că \(F_A\) crește automat cu adâncimea pentru un corp rigid complet cufundat într-un lichid omogen.
Relațiile de memorat: legea lui Arhimede: \[ \boxed{ F_A = \rho_f gV_d } \] greutatea corpului: \[ \boxed{ G = \rho_c gV_c } \] corp complet cufundat: \[ \boxed{ F_{\mathrm{rez}} = (\rho_f-\rho_c)Vg } \] plutire: \[ \boxed{ F_A=G } \]
