9.8 Barometre

Măsurarea presiunii atmosferice, barometrul cu mercur, condiția de vid deasupra coloanei, barometrul metalic aneroid, mecanismul cu membrană și necesitatea etalonării.

Barometrul cu mercur

Tubul lui Torricelli

Bunget arată că forma cea mai simplă de barometru este tubul lui Torricelli.

Pentru o măsurare precisă, spațiul de deasupra coloanei de mercur trebuie să fie vidat.

Dacă rămâne gaz în tub, presiunea acestuia contribuie la echilibrul coloanei de mercur.

\[ \boxed{ p_{\mathrm{atm}} = p_{\mathrm{sus}} + \rho_{\mathrm{Hg}}g h } \]

În construcția prezentată de Compendiu, tubul este gradat astfel încât diferența de nivel a mercurului să poată fi citită direct.

Barometrul metalic

Barometrul aneroid

Bunget descrie apoi barometrul aneroid, mai robust și mai ușor de transportat decât barometrul cu mercur.

El conține o cutie metalică închisă ermetic și vidată, prevăzută cu o membrană subțire și flexibilă.

Variațiile presiunii atmosferice deplasează membrana, iar deplasările sunt amplificate printr-un sistem de pârghii și transmise unui ac indicator.

Scara este verificată prin comparație cu un barometru cu mercur, deoarece proprietățile elastice ale membranei se pot modifica în timp.

Sinteză

De reținut din §9.8

Barometru

Instrument pentru măsurarea presiunii atmosferice.

Cu mercur

\[ \boxed{ p_{\mathrm{atm}} = p_{\mathrm{sus}} + \rho_{\mathrm{Hg}}gh } \]

Cu spațiul superior vidat

\[ p_{\mathrm{sus}} \approx0 \]
\[ \boxed{ p_{\mathrm{atm}} \approx \rho_{\mathrm{Hg}}gh } \]

Aneroid

Folosește deformarea unei capsule metalice vidate.

Mecanism

Deplasarea membranei este amplificată și transmisă unui ac indicator.

Verificare

Barometrul aneroid trebuie controlat periodic prin comparație cu un instrument etalon.

Titularizare

Precizări pentru examen

Această secțiune este separată de corpul §9.8 al Compendiului. Reperul oficial utilizat este programa pentru Titularizare Fizică 2026.

Statut în programa 2026

„Barometrele” nu apar ca punct științific autonom în tematica oficială.

Programa cere însă explicit:

Noțiuni de statica fluidelor. Legile hidrostaticii.

Barometrul este, prin urmare, o aplicație experimentală directă a echilibrului hidrostatic și a presiunii atmosferice.

Mărimea măsurată: barometrul măsoară: \[ \boxed{ p_{\mathrm{atm}} } \] adică presiunea atmosferică.
Unitatea SI: \[ \boxed{ [p]=\mathrm{Pa} } \] cu: \[ \boxed{ 1\,\mathrm{Pa} = 1\,\mathrm{N/m^2} } \]
Barometru cu mercur — relația generală: \[ \boxed{ p_{\mathrm{atm}} = p_{\mathrm{sus}} + \rho_{\mathrm{Hg}}g\Delta h } \] unde: \[ \Delta h \] este diferența verticală de nivel.
Nu folosi lungimea coloanei măsurată de-a lungul unui tub înclinat. În relația hidrostatică intră: \[ \boxed{ \Delta h = \text{diferența verticală de nivel} } \]
Dacă spațiul superior este ideal vidat: \[ p_{\mathrm{sus}} \approx0. \] Atunci: \[ \boxed{ p_{\mathrm{atm}} \approx \rho_{\mathrm{Hg}} g \Delta h } \]
Pentru măsurări precise: deasupra mercurului nu există un „vid matematic” perfect. Pot exista vapori de mercur, iar corecțiile metrologice pot include efecte legate de temperatură, densitatea mercurului și valoarea locală a accelerației gravitaționale.
Atmosfera standard: \[ \boxed{ 1\,\mathrm{atm} = 101325\,\mathrm{Pa} } \]
Torr: \[ \boxed{ 1\,\mathrm{Torr} = \frac{ 101325 }{ 760 } \,\mathrm{Pa} } \] adică aproximativ: \[ \boxed{ 1\,\mathrm{Torr} \approx 133{,}322\,\mathrm{Pa} } \]
Milimetrul coloană de mercur: \[ \boxed{ 1\,\mathrm{mmHg} \approx 133{,}322\,\mathrm{Pa} } \] în utilizarea curentă.
Pentru calcule SI, lucrează în pascali. Unitățile: \[ \mathrm{Torr} \] și: \[ \mathrm{mmHg} \] sunt utile pentru interpretarea instrumentelor și a datelor istorice, dar nu înlocuiesc unitatea SI.
Barometru versus manometru: barometrul măsoară presiunea atmosferică. Un manometru este utilizat în general pentru măsurarea unei presiuni sau a unei diferențe de presiune într-un sistem.
Nu confunda: \[ p_{\mathrm{atm}} \] cu: \[ p_{\mathrm{man}} = p-p_{\mathrm{atm}}. \] Prima este presiune atmosferică absolută; a doua este presiune raportată la atmosferă.
Barometrul aneroid — principiul: presiunea atmosferică produce deformarea elastică a unei capsule metalice cu presiune interioară foarte mică.
Lanțul funcțional: \[ \boxed{ p_{\mathrm{atm}} \rightarrow \text{deformarea capsulei} \rightarrow \text{mecanism de amplificare} \rightarrow \text{ac indicator} } \]
Avantajul aneroidului: nu necesită o coloană de lichid, este compact și poate fi transportat mai ușor.
Dezavantaj: răspunsul elastic al capsulei și al mecanismului poate suferi modificări în timp. De aceea este necesară: \[ \boxed{ \text{etalonarea / verificarea periodică} } \]
Etalonare: indicația instrumentului este comparată cu o valoare de referință cunoscută. O eroare sistematică identificată astfel poate necesita reglarea sau corectarea instrumentului.
Eroare conceptuală: barometrul aneroid nu măsoară presiunea prin: \[ p=\rho gh. \] Această relație descrie direct barometrul cu coloană de lichid. Aneroidul transformă presiunea într-o deformare elastică.
Conexiune cu elasticitatea: barometrul aneroid leagă două teme din mecanică:

presiunea fluidelor;
deformarea elastică a unei membrane metalice.
Verificare dimensională pentru barometrul cu mercur: \[ [\rho g h] = \frac{\mathrm{kg}}{\mathrm{m^3}} \cdot \frac{\mathrm m}{\mathrm{s^2}} \cdot \mathrm m \] \[ = \frac{ \mathrm{kg} }{ \mathrm{m\,s^2} } \] \[ = \boxed{ \mathrm{Pa} } \]
Patru erori de evitat:

1. confundarea barometrului cu manometrul;

2. folosirea unei lungimi oblice în locul diferenței verticale de nivel;

3. ignorarea presiunii gazului rămas deasupra coloanei atunci când aceasta nu poate fi neglijată;

4. exprimarea rezultatului fără unitate.
Schema pentru o problemă cu barometru cu lichid:

1. identifică presiunile de la cele două capete ale coloanei;
2. identifică lichidul și densitatea: \[ \rho; \]
3. determină diferența verticală de nivel: \[ \Delta h; \]
4. scrie relația hidrostatică: \[ \Delta p = \rho g\Delta h; \]
5. stabilește dacă presiunea superioară poate fi neglijată;
6. calculează în SI;
7. verifică: \[ [p]=\mathrm{Pa}; \]
8. verifică sensul fizic al rezultatului.
Activitate didactică sigură: pentru evidențierea variației presiunii atmosferice se poate utiliza un barometru aneroid sau un senzor electronic de presiune. Elevii pot înregistra valorile presiunii pe parcursul mai multor zile și pot reprezenta: \[ \boxed{ p=f(t) } \]
Mercurul nu este potrivit pentru experimente școlare improvizate. Este o substanță toxică. Pentru demonstrații actuale, sunt preferabile instrumentele fără mercur, senzorii sau simulările.
Ce trebuie să poți explica la concurs:

principiul barometrului cu mercur;
rolul vidului deasupra coloanei;
semnificația lui \(\Delta h\);
principiul barometrului aneroid;
motivul etalonării;
diferența dintre barometru și manometru.
Prioritate: pentru programa 2026, relațiile hidrostatice și interpretarea fizică sunt mai importante decât memorarea detaliilor constructive ale unui anumit model de barometru.
Titularizare 2027: această încadrare este realizată după programa oficială 2026. Programa oficială pentru sesiunea 2027 trebuie reverificată după publicare.
