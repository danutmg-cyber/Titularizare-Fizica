6.4 Centrul de greutate

Greutatea ca rezultantă a forțelor gravitaționale, definirea centrului de greutate, determinarea sa experimentală, utilizarea simetriei și legătura cu centrul de masă.

Ion Bunget Compendiu de Fizică §6.4
Sursa

Compendiu de Fizică

Partea I. Mecanică și acustică
6. Statica
6.4 Centrul de greutate
Pagini: 162–163
Punct de plecare

Greutatea corpului

Compendiul pornește de la un corp de masă totală \(M\), atras de Pământ cu o forță egală cu greutatea sa.

\[ \boxed{ G=Mg } \]

Pentru analiza unui corp de dimensiuni finite, acesta poate fi considerat alcătuit dintr-un număr foarte mare de elemente materiale mici.

Modelul corpului

Împărțirea în elemente materiale

Fiecărui element material îi corespunde o masă:

\[ m_i \]

și o greutate proprie:

\[ G_i=m_i g. \]

Corpul poate fi astfel privit ca un sistem de puncte materiale asupra cărora acționează forțe gravitaționale.

Sistem de forțe

Greutățile elementelor sunt practic paralele

Toate greutățile:

\[ \vec G_1,\, \vec G_2,\, \ldots,\, \vec G_N \]

sunt orientate după verticala locului.

Pentru corpuri de dimensiuni obișnuite, Compendiul le consideră practic paralele.

\[ \vec G_i \parallel \vec G_j \]

Se obține astfel un sistem de forțe paralele, de același sens.

Rezultanta

Greutatea întregului corp

Greutatea corpului este rezultanta tuturor greutăților elementelor materiale componente.

\[ \boxed{ \vec G = \sum_{i=1}^{N} \vec G_i } \]

Pentru module:

\[ G = \sum_iG_i. \]

Cum:

\[ G_i=m_i g, \]

rezultă:

\[ G = g\sum_i m_i = Mg. \]
Definiție

Centrul de greutate

Centrul de greutate

Punctul de aplicație al rezultantei forțelor gravitaționale care acționează asupra elementelor corpului.

Greutatea totală a corpului poate fi considerată aplicată în acest punct.

\[ \boxed{ \vec G \text{ se aplică în centrul de greutate} } \]
Proprietate

Poziția centrului de greutate

În cadrul modelului utilizat de Compendiu, poziția centrului de greutate este bine determinată pentru corpul considerat.

Ea nu se schimbă atunci când corpul este orientat diferit în spațiu.

Această proprietate permite tratarea greutății întregului corp ca o singură forță aplicată într-un punct bine definit.

Metodă experimentală

Suspendarea corpului

Compendiul prezintă o metodă experimentală de determinare a centrului de greutate pentru un corp de formă oarecare.

Corpul este suspendat cu ajutorul unui fir flexibil.

După atingerea poziției de echilibru, firul se orientează pe direcția rezultantei forțelor gravitaționale.

Prima suspendare

Dreapta \(AB\)

Se suspendă corpul într-un prim punct \(A\).

Firul ia o direcție verticală.

Se prelungește această direcție prin corp.

\[ AB. \]

Centrul de greutate trebuie să se afle pe această dreaptă.

\[ \boxed{ C\in AB } \]
Explicație

De ce centrul de greutate se află pe verticala suspendării

În poziția de echilibru, suportul greutății trebuie să treacă prin punctul de suspendare.

Dacă nu ar trece prin acest punct, greutatea ar produce un moment nenul față de punctul de suspendare.

Corpul ar continua să se rotească.

\[ M_A(G)=0 \]

în poziția finală de echilibru.

A doua suspendare

Dreapta \(A'B'\)

Corpul este suspendat apoi dintr-un alt punct:

\[ A'. \]

Se trasează din nou direcția verticală indicată de fir.

\[ A'B'. \]

Centrul de greutate trebuie să aparțină și acestei drepte.

\[ \boxed{ C\in A'B' } \]
Rezultatul experimentului

Intersecția verticalelor

Centrul de greutate trebuie să se afle simultan pe ambele drepte.

\[ \boxed{ C = AB \cap A'B' } \]

Punctul lor de intersecție determină experimental poziția centrului de greutate.

Verificare

Alte puncte de suspendare

Experiența poate fi repetată suspendând corpul din alte puncte.

Direcțiile verticale obținute trebuie să treacă prin același punct \(C\).

\[ \boxed{ \text{toate verticalele} \longrightarrow C } \]

Aceasta constituie o verificare experimentală a poziției centrului de greutate.

Corpuri omogene

Utilizarea simetriei

Pentru corpurile omogene cu forme geometrice regulate, determinarea centrului de greutate poate fi simplificată folosind proprietățile de simetrie.

Dacă un corp omogen posedă o axă de simetrie, centrul său de greutate se află pe aceasta.

\[ \boxed{ C \in \text{axa de simetrie} } \]
Plan de simetrie

Centrul de greutate aparține planului de simetrie

Dacă un corp omogen posedă un plan de simetrie, centrul său de greutate trebuie să se afle în acel plan.

\[ \boxed{ C \in \text{planul de simetrie} } \]

Dacă există mai multe axe sau plane de simetrie, poziția centrului este stabilită prin intersecția lor.

Exemplu

Sfera omogenă

Pentru o sferă omogenă, orice diametru reprezintă o axă de simetrie.

Toate diametrele se intersectează în centrul geometric al sferei.

\[ \boxed{ C = \text{centrul sferei} } \]
Exemplu

Cilindrul omogen

Pentru un cilindru omogen, centrul de greutate se află pe axa cilindrului.

El aparține și planului perpendicular pe axă care împarte înălțimea cilindrului în două părți egale.

\[ \boxed{ C = \text{centrul geometric al cilindrului} } \]
Exemplu

Bara prismatică dreaptă

O bară prismatică dreaptă și omogenă posedă mai multe plane de simetrie.

Centrul de greutate se află în punctul comun al acestor plane.

\[ \boxed{ C = \text{intersecția planelor de simetrie} } \]
Corpuri compuse

Împărțirea în corpuri simple

Pentru un corp cu formă geometrică mai complicată, Compendiul recomandă, atunci când este posibil, împărțirea sa în părți cu forme regulate.

Pentru fiecare parte se determină centrul de greutate separat.

\[ C_1,\, C_2,\, \ldots,\, C_n. \]
Sistem echivalent

Greutățile părților componente

Fiecărei părți îi corespunde o greutate:

\[ \vec G_1,\, \vec G_2,\, \ldots,\, \vec G_n \]

aplicată în centrul de greutate al părții respective.

Centrul de greutate al corpului compus este punctul de aplicație al rezultantei acestor forțe paralele.

Poziția rezultantei

Relația vectorială

Dacă \(\vec r_i\) reprezintă vectorul de poziție al elementului de masă \(m_i\), iar \(M\) este masa totală:

\[ M = \sum_{i=1}^{N}m_i. \]

Poziția centrului de greutate este exprimată prin relația reluată din §5.2:

\[ \boxed{ \vec r_G = \frac{ \displaystyle \sum_{i=1}^{N} m_i\vec r_i }{ \displaystyle \sum_{i=1}^{N} m_i } } \]

sau:

\[ \boxed{ \vec r_G = \frac1M \sum_{i=1}^{N} m_i\vec r_i } \]
Interpretare

Medie ponderată prin mase

Poziția centrului de greutate rezultă ca o medie a pozițiilor elementelor corpului, ponderată cu masele acestora.

\[ x_G = \frac{ \sum_i m_i x_i }{ \sum_i m_i } \]
\[ y_G = \frac{ \sum_i m_i y_i }{ \sum_i m_i } \]
\[ z_G = \frac{ \sum_i m_i z_i }{ \sum_i m_i }. \]
Corp omogen

Densitatea este constantă

Pentru un corp omogen, densitatea:

\[ \rho \]

este aceeași pentru toate elementele.

Masa unui element de volum \(V_i\) este:

\[ \boxed{ m_i=\rho V_i } \]
Simplificare

Poziția depinde de geometrie

Introducând:

\[ m_i=\rho V_i \]

în relația centrului de greutate:

\[ \vec r_G = \frac{ \sum_i \rho V_i\vec r_i }{ \sum_i \rho V_i }. \]

Densitatea se simplifică:

\[ \boxed{ \vec r_G = \frac{ \displaystyle \sum_i V_i\vec r_i }{ \displaystyle \sum_i V_i } } \]
Volumul total

\(V=\sum V_i\)

Dacă:

\[ V=\sum_i V_i, \]

relația poate fi scrisă:

\[ \boxed{ \vec r_G = \frac1V \sum_i V_i\vec r_i } \]

Pentru un corp omogen, poziția centrului este astfel determinată de forma geometrică și distribuția volumului.

Observație importantă

Centrul de greutate poate fi în afara materialului

Bunget atrage atenția că centrul de greutate nu trebuie să aparțină neapărat substanței corpului.

Acest lucru apare, în special, pentru corpuri găurite sau corpuri cu cavități.

\[ \boxed{ C \text{ poate fi în afara substanței corpului} } \]
Exemplu

Sfera goală

Pentru o sferă goală omogenă și concentrică, centrul de greutate se află în centrul comun al suprafețelor sferice.

Acel punct poate să nu aparțină materialului propriu-zis al corpului.

\[ \boxed{ C = \text{centrul geometric al sferei goale} } \]
Legătura cu §5.2

Centrul de greutate și centrul de masă

La finalul §6.4, Compendiul face legătura directă cu noțiunea introdusă în §5.2.

În cadrul tratării utilizate de Bunget, centrul de greutate coincide cu centrul de masă al rigidului.

\[ \boxed{ \vec r_G = \vec r_C } \]

De aceea este reutilizată aceeași relație:

\[ \vec r_C = \frac{ \sum_i m_i\vec r_i }{ M }. \]
Observația finală a sursei

Demonstrația nu este reluată

Compendiul precizează că demonstrarea completă, în cadrul staticii, a relației pentru poziția centrului de greutate este mai complicată.

Ea nu este dezvoltată în acest paragraf.

§6.4 utilizează relația stabilită anterior pentru centrul de masă.

Legătura logică

De la greutățile elementelor la centrul de greutate

Element material

\[ G_i=m_i g } \]

Sistem de greutăți

\[ \vec G_i \parallel \vec G_j } \]

Greutatea totală

\[ \boxed{ \vec G = \sum_i \vec G_i } \]

Centrul de greutate

Punctul de aplicație al rezultantei \(\vec G\).

Poziția centrului

\[ \boxed{ \vec r_G = \frac1M \sum_i m_i\vec r_i } \]

Corp omogen

\[ \boxed{ \vec r_G = \frac1V \sum_i V_i\vec r_i } \]
Metoda experimentală

Determinarea prin suspendare

Prima suspendare

Se trasează verticala indicată de firul cu plumb.

\[ C\in d_1 } \]

A doua suspendare

Se trasează o nouă verticală.

\[ C\in d_2 } \]

Centrul de greutate

\[ \boxed{ C=d_1\cap d_2 } \]

Verificare

Verticalele corespunzătoare altor puncte de suspendare trebuie să treacă prin același punct.

Sinteză

De reținut din §6.4

Greutatea corpului

\[ \boxed{ G=Mg } \]

Rezultanta greutăților

\[ \boxed{ \vec G = \sum_i \vec G_i } \]

Centrul de greutate

Punctul de aplicație al greutății rezultante.

Determinare experimentală

\[ \boxed{ C = \text{intersecția verticalelor de suspendare} } \]

Simetrie

Pentru corpuri omogene, centrul de greutate aparține axelor și planelor de simetrie.

Corpuri găurite

Centrul poate fi situat în afara materialului.

Poziția

\[ \boxed{ \vec r_G = \frac{ \sum_i m_i\vec r_i }{ \sum_i m_i } } \]

Corp omogen

\[ \boxed{ \vec r_G = \frac{ \sum_i V_i\vec r_i }{ \sum_iV_i } } \]
Titularizare

Precizări pentru examen

Această secțiune este separată de conținutul §6.4 al Compendiului. Reperul oficial utilizat este programa pentru Titularizare Fizică 2026.

Statut în programa 2026

„Centrul de greutate” nu este enumerat ca temă științifică autonomă.

Programa cere însă explicit:

4. Principiile mecanicii newtoniene.

și:

6. Mișcarea solidului rigid cu axă fixă. Momente de inerție. Pendulul fizic.

Definiția operațională: centrul de greutate este punctul în care poate fi considerată aplicată rezultanta forțelor gravitaționale care acționează asupra corpului.
Greutatea: într-un câmp gravitațional uniform: \[ \boxed{ \vec G = M\vec g } \] Unitatea SI: \[ \boxed{ [G]=\mathrm N } \]
Precizare actuală importantă: centrul de masă și centrul de greutate sunt noțiuni distincte în general. Coincidența lor este directă atunci când câmpul gravitațional poate fi considerat uniform pe întinderea corpului.
Centrul de masă: pentru un sistem discret: \[ \boxed{ \vec r_C = \frac{ \sum_i m_i\vec r_i }{ M } } \] unde: \[ \boxed{ M=\sum_i m_i } \]
În câmp gravitațional uniform: \[ \vec G_i = m_i\vec g. \] Prin urmare: \[ \vec r_G = \frac{ \sum_i G_i\vec r_i }{ \sum_iG_i } \] devine: \[ \boxed{ \vec r_G = \frac{ \sum_i m_i\vec r_i }{ \sum_i m_i } = \vec r_C } \]
Nu afirma fără condiție: „centrul de greutate este întotdeauna centrul de masă”. Pentru pregătirea actuală, formulează:

în câmp gravitațional uniform, centrul de greutate coincide cu centrul de masă.
Pentru o distribuție continuă de masă: forma modernă a relației pentru centrul de masă este: \[ \boxed{ \vec r_C = \frac1M \int \vec r\,dm } \]
Pentru un corp omogen: \[ dm=\rho\,dV, \] cu \(\rho=\text{constant}\). Rezultă: \[ \boxed{ \vec r_C = \frac1V \int_V \vec r\,dV } \]
Greșeală frecventă: centrul de greutate nu trebuie să fie obligatoriu în interiorul materialului. Exemple:

inel;
cadru;
sferă goală;
corpuri cu decupaje.
Simetria este primul instrument de verificat: pentru un corp omogen:

dacă există un plan de simetrie, centrul se află în el;

dacă există o axă de simetrie, centrul se află pe ea;

dacă există mai multe elemente de simetrie, centrul se află la intersecția lor.
Atenție la cuvântul „omogen”. Simetria geometrică singură nu este suficientă dacă distribuția masei nu respectă aceeași simetrie.
Corp compus: dacă este format din părți de mase \(m_1,m_2,\ldots\) ale căror centre sunt cunoscute: \[ \boxed{ \vec r_C = \frac{ m_1\vec r_1+ m_2\vec r_2+\cdots }{ m_1+m_2+\cdots } } \]
În plan: \[ \boxed{ x_C = \frac{ \sum_i m_ix_i }{ \sum_i m_i } } \] și: \[ \boxed{ y_C = \frac{ \sum_i m_iy_i }{ \sum_i m_i } } \]
Pentru goluri sau decupaje: în calculele de corpuri compuse se poate utiliza convenția unei „mase negative” pentru partea eliminată. Aceasta este o metodă de calcul, nu o masă fizică negativă.
Metoda experimentală prin suspendare:

1. suspendă corpul dintr-un punct;
2. trasează verticala indicată de firul cu plumb;
3. suspendă corpul dintr-un al doilea punct;
4. trasează a doua verticală;
5. intersecția lor reprezintă centrul de greutate;
6. o a treia suspendare poate verifica rezultatul.
De ce funcționează metoda? În echilibru, greutatea nu trebuie să producă moment față de punctul de suspendare. Prin urmare, suportul lui \(\vec G\) trece prin punctul de suspendare: \[ \boxed{ M_A(G)=0 } \]
Tip de eroare experimentală: nu identifica centrul de greutate cu punctul de suspendare. Punctul de suspendare este numai un punct prin care trece verticala ce conține centrul de greutate.
Relevanță didactică directă: materialul încărcat pentru Titularizare 2020 conține chiar o activitate de laborator intitulată: „Centrul de greutate”. Dispozitivul utilizează o placă de carton cu formă neregulată, stativ, puncte de suspendare, fir cu plumb, creion și riglă.
Ideea experimentală cerută în materialul 2020: liniile verticale trasate la suspendarea corpului din puncte diferite se intersectează într-un singur punct. Acest punct este identificat drept centrul de greutate.
Pentru didactică, această activitate permite:

formularea unei ipoteze;
realizarea unei investigații;
observarea directă;
trasarea și compararea verticalelor;
formularea unei concluzii pe baza rezultatului experimental.
Delimitare față de §6.5: §6.4 definește și localizează centrul de greutate. Tipurile de echilibru:

stabil;
instabil;
indiferent;

precum și condițiile de răsturnare ale corpurilor sprijinite sunt dezvoltate în §6.5.
