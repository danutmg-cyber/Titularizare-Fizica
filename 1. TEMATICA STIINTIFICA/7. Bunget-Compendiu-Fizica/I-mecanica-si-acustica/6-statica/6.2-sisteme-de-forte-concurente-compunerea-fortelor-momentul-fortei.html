6.2 Sisteme de forțe concurente. Compunerea forțelor. Momentul forței

Forțe alunecătoare, sisteme de forțe concurente, compunerea și descompunerea forțelor, momentul unei forțe, momentul unui sistem de forțe și teorema lui Varignon.

Punct de plecare

Două forțe egale și direct opuse

Compendiul pornește de la un corp rigid asupra căruia acționează două forțe egale ca modul și direct opuse.

Prin „direct opuse” se înțelege că forțele au același suport și sensuri contrare.

\[ \vec F \qquad\text{și}\qquad -\vec F \]

Sistemul format de aceste două forțe nu modifică starea de mișcare sau de repaus a rigidului.

Echivalență

Introducerea sau suprimarea unei perechi de forțe

Dacă asupra unui corp rigid acționează un sistem de forțe, se pot introduce două forțe egale și direct opuse, fără a modifica efectul mecanic al sistemului.

Invers, o asemenea pereche poate fi suprimată fără a modifica efectul asupra rigidului.

\[ \vec F+(-\vec F)=\vec0 \]
Consecință

Forța aplicată rigidului este un vector alunecător

Proprietatea precedentă permite deplasarea punctului de aplicație al unei forțe de-a lungul propriului său suport, fără modificarea efectului exterior asupra corpului rigid.

Forță alunecătoare

Forță al cărei punct de aplicație poate fi deplasat pe suportul său, fără modificarea efectului mecanic asupra rigidului.

\[ \boxed{ \text{forța poate aluneca pe propriul suport} } \]
Construcția din Compendiu

Deplasarea forței din \(A\) în \(B\)

Se consideră o forță \(\vec F\) aplicată în punctul \(A\).

Pe același suport se alege un alt punct \(B\).

În \(B\) se introduc două forțe:

\[ \vec F \qquad\text{și}\qquad -\vec F. \]

Forța \(\vec F\) din \(A\) și forța \(-\vec F\) din \(B\) sunt direct opuse și pot fi suprimate.

Rămâne numai forța \(\vec F\) aplicată în \(B\).

\[ \boxed{ A \longrightarrow B \quad \text{pe același suport} } \]
Definiție

Forțe concurente

Sistem de forțe concurente

Sistem de forțe care acționează asupra rigidului și au același punct de aplicație.

Deoarece punctele de aplicație ale forțelor pot fi deplasate de-a lungul suporturilor, pot fi tratate drept concurente și forțe ale căror suporturi se intersectează într-un punct comun.

Principiul suprapunerii

Rezultanta forțelor concurente

Dacă asupra rigidului acționează mai multe forțe concurente, efectul lor poate fi înlocuit prin efectul unei singure forțe: rezultanta.

Deoarece forța este o mărime vectorială, rezultanta este suma vectorială a forțelor.

\[ \boxed{ \vec R = \sum_{i=1}^{n} \vec F_i } \]

Aceasta este relația (6.1) din Compendiu.

Caz particular

Forțe pe același suport

Dacă toate forțele acționează pe aceeași dreaptă, rezultanta are aceeași direcție.

Mărimea și sensul rezultantei se obțin prin însumarea algebrică a forțelor, după alegerea unui sens pozitiv.

\[ \boxed{ R = \sum_i \varepsilon_iF_i } \]

unde:

\[ \varepsilon_i=\pm1 \]

exprimă sensul fiecărei forțe pe direcția comună.

Două forțe concurente

Regula paralelogramului

Dacă suporturile celor două forțe sunt diferite, ele se compun după regula paralelogramului.

\[ \vec R = \vec F_1+\vec F_2. \]

Dacă \(\alpha\) este unghiul dintre \(\vec F_1\) și \(\vec F_2\), modulul rezultantei este:

\[ \boxed{ R^2 = F_1^2 + F_2^2 + 2F_1F_2\cos\alpha } \]

Aceasta este relația (6.2).

Consecințe geometrice

Cazuri particulare

Același sens

\[ \alpha=0 \]
\[ \boxed{ R=F_1+F_2 } \]

Sensuri opuse

\[ \alpha=\pi \]
\[ \boxed{ R=|F_1-F_2| } \]

Forțe perpendiculare

\[ \alpha=\frac{\pi}{2} \]
\[ \boxed{ R = \sqrt{ F_1^2+F_2^2 } } \]
Mai multe forțe

Compunerea succesivă

Pentru mai mult de două forțe concurente, Bunget procedează prin compuneri succesive.

De exemplu, pentru patru forțe:

\[ \vec R_1 = \vec F_1+\vec F_2, \]
\[ \vec R_2 = \vec R_1+\vec F_3, \]
\[ \vec R = \vec R_2+\vec F_4. \]

Rezultatul este aceeași sumă vectorială:

\[ \boxed{ \vec R = \vec F_1+ \vec F_2+ \vec F_3+ \vec F_4 } \]
Construcție grafică

Poligonul forțelor

Compunerea succesivă poate fi realizată grafic prin așezarea vectorilor forță unul după altul.

Extremitatea primei forțe devine originea celei de-a doua, apoi se continuă în același mod pentru toate forțele.

Vectorul care unește originea primei forțe cu extremitatea ultimei reprezintă rezultanta.

\[ \boxed{ \text{poligonul forțelor} \longrightarrow \vec R } \]
Echilibru

Poligonul forțelor se închide

Dacă extremitatea ultimului vector coincide cu originea primului, rezultanta este nulă.

\[ \boxed{ \vec R=\vec0 } \]

Pentru un sistem de forțe concurente, aceasta este condiția de echilibru de translație.

Problema inversă

Descompunerea unei forțe

Compendiul menționează și problema inversă compunerii.

O forță \(\vec F\) poate fi descompusă după două direcții date.

\[ \vec F = \vec F_1+\vec F_2. \]

Construcția se face tot prin regula paralelogramului.

Mărime mecanică

Momentul unei forțe

Bunget reia definiția momentului forței, introdusă anterior în §3.7.

Dacă \(\vec r\) este vectorul de poziție al punctului de aplicație al forței față de punctul \(O\):

\[ \boxed{ \vec M_O = \vec r \times \vec F } \]

Aceasta este relația (6.3) din Compendiu.

Modul

Brațul forței

Modulul momentului este:

\[ M_O = rF\sin\alpha, \]

unde \(\alpha\) este unghiul dintre \(\vec r\) și \(\vec F\).

Dacă:

\[ d=r\sin\alpha \]

este distanța perpendiculară dintre punctul \(O\) și suportul forței, atunci:

\[ \boxed{ M_O=Fd } \]
Brațul forței

Distanța perpendiculară dintre punctul față de care se calculează momentul și suportul forței.

Caz particular

Suportul trece prin punctul \(O\)

Dacă suportul forței trece prin punctul față de care calculăm momentul:

\[ d=0. \]

Prin urmare:

\[ \boxed{ M_O=0 } \]

Forța nu are efect de rotație față de acel punct.

Sistem de forțe

Momentul rezultant

Pentru un sistem de \(n\) forțe, momentul rezultant față de punctul \(O\) este suma vectorială a momentelor fiecărei forțe.

\[ \boxed{ \vec M_O = \sum_{i=1}^{n} \vec r_i \times \vec F_i } \]

Aceasta este relația (6.4).

Caracter vectorial

Momentele se adună vectorial

Momentul unei forțe este o mărime vectorială.

De aceea, momentul total al unui sistem de forțe nu se obține prin simpla adunare a modulelor.

\[ \boxed{ \vec M_O = \sum_i \vec M_{O,i} } \]
Proprietate

Rezultanta și momentul se comportă diferit

Bunget subliniază că rezultanta forțelor:

\[ \vec R = \sum_i\vec F_i \]

nu se modifică atunci când schimbăm punctul față de care analizăm sistemul.

Momentul rezultant, în schimb, depinde de punctul ales.

\[ \boxed{ \vec M_O \neq \vec M_{O'} \quad \text{în general} } \]
Schimbarea punctului

Momentul față de \(O'\)

Fie:

\[ \vec a = \overrightarrow{OO'}. \]

Vectorul de poziție al punctului de aplicație față de \(O'\) devine:

\[ \vec r_i' = \vec r_i-\vec a. \]

Prin însumarea momentelor:

\[ \boxed{ \vec M_{O'} = \vec M_O - \vec a \times \vec R } \]

Aceasta este forma relației (6.5) din Compendiu.

Consecință

Dacă rezultanta este nulă

Dacă:

\[ \vec R=\vec0, \]

relația de schimbare a punctului devine:

\[ \boxed{ \vec M_{O'} = \vec M_O } \]

În acest caz particular, momentul rezultant nu depinde de punctul ales.

Caz plan

Forțe într-un plan perpendicular pe axa de rotație

Compendiul consideră apoi o axă de rotație care trece prin punctul \(O\) și este perpendiculară pe planul în care se află forțele.

În această situație, momentele tuturor forțelor sunt orientate în lungul axei de rotație.

Forma scalară

Semnul momentului

Pentru fiecare forță, se notează cu \(d_i\) brațul forței.

Se introduce un factor de semn:

\[ \varepsilon_i = \pm1. \]

Compendiul ia semnul pozitiv pentru tendința de rotație în sens trigonometric și semnul negativ pentru sensul opus.

\[ \boxed{ M_O = \sum_{i=1}^{n} \varepsilon_i d_iF_i } \]

Aceasta este relația (6.6).

Interpretare

Tendința de rotație

Sens trigonometric

\[ M>0 \]

Sens invers trigonometric

\[ M<0 \]

Convenția de semn trebuie menținută consecvent pentru toate forțele din aceeași problemă.

Echivalență

O singură forță cu același moment

Pentru un moment total \(M_O\) dat, pot exista mai multe forțe care să producă același efect de rotație.

Dacă o forță echivalentă are modulul \(F\) și brațul \(d\):

\[ \boxed{ M_O=dF } \]

Brațul și modulul forței pot avea valori diferite, cu condiția ca produsul lor să dea același moment.

Rezultanta

Momentul rezultantei

Rezultanta:

\[ \vec R = \sum_i\vec F_i \]

trebuie să producă același efect mecanic exterior ca sistemul de forțe pe care îl înlocuiește.

Dacă \(d_R\) este brațul rezultantei față de \(O\):

\[ \boxed{ M_O = d_RR } \]
Teoremă

Teorema lui Varignon

Bunget ajunge la relația:

\[ M_O = \sum_i \varepsilon_i d_iF_i = d_RR. \]
Teorema lui Varignon

Momentul rezultantei unui sistem de forțe față de un punct este egal cu suma momentelor forțelor componente față de același punct.

\[ \boxed{ \vec M_O(\vec R) = \sum_i \vec M_O(\vec F_i) } \]

În cazul plan discutat:

\[ \boxed{ d_RR = \sum_i \varepsilon_i d_iF_i } \]

Aceasta este relația (6.7).

Observația Compendiului

Teorema nu este limitată la forțe concurente

Bunget precizează că teorema lui Varignon are o valabilitate mai largă decât cazul analizat în acest paragraf.

Ea nu este limitată numai la sistemele de forțe concurente.

Caz tridimensional

Forța nu se află în planul perpendicular pe axă

Dacă forța nu este situată într-un plan perpendicular pe axa de rotație, vectorul momentului său nu mai este orientat integral în lungul axei.

Momentul poate fi descompus în două componente.

Descompunerea momentului

Două efecte mecanice

Componenta paralelă cu axa

Produce tendința de rotație în jurul axei respective.

Componenta perpendiculară pe axă

Tinde să modifice poziția sau orientarea axei.

\[ \vec M = \vec M_{\parallel} + \vec M_{\perp} \]
Legătura logică

De la forțe concurente la momentul rezultantei

Forțe pe rigid

\[ \text{vectori alunecători} \]

\[ \text{suporturi cu punct comun} \]

\[ \boxed{ \vec M_O = \sum_i \vec r_i \times \vec F_i } \]

\[ \boxed{ \vec M_O(\vec R) = \sum_i \vec M_O(\vec F_i) } \]
Sinteză

De reținut din §6.2

Forță alunecătoare

Pe un corp rigid, punctul de aplicație poate fi deplasat pe suportul forței fără schimbarea efectului mecanic exterior.

Forțe concurente

Forțe ale căror suporturi au un punct comun.

Precizări pentru examen

Statut în programa 2026

„Sisteme de forțe concurente” și „teorema lui Varignon” nu sunt enumerate ca puncte științifice autonome.

Programa cere însă explicit:

4. Principiile mecanicii newtoniene.

și:

6. Mișcarea solidului rigid cu axă fixă. Momente de inerție. Pendulul fizic.

Compunerea forțelor și momentul forței sunt instrumente fundamentale pentru aplicarea acestor noțiuni.

Rezultanta: \[ \boxed{ \vec R = \sum_i \vec F_i } \] Pentru echilibru de translație: \[ \boxed{ \sum_i \vec F_i = \vec0 } \]
Pe componente: într-o problemă plană: \[ \boxed{ \sum F_x=0 } \] \[ \boxed{ \sum F_y=0 } \] pentru echilibrul de translație.
Momentul unei forțe față de punctul \(O\): \[ \boxed{ \vec M_O = \vec r \times \vec F } \] Modulul: \[ M_O = rF\sin\alpha \] sau: \[ \boxed{ M_O=Fd } \] unde \(d\) este brațul perpendicular al forței.
Greșeală frecventă: brațul forței nu este, în general, distanța dintre punctul \(O\) și punctul de aplicație. Brațul este distanța perpendiculară de la \(O\) la suportul forței. \[ \boxed{ d=r\sin\alpha } \]
Altă greșeală: dacă suportul forței trece prin axa sau punctul față de care calculăm momentul: \[ d=0, \] chiar dacă forța este mare. Prin urmare: \[ \boxed{ M=0 } \]
Unitatea SI: \[ \boxed{ [M] = \mathrm{N\,m} } \]
Momentul forței și energia au aceeași dimensiune, dar nu sunt aceeași mărime. Lucrul mecanic se exprimă în jouli: \[ \mathrm J, \] în timp ce pentru moment se păstrează notația: \[ \mathrm{N\,m}. \]
Echilibrul complet al unui rigid: în problemele plane, condițiile uzuale sunt: \[ \boxed{ \sum F_x=0 } \] \[ \boxed{ \sum F_y=0 } \] \[ \boxed{ \sum M_O=0 } \]
Numai \(\sum\vec F=\vec0\) nu este suficient pentru un rigid. Este posibil ca rezultanta forțelor să fie nulă, dar momentul rezultant să fie nenul. În această situație corpul poate avea tendință de rotație.
Teorema lui Varignon este foarte utilă în calcule: \[ \boxed{ M_O(\vec R) = \sum_i M_O(\vec F_i) } \] Poți calcula momentul unei forțe folosind componentele sale, dacă acest lucru simplifică problema.
Exemplu: dacă: \[ \vec F = F_x\vec i+ F_y\vec j, \] atunci: \[ M_O(\vec F) = M_O(F_x\vec i) + M_O(F_y\vec j). \] Aceasta este o aplicație directă a teoremei lui Varignon.
Forță alunecătoare: proprietatea deplasării unei forțe pe propriul suport se aplică în mecanica corpului rigid . Pentru un corp deformabil, schimbarea punctului în care este aplicată efectiv forța poate modifica distribuția solicitărilor și deformațiile.
Pentru două forțe concurente: dacă se cunoaște unghiul dintre ele: \[ \boxed{ R = \sqrt{ F_1^2+ F_2^2+ 2F_1F_2\cos\alpha } } \] Este aplicarea teoremei cosinusului la paralelogramul forțelor.
Nu introduce modulele direct în relațiile vectoriale. Relația: \[ \vec R = \vec F_1+\vec F_2 \] este vectorială. Relația: \[ R = F_1+F_2 \] este adevărată numai în cazul particular în care cele două forțe sunt coliniare și au același sens.
Strategie eficientă pentru probleme de statică:

1. izolezi corpul;
2. desenezi numai forțele externe care acționează asupra lui;
3. alegi axele de coordonate;
4. descompui forțele convenabil;
5. scrii condițiile de echilibru de translație;
6. alegi inteligent punctul față de care calculezi momentele;
7. scrii: \[ \sum M_O=0; \]
8. verifici semnele, unitățile și rezultatul fizic.
Alegerea punctului pentru momente: este adesea avantajos să alegi punctul prin care trec suporturile unor forțe necunoscute. Pentru acele forțe: \[ d=0 \] și deci momentul lor față de acel punct este nul.
Relevanță didactică: în materialul încărcat pentru Titularizare 2019, echilibrul unei bare este analizat experimental prin compararea momentelor forțelor. Condiția utilizată este: \[ \boxed{ \sum M=0 } \] alături de condiția echilibrului de translație: \[ \boxed{ \sum\vec F=\vec0 } \]
