8.2 Pârghii

Definiția pârghiei, pârghii de ordinul I, II și III, condiția de echilibru, avantajul de forță, economia de deplasare și conservarea lucrului mecanic.

Ion Bunget Compendiu de Fizică §8.2

8.2 Pârghii
Pagini: 178–181
Definiție

Ce este o pârghie

Bunget consideră o bară sau, mai general, un corp care se poate roti în jurul unui punct fix \(O\).

Asupra corpului acționează:

Forța activă

\[ \boxed{ F } \]

Forța rezistentă

\[ \boxed{ R } \]
Pârghie

Bară sau corp care se poate roti în jurul unui punct fix \(O\), sub acțiunea unei forțe active și a unei forțe rezistente.

Element geometric

Punctul de sprijin

Punctul fix în jurul căruia se poate roti pârghia este notat cu:

\[ \boxed{ O } \]

și este numit punct de sprijin.

Axa de rotație trece prin acest punct.

Geometria sistemului

Forțele și axa de rotație

În configurația generală prezentată de Compendiu, suporturile forței active și forței rezistente se găsesc într-un plan perpendicular pe axa de rotație.

Acest plan trece prin punctul de sprijin \(O\).

Clasificare

Cele trei ordine de pârghii

Clasificarea se face în funcție de poziția punctului de sprijin față de punctele în care acționează forța activă și forța rezistentă.

Ordinul I

Sprijinul între cele două forțe

La pârghia de ordinul I, punctul de sprijin \(O\) se află între forța activă \(F\) și forța rezistentă \(R\).

\[ \boxed{ F \;-\; O \;-\; R } \]
Pârghie de ordinul I

Punctul de sprijin este situat între forța activă și forța rezistentă.

Exemple din Compendiu

Pârghii de ordinul I

ranga;

balanța;

foarfecele;

cleștele de cuie.

Bunget precizează că foarfecele și cleștele reprezintă pârghii duble.

Ordinul II

Forța rezistentă între sprijin și forța activă

La pârghia de ordinul II, punctul de aplicație al forței rezistente este situat între punctul de sprijin \(O\) și punctul de aplicație al forței active \(F\).

\[ \boxed{ O \;-\; R \;-\; F } \]
Pârghie de ordinul II

Forța rezistentă este situată între punctul de sprijin și forța activă.

Exemple din Compendiu

Pârghii de ordinul II

roaba;

spărgătorul de nuci.

Ordinul III

Forța activă între sprijin și forța rezistentă

La pârghia de ordinul III, forța activă este aplicată într-un punct situat între punctul de sprijin și punctul de aplicație al forței rezistente.

\[ \boxed{ O \;-\; F \;-\; R } \]
Pârghie de ordinul III

Forța activă este situată între punctul de sprijin și forța rezistentă.

Exemple din Compendiu

Pârghii de ordinul III

pedala tocilarului;

penseta;

antebrațul.

Observație

Pârghia dreaptă este un caz particular

Bunget atrage atenția că pârghia nu trebuie imaginată obligatoriu ca o bară dreaptă cu toate punctele importante pe aceeași linie.

Cazul în care:

bara este dreaptă;

punctele de aplicație și sprijinul sunt coliniare;

forțele sunt paralele și de sensuri opuse

este numai un caz particular al configurației generale.

Echilibrul

Tendințele de rotație

Forța rezistentă tinde să rotească pârghia într-un anumit sens în jurul punctului \(O\).

Forța activă este orientată astfel încât să producă o tendință de rotație în sens opus.

\[ \vec M_O(F) \quad\text{și}\quad \vec M_O(R) \]

trebuie să se compenseze la echilibru.

Reacțiunea sprijinului

Echilibrul de translație

Rezultanta forței active și a forței rezistente este echilibrată de reacțiunea exercitată în punctul de sprijin.

Pentru stabilirea condiției de rotație, Bunget calculează momentele față de punctul \(O\).

Brațele forțelor

\(d_F\) și \(d_R\)

Notăm cu \(d_F\) brațul forței active:

Brațul forței active

Distanța perpendiculară de la punctul de sprijin \(O\) la suportul forței active.

Analog, \(d_R\) este brațul forței rezistente.

\[ d_F, \qquad d_R \]
Relația (8.1)

Condiția de echilibru a pârghiei

La echilibru, modulele momentelor celor două forțe față de punctul de sprijin sunt egale.

\[ \boxed{ Fd_F = Rd_R } \]

Aceasta este condiția de echilibru a pârghiei utilizată de Bunget.

Formă echivalentă

Raportul forțelor

Din condiția:

\[ Fd_F = Rd_R \]

rezultă:

\[ \boxed{ \frac{R}{F} = \frac{d_F}{d_R} } \]

Raportul dintre forța rezistentă și forța activă este deci determinat de raportul brațelor.

Observația Compendiului

Cele trei ordine sunt o clasificare tradițională

Bunget observă că împărțirea în pârghii de ordinul I, II și III este păstrată în mecanică mai ales prin tradiție.

Din punct de vedere al calculului, toate situațiile sunt cuprinse în teoria momentelor.

\[ \boxed{ \sum M_O=0 } \]
Avantaj de forță

Când \(d_F>d_R\)

Dacă brațul forței active este mai mare decât brațul forței rezistente:

\[ d_F>d_R, \]

atunci din condiția de echilibru rezultă:

\[ \boxed{ R>F } \]

O forță activă mai mică poate echilibra astfel o forță rezistentă mai mare.

Raport

Amplificarea forței

\[ \boxed{ \frac{R}{F} = \frac{d_F}{d_R} } \]

Cu cât brațul forței active este mai mare față de brațul forței rezistente, cu atât forța rezistentă care poate fi echilibrată este mai mare.

Bunget arată că acest caz poate apărea la pârghii de ordinul I și II.

Geometrie

Deplasările punctelor

Din geometria rotației și din triunghiurile asemenea folosite de Bunget, deplasările punctelor de aplicație sunt proporționale cu distanțele lor față de punctul de sprijin.

\[ \boxed{ \frac{AA'}{BB'} = \frac{d_F}{d_R} } \]
Combinarea relațiilor

Forță și deplasare

Din condiția de echilibru:

\[ \frac{R}{F} = \frac{d_F}{d_R}, \]

iar din geometria deplasărilor:

\[ \frac{AA'}{BB'} = \frac{d_F}{d_R}. \]

Rezultă:

\[ \boxed{ \frac{R}{F} = \frac{AA'}{BB'} } \]

Punctul de aplicație al forței active se deplasează mai puțin decât punctul de aplicație al forței rezistente.

Bunget exprimă această proprietate ca o economie de deplasare.

Concluzie

Forță sau deplasare

Compendiul sintetizează astfel avantajele pârghiilor:

Putem economisi forță

atunci când brațul forței active este suficient de mare.

Putem economisi deplasare

atunci când punctul forței active se află mai aproape de sprijin.

Aceste două avantaje nu înseamnă însă obținerea unui câștig de lucru mecanic.

Lucrul mecanic

Nu se câștigă lucru mecanic

Bunget demonstrează această afirmație folosind aceeași pârghie de ordinul III și două poziții foarte apropiate.

Pentru o rotație foarte mică, deplasările punctelor de aplicație pot fi tratate în direcțiile forțelor considerate în demonstrație.

Forța rezistentă

Lucrul mecanic rezistent

Forța rezistentă este orientată în sens opus deplasării punctului său de aplicație.

Lucrul ei este negativ:

\[ \boxed{ L_R = -R\,BB' } \]
Forța activă

Lucrul mecanic activ

Pentru forța activă, în configurația considerată:

\[ \boxed{ L_F = F\,AA' } \]
Relația finală

Conservarea lucrului mecanic

Relația dintre forțe și deplasări conduce la:

\[ R\,BB' = F\,AA'. \]

Prin urmare, în valoare absolută:

\[ \boxed{ |L_R| = L_F } \]

iar cu semne:

\[ \boxed{ L_F+L_R=0 } \]

Compendiul concluzionează că pentru pârghia ideală lucrul mecanic se conservă.

Generalizare

Rezultatul este valabil pentru toate cele trei ordine

Demonstrația este prezentată pentru o pârghie de ordinul III.

Bunget precizează că un raționament asemănător conduce la același rezultat pentru celelalte categorii de pârghii.

\[ \boxed{ L_{\mathrm{activ}} = |L_{\mathrm{rezistent}}| } \]
Ipoteză esențială

Fără frecare în punctul de sprijin

La finalul §8.2, Bunget precizează explicit ipoteza în care au fost obținute atât condiția de echilibru, cât și conservarea lucrului mecanic.

\[ \boxed{ \text{frecarea în punctul de sprijin este neglijată} } \]

Rezultatele prezentate în această formă descriu, așadar, pârghia idealizată.

Titularizare

Precizări pentru examen

Această secțiune este separată de corpul §8.2 al Compendiului. Reperul oficial utilizat este programa pentru Titularizare Fizică 2026.

Statut în programa 2026

„Pârghiile” și „mașinile simple” nu sunt enumerate ca teme științifice autonome.

Ele constituie însă aplicații directe ale principiilor mecanicii, momentului forței, echilibrului și lucrului mecanic.

Condiția generală de echilibru de rotație: \[ \boxed{ \sum M_O=0 } \] Pentru pârghia cu două forțe: \[ Fd_F-Rd_R=0, \] deci: \[ \boxed{ Fd_F=Rd_R } \]
Brațul unei forțe: nu este în general distanța de la \(O\) la punctul de aplicație. Este distanța perpendiculară de la punctul de sprijin la suportul forței. \[ \boxed{ d = \text{distanța perpendiculară la suport} } \]
Greșeală frecventă: dacă forța nu este perpendiculară pe bară, nu se poate utiliza automat lungimea barei drept braț. Forma generală este: \[ M_O = rF\sin\alpha. \] Echivalent: \[ \boxed{ M_O=Fd } \]
Avantajul mecanic ideal: putem defini: \[ A_m = \frac{R}{F}. \] Pentru pârghia ideală în echilibru: \[ \boxed{ A_m = \frac{d_F}{d_R} } \]
Dacă: \[ d_F>d_R, \] atunci: \[ A_m>1 \] și: \[ \boxed{ R>F } \] Pârghia oferă avantaj de forță.
Dacă: \[ d_FR } \] Nu există avantaj de forță, dar poate exista avantaj de deplasare.
Clasificarea în ordine nu spune singură dacă există avantaj de forță. Ordinul pârghiei este determinat de pozițiile relative ale:

punctului de sprijin;
forței active;
forței rezistente.

Avantajul mecanic este determinat de raportul brațelor.
Ordinul I: \[ \boxed{ F-O-R } \] poate avea: \[ d_F>d_R, \] \[ d_F=d_R \] sau: \[ d_F
Ordinul II: \[ \boxed{ O-R-F } \] în configurația uzuală are: \[ d_F>d_R, \] deci: \[ \boxed{ R>F } \]
Ordinul III: \[ \boxed{ O-F-R } \] are: \[ d_FR } \] Nu amplifică forța, dar punctul rezistent poate avea o deplasare mai mare.
Antebrațul: Bunget îl dă ca exemplu de pârghie de ordinul III. În modelul mecanic simplificat:

articulația cotului joacă rolul sprijinului;
forța musculară este aplicată între cot și sarcina de la extremitatea antebrațului.
Unitatea SI pentru braț: \[ \boxed{ [d]=\mathrm m } \] Pentru momentul forței: \[ \boxed{ [M]=\mathrm{N\,m} } \]
Nu confunda: momentul forței: \[ \mathrm{N\,m} \] și energia: \[ \mathrm J. \] Au aceeași dimensiune, dar reprezintă mărimi fizice diferite.
Pentru o rotație mică \(d\varphi\): un punct aflat la distanța \(r\) de axă parcurge: \[ ds=r\,d\varphi. \] Astfel, pentru cele două puncte ale pârghiei: \[ \frac{ds_F}{ds_R} = \frac{d_F}{d_R} \] în configurația în care brațele coincid cu razele relevante.
Pentru pârghia ideală: \[ F\,ds_F = R\,ds_R. \] Prin urmare: \[ \boxed{ L_{\mathrm{activ}} = |L_{\mathrm{rezistent}}| } \] Acesta este schimbul dintre forță și deplasare.
Nu există avantaj simultan gratuit de forță și de deplasare. Dacă: \[ R>F, \] deplasarea asociată forței active trebuie să fie corespunzător mai mare pentru o mașină ideală.
Forma energetică: în modul: \[ \boxed{ F\,s_F = R\,s_R } \] pentru pârghia ideală și deplasările compatibile cu modelul.
Într-o pârghie reală: frecările, deformările și alte pierderi fac ca rezultatul ideal să nu fie realizat perfect. Nu atribui însă această completare §8.2: Bunget încheie paragraful prin ipoteza explicită a lipsei frecării în punctul de sprijin.
Metodă rapidă de rezolvare:

1. marchează punctul de sprijin \(O\);
2. reprezintă \(F\), \(R\) și reacțiunea sprijinului;
3. determină brațele perpendiculare \(d_F\) și \(d_R\);
4. stabilește sensul pozitiv al momentelor;
5. scrie: \[ \sum M_O=0; \]
6. obține: \[ Fd_F=Rd_R; \]
7. verifică dacă rezultatul exprimă avantaj de forță sau de deplasare;
8. verifică unitățile.
Alegerea punctului \(O\) este foarte eficientă: reacțiunea sprijinului trece prin \(O\), deci brațul ei față de \(O\) este nul. \[ \boxed{ M_O(R_O)=0 } \] Astfel reacțiunea necunoscută dispare din ecuația momentelor.
Verificare dimensională: în relația: \[ Fd_F=Rd_R, \] ambele membre au unitatea: \[ \mathrm{N\,m}. \] Relația este dimensional corectă.
Statut pentru Titularizare: programa oficială 2026 nu enumeră „pârghiile” ca punct științific autonom. Noțiunea trebuie privită aici ca aplicație a mecanicii newtoniene, momentului forței, echilibrului și lucrului mecanic.
