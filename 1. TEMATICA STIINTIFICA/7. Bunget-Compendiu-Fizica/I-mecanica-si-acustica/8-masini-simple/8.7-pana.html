8.7 Pana

Pana ca mașină simplă, reacțiunile pieselor laterale, forțele de frecare, echilibrul unei pene simetrice, amplificarea forței laterale și condiția de menținere după batere.

Ion Bunget Compendiu de Fizică §8.7
Sursa

Compendiu de Fizică

Partea I. Mecanică și acustică
8. Mașini simple
8.7 Pana

Pagini: 193–194 în transcrierea ediției 1972.
§8.8 Șurubul urmează imediat.
Definiție

Ce este pana

Bunget prezintă pana ca pe o piesă de îmbinare având forma unei prisme triunghiulare.

Ea este introdusă între două piese, notate în figura I.8.16 cu:

\[ A \qquad\text{și}\qquad B. \]
Pană

Piesă cu formă de prismă triunghiulară care, prin introducerea între două corpuri, transformă acțiunea unei forțe aplicate în efecte laterale asupra acestora.

Utilizări

Exemple indicate de Compendiu

Bunget menționează utilizarea penei:

în construcția pieselor;

la îmbinarea pieselor;

la despicarea lemnului.

Forța activă

Introducerea penei

Forța activă este notată:

\[ \boxed{ F } \]

Ea împinge pana în locașul dintre cele două piese.

Prin suprafețele sale laterale, pana acționează asupra pieselor \(A\) și \(B\).

Contactul lateral

Reacțiuni și frecare

Cele două piese laterale exercită asupra penei reacțiunile normale:

\[ \boxed{ N_1 \qquad\text{și}\qquad N_2 } \]

La contact apar, de asemenea, forțe de frecare:

\[ F_{f1} \qquad\text{și}\qquad F_{f2}. \]
Echilibru

Sistemul de forțe

Pana se află în echilibru atunci când acțiunea forței active este compensată de reacțiunile pereților și de forțele de frecare.

\[ \boxed{ \vec F + \vec N_1 + \vec N_2 + \vec F_{f1} + \vec F_{f2} = \vec0 } \]
Proiecția pe axa penei

Echilibrul pe direcția forței active

Proiectând forțele pe direcția axei penei, Bunget obține:

\[ \boxed{ F = N_1\sin\alpha + N_2\sin\alpha + F_{f1}\cos\alpha + F_{f2}\cos\alpha } \]

Unghiul \(\alpha\) este unghiul geometric utilizat în figura I.8.16 pentru fețele penei.

Caz simetric

Reacțiuni egale

Pentru o pană simetrică, cele două reacțiuni normale au aceeași valoare:

\[ \boxed{ N_1=N_2=N } \]

Compendiul utilizează pentru frecare:

\[ F_f=\mu N. \]
Simplificare

Forța activă și reacțiunea

Relația de echilibru devine:

\[ F = 2N\sin\alpha + 2\mu N\cos\alpha. \]

Factorizând:

\[ \boxed{ F = 2N \left( \sin\alpha + \mu\cos\alpha \right) } \]
Relația (8.21)

Reacțiunea normală

Din relația precedentă rezultă reacțiunea fiecăruia dintre pereți:

\[ \boxed{ N = \frac{ F }{ 2 \left( \sin\alpha + \mu\cos\alpha \right) } } \]
Efectul util

Forța exercitată asupra uneia dintre piesele laterale

Bunget determină apoi forța cu care pana împinge lateral una dintre piesele \(A\) sau \(B\).

Notăm această forță cu:

\[ R. \]

Componenta reacțiunii normale care produce efectul lateral este:

\[ N\cos\alpha, \]

iar frecarea introduce componenta opusă:

\[ F_f\sin\alpha. \]
Forța laterală

Expresia lui \(R\)

Rezultă:

\[ R = N\cos\alpha - F_f\sin\alpha. \]

Deoarece:

\[ F_f=\mu N, \]

obținem:

\[ \boxed{ R = N \left( \cos\alpha - \mu\sin\alpha \right) } \]
Eliminarea reacțiunii

Legătura directă dintre \(F\) și \(R\)

Din relația forței laterale:

\[ N = \frac{ R }{ \cos\alpha - \mu\sin\alpha }. \]

Introducând această expresie în relația de echilibru a penei, se obține relația dintre forța activă și efectul lateral.

Relația (8.22)

Forța necesară pentru introducerea penei

\[ \boxed{ F = 2R \frac{ \sin\alpha + \mu\cos\alpha }{ \cos\alpha - \mu\sin\alpha } } \]

Relația arată influența simultană a geometriei penei și a frecării asupra forței necesare.

Simetrie

Cealaltă piesă laterală

Deoarece pana considerată este simetrică, pentru cealaltă piesă se obține o relație analogă.

\[ \boxed{ R_1=R_2=R } \]

în configurația simetrică analizată.

Mișcare inversă

Scoaterea penei

Bunget analizează apoi situația în care pana este scoasă dintre cele două piese.

Sensul tendinței de mișcare se inversează.

Ca urmare, se inversează și sensul forțelor de frecare.

\[ \boxed{ \text{scoaterea penei} \Rightarrow \text{inversarea sensului frecării} } \]
Relația pentru scoatere

Forța activă la mișcarea inversă

După schimbarea sensului frecărilor, relația corespunzătoare devine:

\[ \boxed{ F = 2R \frac{ \sin\alpha - \mu\cos\alpha }{ \cos\alpha + \mu\sin\alpha } } \]
Condiție de fixare

Când pana rămâne fixată după batere

Bunget urmărește condiția în care pana nu tinde să iasă singură din locaș după introducere.

Pentru aceasta, forța corespunzătoare scoaterii trebuie să fie nulă sau să aibă sensul opus celui necesar extragerii spontane.

\[ \boxed{ F\leq0 } \]
Condiția geometrică

Numărătorul relației

Din expresia forței la scoatere, condiția relevantă este:

\[ \sin\alpha - \mu\cos\alpha \leq0. \]

Rezultă:

\[ \sin\alpha \leq \mu\cos\alpha. \]
Concluzia §8.7

Condiția de menținere a penei

Împărțind prin \(\cos\alpha\), pentru configurația analizată:

\[ \boxed{ \mu \geq \tan\alpha } \]

Aceasta este condiția care rezultă din analiza Compendiului pentru ca pana să rămână fixată după batere.

Sinteză

De reținut din §8.7

Forma penei

Efect mecanic

\[ N_1=N_2=N \]

\[ \boxed{ N = \frac{ F }{ 2( \sin\alpha + \mu\cos\alpha ) } } \]

\[ \boxed{ R = N( \cos\alpha - \mu\sin\alpha ) } \]

\[ \boxed{ F = 2R \frac{ \sin\alpha + \mu\cos\alpha }{ \cos\alpha - \mu\sin\alpha } } \]

Titularizare

Precizări pentru examen

Această secțiune este separată de corpul §8.7 al Compendiului. Reperul oficial utilizat este programa pentru Titularizare Fizică 2026.

Statut în programa 2026

„Pana” și „mașinile simple” nu sunt enumerate ca teme științifice autonome.

§8.7 este însă o aplicație directă a principiilor mecanicii newtoniene, echilibrului forțelor și frecării.

Mărimi și unități SI: \[ [F] = [R] = [N] = [F_f] = \mathrm N \] iar coeficientul de frecare: \[ \boxed{ [\mu]=1 } \]
Ideea fizică esențială: pana transformă o forță aplicată aproximativ în lungul axei sale în două acțiuni laterale. Pentru o pană simetrică: \[ \boxed{ R_1=R_2 } \]
Atenție la factorul 2: în relația: \[ F = 2R \frac{ \sin\alpha + \mu\cos\alpha }{ \cos\alpha - \mu\sin\alpha }, \] \(R\) reprezintă forța laterală exercitată asupra uneia dintre cele două piese. Nu este suma celor două forțe laterale.
Cazul fără frecare: pentru: \[ \mu=0, \] relația de introducere devine: \[ F = 2R \frac{ \sin\alpha }{ \cos\alpha }. \] Deci: \[ \boxed{ F = 2R\tan\alpha } \]
Avantajul de forță în cazul ideal: din: \[ F=2R\tan\alpha \] rezultă: \[ \boxed{ \frac RF = \frac{ 1 }{ 2\tan\alpha } } \] pentru forța laterală exercitată asupra unei singure piese.
Interpretare: pentru o pană cu unghi mic \(\alpha\), \(\tan\alpha\) este mic. Astfel, o forță axială relativ mică poate produce o forță laterală considerabilă.
Verificare de limită: dacă: \[ \alpha\rightarrow0, \] atunci, în modelul fără frecare: \[ F = 2R\tan\alpha \rightarrow0. \] Rezultatul exprimă avantajul mecanic foarte mare al unei pene foarte ascuțite în modelul idealizat.
În realitate, frecarea nu poate fi ignorată tocmai în această analiză. §8.7 este un exemplu în care frecarea nu reprezintă numai o pierdere energetică. Ea poate contribui și la menținerea penei în poziție.
Precizare modernă despre frecare: pentru frecarea statică nu se scrie în general: \[ F_f=\mu N. \] Relația generală este: \[ \boxed{ F_f \leq \mu_sN } \] iar egalitatea este atinsă la limita alunecării.
La mișcare iminentă: \[ \boxed{ F_f = \mu_sN } \] iar sensul frecării este întotdeauna opus tendinței de alunecare relativă.
De aceea, sensul frecării se schimbă când trecem de la introducerea penei la scoaterea ei. Nu se schimbă valoarea coeficientului de frecare din acest motiv; se schimbă sensul forței de frecare.
Introducere: \[ \boxed{ F_{\mathrm{in}} = 2R \frac{ \sin\alpha + \mu\cos\alpha }{ \cos\alpha - \mu\sin\alpha } } \]
Scoatere: \[ \boxed{ F_{\mathrm{out}} = 2R \frac{ \sin\alpha - \mu\cos\alpha }{ \cos\alpha + \mu\sin\alpha } } \]
Nu confunda semnele. La introducere, termenul de frecare din numărător se adaugă: \[ \sin\alpha + \mu\cos\alpha. \] La scoatere, datorită inversării sensului frecării: \[ \sin\alpha - \mu\cos\alpha. \]
Condiția de autoblocare: pentru ca pana să nu tindă să iasă singură: \[ \sin\alpha - \mu\cos\alpha \leq0. \] Deci: \[ \boxed{ \mu \geq \tan\alpha } \]
Unghiul de frecare: definind: \[ \tan\varphi = \mu, \] condiția precedentă poate fi scrisă: \[ \boxed{ \alpha \leq \varphi } \] pentru domeniul geometric uzual.
Delimitare de sursă: formularea prin „unghiul de frecare” este o completare modernă de interpretare. Bunget formulează concluzia direct prin relația dintre \(\mu\) și \(\tan\alpha\).
Sens fizic al autoblocării: când frecarea este suficient de mare în raport cu unghiul penei, reacțiunile de contact și frecarea împiedică extragerea spontană.
Greșeală conceptuală: „mai multă frecare” nu înseamnă aici numai că este necesară o forță mai mare la introducere. Frecarea este și mecanismul care poate produce fixarea penei după batere.
Verificarea formulei de introducere: dacă: \[ \mu\rightarrow0, \] atunci: \[ F \rightarrow 2R \frac{ \sin\alpha }{ \cos\alpha } \] și: \[ \boxed{ F = 2R\tan\alpha } \] deci se recuperează cazul fără frecare.
Verificare dimensională: în relația: \[ F = 2R \frac{ \sin\alpha + \mu\cos\alpha }{ \cos\alpha - \mu\sin\alpha }, \] raportul este adimensional. Prin urmare: \[ \boxed{ [F]=[R]=\mathrm N } \]
Schema de rezolvare pentru o problemă cu pană:

1. desenează pana și piesele laterale;
2. indică forța activă \(F\);
3. reprezintă reacțiunile normale \(N_1\) și \(N_2\);
4. stabilește tendința de mișcare;
5. trasează frecările în sens opus tendinței de alunecare;
6. pentru pana simetrică, folosește: \[ N_1=N_2=N; \]
7. proiectează forțele pe axa penei și pe direcția laterală;
8. elimină reacțiunea \(N\);
9. verifică limita: \[ \mu\rightarrow0; \]
10. verifică unitățile și sensul fizic al rezultatului.
Eroare tipică: folosirea aceleiași orientări a frecării atât la introducerea, cât și la extragerea penei. Frecarea trebuie stabilită de fiecare dată după tendința de mișcare.
Statut pentru Titularizare 2026: „pana” nu apare ca punct științific autonom. Ea trebuie privită ca aplicație a principiilor mecanicii newtoniene, echilibrului și forțelor de frecare.
