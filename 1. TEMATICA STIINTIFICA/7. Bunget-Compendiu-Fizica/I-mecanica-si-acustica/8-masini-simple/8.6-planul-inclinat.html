8.6 Planul înclinat

Descompunerea greutății, condiția de echilibru, avantajul de forță, conservarea lucrului mecanic și influența frecării atunci când forța activă este aplicată oblic.

Ion Bunget Compendiu de Fizică §8.6

Definiție

Rolul planului înclinat

Bunget prezintă planul înclinat ca pe o mașină simplă care permite reducerea forței necesare pentru ridicarea unei greutăți.

Plan înclinat

Mașină simplă prin intermediul căreia o greutate poate fi ridicată la o anumită înălțime folosind o forță mai mică decât greutatea corpului, în modelul ideal.

Figura I.8.15 a

Corp pe un plan înclinat

Se consideră un corp așezat pe un plan care formează cu orizontala unghiul:

\[ \boxed{ \alpha } \]

Greutatea corpului, considerată de Bunget drept forța rezistentă, este notată:

\[ \boxed{ R } \]
Descompunerea greutății

Componente paralelă și perpendiculară

Forța \(R\) este descompusă în două componente.

Componenta paralelă cu planul

\[ \boxed{ R_{\parallel} = R\sin\alpha } \]

Aceasta tinde să deplaseze corpul în jos, de-a lungul planului.

Componenta perpendiculară pe plan

\[ \boxed{ R_{\perp} = R\cos\alpha } \]

Aceasta apasă corpul asupra planului.

Reacțiunea planului

Echilibrul pe direcția perpendiculară

În primul caz analizat, fără frecare și cu forța activă aplicată în lungul planului, componenta perpendiculară:

\[ R\cos\alpha \]

este echilibrată de reacțiunea normală a planului:

\[ \boxed{ N = R\cos\alpha } \]
Relația (8.17)

Forța activă necesară

Pentru echilibrul corpului pe direcția planului, forța activă \(F\) trebuie să echilibreze componenta:

\[ R\sin\alpha. \]

Prin urmare:

\[ \boxed{ F = R\sin\alpha } \]
Avantaj mecanic

De ce se economisește forță

Pentru un plan cu:

\[ 0<\alpha<90^\circ, \]

avem:

\[ \sin\alpha<1. \]

Din:

\[ F = R\sin\alpha \]

rezultă:

\[ \boxed{ F
Geometria planului

Lungimea și înălțimea

Bunget notează lungimea planului înclinat cu:

\[ l \]

și înălțimea acestuia cu:

\[ h. \]

Din geometria triunghiului dreptunghic:

\[ \boxed{ \sin\alpha = \frac hl } \]
Relația (8.18)

Formula planului înclinat

Înlocuind:

\[ \sin\alpha = \frac hl \]

în relația:

\[ F=R\sin\alpha, \]

se obține:

\[ \boxed{ F = R\frac hl } \]

Aceasta este formula planului înclinat ideal prezentată de Compendiu.

Formă echivalentă

Raportul forțelor

Din:

\[ F = R\frac hl \]

rezultă:

\[ \boxed{ \frac RF = \frac lh } \]

Cu cât lungimea planului este mai mare față de înălțimea sa, cu atât forța activă necesară este mai mică, în modelul ideal.

Lucrul mecanic

Ridicarea directă pe verticală

Pentru a ridica greutatea \(R\) direct pe verticală la înălțimea \(h\), lucrul mecanic necesar este:

\[ \boxed{ L = Rh } \]
Ridicarea pe plan

Lucrul forței active

Dacă același corp este ridicat pe plan până la aceeași înălțime, punctul de aplicație al forței active parcurge lungimea:

\[ l. \]

Lucrul mecanic este:

\[ \boxed{ L' = Fl } \]
Conservarea lucrului

Planul înclinat ideal

Folosind:

\[ F = R\frac hl, \]

obținem:

\[ L' = Fl = R\frac hl l. \]

Deci:

\[ \boxed{ L' = Rh = L } \]

Bunget arată astfel că și în cazul planului înclinat ideal lucrul mecanic se conservă.

Interpretare

Forță mai mică, drum mai lung

Avantajul de forță este compensat de distanța mai mare pe care trebuie deplasat corpul.

Ridicare verticală

\[ R \quad\text{pe}\quad h \]

Plan înclinat

\[ F \quad\text{pe}\quad l \]

cu:

\[ \boxed{ Fl=Rh } \]
Figura I.8.15 b

Cazul cu frecare și forță oblică

Bunget consideră apoi o situație mai generală.

Forța activă \(F\) nu mai este neapărat paralelă cu planul, ci formează cu acesta un unghi:

\[ \boxed{ \beta } \]

În plus, între corp și plan există frecare.

Forțele

Sistemul de forțe

În modelul prezentat acționează:

Forța activă

\[ F \]

Greutatea / forța rezistentă

\[ R \]

Reacțiunea normală

\[ N \]

Forța de frecare

\[ F_f \]
Echilibru

Relația vectorială

Bunget scrie echilibrul corpului sub forma compensării celor patru forțe.

Proiectarea pe direcția paralelă și pe direcția perpendiculară pe plan conduce la două ecuații scalare.

Proiecția pe plan

Ecuația paralelă

Componenta forței active în lungul planului este:

\[ F\cos\beta. \]

Ea echilibrează componenta greutății și forța de frecare.

\[ \boxed{ F\cos\beta = R\sin\alpha + F_f } \]
Proiecția perpendiculară

Ecuația normală

Componenta:

\[ F\sin\beta \]

este orientată astfel încât să micșoreze apăsarea corpului asupra planului.

Bunget scrie:

\[ \boxed{ F\sin\beta + N = R\cos\alpha } \]
Reacțiunea normală

Influența forței oblice

Din ecuația perpendiculară rezultă:

\[ \boxed{ N = R\cos\alpha - F\sin\beta } \]

Componenta normală a forței active reduce reacțiunea planului în configurația analizată de Compendiu.

Legea frecării

Forța de frecare

Bunget utilizează relația:

\[ \boxed{ F_f = \mu N } \]

unde \(\mu\) este coeficientul de frecare.

Eliminarea lui \(N\)

Ecuația forței active

Înlocuind:

\[ F_f = \mu \left( R\cos\alpha - F\sin\beta \right) \]

în ecuația paralelă:

\[ F\cos\beta = R\sin\alpha + \mu \left( R\cos\alpha - F\sin\beta \right). \]
Gruparea termenilor

Termenii care conțin \(F\)

Regrupând:

\[ \boxed{ F \left( \cos\beta + \mu\sin\beta \right) = R \left( \sin\alpha + \mu\cos\alpha \right) } \]
Relația (8.19)

Forța activă în cazul general

Bunget obține:

\[ \boxed{ F = R \frac{ \sin\alpha + \mu\cos\alpha }{ \cos\beta + \mu\sin\beta } } \]
Relația (8.20)

Forța activă paralelă cu planul

Dacă forța activă este aplicată chiar în lungul planului:

\[ \beta=0. \]

Atunci:

\[ \cos\beta=1, \qquad \sin\beta=0. \]

Relația devine:

\[ \boxed{ F = R \left( \sin\alpha + \mu\cos\alpha \right) } \]
Verificarea limitei

Revenirea la planul ideal

Dacă frecarea este neglijată:

\[ \mu=0, \]

relația precedentă devine:

\[ \boxed{ F = R\sin\alpha } \]

adică relația (8.17) obținută la începutul paragrafului.

Sinteză

De reținut din §8.6

Componentele greutății

\[ \boxed{ R_{\parallel} = R\sin\alpha } \]
\[ \boxed{ R_{\perp} = R\cos\alpha } \]

Plan ideal

\[ \boxed{ F = R\sin\alpha } \]

Geometrie

\[ \boxed{ \sin\alpha = \frac hl } \]

Formula planului înclinat

\[ \boxed{ F = R\frac hl } \]

Conservarea lucrului

\[ \boxed{ Fl=Rh } \]

Cu frecare și forță oblică

\[ \boxed{ F = R \frac{ \sin\alpha + \mu\cos\alpha }{ \cos\beta + \mu\sin\beta } } \]

Cu frecare, \(F\) paralelă cu planul

\[ \boxed{ F = R \left( \sin\alpha + \mu\cos\alpha \right) } \]
Titularizare

Precizări pentru examen

Această secțiune este separată de conținutul §8.6 al Compendiului. Reperul oficial utilizat este programa pentru Titularizare Fizică 2026.

Statut în programa 2026

„Planul înclinat” și „mașinile simple” nu sunt enumerate ca teme științifice autonome.

Planul înclinat este însă o aplicație directă a principiilor mecanicii newtoniene, a descompunerii forțelor și a conservării energiei.

Atenție la notația Bunget: în §8.6, simbolul: \[ R \] desemnează forța rezistentă, adică greutatea corpului . Nu desemnează reacțiunea normală. Pentru reacțiunea planului Bunget folosește: \[ \boxed{ N } \]
În notație modernă pentru probleme: este adesea mai clar să scriem greutatea: \[ \boxed{ G=mg } \] și reacțiunea normală: \[ \boxed{ N } \]
Unități SI: \[ [F] = [R] = [N] = \mathrm N \] \[ [l] = [h] = \mathrm m \] \[ [\mu]=1. \] Unghiurile \(\alpha\) și \(\beta\) sunt adimensionale; în calcul trigonometria utilizează valoarea unghiului conform convenției calculatorului.
Alegerea axelor: pentru planul înclinat, cea mai eficientă alegere este:

axa \(Ox\) paralelă cu planul;
axa \(Oy\) perpendiculară pe plan.
Greutatea: dacă: \[ G=mg, \] componentele sunt: \[ \boxed{ G_x = mg\sin\alpha } \] și: \[ \boxed{ G_y = mg\cos\alpha } \]
Greșeală foarte frecventă: inversarea lui \(\sin\alpha\) și \(\cos\alpha\). Pentru unghiul planului față de orizontală: \[ \boxed{ G_{\parallel} = mg\sin\alpha } \] \[ \boxed{ G_{\perp} = mg\cos\alpha } \]
Verificare fizică rapidă: dacă: \[ \alpha\rightarrow0, \] atunci: \[ G_{\parallel} \rightarrow0 \] și: \[ G_{\perp} \rightarrow mg. \] Acesta este rezultatul corect pentru un plan aproape orizontal.
Cealaltă limită: dacă: \[ \alpha\rightarrow90^\circ, \] atunci: \[ G_{\parallel} \rightarrow mg, \] iar: \[ G_{\perp} \rightarrow0. \]
Plan ideal, mișcare uniformă sau echilibru: dacă forța \(F\) este paralelă cu planul: \[ F-mg\sin\alpha=0. \] Deci: \[ \boxed{ F = mg\sin\alpha } \]
Avantajul mecanic ideal: \[ A_m = \frac RF. \] Din: \[ F = R\frac hl \] rezultă: \[ \boxed{ A_m = \frac lh } \]
\(l/h\) nu reprezintă un câștig energetic. Este avantajul de forță al planului ideal. Forța mai mică acționează pe o distanță mai mare.
Conservarea energiei: pentru urcare fără frecare și fără variația energiei cinetice: \[ L_F = \Delta E_p. \] Astfel: \[ Fl = mgh. \] Dacă: \[ R=mg, \] obținem: \[ \boxed{ Fl=Rh } \]
Verificare prin energie: din: \[ Fl=mgh \] rezultă: \[ F = mg\frac hl. \] Cum: \[ \frac hl = \sin\alpha, \] recuperăm: \[ \boxed{ F = mg\sin\alpha } \]
Cu frecare și \(F\) paralelă cu planul: reacțiunea este: \[ \boxed{ N = mg\cos\alpha } \] dacă forța activă nu are componentă normală.
Pentru alunecare uniformă în sus în modelul Coulomb: \[ F_f = \mu N = \mu mg\cos\alpha. \] Ecuația pe direcția planului este: \[ F - mg\sin\alpha - \mu mg\cos\alpha = 0. \] Deci: \[ \boxed{ F = mg \left( \sin\alpha + \mu\cos\alpha \right) } \]
Precizare importantă despre frecarea statică: relația: \[ F_f=\mu N \] nu descrie orice stare de echilibru static. Pentru frecare statică: \[ \boxed{ F_f \leq \mu_s N } \] iar egalitatea apare la limita alunecării. Relațiile lui Bunget cu \(F_f=\mu N\) trebuie citite în modelul de frecare adoptat în §8.6.
Sensul frecării: forța de frecare se opune tendinței de mișcare relativă. Formula Bunget: \[ F = R \frac{ \sin\alpha + \mu\cos\alpha }{ \cos\beta + \mu\sin\beta } \] corespunde configurației în care corpul este tras în sus pe plan, iar frecarea se opune acestei tendințe.
De ce forța oblică modifică frecarea: componenta: \[ F\sin\beta \] tinde să desprindă parțial corpul de plan. De aceea: \[ N = mg\cos\alpha - F\sin\beta. \] Dacă \(N\) scade, scade și frecarea în modelul: \[ F_f=\mu N. \]
Condiție fizică a contactului: modelul cu corpul sprijinit pe plan presupune: \[ \boxed{ N\geq0 } \] Dacă relația ar conduce la: \[ N<0, \] corpul nu mai poate rămâne în contact cu planul în forma presupusă de model.
Verificarea formulei generale: pornim de la: \[ F = R \frac{ \sin\alpha + \mu\cos\alpha }{ \cos\beta + \mu\sin\beta }. \] Dacă: \[ \beta=0, \] rezultă: \[ \boxed{ F = R \left( \sin\alpha + \mu\cos\alpha \right) } \]
Dacă în plus: \[ \mu=0, \] obținem: \[ \boxed{ F = R\sin\alpha } \] exact relația planului ideal.
Acesta este un test foarte bun pentru formulă: o relație generală trebuie să redea corect cazurile-limită mai simple.
Lucrul mecanic al frecării, pentru urcarea pe distanța \(l\): dacă: \[ F_f=\mu N, \] atunci: \[ \boxed{ L_f = -F_f l } \] deoarece frecarea are sens opus deplasării.
Bilanț energetic cu frecare: pentru mișcare uniformă în sus: \[ L_F = \Delta E_p + E_{\mathrm{diss}}. \] În cazul \(F\parallel\) planului: \[ Fl = mgh + \mu mg\cos\alpha\,l. \]
Nu aplica simultan două metode incomplete. Poți rezolva problema prin:

ecuațiile lui Newton pe axele paralelă și perpendiculară;

sau prin energie, dacă toate lucrurile mecanice sunt incluse corect.
Schema recomandată pentru probleme:

1. transformă datele în SI;
2. desenează corpul și toate forțele;
3. alege axele: \[ Ox\parallel\text{plan}, \qquad Oy\perp\text{plan}; \]
4. descompune greutatea: \[ mg\sin\alpha, \qquad mg\cos\alpha; \]
5. calculează reacțiunea \(N\);
6. stabilește sensul frecării;
7. aplică: \[ \sum F_x=ma_x, \qquad \sum F_y=ma_y; \]
8. pentru echilibru sau mișcare uniformă: \[ a=0; \]
9. verifică energia și cazurile-limită;
10. scrie răspunsul cu unități.
Trei erori de evitat:

1. să scrii: \[ N=mg \] pe un plan înclinat;

2. să scrii automat: \[ F_f=\mu mg; \]

3. să alegi sensul frecării fără să analizezi tendința de mișcare.
Pentru planul ideal: trebuie să poți trece rapid între cele trei forme echivalente: \[ \boxed{ F = R\sin\alpha } \] \[ \boxed{ F = R\frac hl } \] \[ \boxed{ Fl = Rh } \]
Statut pentru Titularizare 2026: planul înclinat nu este enumerat ca temă autonomă. Programa cere însă explicit principiile mecanicii newtoniene și teoremele mecanicii clasice cu legile de conservare. Din acest motiv, §8.6 este o aplicație foarte bună pentru aceste teme.
