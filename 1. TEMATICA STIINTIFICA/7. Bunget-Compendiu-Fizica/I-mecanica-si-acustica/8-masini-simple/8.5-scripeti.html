8.5 Scripeți

Scripetele fix, scripetele mobil, influența frecării, sisteme de scripeți, palanul exponențial, palanul cu mufle și conservarea lucrului mecanic.

8.5 Scripeți

Definiție

Ce este scripetele

Bunget încadrează scripetele în categoria mașinilor bazate pe principiul pârghiei.

El este alcătuit dintr-un disc circular prevăzut pe margine cu un șanț prin care trece un cablu.

Scripete

Mașină simplă alcătuită dintr-un disc circular cu șanț periferic pentru cablu, discul putându-se roti în jurul unei axe care trece prin centrul său.

Construcție

Axul și furca

Axul scripetelui trece prin centrul discului.

Acesta este susținut într-o furcă terminată cu un cârlig.

Poziția furcii și posibilitatea deplasării axului diferențiază cele două tipuri simple analizate de Compendiu.

Clasificare

Cele două tipuri simple

Scripete fix

Axul scripetelui nu se deplasează în timpul funcționării.

Scripete mobil

Axul scripetelui se deplasează împreună cu sarcina.

a) Scripetele fix

Axul rămâne fix

La scripetele fix, furca este orientată în sus.

Scripetele nu se deplasează în timpul lucrului, ci numai se rotește în jurul axei sale.

\[ \boxed{ \text{scripete fix} \Rightarrow \text{axa nu se deplasează} } \]
Forțele

\(F\), \(R\) și reacțiunea axei

Asupra scripetelui acționează forța activă:

\[ F, \]

forța rezistentă:

\[ R, \]

și reacțiunea axei:

\[ N. \]

Reacțiunea axei echilibrează rezultanta forțelor transmise de cele două ramuri ale cablului.

Relația (8.10)

Scripetele fix ideal

Bunget presupune mai întâi că firul nu alunecă pe șanțul scripetelui și neglijează frecările.

Cele două forțe acționează la aceeași rază față de axă.

Condiția de echilibru a momentelor conduce la:

\[ \boxed{ F=R } \]
Interpretare

Nu există economie de forță

Pentru scripetele fix ideal:

\[ F=R. \]

Prin urmare, scripetele fix simplu nu micșorează valoarea forței active necesare.

\[ \boxed{ \frac RF=1 } \]
Avantaj

Schimbarea direcției forței

Avantajul scripetelui fix constă în posibilitatea schimbării direcției în care trebuie aplicată forța activă.

\[ \boxed{ \text{scripete fix} \Rightarrow \text{schimbarea convenabilă a direcției forței} } \]
Scripete real

Frecarea dintre roată și ax

Compendiul analizează apoi influența frecării dintre roata scripetelui și axul său.

Notăm cu \(D\) diametrul scripetelui, cu \(d\) diametrul fusului, iar cu \(\mu\) coeficientul de frecare.

Momentul forței active trebuie să echilibreze atât momentul forței rezistente, cât și momentul produs de frecare.

\[ \boxed{ F\frac D2 = R\frac D2 + \mu N\frac d2 } \]
Reacțiunea axei

Modulul lui \(N\)

Dacă \(\alpha\) este unghiul dintre suporturile forțelor \(F\) și \(R\), Compendiul dă pentru modulul reacțiunii:

\[ \boxed{ N = \sqrt{ F^2+R^2+2FR\cos\alpha } } \]
Caz particular

Suporturile forțelor paralele

Dacă suporturile sunt paralele în configurația analizată:

\[ \alpha=0. \]

Atunci:

\[ \boxed{ N=F+R } \]
Relația (8.11)

Forța activă când există frecare

Pentru \(\alpha=0\), relația momentelor devine:

\[ FD = RD + \mu(F+R)d. \]

Prin gruparea termenilor:

\[ F(D-\mu d) = R(D+\mu d). \]

Rezultă:

\[ \boxed{ F = R \frac{ D+\mu d }{ D-\mu d } } \]
Altă abatere de la idealizare

Cablul nu este perfect flexibil

Bunget mai observă că, în realitate, cablul are o anumită rigiditate.

Din acest motiv, el nu se așază perfect în șanțul scripetelui.

Luarea în calcul a acestei proprietăți complică suplimentar relațiile ideale.

b) Scripetele mobil

Axul se deplasează

Scripete mobil

Scripete al cărui ax se deplasează împreună cu sarcina.

Furca este orientată în jos, iar de ea este suspendată greutatea care trebuie ridicată.

Unul dintre capetele cablului este fixat.

Acțiunea forței active

\(F\) ridică scripetele și sarcina

Forța activă \(F\) ridică atât scripetele mobil, cât și sarcina suspendată de acesta.

Forța rezistentă este notată cu:

\[ R. \]
Tensiunea cablului

Relația (8.12)

Pe cealaltă ramură a cablului apare tensiunea \(T\).

Scriind ecuația momentelor în raport cu axa scripetelui:

\[ T\frac D2 = F\frac D2. \]

Rezultă:

\[ \boxed{ T=F } \]
Geometria cablului

Unghiul dintre cele două ramuri

Compendiul consideră unghiul \(\alpha\) dintre cele două ramuri ale cablului.

Cele două forțe \(T\) și \(F\) sunt simetrice față de direcția forței rezistente.

Relația (8.13)

Echilibrul scripetelui mobil

Componentele forțelor \(T\) și \(F\) pe direcția forței rezistente trebuie să echilibreze \(R\).

\[ T\cos\frac{\alpha}{2} + F\cos\frac{\alpha}{2} = R. \]

Cum:

\[ T=F, \]

rezultă:

\[ \boxed{ F = \frac{ R }{ 2\cos(\alpha/2) } } \]
Relația (8.14)

Ramuri paralele

Când cele două ramuri ale cablului sunt paralele:

\[ \alpha=0. \]

Deoarece:

\[ \cos0=1, \]

relația devine:

\[ \boxed{ F = \frac R2 } \]
Avantaj mecanic

Scripetele mobil economisește forță

Pentru ramuri paralele:

\[ F=\frac R2. \]

Prin urmare:

\[ \boxed{ \frac RF=2 } \]

Forța activă necesară este jumătate din forța rezistentă în modelul ideal.

Orientarea optimă

Când este \(F\) minimă

Din:

\[ F = \frac{ R }{ 2\cos(\alpha/2) }, \]

forța activă are valoarea minimă pentru:

\[ \alpha=0. \]

Bunget asociază acest caz cu orientarea verticală convenabilă a forței active.

Caz-limită

Cablu perfect întins

Compendiul examinează și limita:

\[ \alpha\rightarrow180^\circ. \]

Atunci:

\[ \cos\frac{\alpha}{2} \rightarrow0. \]

Din relația pentru \(F\):

\[ \boxed{ F\rightarrow\infty } \]
Aplicație

Legătura cu funicularele

Bunget folosește cazul-limită anterior pentru a explica de ce un cablu care susține o sarcină nu poate fi perfect întins.

Pe măsură ce cablul se apropie de poziția perfect întinsă, tensiunea necesară crește foarte mult.

Din acest motiv, cablul trebuie să aibă o anumită săgeată.

c) Sisteme de scripeți

Combinarea scripeților

Pentru obținerea unei economii mai mari de forță, scripeții pot fi combinați în sisteme.

Asocierea permite simultan:

reducerea forței active;

schimbarea convenabilă a direcției forței.

Combinație simplă

Un scripete mobil și unul fix

Compendiul arată că scripetele mobil este frecvent asociat cu un scripete fix.

Scripetele mobil oferă avantajul de forță, iar scripetele fix permite schimbarea sensului forței active.

Figura I.8.11

Sistem cu mai mulți scripeți mobili

Bunget consideră un sistem format din \(n\) scripeți mobili legați succesiv și un scripete fix.

Pentru fiecare scripete mobil ideal cu ramuri paralele, forța necesară se înjumătățește.

Relația (8.15)

Forța pentru \(n\) scripeți mobili

Aplicând succesiv:

\[ F=\frac R2, \]

pentru fiecare treaptă a sistemului, se obține:

\[ \boxed{ F = \frac{ R }{ 2^n } } \]
Denumire

Palan exponențial

Deoarece numărul scripeților mobili \(n\) apare la exponent în expresia forței active, Bunget menționează denumirea:

Palan exponențial

Sistem succesiv de scripeți mobili pentru care, în modelul ideal prezentat, forța activă scade după factorul \(2^n\).

\[ \boxed{ A_m = \frac RF = 2^n } \]
d) Palanul

Două mufle

Bunget prezintă apoi un alt tip de sistem de scripeți: palanul format din două mufle.

Muflă

Asociație de scripeți montați pe aceeași furcă.

Construcția muflei

Montarea scripeților

Dacă scripeții au același diametru, ei pot fi montați pe același ax.

Dacă au diametre diferite, pot fi montați pe axe paralele fixate în aceeași furcă.

Cele două mufle

Una fixă, una mobilă

Dintre cele două mufle ale palanului:

o muflă este fixă;

cealaltă muflă este mobilă.

Forța rezistentă acționează asupra muflei mobile.

Cablul

Un singur cablu continuu

Un capăt al cablului este legat de furca muflei fixe.

Cablul trece succesiv peste scripeții celor două mufle.

La capătul liber se aplică forța activă:

\[ F. \]
Model ideal

Tensiunea este aceeași în cablu

Pentru sistemul ideal analizat de Bunget, relațiile succesive pentru scripeți conduc la egalitatea tensiunilor din ramurile cablului.

\[ \boxed{ T_1=T_2=\cdots=F } \]
Exemplul din Compendiu

Trei scripeți în fiecare muflă

Pentru exemplul reprezentat de Bunget, mufla mobilă este susținută de șase ramuri ale cablului.

Fiecare ramură exercită, în modelul ideal, aceeași tensiune \(F\).

\[ \boxed{ R=6F } \]

deci:

\[ \boxed{ F=\frac R6 } \]
Relația (8.16)

Palan cu \(n\) scripeți în fiecare muflă

Dacă fiecare dintre cele două mufle conține \(n\) scripeți, mufla mobilă este susținută de \(2n\) ramuri ale cablului.

În modelul ideal:

\[ R=2nF. \]

Prin urmare:

\[ \boxed{ F = \frac{ R }{ 2n } } \]
Comparație

Două sisteme diferite

Sistem succesiv de scripeți mobili

\[ \boxed{ F = \frac{ R }{ 2^n } } \]

Palan cu două mufle, câte \(n\) scripeți în fiecare

\[ \boxed{ F = \frac{ R }{ 2n } } \]
Finalul §8.5

Conservarea lucrului mecanic

Bunget încheie studiul scripeților prin analizarea lucrului mecanic.

Exemplul ales este scripetele mobil simplu.

Figura I.8.14

Deplasarea sarcinii

Dacă scripetele mobil se ridică pe distanța:

\[ l, \]

punctul de aplicație al forței rezistente se ridică tot cu:

\[ l. \]
Capătul liber

Forța activă se deplasează pe \(2l\)

Cele două ramuri care susțin scripetele mobil trebuie să se scurteze fiecare cu \(l\).

Ca urmare, capătul liber al cablului trebuie deplasat cu:

\[ \boxed{ s_F=2l } \]
Forța rezistentă

Lucrul mecanic rezistent

Pentru ridicarea sarcinii pe distanța \(l\), lucrul forței rezistente are semn negativ:

\[ \boxed{ L_R=-Rl } \]
Forța activă

Lucrul mecanic motor

Forța activă se deplasează pe distanța \(2l\).

Lucrul său este:

\[ L_F=F\cdot2l. \]

Pentru scripetele mobil ideal:

\[ F=\frac R2. \]

Rezultă:

\[ \boxed{ L_F = Rl } \]
Concluzie

Fără frecare, lucrul mecanic se conservă

\[ \boxed{ L_F = |L_R| } \]

Echivalent, dacă se păstrează semnele lucrurilor:

\[ \boxed{ L_F+L_R=0 } \]

Economia de forță este compensată de o deplasare mai mare a punctului în care se aplică forța activă.

Sistem real

Când există frecare

Dacă frecările nu mai sunt neglijate, lucrul efectuat de forța activă trebuie să acopere și lucrul mecanic rezistent al forțelor de frecare.

\[ \boxed{ L_{\mathrm{activ}} = L_{\mathrm{util}} + L_{\mathrm{pierderi}} } \]
Legătura logică

Firul §8.5

Scripete fix ideal

\[ \boxed{ F=R } \]

Schimbă direcția forței.

Scripete mobil ideal

\[ \boxed{ F = \frac{ R }{ 2\cos(\alpha/2) } } \]

Ramuri paralele

\[ \boxed{ F=\frac R2 } \]

Sistem succesiv cu \(n\) scripeți mobili

\[ \boxed{ F = \frac R{2^n} } \]

Palan cu două mufle

\[ \boxed{ F = \frac R{2n} } \]

Lucru mecanic ideal

\[ \boxed{ L_F = |L_R| } \]
Sinteză

De reținut din §8.5

Scripete fix

\[ \boxed{ F=R } \]

Reacțiunea axei

\[ \boxed{ N = \sqrt{ F^2+R^2+2FR\cos\alpha } } \]

Scripete fix cu frecare, pentru \(\alpha=0\)

\[ \boxed{ F = R \frac{ D+\mu d }{ D-\mu d } } \]

Scripete mobil

\[ \boxed{ F = \frac{ R }{ 2\cos(\alpha/2) } } \]

Scripete mobil, ramuri paralele

\[ \boxed{ F=\frac R2 } \]

Palan exponențial

\[ \boxed{ F = \frac R{2^n} } \]

Palan cu mufle

\[ \boxed{ F = \frac R{2n} } \]

Scripete mobil ideal

\[ \boxed{ s_F=2s_R } \]

Conservarea lucrului

\[ \boxed{ Fs_F = Rs_R } \]
Titularizare

Precizări pentru examen

Această secțiune este separată de corpul §8.5 al Compendiului. Reperul oficial utilizat este programa pentru Titularizare Fizică 2026.

Statut în programa 2026

„Scripeții” și „mașinile simple” nu apar nominal ca teme științifice autonome.

Ele sunt însă aplicații directe ale:

principiilor mecanicii newtoniene;
echilibrului forțelor;
momentului forței;
legii conservării energiei.

Mărimi și unități SI: \[ [F]=[R]=[T]=[N] = \mathrm N \] \[ [D]=[d]=[l] = \mathrm m \] \[ [\mu]=1. \]
Scripete fix ideal: deoarece raza celor două forțe este aceeași: \[ Fr=Rr. \] Prin urmare: \[ \boxed{ F=R } \] și: \[ \boxed{ A_m = \frac RF = 1 } \]
Greșeală frecventă: scripetele fix simplu nu înjumătățește forța. Relația ideală este: \[ \boxed{ F=R } \] Avantajul lui este schimbarea direcției forței.
Scripete mobil ideal: pentru două ramuri verticale ale aceluiași cablu ideal, fiecare ramură exercită tensiunea: \[ T=F. \] Echilibrul vertical dă: \[ 2F=R. \] Deci: \[ \boxed{ F=\frac R2 } \]
Avantajul mecanic ideal: \[ A_m = \frac RF. \] Pentru un singur scripete mobil: \[ \boxed{ A_m=2 } \]
Nu număra scripeții, numără ramurile care susțin sarcina. Pentru un sistem ideal cu un singur cablu continuu, avantajul mecanic al muflei mobile este determinat de numărul ramurilor de cablu care susțin efectiv partea mobilă.
Regula practică pentru un palan ideal: dacă partea mobilă este susținută de \(m\) ramuri ale aceluiași cablu, fiecare având tensiunea \(T=F\): \[ R=mF. \] Prin urmare: \[ \boxed{ F=\frac Rm } \]
Această regulă nu trebuie aplicată mecanic palanului exponențial din Bunget. În sistemul succesiv din figura I.8.11, fiecare scripete mobil înjumătățește succesiv forța transmisă, astfel încât: \[ \boxed{ F=\frac R{2^n} } \]
Distincție de memorat: palan exponențial: \[ \boxed{ F=\frac R{2^n} } \] palan cu două mufle, câte \(n\) scripeți în fiecare: \[ \boxed{ F=\frac R{2n} } \] Sunt configurații mecanice diferite.
Cazul general al scripetelui mobil: dacă ramurile cablului formează unghiul \(\alpha\): \[ \boxed{ 2F \cos\frac{\alpha}{2} = R } \] deci: \[ \boxed{ F = \frac{ R }{ 2\cos(\alpha/2) } } \]
Observă dependența: pentru: \[ \alpha=0, \] avem: \[ F=\frac R2. \] Pe măsură ce \(\alpha\) crește: \[ \cos\frac{\alpha}{2} \downarrow \] și: \[ F\uparrow. \]
Caz-limită: \[ \alpha \rightarrow 180^\circ \] conduce la: \[ \cos\frac{\alpha}{2} \rightarrow0 \] și deci: \[ \boxed{ F\rightarrow\infty } \] în modelul idealizat.
Interpretarea fizică: o coardă care susține o sarcină între două puncte nu poate fi adusă perfect pe orizontală cu o tensiune finită. Este necesară o anumită săgeată a cablului.
Deplasările la scripetele mobil: dacă sarcina se ridică cu: \[ h, \] cele două segmente care susțin scripetele se scurtează fiecare cu \(h\). Capătul liber trebuie deplasat cu: \[ \boxed{ s_F=2h } \]
Lucrul mecanic ideal: \[ F=\frac R2 \] și: \[ s_F=2h. \] Atunci: \[ L_F = F s_F \] \[ = \frac R2 \cdot2h \] \[ = Rh. \] Deci: \[ \boxed{ L_F=L_{\mathrm{util}} } \]
Mașina simplă nu produce energie. La scripetele ideal: \[ \boxed{ \text{avantaj de forță} \Longleftrightarrow \text{deplasare mai mare} } \]
Cu frecări: lucrul activ trebuie să acopere atât lucrul util, cât și pierderile: \[ \boxed{ L_{\mathrm{activ}} = L_{\mathrm{util}} + L_{\mathrm{frecare}} } \] în bilanț de module pentru ridicarea sarcinii.
Formula cu frecare pentru scripetele fix: relația: \[ F = R \frac{ D+\mu d }{ D-\mu d } \] rezultă din modelul de frecare adoptat în Compendiu. Nu o transforma într-o formulă universală pentru orice scripete real.
Verificarea limitei ideale: dacă: \[ \mu\rightarrow0, \] atunci: \[ F \rightarrow R \frac DD = R. \] Se recuperează relația scripetelui fix ideal.
Metodă de rezolvare pentru un sistem de scripeți:

1. desenează fiecare corp sau muflă separat;
2. stabilește ce părți sunt fixe și ce părți sunt mobile;
3. identifică toate ramurile cablului;
4. pentru cablu ideal, stabilește unde tensiunea are aceeași valoare;
5. scrie echilibrul părții mobile;
6. nu număra automat numărul total de scripeți;
7. verifică deplasările folosind lungimea constantă a cablului;
8. verifică bilanțul energetic.
Eroare tipică: afirmația: „sunt trei scripeți, deci forța este \(R/3\)” nu este justificată. Rezultatul depinde de modul în care scripeții sunt conectați.
Verificare foarte bună a rezultatului: dacă un sistem ideal îți oferă un avantaj mecanic: \[ A_m = \frac RF, \] atunci deplasarea punctului de aplicație al forței active trebuie să fie, în configurația ideală corespunzătoare: \[ \boxed{ \frac{s_F}{s_R} = A_m } \] astfel încât: \[ Fs_F = Rs_R. \]
Legătura didactică: scripeții permit verificarea experimentală a raportului dintre:

forța activă;
numărul ramurilor portante;
deplasarea sarcinii;
deplasarea capătului liber.

Sunt potriviți pentru o activitate de laborator bazată pe dinamometru, mase marcate și măsurarea deplasărilor.
Pentru Titularizare 2026: scripeții nu sunt o temă autonomă în tematica științifică. Prioritatea lor este de aplicație pentru mecanică, echilibru și energie.
