8.8 Șurubul

Șurubul ca plan înclinat înfășurat pe un cilindru, pasul șurubului, unghiul elicei, piulița, momentul motor, frecarea în filet și condiția de autofixare.

Ion Bunget Compendiu de Fizică §8.8

Compendiu de Fizică

8.8 Șurubul

Pagini: 194–196.
§8.9 Randamentul mașinilor simple începe imediat după §8.8.
Definiție

Șurubul și planul înclinat

Bunget încadrează șurubul în categoria mașinilor simple derivate din planul înclinat.

Șurub

Corp format dintr-un cilindru drept pe a cărui suprafață laterală este realizat un șanț elicoidal.

La capătul superior, șurubul este prevăzut cu un element prin intermediul căruia poate fi rotit.

Interpretare geometrică

Filetul ca plan înclinat înfășurat pe cilindru

Dacă suprafața laterală a cilindrului este desfășurată într-un plan, urma elicoidală a filetului devine o linie oblică.

Se obține astfel imaginea geometrică a unui plan înclinat.

\[ \boxed{ \text{șurub} \longleftrightarrow \text{plan înclinat înfășurat pe cilindru} } \]
Mărime geometrică

Pasul șurubului

Pasul șurubului

Distanța cu care înaintează șurubul în lungul axei sale la efectuarea unei rotații complete.

Notăm pasul cu:

\[ \boxed{ h } \]
Unghiul filetului

Unghiul \(\alpha\)

Bunget notează cu \(\alpha\) unghiul făcut de urma filetului cu planul de rotație al șurubului.

\[ \boxed{ \alpha } \]

Acesta joacă rolul unghiului planului înclinat după desfășurarea suprafeței cilindrice.

Desfășurarea cilindrului

O rotație completă

Dacă raza cilindrului pe care este realizat filetul este \(r\), lungimea corespunzătoare unei rotații complete este:

\[ \boxed{ 2\pi r } \]

În același timp, șurubul înaintează axial cu pasul:

\[ h. \]
Relația (8.23)

Legătura dintre pas și unghiul elicei

Din triunghiul obținut prin desfășurarea suprafeței cilindrului rezultă:

\[ \boxed{ \tan\alpha = \frac{h}{2\pi r} } \]

Echivalent:

\[ \boxed{ h = 2\pi r\tan\alpha } \]
Element asociat

Piulița

Șurubul se înșurubează într-o piesă numită:

Piuliță

Piesă prevăzută cu un gol cilindric pe suprafața căruia este realizat un șanț elicoidal corespunzător filetului șurubului.

Elementele geometrice ale celor două filete trebuie să corespundă.

Configurații posibile

Șurub mobil sau piuliță mobilă

Compendiul precizează că în practică se întâlnesc situații în care:

piulița este fixă și șurubul este mobil;

șurubul este fix și piulița este mobilă.

Pentru analiză, Bunget alege cazul cu piulița fixă și șurubul mobil.

Rezultatele obținute rămân aplicabile și celorlalte situații corespunzătoare.

Figura I.8.18

Acțiunile asupra șurubului

Asupra șurubului acționează un cuplu sau moment motor:

\[ \boxed{ M_m } \]

produs de forța activă.

În notația Compendiului:

\[ \boxed{ M_m=FD } \]

unde \(D\) este brațul corespunzător forței active în configurația analizată.

Forța rezistentă

Sarcina axială

Forța rezistentă este notată:

\[ \boxed{ R } \]

și acționează în lungul axei șurubului.

Contactul dintre filete

Reacțiuni normale și forțe de frecare

În punctele de contact dintre filetul șurubului și filetul piuliței apar reacțiuni normale:

\[ N_i. \]

Apar și forțe de frecare tangențiale la filet:

\[ F_{fi}. \]

Bunget utilizează relația:

\[ \boxed{ F_{fi} = \mu N_i } \]

iar frecarea este orientată în sens opus deplasării.

Proiecția pe axă

Condiția de echilibru axial

Proiectând acțiunile de contact pe axa șurubului, relația poate fi scrisă:

\[ \boxed{ R = \left( \cos\alpha - \mu\sin\alpha \right) \sum_i N_i } \]

Suma se referă la toate punctele de contact ale filetului.

O rotație completă

Bilanțul lucrului mecanic

Bunget obține a doua relație necesară analizând lucrul mecanic efectuat într-o rotație completă.

La o rotație completă, șurubul înaintează pe distanța:

\[ h. \]

Lucrul motor trebuie să învingă:

lucrul asociat forței rezistente \(R\);

lucrul împotriva forțelor de frecare din filet.

Lucrul momentului motor

O rotație de \(2\pi\)

Pentru o rotație completă, lucrul momentului motor este:

\[ \boxed{ L_m = 2\pi M_m } \]

În același timp, lucrul necesar împotriva forței axiale este:

\[ Rh. \]
Relația (8.24)

Momentul necesar la înșurubare

Eliminând reacțiunile de contact și folosind relația geometrică:

\[ \tan\alpha = \frac{h}{2\pi r}, \]

se obține momentul motor:

\[ \boxed{ M_m = Rr \frac{ \sin\alpha + \mu\cos\alpha }{ \cos\alpha - \mu\sin\alpha } } \]
Relația (8.25)

Șurubul ideal

Dacă frecarea este neglijată:

\[ \mu=0, \]

relația precedentă devine:

\[ \boxed{ M_m = Rr\tan\alpha } \]

Folosind:

\[ \tan\alpha = \frac{h}{2\pi r}, \]

rezultă:

\[ \boxed{ M_m = \frac{Rh}{2\pi} } \]
Interpretare

Moment și deplasare axială

Relația ideală arată că la o rotație completă:

\[ 2\pi M_m = Rh. \]

Lucrul motor corespunzător rotației este egal cu lucrul asociat deplasării axiale a forței rezistente.

Mișcare inversă

Deșurubarea

La deșurubare, sensul deplasării relative se inversează.

Ca urmare, se schimbă și sensul forțelor de frecare din filet.

\[ \boxed{ \text{deșurubare} \Rightarrow \text{inversarea sensului frecării} } \]
Relația (8.26)

Momentul la deșurubare

După inversarea sensului frecării, Bunget obține:

\[ \boxed{ M_d = Rr \frac{ \sin\alpha - \mu\cos\alpha }{ \cos\alpha + \mu\sin\alpha } } \]
Autofixare

Când șurubul nu se desface singur

Bunget urmărește condiția ca șurubul, după strângere, să nu se deșurubeze singur sub acțiunea forței rezistente.

În formularea Compendiului, pentru autofixare momentul corespunzător deșurubării trebuie să fie:

\[ M_d<0. \]
Condiția finală

Frecarea și unghiul filetului

Din numărătorul relației (8.26):

\[ \sin\alpha - \mu\cos\alpha < 0. \]

Rezultă:

\[ \boxed{ \mu > \tan\alpha } \]

Aceasta este condiția de autofixare formulată la finalul §8.8.

Sens fizic

Rolul frecării

La șurub, frecarea nu reprezintă numai o rezistență suplimentară la mișcare.

Dacă este suficient de mare în raport cu unghiul filetului, ea împiedică mișcarea inversă spontană.

\[ \boxed{ \text{frecare suficientă} \Rightarrow \text{autofixare} } \]
Legătura logică

Firul §8.8

Filet elicoidal

Plan înclinat înfășurat pe cilindru.

Pas

\[ \boxed{ h } \]

Geometria filetului

\[ \boxed{ \tan\alpha = \frac{h}{2\pi r} } \]

\[ \boxed{ M_m=FD } \]

\[ \boxed{ M_m = Rr \frac{ \sin\alpha + \mu\cos\alpha }{ \cos\alpha - \mu\sin\alpha } } \]

Titularizare

Precizări pentru examen

Această secțiune este separată de corpul §8.8 al Compendiului. Reperul oficial utilizat este programa pentru Titularizare Fizică 2026.

Statut în programa 2026

„Șurubul” și „mașinile simple” nu sunt enumerate ca teme științifice autonome.

§8.8 este însă o aplicație directă a:

principiilor mecanicii newtoniene;
momentului forței;
mișcării de rotație;
lucrului mecanic;
forțelor de frecare.

Mărimi și unități SI: forța: \[ [F]=[R]=\mathrm N; \] pasul și raza: \[ [h]=[r]=\mathrm m; \] momentul: \[ \boxed{ [M] = \mathrm{N\,m} } \] coeficientul de frecare: \[ \boxed{ [\mu]=1 } \]
Nu confunda pasul cu raza sau circumferința. La o rotație completă:

deplasarea axială este: \[ \boxed{ h } \] iar lungimea corespunzătoare unei rotații pe cilindrul de rază \(r\) este: \[ \boxed{ 2\pi r } \]
Relația geometrică: \[ \boxed{ \tan\alpha = \frac{h}{2\pi r} } \] poate fi reconstruită direct din triunghiul obținut prin desfășurarea filetului.
Verificare: pentru un pas foarte mic: \[ h\downarrow \] avem: \[ \alpha\downarrow. \] Filetul devine astfel mai puțin înclinat față de planul de rotație.
Model ideal: la o rotație completă, un moment constant \(M_m\) efectuează lucrul: \[ \boxed{ L_m = 2\pi M_m } \] iar sarcina axială: \[ R \] este deplasată cu: \[ h. \]
Fără frecare: conservarea lucrului conduce la: \[ 2\pi M_m = Rh. \] Deci: \[ \boxed{ M_m = \frac{Rh}{2\pi} } \]
Dacă momentul este produs de o forță \(F\) aplicată la brațul \(D\): \[ M_m=FD. \] În cazul ideal: \[ FD = \frac{Rh}{2\pi}. \] Prin urmare: \[ \boxed{ F = \frac{Rh}{2\pi D} } \]
Avantajul mecanic ideal: din relația precedentă: \[ \boxed{ \frac RF = \frac{2\pi D}{h} } \] în modelul în care \(D\) este brațul forței active.
Sens fizic: un pas \(h\) mai mic poate produce un avantaj mecanic mai mare. În schimb, pentru aceeași deplasare axială sunt necesare mai multe rotații.
Numărul de rotații: dacă șurubul trebuie să înainteze axial pe distanța \(x\): \[ \boxed{ n = \frac{x}{h} } \] pentru un filet la care avansul pe rotație este \(h\).
Unghiul de frecare: putem introduce o mărime \(\varphi\) prin: \[ \boxed{ \tan\varphi=\mu } \]
Momentul la înșurubare: deoarece: \[ \tan(\alpha+\varphi) = \frac{ \tan\alpha+\tan\varphi }{ 1-\tan\alpha\tan\varphi }, \] relația Bunget poate fi scrisă echivalent: \[ \boxed{ M_m = Rr \tan(\alpha+\varphi) } \] în modelul de frecare utilizat.
La deșurubare: relația devine echivalent: \[ \boxed{ M_d = Rr \tan(\alpha-\varphi) } \]
Delimitare de sursă: reformularea prin unghiul de frecare \(\varphi\) este o completare modernă de interpretare. Bunget exprimă relațiile direct prin \(\mu\) și \(\alpha\).
Autofixare: condiția: \[ \mu>\tan\alpha \] este echivalentă, dacă: \[ \mu=\tan\varphi, \] cu: \[ \boxed{ \varphi>\alpha } \]
Pragul: pentru: \[ \mu=\tan\alpha \] numărătorul relației de deșurubare devine zero. Acesta este cazul-limită. Condiția strictă formulată de Bunget pentru autofixare este: \[ \boxed{ \mu>\tan\alpha } \]
Coeficientul relevant pentru autofixare: într-o interpretare modernă a problemei de pornire spontană, trebuie analizată frecarea statică. De aceea este mai precis să distingem: \[ \mu_s \] de coeficientul de frecare la alunecare.
Nu scrie automat: \[ F_f=\mu_sN \] pentru orice echilibru static. În general: \[ \boxed{ F_f\leq\mu_sN } \] iar egalitatea apare la limita alunecării.
Verificarea formulei de înșurubare: \[ M_m = Rr \frac{ \sin\alpha + \mu\cos\alpha }{ \cos\alpha - \mu\sin\alpha }. \] Dacă: \[ \mu\rightarrow0, \] obținem: \[ M_m \rightarrow Rr \frac{ \sin\alpha }{ \cos\alpha }. \] Deci: \[ \boxed{ M_m = Rr\tan\alpha } \]
A doua verificare: folosind: \[ \tan\alpha = \frac{h}{2\pi r}, \] rezultă: \[ Rr\tan\alpha = Rr \frac{h}{2\pi r} \] și: \[ \boxed{ M_m = \frac{Rh}{2\pi} } \]
Greșeală frecventă: în expresia lucrului unui moment constant: \[ L=M\Delta\varphi, \] unghiul trebuie exprimat în radiani. Pentru o rotație completă: \[ \boxed{ \Delta\varphi=2\pi } \]
Momentul forței și energia: momentul are unitatea: \[ \mathrm{N\,m}, \] iar energia: \[ \mathrm J. \] Deși unitățile fundamentale sunt dimensional echivalente, mărimile fizice nu sunt identice.
Schema de rezolvare pentru o problemă cu șurub:

1. identifică pasul \(h\);
2. identifică raza filetului \(r\);
3. determină unghiul elicei din: \[ \tan\alpha = \frac{h}{2\pi r}; \]
4. identifică forța axială \(R\);
5. stabilește dacă frecarea este neglijată;
6. pentru cazul ideal, folosește: \[ M = \frac{Rh}{2\pi}; \]
7. dacă există frecare, stabilește dacă problema este de înșurubare sau de deșurubare;
8. verifică sensul frecării;
9. verifică eventual condiția de autofixare;
10. verifică unitățile și cazul-limită \(\mu\rightarrow0\).
Trei relații care nu trebuie confundate: geometria: \[ \boxed{ \tan\alpha = \frac{h}{2\pi r} } \] momentul ideal: \[ \boxed{ M = \frac{Rh}{2\pi} } \] autofixarea: \[ \boxed{ \mu>\tan\alpha } \]
Legătura cu §8.9: în §8.8 apare deja diferența dintre modelul fără frecare și situația reală cu frecare. Paragraful următor va generaliza această idee prin noțiunea de: \[ \boxed{ \text{randament} } \] al mașinilor simple.
Statut pentru Titularizare 2026: șurubul nu apare ca temă științifică autonomă. Este o aplicație a mecanicii newtoniene, lucrului mecanic, rotației corpului rigid și frecării.
