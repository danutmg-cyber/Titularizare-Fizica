Punct de plecare

De la echilibru la funcționare

Bunget observă că în paragrafele precedente au fost stabilite, în general, condițiile de echilibru pentru diferitele mașini simple.

Dacă forța activă este mărită puțin față de valoarea corespunzătoare echilibrului, sistemul este pus în mișcare.

\[ \boxed{ F_{\mathrm{activă}} > F_{\mathrm{echilibru}} \quad\Rightarrow\quad \text{mișcare} } \]
Regim static

Dispozitive folosite în principal pentru echilibru

Compendiul arată că unele dintre dispozitivele studiate funcționează în principal în regim static.

unele pârghii utilizate în elemente de construcții;

pana;

șuruburile de îmbinare sau de strângere.

Regim de funcționare

Dispozitive pentru care deplasarea este esențială

Pentru alte mașini simple, considerarea deplasărilor produse este esențială.

pârghii care intră în componența mașinilor;

scripeți;

planul înclinat;

șuruburi de acționare mecanică.

Mașină ideală

Fără frecare, lucrul mecanic se conservă

Bunget reamintește rezultatul obținut pentru majoritatea mașinilor simple studiate anterior.

Dacă frecările sunt neglijate, lucrul mecanic produs de forța activă este egal în modul cu lucrul mecanic al forței rezistente.

\[ \boxed{ L_{\mathrm{motor}} = \left| L_{\mathrm{rezistent}} \right| } \]
Mașină reală

Frecarea produce pierderi

Într-o mașină reală, forța activă trebuie să învingă nu numai forța rezistentă utilă, ci și forțele de frecare.

Din acest motiv, lucrul mecanic produs de forța activă este mai mare decât lucrul necesar numai pentru învingerea forței rezistente.

\[ \boxed{ L_{\mathrm{consumat}} > L_{\mathrm{util}} } \]
Definiție

Lucrul mecanic consumat

Lucru mecanic consumat

Lucrul mecanic produs de forța activă, adică lucrul mecanic motor furnizat mașinii.

Îl notăm:

\[ \boxed{ L_c } \]
Definiție

Lucrul mecanic util

Lucru mecanic util

Lucrul mecanic necesar pentru învingerea forței rezistente, adică pentru realizarea scopului pentru care a fost construită mașina.

Îl notăm:

\[ \boxed{ L_u } \]
Frecare

Lucrul pentru învingerea forțelor de frecare

Bunget introduce separat lucrul mecanic necesar pentru învingerea forțelor de frecare.

Îl reprezentăm prin:

\[ \boxed{ L_p } \]

unde indicele \(p\) poate fi citit aici ca asociat pierderilor mecanice prin frecare.

Relația (8.27)

Bilanțul lucrului mecanic

Lucrul mecanic furnizat mașinii se distribuie între partea utilă și partea necesară învingerii frecărilor.

\[ \boxed{ L_c = L_u + L_p } \]

Aceasta este relația de bilanț energetic folosită în §8.9.

Convenția Compendiului

Mărimi pozitive pentru bilanțul energetic

În acest bilanț, \(L_u\) și \(L_p\) reprezintă mărimile lucrurilor mecanice care trebuie compensate de lucrul motor.

Forța rezistentă și forțele de frecare efectuează, considerate direct, lucruri mecanice negative în raport cu mișcarea.

\[ L_u = \left| L_R \right| \]
\[ L_p = \left| L_f \right| \]
Definiție

Randamentul

Randamentul unei mașini

Raportul dintre lucrul mecanic util și lucrul mecanic consumat.

Relația (8.28)

Formula randamentului

\[ \boxed{ \eta = \frac{ L_u }{ L_c } } \]

Randamentul exprimă ce parte din lucrul mecanic furnizat mașinii este folosită efectiv pentru scopul urmărit.

Caz ideal

Randament egal cu unu

Dacă nu există frecare:

\[ L_p=0. \]

Din relația (8.27):

\[ L_c=L_u. \]

Deci:

\[ \boxed{ \eta=1 } \]
Caz real

Randament mai mic decât unu

Pentru o mașină reală există pierderi prin frecare:

\[ L_p>0. \]

Atunci:

\[ L_c>L_u, \]

iar:

\[ \boxed{ \eta<1 } \]
Interpretare

Când randamentul este mai bun

Bunget arată că o mașină are un randament mai bun atunci când \(\eta\) este mai apropiat de unitate.

Aceasta înseamnă că o parte mai mică din lucrul mecanic furnizat este folosită pentru învingerea forțelor de frecare.

\[ \boxed{ \eta\uparrow \quad\Longleftrightarrow\quad \text{pierderi relative mai mici} } \]
Formă echivalentă

Randamentul și pierderile

Din:

\[ L_c=L_u+L_p \]

rezultă:

\[ L_u=L_c-L_p. \]

Introducând în definiția randamentului:

\[ \boxed{ \eta = 1 - \frac{ L_p }{ L_c } } \]
Definiție

Coeficientul de pierdere

Bunget numește raportul:

\[ \boxed{ \frac{ L_p }{ L_c } } \]

coeficient de pierdere.

\[ \boxed{ \eta = 1 - \text{coeficientul de pierdere} } \]
Exemplul Compendiului

Planul înclinat

Pentru aplicarea definiției randamentului, Bunget revine la planul înclinat studiat în §8.6.

Corpul de greutate \(R\) este ridicat pe un plan de lungime:

\[ l \]

care formează cu orizontala unghiul:

\[ \alpha. \]
Geometrie

Înălțimea

Înălțimea atinsă este:

\[ \boxed{ h=l\sin\alpha } \]
Lucru util

Creșterea poziției corpului

Lucrul mecanic util este cel necesar ridicării greutății \(R\) la înălțimea \(h\).

\[ L_u=Rh. \]

Cum:

\[ h=l\sin\alpha, \]

rezultă:

\[ \boxed{ L_u = Rl\sin\alpha } \]
Lucru consumat

Forța activă pe lungimea planului

Pentru cazul analizat în §8.6, cu forța activă paralelă cu planul și cu frecare, Bunget folosise:

\[ F = R \left( \sin\alpha + \mu\cos\alpha \right). \]

Lucrul mecanic consumat este:

\[ L_c=Fl. \]

Deci:

\[ \boxed{ L_c = R \left( \sin\alpha + \mu\cos\alpha \right) l } \]
Randamentul planului înclinat

Raportul dintre lucrul util și cel consumat

Aplicând definiția:

\[ \eta = \frac{L_u}{L_c}, \]

rezultă:

\[ \boxed{ \eta = \frac{ \sin\alpha }{ \sin\alpha + \mu\cos\alpha } } \]
Forma trigonometrică

Introducerea unghiului \(\varphi\)

Bunget introduce unghiul \(\varphi\) prin relația:

\[ \boxed{ \mu = \tan\varphi } \]

Folosind această notație, randamentul poate fi scris:

\[ \boxed{ \eta = \frac{ \sin\alpha\cos\varphi }{ \sin(\alpha+\varphi) } } \]
Verificare

Limita fără frecare

Dacă:

\[ \mu=0, \]

atunci:

\[ \varphi=0. \]

Relația randamentului conduce la:

\[ \boxed{ \eta=1 } \]

Acesta este cazul ideal, fără pierderi prin frecare.

Titularizare

Precizări pentru examen

Această secțiune este separată de corpul §8.9 al Compendiului. Reperul oficial utilizat este programa pentru Titularizare Fizică 2026.

Statut în programa 2026

„Randamentul mașinilor simple” nu este enumerat ca temă științifică autonomă.

Conținutul este însă legat de teoremele mecanicii clasice, legile de conservare și analiza efectului forțelor disipative.

Definiția modernă de bază: \[ \boxed{ \eta = \frac{ L_{\mathrm{util}} }{ L_{\mathrm{consumat}} } } \] Randamentul este o mărime adimensională. \[ \boxed{ [\eta]=1 } \]
Domeniul valorilor: pentru o mașină care funcționează normal: \[ \boxed{ 0<\eta\leq1 } \] Într-o mașină ideală: \[ \eta=1. \] Pentru o mașină reală cu pierderi: \[ \eta<1. \]
Un randament mai mare decât 1 indică o eroare. Dacă obții: \[ \eta>1, \] verifică:

care este lucrul util;
care este lucrul consumat;
semnele lucrurilor mecanice;
unitățile;
datele introduse în formulă.
Exprimarea procentuală: \[ \boxed{ \eta_{\%} = 100\,\eta } \] De exemplu: \[ \eta=0{,}80 \] înseamnă: \[ \boxed{ \eta=80\% } \]
Nu scrie simultan: \[ \eta=80 \] și: \[ \eta=80\%. \] Forma fără procent este: \[ \boxed{ \eta=0{,}80 } \]
Bilanț energetic: putem scrie: \[ \boxed{ L_c = L_u + L_{\mathrm{pierderi}} } \] astfel încât: \[ \boxed{ \eta = 1 - \frac{ L_{\mathrm{pierderi}} }{ L_c } } \]
Pierderea de energie nu înseamnă dispariția energiei. Energia mecanică considerată „pierdută” pentru scopul util este transformată, de exemplu, în energie internă prin frecare. Conservarea energiei totale nu este încălcată.
La funcționare staționară se poate utiliza și puterea: \[ \boxed{ \eta = \frac{ P_u }{ P_c } } \] unde: \[ P_u \] este puterea utilă, iar: \[ P_c \] este puterea consumată.
Delimitare de sursă: în §8.9, Bunget definește randamentul prin lucruri mecanice. Forma: \[ \eta = \frac{P_u}{P_c} \] este o completare modernă utilă pentru regimuri în care raportul puterilor este relevant.
Pentru planul înclinat: dacă: \[ R=mg, \] lucrul util este: \[ \boxed{ L_u=mgh } \] iar dacă forța activă este paralelă cu planul: \[ \boxed{ L_c=Fl } \]
Deci randamentul planului înclinat poate fi scris direct: \[ \boxed{ \eta = \frac{ mgh }{ Fl } } \]
Folosind: \[ h=l\sin\alpha \] și: \[ F = mg \left( \sin\alpha + \mu\cos\alpha \right), \] rezultă: \[ \boxed{ \eta = \frac{ \sin\alpha }{ \sin\alpha + \mu\cos\alpha } } \]
O formă echivalentă: împărțind numărătorul și numitorul prin \(\sin\alpha\): \[ \boxed{ \eta = \frac{ 1 }{ 1+\mu\cot\alpha } } \]
Delimitare de sursă: forma: \[ \eta = \frac{ 1 }{ 1+\mu\cot\alpha } \] este doar o transformare algebrică modernă a relației din §8.9.
Verificare importantă: dacă: \[ \mu=0, \] atunci: \[ \eta = \frac{ \sin\alpha }{ \sin\alpha } = 1. \] Rezultatul corespunde planului ideal.
Dacă există frecare: pentru: \[ \mu>0, \] numitorul: \[ \sin\alpha + \mu\cos\alpha \] este mai mare decât numărătorul. Deci: \[ \boxed{ \eta<1 } \]
Exemplu de interpretare: dacă: \[ \eta=0{,}75, \] atunci 75% din lucrul mecanic furnizat este asociat efectului util, iar fracția corespunzătoare pierderilor este: \[ 1-\eta = 0{,}25. \] adică: \[ \boxed{ 25\% } \]
Coeficientul de pierdere din §8.9: \[ k_p = \frac{ L_p }{ L_c } \] poate fi legat imediat de randament: \[ \boxed{ k_p = 1-\eta } \]
Notația \(k_p\) nu este introdusă astfel de Bunget. Compendiul numește raportul: \[ \frac{L_p}{L_c} \] „coeficient de pierdere”. Simbolul \(k_p\) este folosit aici numai pentru comoditatea prezentării moderne.
Verificare dimensională: \[ [L_u] = [L_c] = [L_p] = \mathrm J. \] Prin urmare: \[ \left[ \frac{L_u}{L_c} \right] = 1. \] Deci randamentul este adimensional.
Greșeală frecventă: inversarea raportului. Formula corectă este: \[ \boxed{ \eta = \frac{ L_{\mathrm{util}} }{ L_{\mathrm{consumat}} } } \] și nu: \[ \frac{ L_{\mathrm{consumat}} }{ L_{\mathrm{util}} }. \]
Test rapid: numărătorul trebuie să fie mai mic sau cel mult egal cu numitorul. Astfel: \[ \boxed{ \eta\leq1 } \]
Schema pentru o problemă de randament:

1. identifică efectul util;
2. calculează: \[ L_u; \]
3. identifică energia sau lucrul furnizat mașinii;
4. calculează: \[ L_c; \]
5. aplică: \[ \eta = \frac{L_u}{L_c}; \]
6. verifică: \[ 0<\eta\leq1; \]
7. transformă în procente numai la final, dacă este cerut;
8. explică fizic pierderile.
Verificarea prin bilanț: după calcul, trebuie să poți scrie: \[ \boxed{ L_c = L_u + L_p } \] Dacă această relație nu este satisfăcută, trebuie reverificate semnele și definițiile lucrurilor mecanice.
Pentru Titularizare 2026: „randamentul mașinilor simple” nu este un punct științific separat în programă. Programa include însă teoremele mecanicii clasice și legile de conservare, pentru care bilanțurile energetice rămân fundamentale.
Titularizare 2027: reperul oficial utilizat aici este programa 2026. Programa oficială pentru sesiunea 2027 trebuie reverificată după publicare.
