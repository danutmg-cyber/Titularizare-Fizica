Definiție

Ce este troliul

Bunget încadrează troliul în categoria mașinilor bazate pe principiul pârghiei.

Rolul său este ridicarea greutăților.

Troliu

Sistem mecanic format fie din două roți concentrice și solidare, fie dintr-o manivelă solidară cu un cilindru, toate având aceeași axă de rotație.

Elementul de ridicare

Cablul și sarcina

Pe cilindrul troliului este înfășurat un cablu.

De cablu este suspendată sarcina care trebuie ridicată.

Bunget notează această forță rezistentă cu:

\[ \boxed{ R } \]
Forța activă

Acționarea troliului

Troliul este pus în mișcare printr-o forță activă:

\[ \boxed{ F } \]

aplicată la roata mare sau la manivela solidară cu cilindrul.

Geometria troliului

Diametrele \(D\) și \(d\)

În notația utilizată în relația lui Bunget, mărimea:

\[ D \]

caracterizează cercul pe care acționează forța activă, iar:

\[ d \]

caracterizează cilindrul pe care se înfășoară cablul.

Brațele celor două forțe față de axa comună sunt astfel:

\[ \boxed{ \frac D2 \qquad\text{și}\qquad \frac d2 } \]
Model ideal

Neglijarea frecărilor

Bunget studiază mai întâi troliul ideal.

Frecările sunt neglijate.

\[ \boxed{ \text{troliu ideal} \Rightarrow \text{frecări neglijate} } \]

La echilibru, momentele forței active și ale forței rezistente față de axa de rotație trebuie să fie egale.

Relația (8.8)

Condiția de echilibru

Momentul forței active este:

\[ M_F = F\frac D2. \]

Momentul forței rezistente este:

\[ M_R = R\frac d2. \]

La echilibru:

\[ \boxed{ F\frac D2 = R\frac d2 } \]
Formula troliului

Relația dintre forțe

Simplificând factorul \(1/2\):

\[ FD=Rd. \]

Bunget obține:

\[ \boxed{ F = R\frac dD } \]
Avantaj de forță

Amplificarea forței

Din relația:

\[ F = R\frac dD \]

rezultă:

\[ \boxed{ \frac RF = \frac Dd } \]

Compendiul exprimă acest rezultat spunând că forța activă este amplificată cu factorul:

\[ \boxed{ \frac Dd } \]
Caz uzual

Dacă \(D>d\)

Pentru:

\[ D>d, \]

raportul:

\[ \frac dD<1. \]

Prin urmare:

\[ \boxed{ F

O sarcină mai mare poate fi echilibrată de o forță activă mai mică.

Schimbul mecanic

Avantajul de forță are un cost în deplasare

Bunget precizează imediat că amplificarea forței nu reprezintă un câștig gratuit.

Mâna care acționează manivela trebuie să parcurgă o distanță mai mare decât lungimea de cablu înfășurată pe tambur.

Raport geometric

Deplasările pentru aceeași rotație

La o rotație cu același unghi, punctul de aplicație al forței active se deplasează pe un cerc de diametru \(D\).

În același timp, cablul se înfășoară pe cilindrul de diametru \(d\).

Raportul deplasărilor este:

\[ \boxed{ \frac{s_F}{s_R} = \frac Dd } \]
Formularea Compendiului

Pentru un centimetru de cablu

Bunget formulează raportul într-o manieră directă:

pentru înfășurarea unei unități de lungime de cablu, mâna care acționează manivela parcurge de \(\frac Dd\) ori acea lungime.

\[ \boxed{ s_F = \frac Dd s_R } \]
Consecință

Forță mai mică, deplasare mai mare

Avantaj de forță

\[ \frac RF = \frac Dd \]

Raportul deplasărilor

\[ \frac{s_F}{s_R} = \frac Dd \]

Același raport geometric apare atât la amplificarea forței, cât și la deplasare.

Model mai complet

Greutatea proprie a cablului

Bunget trece apoi la cazul în care greutatea cablului nu mai poate fi neglijată.

Se notează cu \(q\) greutatea cablului pe unitatea de lungime.

\[ \boxed{ q } \]

Iar cu:

\[ \boxed{ l } \]

lungimea porțiunii de cablu care atârnă.

Greutatea porțiunii suspendate

Termenul \(ql\)

Greutatea porțiunii de cablu suspendate este:

\[ \boxed{ G_{\text{cablu}} = ql } \]

Sarcina totală care solicită tamburul devine:

\[ \boxed{ R+ql } \]
Relația (8.9)

Echilibrul cu greutatea cablului

Momentul forței active trebuie să echilibreze acum momentul produs de sarcină și de cablul suspendat.

\[ \boxed{ F\frac D2 = (R+ql) \frac d2 } \]

Rezultă:

\[ \boxed{ F = (R+ql) \frac dD } \]
Consecință

Forța activă nu mai este constantă

Dacă \(D\) și \(d\) sunt constante, relația:

\[ F = (R+ql) \frac dD \]

arată că forța activă depinde de lungimea porțiunii de cablu care rămâne suspendată.

\[ \boxed{ F=F(l) } \]
Ridicarea sarcinii

Ce se întâmplă cu \(l\)

Pe măsură ce sarcina este ridicată, o parte tot mai mare din cablu se înfășoară pe tambur.

Lungimea porțiunii de cablu care atârnă scade:

\[ \boxed{ l\downarrow } \]

În consecință, scade și termenul:

\[ R+ql. \]
Problema practică

Cum poate fi menținută forța \(F\) constantă

Bunget urmărește realizarea unui troliu pentru care forța activă să rămână constantă în timpul ridicării.

Din:

\[ F = \frac{ (R+ql)d }{ D }, \]

dacă \(F\) și \(D\) trebuie menținute constante, este necesar ca:

\[ \boxed{ (R+ql)d = \text{constant} } \]
Compensarea variației

Când \(l\) scade, \(d\) trebuie să crească

Pe măsură ce sarcina urcă:

\[ l\downarrow. \]

Atunci:

\[ R+ql \downarrow. \]

Pentru ca produsul:

\[ (R+ql)d \]

să rămână constant, diametrul efectiv al tamburului trebuie să crească.

\[ \boxed{ l\downarrow \quad\Rightarrow\quad d\uparrow } \]
Figura I.8.6 c

Tamburul tronconic

Pentru a realiza această variație a diametrului, Bunget propune un tambur de formă tronconică.

Pe măsură ce cablul se înfășoară, el ajunge pe regiuni cu diametru din ce în ce mai mare.

\[ \boxed{ \text{tambur tronconic} \Rightarrow d \text{ variabil} } \]
Definiție

Troliul regulator

Regulator

Troliul cu tambur de formă tronconică, proiectat astfel încât variația diametrului să compenseze modificarea greutății cablului suspendat și să permită menținerea aproximativ constantă a forței active.

\[ \boxed{ (R+ql)d = \text{constant} } \]

Firul §8.4

Titularizare

Precizări pentru examen

Această secțiune este separată de corpul §8.4 al Compendiului. Reperul oficial utilizat este programa pentru Titularizare Fizică 2026.

Statut în programa 2026

„Troliul” și „mașinile simple” nu sunt enumerate ca teme științifice autonome.

Troliul reprezintă însă o aplicație directă a mecanicii rigidului, a momentului forței, a echilibrului și a lucrului mecanic.

Mărimi și unități SI: forța activă: \[ F, \qquad [F]=\mathrm N; \] forța rezistentă: \[ R, \qquad [R]=\mathrm N; \] diametrele: \[ D,\ d, \qquad [D]=[d]=\mathrm m. \]
Pentru cablu: dacă \(q\) reprezintă greutatea pe unitatea de lungime: \[ \boxed{ [q] = \mathrm{\frac Nm} } \] iar: \[ [l]=\mathrm m. \] Astfel: \[ [ql]=\mathrm N. \]
Nu confunda \(q\) cu densitatea liniară de masă. În relația lui Bunget: \[ ql \] trebuie să reprezinte o greutate. Dacă într-o problemă modernă este dată densitatea liniară de masă \(\lambda\), atunci: \[ \boxed{ G_{\text{cablu}} = \lambda lg } \]
Forma modernă cu raze: dacă notăm raza la care se aplică forța activă cu \(r_F\) și raza tamburului cu \(r_R\): \[ \boxed{ Fr_F = Rr_R } \] pentru troliul ideal în echilibru.
Cum se recuperează notația Bunget: \[ r_F=\frac D2, \] \[ r_R=\frac d2. \] Atunci: \[ F\frac D2 = R\frac d2. \]
Greșeală frecventă: avantajul mecanic nu este: \[ \frac dD. \] Pentru troliul ideal: \[ \boxed{ A_m = \frac RF = \frac Dd } \]
Dacă \(D=5d\): relația ideală dă: \[ F = \frac R5. \] Aceasta înseamnă avantaj mecanic: \[ \boxed{ A_m=5 } \] Nu înseamnă însă că lucrul mecanic necesar este redus de cinci ori.
Conservarea lucrului pentru troliul ideal: din: \[ \frac RF = \frac Dd \] și: \[ \frac{s_F}{s_R} = \frac Dd \] rezultă: \[ \boxed{ Fs_F = Rs_R } \]
Echivalent: \[ \boxed{ L_{\mathrm{activ}} = |L_{\mathrm{rezistent}}| } \] pentru modelul ideal, fără pierderi prin frecare.
Principiul de verificat: câștigul de forță este compensat de deplasarea mai mare a punctului în care se aplică forța activă. \[ \boxed{ F\downarrow \quad\Longleftrightarrow\quad s_F\uparrow } \] în comparația ideală la aceeași sarcină și aceeași ridicare.
Pentru o rotație cu unghiul \(\varphi\): deplasarea punctului de aplicație al forței active: \[ s_F = \frac D2 \varphi. \] Lungimea de cablu înfășurată: \[ s_R = \frac d2 \varphi. \] Prin împărțire: \[ \boxed{ \frac{s_F}{s_R} = \frac Dd } \]
Unghiul \(\varphi\) trebuie exprimat în radiani atunci când se utilizează relația geometrică: \[ s=r\varphi. \]
Dacă este inclusă greutatea cablului: forța rezistentă efectivă devine: \[ \boxed{ R_{\mathrm{ef}} = R+ql } \] iar condiția momentelor: \[ \boxed{ F\frac D2 = (R+ql) \frac d2 } \]
Prin urmare: \[ \boxed{ F = (R+ql) \frac dD } \] Dacă \(l\) scade în timpul ridicării, iar toate celelalte mărimi sunt constante, \(F\) scade.
Troliul regulator: ideea nu este că sarcina \(R\) se modifică. Se modifică termenul corespunzător cablului suspendat: \[ ql. \] Pe măsură ce: \[ l\downarrow, \] trebuie să avem: \[ d\uparrow \] dacă dorim \(F=\text{constant}\).
Condiția regulatorului: pentru \(D\) constant: \[ F = \frac{ (R+ql)d }{ D }. \] Dacă: \[ F=\text{constant}, \] rezultă: \[ \boxed{ (R+ql)d = \text{constant} } \]
Sensul formei tronconice: tamburul oferă raze diferite pentru cablu în diferite etape ale ridicării. Astfel se poate compensa variația forței rezistente datorată lungimii de cablu suspendate.
Nu confunda troliul cu scripetele. La troliu, avantajul mecanic provine din existența a două raze diferite în jurul aceleiași axe de rotație. Scripeții sunt tratați separat în §8.5.
Schema de rezolvare pentru o problemă cu troliu:

1. identifică axa de rotație;
2. identifică forța activă \(F\);
3. identifică forța rezistentă \(R\);
4. determină razele sau diametrele corespunzătoare;
5. verifică dacă frecările sunt neglijate;
6. scrie condiția: \[ \sum M_O=0; \]
7. obține relația dintre \(F\) și \(R\);
8. dacă este cerută deplasarea, folosește: \[ s=r\varphi; \]
9. dacă greutatea cablului contează, înlocuiește: \[ R \longrightarrow R+ql; \]
10. verifică unitățile și sensul fizic.
Verificare dimensională: în relația: \[ F\frac D2 = R\frac d2, \] ambele membre au unitatea: \[ \boxed{ \mathrm{N\,m} } \] fiind momente ale forțelor.
Momentul forței nu este energie: unitatea se scrie: \[ \mathrm{N\,m} \] pentru moment, în timp ce pentru energie se utilizează: \[ \mathrm J. \]
Legătura conceptuală cu programa: troliul poate fi analizat ca aplicație a unui corp rigid cu axă fixă: \[ \boxed{ \text{rotație în jurul unei axe fixe} } \] împreună cu echilibrul momentelor și conservarea energiei în modelul ideal.
Prioritate pentru Titularizare: troliul nu este o temă autonomă în programa 2026. Este util ca aplicație a mecanicii, dar trebuie studiat după temele explicit cerute în programă.
