3.9 Forțe în mișcarea circulară uniformă

Accelerația centripetă, forța centripetă și aplicarea principiilor mecanicii la mișcarea circulară uniformă.

Accelerația centripetă

Rezultatul obținut în cinematică

În capitolul consacrat cinematicii a fost stabilită expresia accelerației care apare în mișcarea circulară uniformă.

Această accelerație este orientată după raza traiectoriei, către centrul cercului.

Din acest motiv ea a fost numită accelerație centripetă.

\[ \boxed{ a_n = \frac{v^2}{r} = \omega^2r } \]

Dacă vectorul de poziție \(\vec r\) este orientat de la centrul cercului spre mobil, forma vectorială este:

\[ \boxed{ \vec a_n = -\omega^2\vec r } \]

Semnul minus exprimă orientarea accelerației spre centrul traiectoriei.

Principiul al doilea

Forța centripetă

Conform principiului al doilea al mecanicii, apariția accelerației centripete se datorește unei forțe.

Această forță este numită în Compendiu forță centripetă.

Forța centripetă

Forța care produce accelerația centripetă și care este orientată după rază, către centrul traiectoriei circulare.

Aplicând:

\[ F=ma \]

se obține:

\[ \boxed{ F_c = m\frac{v^2}{r} = m\omega^2r } \]
Forma vectorială

Orientarea forței

Forța centripetă are aceeași direcție și același sens cu accelerația centripetă.

Ea este deci îndreptată către centrul cercului.

\[ \boxed{ \vec F_c = -m\omega^2\vec r } \]

Pentru modul:

\[ F_c = \frac{mv^2}{r} \]
\[ F_c = m\omega^2r \]
Principiul al treilea

Acțiunea reciprocă dintre corpuri

Compendiul aplică în continuare principiul al treilea al mecanicii.

Odată cu forța centripetă care acționează asupra mobilului apare, asupra corpului care îl constrânge să descrie traiectoria circulară, o forță egală ca mărime și de sens contrar.

În terminologia utilizată în Compendiu, această forță este numită forță centrifugă.

\[ \boxed{ \vec F_{\mathrm{cf}} = -\vec F_c } \]

Cele două forțe apar și dispar simultan.

Exemplul 1

Corp legat cu o sfoară

Se consideră un corp care se rotește fiind legat cu o sfoară.

Sfoara exercită asupra corpului forța necesară pentru menținerea mișcării circulare.

Această forță este orientată spre centrul cercului și reprezintă forța centripetă.

\[ F_c = \frac{mv^2}{r} \]

Corpul acționează, la rândul său, asupra sforii cu o forță egală ca mărime și opusă ca sens.

Mâna care ține capătul sforii simte această acțiune.

Acțiune și reacțiune

Cele două corpuri

Asupra mobilului: sfoara exercită o forță orientată spre centrul cercului.

\[ \vec F_{\mathrm{sfoară\to corp}} = \vec F_c \]

Asupra sforii: corpul exercită o forță egală și opusă.

\[ \vec F_{\mathrm{corp\to sfoară}} = -\vec F_c \]
Exemplul 2

Vagonul care cotește într-o curbă

Compendiul analizează apoi un vagon care se deplasează pe o porțiune curbată de cale ferată.

Șinele exercită asupra roților vagonului o forță orientată către centrul arcului de cerc descris de cale.

Această forță are rolul de forță centripetă.

\[ \boxed{ F_c = \frac{mv^2}{r} } \]

Roțile exercită asupra șinelor o forță egală ca mărime și de sens contrar.

În terminologia Compendiului, aceasta este forța centrifugă.

Înclinarea terasamentului

Calea ferată în curbă

Forța exercitată de vagon asupra șinelor produce solicitarea laterală a acestora.

Pentru reducerea acestei solicitări, terasamentul căii ferate este înclinat cu un unghi \(\alpha\).

Compendiul consideră situația în care o componentă a greutății vagonului echilibrează acțiunea laterală asupra șinei.

\[ G_t = F_{\mathrm{cf}} \]
Relația de calcul

Unghiul de înclinare

Din geometria forțelor rezultă:

\[ G\tan\alpha = \frac{mv^2}{r} \]

Deoarece:

\[ G=mg, \]

se obține:

\[ mg\tan\alpha = \frac{mv^2}{r} \]

Simplificând masa:

\[ \boxed{ \tan\alpha = \frac{v^2}{rg} } \]
Viteza în curbă

Relația dintre \(v\), \(r\) și \(\alpha\)

Relația:

\[ \tan\alpha = \frac{v^2}{rg} \]

stabilește legătura dintre viteza trenului, raza curbei și unghiul de înclinare al terasamentului.

Pentru \(r\) și \(\alpha\) date, viteza corespunzătoare este:

\[ \boxed{ v = \sqrt{ rg\tan\alpha } } \]

Compendiul arată că pentru această situație solicitarea laterală a șinelor este evitată.

Sinteză

De reținut din §3.9

Accelerația centripetă

\[ \boxed{ a_n = \frac{v^2}{r} = \omega^2r } \]
\[ \boxed{ \vec a_n = -\omega^2\vec r } \]

Forța centripetă

\[ \boxed{ F_c = \frac{mv^2}{r} = m\omega^2r } \]
\[ \boxed{ \vec F_c = -m\omega^2\vec r } \]

Acțiune și reacțiune

\[ \boxed{ \vec F_{\mathrm{cf}} = -\vec F_c } \]

În prezentarea Compendiului, cele două forțe se aplică unor corpuri diferite.

Calea ferată înclinată

\[ \boxed{ \tan\alpha = \frac{v^2}{rg} } \]
\[ \boxed{ v = \sqrt{ rg\tan\alpha } } \]
Titularizare

Precizări pentru examen

Această secțiune este separată de conținutul §3.9 al Compendiului. Ea se raportează la programa oficială pentru Titularizare Fizică 2026.

Cerințe explicite în programa 2026

Programa include explicit:

  • mișcarea circulară uniformă;
  • principiile mecanicii newtoniene;
  • sisteme de referință inerțiale și neinerțiale;
  • forțe complementare.
Relația centrală pentru rezolvarea problemelor de mișcare circulară:

\[ \boxed{ \sum F_{\mathrm{radial}} = m\frac{v^2}{r} = m\omega^2r } \] Sensul pozitiv radial trebuie ales și respectat consecvent în ecuația de mișcare.
Atenție la terminologie: în corpul lecției am păstrat terminologia utilizată de Compendiul din 1972. Acolo, forța egală și opusă forței centripete este denumită „forță centrifugă” și este aplicată corpului care constrânge mobilul, de exemplu sforii sau șinei. Pentru examen trebuie să identifici întotdeauna foarte clar corpul asupra căruia acționează fiecare forță și sistemul de referință utilizat.
Pentru §3.9 trebuie fixate:

\[ a_n = \frac{v^2}{r} = \omega^2r \] \[ F_c = \frac{mv^2}{r} = m\omega^2r \] direcția radială și sensul către centrul traiectoriei;
aplicarea principiilor II și III;
identificarea perechilor acțiune–reacțiune;
și relația pentru curba înclinată: \[ \boxed{ \tan\alpha = \frac{v^2}{rg} } \]
Titularizare 2027: programa oficială pentru sesiunea 2027 trebuie reverificată după publicare.
