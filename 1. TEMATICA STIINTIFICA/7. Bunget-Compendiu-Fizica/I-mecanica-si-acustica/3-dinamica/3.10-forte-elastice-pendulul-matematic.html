3.10 Forțe elastice. Pendulul matematic
Pagini: 82–93
a) Forțe elastice și oscilații elastice

Deformația

Forțele exterioare care acționează asupra unui corp pot deplasa diferitele sale regiuni unele față de altele.

În acest mod se produce o modificare a formei corpului.

Deformație

Modificarea formei unui corp produsă prin deplasarea diferitelor sale regiuni unele față de altele.

Forțe interne

Revenirea la forma inițială

Prin deformarea corpului apar forțe interne.

Aceste forțe se exercită asupra regiunilor deplasate și tind să refacă forma inițială a corpului.

După încetarea acțiunii exterioare, forțele interne tind să readucă corpul la forma pe care o avea înainte de deformare.

Elasticitatea

Deformații elastice

În realitate, după încetarea acțiunii exterioare, deformarea nu dispare întotdeauna complet.

Pentru multe corpuri, deformația rămasă este însă suficient de mică pentru a putea considera că forma inițială a fost refăcută.

Deformații elastice

Deformațiile care pot dispărea după încetarea acțiunii forțelor exterioare.

Forțe elastice

Forțele interne care tind să înlăture deformația elastică.

Elasticitatea

Proprietatea corpurilor de a se deforma sub acțiunea unor forțe exterioare și de a reveni la forma inițială după încetarea solicitării.

Resort elastic

Deplasarea capătului resortului

Se consideră un resort al cărui capăt este deplasat cu distanța orientată \(y\) față de poziția de echilibru.

Vectorul \(\vec y\) este orientat de la poziția de echilibru spre poziția în care a ajuns capătul resortului.

Experiența arată că forța elastică este proporțională cu această deplasare.

\[ \boxed{ \vec F_e=-k\vec y } \]

Constanta pozitivă \(k\) caracterizează resortul.

Constanta elastică \(k\)

Constanta de proporționalitate dintre mărimea forței elastice și deplasarea față de poziția de echilibru.

Sensul forței

Semnul minus

Semnul minus din relația:

\[ \vec F_e=-k\vec y \]

arată că forța elastică se opune deplasării capătului resortului față de poziția de echilibru.

Această proprietate este valabilă atât atunci când resortul este întins, cât și atunci când este comprimat.

Pendulul elastic

Resort și bilă

Se consideră un resort elastic vertical.

De capătul liber al resortului se suspendă o bilă de masă \(m\).

Pendul elastic

Sistemul format din resortul elastic și bila suspendată de acesta.

Poziția de echilibru

Alungirea statică

În poziția de echilibru, greutatea bilei este compensată de forța elastică a resortului.

\[ G=mg \]

Dacă \(s\) este alungirea resortului în poziția de echilibru:

\[ mg-ks=0 \]

de unde:

\[ \boxed{ s=\frac{mg}{k} } \]
Oscilația

Deplasarea față de poziția de echilibru

Dacă bila este deplasată pe verticală din poziția de echilibru și apoi lăsată liberă, ea începe să se miște de o parte și de alta a acestei poziții.

Neglijând frecările, forța rezultantă care acționează asupra bilei este orientată permanent către poziția de echilibru.

Alegând originea în poziția de echilibru:

\[ \boxed{ \vec F=-k\vec y } \]
Ecuația de mișcare

Principiul al doilea

Aplicând principiul al doilea al mecanicii:

\[ m\vec a=-k\vec y \]

Pe axa \(Oy\):

\[ ma=-ky \]

deci:

\[ \boxed{ a=-\frac{k}{m}y } \]

Accelerația este proporțională cu distanța față de poziția de echilibru și are sens opus deplasării.

Oscilația armonică

Pulsația proprie

Comparând ecuația mișcării cu ecuația cinematică a oscilației armonice rezultă:

\[ \boxed{ \omega_0^2=\frac{k}{m} } \]

sau:

\[ \boxed{ \omega_0=\sqrt{\frac{k}{m}} } \]
Pulsația proprie

Pulsația oscilației libere a pendulului elastic.

Perioada

Perioada pendulului elastic

Perioada oscilației este:

\[ \boxed{ T = \frac{2\pi}{\omega_0} = 2\pi \sqrt{ \frac{m}{k} } } \]

Mișcarea este oscilatorie și periodică.

Ecuația diferențială

Oscilația liberă

Deoarece:

\[ a=\frac{d^2y}{dt^2}, \]

ecuația mișcării poate fi scrisă:

\[ \boxed{ \frac{d^2y}{dt^2} + \omega_0^2y = 0 } \]

Soluția are forma:

\[ y(t) = A\sin(\omega_0t+\varphi) \]

Dacă originea timpului este aleasă când pendulul trece prin poziția de echilibru:

\[ y(0)=0, \]

atunci faza inițială poate fi aleasă nulă și:

\[ \boxed{ y=A\sin\omega_0t } \]
Cazul real

Forța de rezistență

În cazul real, pe lângă forța elastică acționează și o forță de frecare.

Compendiul consideră o forță de rezistență proporțională cu viteza și de sens contrar acesteia:

\[ \boxed{ F_f=-bv } \]

unde \(b\) este o constantă pozitivă.

Oscilații amortizate

Ecuația mișcării

Principiul al doilea conduce la:

\[ m\frac{d^2y}{dt^2} = -ky - b\frac{dy}{dt} \]

sau:

\[ \boxed{ \frac{d^2y}{dt^2} + \frac{b}{m}\frac{dy}{dt} + \omega_0^2y = 0 } \]

unde:

\[ \omega_0^2=\frac{k}{m} \]
Amortizare puternică

Mișcarea aperiodică

Compendiul introduce:

\[ b'=\frac{b}{2m} \]

Dacă:

\[ b'^2>\omega_0^2, \]

mișcarea este puternic amortizată și aperiodică.

Elongația scade rapid în timp, iar corpul tinde către poziția de echilibru fără a mai executa oscilații de o parte și de alta a acesteia.

Cazul limită:

\[ b'^2=\omega_0^2 \]

este tratat separat de Compendiu în cadrul soluțiilor ecuației diferențiale.

Oscilație amortizată

Rezistență mai mică

O situație frecvent întâlnită este:

\[ b'^2<\omega_0^2 \]

Se introduce pulsația:

\[ \boxed{ \omega' = \sqrt{ \omega_0^2-b'^2 } } \]

Elongația are forma:

\[ \boxed{ y(t) = Ae^{-b't} \sin(\omega't+\varphi) } \]

Pentru condiția inițială \(y(0)=0\):

\[ y(t) = Ae^{-b't} \sin\omega't \]
Amplitudinea

Scăderea exponențială

Factorul:

\[ e^{-b't} \]

determină scăderea treptată a amplitudinii.

Maximele și minimele succesive ale elongației formează șiruri descrescătoare.

Mișcare oscilatorie amortizată

Mișcarea oscilatorie a cărei amplitudine scade treptat în timp.

Oscilații forțate

Forță externă periodică

Se consideră acum o forță externă care variază armonic în timp:

\[ \boxed{ F_{\mathrm{ext}} = F_0\cos\omega t } \]

Ecuația de mișcare devine:

\[ \boxed{ m\frac{d^2y}{dt^2} = -ky - b\frac{dy}{dt} + F_0\cos\omega t } \]
Ecuația oscilației forțate

Forma diferențială

\[ \boxed{ \frac{d^2y}{dt^2} + \frac{b}{m}\frac{dy}{dt} + \omega_0^2y = \frac{F_0}{m} \cos\omega t } \]

Mișcarea întreținută are pulsația impusă de forța exterioară.

\[ T=\frac{2\pi}{\omega} \]

Elongația mișcării întreținute are forma:

\[ y = A\sin(\omega t+\varphi) \]

Amplitudinea depinde de pulsația forței exterioare, de pulsația proprie și de rezistența mediului.

Rezonanța

Amplitudinea maximă

Compendiul arată că amplitudinea oscilației devine maximă atunci când pulsația forței exterioare coincide cu pulsația proprie a pendulului elastic:

\[ \boxed{ \omega=\omega_0 } \]
Rezonanța

Fenomenul de realizare a unei oscilații cu amplitudine maximă atunci când forța exterioară periodică are aceeași perioadă cu oscilatorul.

La rezonanță

Amplitudinea

Pentru cazul de rezonanță tratat în Compendiu, amplitudinea este:

\[ \boxed{ A_{\mathrm{rez}} = \frac{F_0}{b\omega_0} } \]

Amplitudinea la rezonanță este invers proporțională cu coeficientul \(b\).

Cu cât rezistența mediului este mai mică, cu atât amplitudinea la rezonanță este mai mare.

Oscilații întreținute

Definiție

Oscilații întreținute sau forțate

Oscilațiile care au loc sub acțiunea unei forțe periodice exterioare.

b) Pendulul matematic

Definiție

Pendulul matematic

Sistemul format dintr-un punct material de masă \(m\), suspendat de un fir inextensibil, fără greutate, de lungime \(l\).

Pendulul matematic este un sistem idealizat.

Pendul real

Condițiile aproximării

Se poate utiliza drept aproximare un sistem format dintr-o sferă suspendată de un fir.

Pentru ca acest sistem real să poată fi asimilat unui pendul matematic, Compendiul impune mai multe condiții.

Dimensiunea sferei trebuie să fie mult mai mică decât lungimea pendulului:

\[ r\ll l \]

Alungirea firului trebuie să fie neglijabilă:

\[ \Delta l\ll l \]

Masa firului trebuie să fie neglijabilă în comparație cu masa sferei.

Echilibrul

Poziția verticală

Pendulul matematic este în echilibru atunci când direcția firului coincide cu verticala locului.

În această poziție, greutatea punctului material este compensată de reacțiunea firului.

\[ \vec G+\vec R=0 \]
Mișcarea pendulului

Deplasarea cu unghiul \(\alpha\)

Se scoate pendulul din poziția de echilibru astfel încât firul să formeze unghiul \(\alpha\) cu verticala.

Punctul material se poate deplasa numai pe un arc de cerc de rază \(l\), cu centrul în punctul de suspensie.

Greutatea

Componentele forței

Componenta greutății pe direcția firului este:

\[ G_n=G\cos\alpha \]

Aceasta este compensată de reacțiunea firului.

Componenta tangențială este:

\[ \boxed{ G_t=G\sin\alpha } \]

Ea este orientată permanent către poziția de echilibru.

Micile oscilații

Aproximația pentru unghiuri mici

Pentru unghiuri suficient de mici, Compendiul utilizează aproximația:

\[ \boxed{ \sin\alpha\simeq\alpha } \]

unghiul fiind exprimat în radiani.

În text este indicat domeniul:

\[ \alpha<4^\circ \]
Elongația

Lungimea arcului

Dacă \(s\) este lungimea arcului descris de pendul:

\[ s=l\alpha \]

pentru oscilații mici, lungimea arcului poate fi aproximată prin deplasarea liniară \(y\).

\[ s\simeq y \]
Forța de revenire

Forma liniară

Pentru unghiuri mici:

\[ G_t \simeq mg\alpha \]

iar folosind:

\[ \alpha\simeq\frac{y}{l}, \]

rezultă pentru modul:

\[ G_t = \frac{mg}{l}y \]

Ținând seama de sensul către poziția de echilibru:

\[ \boxed{ \vec G_t = -\frac{mg}{l}\vec y } \]
Analogie

Forță de tip elastic

Relația:

\[ \vec G_t = -\frac{mg}{l}\vec y \]

are aceeași formă cu relația:

\[ \vec F=-k\vec y. \]

Pentru pendulul matematic, constanta corespunzătoare este:

\[ \boxed{ k=\frac{mg}{l} } \]
Pulsația proprie

Pendulul matematic

Din analogia cu pendulul elastic:

\[ \omega_0^2 = \frac{k}{m} \]

și:

\[ k=\frac{mg}{l}, \]

rezultă:

\[ \boxed{ \omega_0 = \sqrt{ \frac{g}{l} } } \]
Legea mișcării

Oscilația pendulului matematic

Pentru micile oscilații, mișcarea are forma:

\[ \boxed{ y(t) = A\sin(\omega_0t+\varphi) } \]

Prin urmare, în aproximația micilor oscilații, pendulul matematic execută o mișcare oscilatorie armonică.

Perioada

Formula pendulului matematic

Perioada este:

\[ \boxed{ T = 2\pi \sqrt{ \frac{l}{g} } } \]

Pentru oscilații mici, perioada depinde de lungimea pendulului și de accelerația gravitației.

Ecuația lui Newton

Ecuația diferențială

Același rezultat se obține direct din principiul al doilea al mecanicii.

\[ m\frac{d^2y}{dt^2} = -\frac{mg}{l}y \]

După simplificarea masei:

\[ \boxed{ \frac{d^2y}{dt^2} + \frac{g}{l}y = 0 } \]
Izocronism

Legea micilor oscilații

Formula perioadei:

\[ T = 2\pi\sqrt{\frac{l}{g}} \]

arată că, pentru unghiuri mici, perioada nu depinde de amplitudinea oscilației.

Legea izocronismului micilor oscilații

Pentru micile oscilații ale pendulului matematic, perioada nu depinde de amplitudine.

Compendiul atribuie această lege lui Galilei.

Pendul real

Amortizarea oscilațiilor

Un pendul real nu oscilează la nesfârșit.

Amplitudinea scade treptat datorită rezistenței mediului și frecărilor din punctul de suspensie.

Considerând din nou o forță de frecare proporțională cu viteza:

\[ F_f=-bv, \]

se obține o ecuație de tipul celei întâlnite la pendulul elastic.

\[ \boxed{ \frac{d^2y}{dt^2} + \frac{b}{m}\frac{dy}{dt} + \frac{g}{l}y = 0 } \]

Mișcarea se amortizează exponențial în timp.

Oscilații întreținute

Forță periodică asupra pendulului

Dacă asupra pendulului acționează o forță externă periodică:

\[ F_{\mathrm{ext}} = F_0\cos\omega t, \]

se obțin oscilații armonice întreținute.

Rezonanța are loc atunci când:

\[ \boxed{ \omega=\omega_0 } \]

adică atunci când pulsația forței exterioare coincide cu pulsația proprie a pendulului.

Punerea în evidență a rezonanței

Sistemul de pendule

Compendiul prezintă un dispozitiv format din mai multe pendule suspendate de același suport.

Oscilația unui pendul este transmisă prin suport celorlalte pendule.

Pendulele de lungimi diferite au pulsații proprii diferite și oscilează cu amplitudini diferite.

Pendulul a cărui pulsație proprie este egală cu pulsația excitației capătă amplitudinea cea mai mare.

\[ \omega=\omega_0 \quad\Longrightarrow\quad A=A_{\max} \]
Observație experimentală

Pendule de aceeași lungime

Compendiul consideră și pendule de aceeași lungime, dar cu mase diferite.

Experiența arată că proprietățile oscilației analizate nu depind de masa pendulului.

Această independență este în acord cu relația:

\[ T = 2\pi \sqrt{ \frac{l}{g} }, \]

în care masa nu apare.

c) Aplicațiile pendulului

Măsurarea timpului

Legile micilor oscilații ale pendulului matematic au permis construirea unor dispozitive pentru măsurarea precisă a timpului.

Pendulul care bate secunda

Perioada de două secunde

Compendiul numește pendul care bate secunda un pendul pentru care două treceri consecutive prin același punct, indiferent de sens, sunt separate de o secundă.

Perioada unui asemenea pendul este:

\[ T=2\,\mathrm{s} \]

Din:

\[ T = 2\pi\sqrt{\frac{l}{g}} \]

rezultă lungimea:

\[ \boxed{ l=\frac{g}{\pi^2} } \]
Orologiul

Pendulul ca regulator

Compendiul descrie un orologiu care utilizează drept parte principală un pendul care bate secunda.

Numărul oscilațiilor pendulului permite înregistrarea timpului pe cadran prin intermediul roților dințate și al acelor indicatoare.

Deoarece frecările ar determina scăderea treptată a amplitudinii, oscilația pendulului este întreținută de un dispozitiv motor.

Mecanismul orologiului

Regularizarea mișcării

Dispozitivul motor descris în Compendiu utilizează o greutate suspendată printr-un fir înfășurat pe un cilindru.

Mișcarea este transmisă printr-un sistem de roți dințate.

Pentru transformarea mișcării produse de greutatea în cădere într-o mișcare regulată, sistemul este prevăzut cu un regulator.

Ancora regulatorului blochează și deblochează succesiv roata dințată, sincronizat cu oscilația pendulului.

În același timp se transmit pendulului impulsuri care îi întrețin oscilația.

Determinarea lui \(g\)

Pendulul ca instrument de măsură

O altă aplicație importantă a pendulului este determinarea accelerației gravitației.

Din relația:

\[ T = 2\pi \sqrt{ \frac{l}{g} }, \]

rezultă:

\[ \boxed{ g = \frac{ 4\pi^2l }{ T^2 } } \]

Măsurând lungimea pendulului și perioada sa se poate determina accelerația gravitației în locul respectiv.

Variația lui \(g\)

Latitudine și altitudine

Măsurătorile efectuate în diferite puncte de pe suprafața Pământului arată că accelerația gravitației depinde de altitudine și, în mod deosebit, de latitudinea geografică.

Compendiul arată că \(g\) este maximă la poli și minimă la ecuator.

Titularizare

Precizări pentru examen

Această secțiune este separată de conținutul §3.10 al Compendiului. Ea este raportată la programa oficială pentru Titularizare Fizică 2026.

Cerințe explicite în programa 2026

Programa include două puncte direct legate de această lecție.

9. Deformări elastice izotrope. Legea lui Hooke. Energia potențială elastică.

10. Oscilatorul armonic liniar — oscilații libere, amortizate și forțate; rezonanță și factor de calitate.

Din §3.10 sunt acoperite direct:

forța elastică: \[ \vec F_e=-k\vec y \] oscilația liberă: \[ \omega_0=\sqrt{\frac{k}{m}} \] \[ T=2\pi\sqrt{\frac{m}{k}} \] oscilația amortizată: \[ m\ddot y+b\dot y+ky=0 \] oscilația forțată: \[ m\ddot y+b\dot y+ky = F_0\cos\omega t \] și rezonanța: \[ \omega=\omega_0. \]
Completare necesară pentru programă: factorul de calitate este cerut explicit de programa 2026, dar nu este definit în §3.10 al Compendiului. El trebuie studiat separat ca o completare pentru Titularizare.
De asemenea: deformările elastice izotrope, formularea generală a legii lui Hooke și proprietățile mecanice ale materialelor sunt dezvoltate mai târziu în capitolul 7 al Compendiului. Energia potențială elastică este tratată în capitolul referitor la energie.
Pendulul matematic: relația \[ T=2\pi\sqrt{\frac{l}{g}} \] este obținută aici numai în aproximația micilor oscilații, \[ \sin\alpha\simeq\alpha. \] Această condiție nu trebuie omisă într-o demonstrație.
Nu confunda: pendulul matematic din §3.10 cu pendulul fizic. Programa oficială 2026 cere separat pendulul fizic în cadrul mișcării solidului rigid cu axă fixă.
Titularizare 2027: programa oficială 2027 trebuie reverificată după publicare.
