Mișcarea planetelor

Legile lui Kepler

În urma observațiilor astronomice, J. Kepler a stabilit legile care descriu mișcarea planetelor în jurul Soarelui.

Legea I

Planetele se mișcă pe elipse, Soarele fiind situat într-unul dintre focarele elipsei.

Legea a II-a

Raza vectoare a planetei descrie arii egale în intervale de timp egale.

Legea a III-a

Pătratele perioadelor de revoluție sunt direct proporționale cu cuburile semiaxelor mari ale orbitelor.

\[ \boxed{ T^2=CR^3 } \]

Prin perioada de revoluție \(T\) se înțelege timpul în care planeta descrie o orbită completă.

Legea ariilor

Arii egale în timpuri egale

Dacă raza vectoare a planetei descrie două suprafețe în intervale egale de timp, conform celei de-a doua legi a lui Kepler aceste suprafețe sunt egale.

\[ \Delta t_1=\Delta t_2 \quad\Longrightarrow\quad \Delta S_1=\Delta S_2 \]
Model

Soarele și planeta ca puncte materiale

În continuarea demonstrației, Soarele și planetele sunt tratate ca puncte materiale.

Dimensiunile acestora sunt considerate neglijabile în raport cu distanțele care le separă.

Newton

Explicarea mișcării planetelor

Newton a explicat legile mișcării planetelor presupunând că Soarele exercită asupra fiecărei planete o forță de atracție.

Forța este orientată către Soare și joacă rolul forței centripete care curbează traiectoria planetei.

Mărimea forței este proporțională cu produsul maselor și invers proporțională cu pătratul distanței dintre ele.

Forța de atracție

Soare–planetă

Dacă \(M_S\) este masa Soarelui, \(m_p\) masa planetei și \(r\) distanța dintre ele:

\[ \boxed{ F = K \frac{ M_Sm_p }{ r^2 } } \]

Constanta \(K\) este constanta de proporționalitate.

Forma vectorială

Sensul forței

Se consideră vectorul \(\vec r\) orientat de la Soare către planetă.

Forța de atracție are aceeași direcție, dar sens contrar.

\[ \boxed{ \vec F = -K \frac{ M_Sm_p }{ r^3 } \vec r } \]

Semnul minus exprimă caracterul atractiv al forței.

Momentul forței

Moment nul față de Soare

Momentul forței de atracție față de Soare este:

\[ \vec M = \vec r\times\vec F \]

Deoarece \(\vec F\) este coliniară cu \(\vec r\):

\[ \boxed{ \vec M=0 } \]
Momentul cinetic

Conservarea momentului cinetic

Din relația dintre momentul forței și momentul cinetic:

\[ \frac{d\vec L}{dt} = \vec M, \]

rezultă:

\[ \frac{d\vec L}{dt}=0. \]

Prin urmare:

\[ \boxed{ \vec L = \text{constant} } \]

Momentul cinetic:

\[ \vec L = \vec r\times\vec p \]

își păstrează mărimea, direcția și sensul în timpul mișcării.

Traiectoria

Mișcarea are loc într-un plan

Vectorul moment cinetic este perpendicular pe planul determinat de vectorul de poziție și vectorul viteză.

Deoarece \(\vec L\) își păstrează permanent direcția, orientarea acestui plan nu se modifică.

Traiectoria corpului aflat sub acțiunea forței de atracție este deci o curbă plană.

Forma traiectoriei

Elipsă, parabolă sau hiperbolă

Determinarea matematică a formei traiectoriei necesită calcule mai complicate.

Compendiul precizează că, în funcție de condițiile inițiale, traiectoria poate fi:

  • elipsă;
  • parabolă;
  • hiperbolă.

Pentru planete sunt realizate condițiile corespunzătoare orbitelor eliptice.

Se obține astfel prima lege a lui Kepler.

Legea a II-a

Viteza areolară

Într-un interval de timp foarte mic, vectorul de poziție descrie suprafața elementară:

\[ d\vec S = \frac12 \vec r\times d\vec r \]

Împărțind la \(dt\):

\[ \frac{d\vec S}{dt} = \frac12 \vec r \times \frac{d\vec r}{dt} \]

Deoarece:

\[ \frac{d\vec r}{dt} = \vec v \]

și:

\[ \vec L = \vec r\times m_p\vec v, \]

rezultă:

\[ \boxed{ \frac{d\vec S}{dt} = \frac{\vec L}{2m_p} } \]
Consecință

Aria este proporțională cu timpul

Deoarece momentul cinetic este constant, viteza areolară este constantă.

\[ \boxed{ \frac{dS}{dt} = \frac{L}{2m_p} = \text{constant} } \]

Prin integrare:

\[ S = \frac{L}{2m_p}t \]

În intervale egale de timp sunt descrise arii egale.

Se obține astfel a doua lege a lui Kepler.

Legea a III-a

Cazul unei orbite circulare

Pentru simplificarea demonstrației celei de-a treia legi, Compendiul consideră o orbită circulară de rază \(R\).

Forța de atracție este egalată cu forța centripetă:

\[ K \frac{ M_Sm_p }{ R^2 } = m_p\omega^2R \]

După simplificarea masei planetei:

\[ KM_S = \omega^2R^3 \]
Perioada orbitală

Relația \(T^2\sim R^3\)

Pentru mișcarea circulară:

\[ \omega = \frac{2\pi}{T} \]

și deci:

\[ KM_S = \frac{ 4\pi^2R^3 }{ T^2 } \]

Rezultă:

\[ \boxed{ T^2 = \frac{ 4\pi^2 }{ KM_S } R^3 } \]

Notând factorul constant cu \(C\):

\[ \boxed{ T^2=CR^3 } \]

Se obține astfel legea a treia a lui Kepler.

Forța centrală

Direcția forței

Direcția forței de atracție trece în permanență prin centrul corpului care produce atracția.

Forță centrală

Forța a cărei direcție trece permanent printr-un punct fix.

Forța de atracție dintre Soare și planetă este astfel o forță centrală.

Mai multe atracții

Pământul, Soarele și Luna

Pământul nu este supus numai atracției Soarelui.

Asupra lui acționează și atracțiile exercitate de celelalte corpuri ale sistemului solar.

Compendiul analizează în mod particular atracția exercitată de Lună.

Forța totală care acționează asupra Pământului este suma vectorială a forțelor de atracție.

\[ \boxed{ \vec F = \vec F_S+\vec F_L } \]

Accelerația Pământului rezultă din această forță totală.

Generalizarea lui Newton

Legea atracției universale

Newton generalizează relația stabilită pentru Soare și planete.

Între orice două corpuri din Univers se exercită o forță de atracție.

Legea atracției universale

Forța de atracție dintre două corpuri este direct proporțională cu produsul maselor lor și invers proporțională cu pătratul distanței dintre centrele lor.

\[ \boxed{ F = K \frac{ m_1m_2 }{ r_{12}^{\,2} } } \]
Constanta atracției universale

Constanta \(K\)

Constanta \(K\) este aceeași pentru toate perechile de corpuri care se atrag.

Dacă cele două mase sunt egale cu unitatea, iar distanța dintre ele este egală cu unitatea, forța este numeric egală cu \(K\).

Valoarea indicată în Compendiu este:

\[ \boxed{ K = 6{,}66 \cdot 10^{-11} \; \mathrm{ N\,m^2/kg^2 } } \]

Datorită valorii foarte mici a constantei, atracția dintre corpuri obișnuite este greu de pus în evidență.

Atracția Pământului este însă importantă datorită masei foarte mari a acestuia.

Atracția Pământului

Greutatea unui corp

Forța cu care Pământul atrage un corp reprezintă greutatea acelui corp.

Pentru un corp de masă \(m\) aflat la suprafața Pământului:

\[ mg_0 = K \frac{ mM_P }{ R^2 } \]

unde \(M_P\) este masa Pământului și \(R\) raza sa.

După simplificarea masei \(m\):

\[ \boxed{ g_0 = K \frac{ M_P }{ R^2 } } \]
Masa Pământului

Determinarea din \(g_0\)

Cunoscând accelerația gravitației, raza Pământului și constanta atracției universale, se poate determina masa Pământului.

\[ \boxed{ M_P = \frac{ g_0R^2 }{ K } } \]

Pentru raza Pământului de aproximativ:

\[ R\simeq6400\,\mathrm{km}, \]

Compendiul obține o masă de ordinul:

\[ M_P \simeq 6\cdot10^{24}\,\mathrm{kg} \]
Altitudinea

Accelerația gravitației la înălțimea \(h\)

Dacă un corp se află la altitudinea \(h\), distanța sa față de centrul Pământului este:

\[ R+h \]

Legea atracției universale conduce la:

\[ mg_h = K \frac{ mM_P }{ (R+h)^2 } \]

și deci:

\[ \boxed{ g_h = K \frac{ M_P }{ (R+h)^2 } } \]
Variația lui \(g\)

Raportarea la suprafața Pământului

Deoarece:

\[ g_0 = K\frac{M_P}{R^2}, \]

accelerația gravitației la altitudinea \(h\) poate fi scrisă:

\[ \boxed{ g_h = g_0 \left( \frac{R}{R+h} \right)^2 } \]

Accelerația gravitației scade odată cu creșterea altitudinii.

În consecință, și greutatea unui corp variază cu altitudinea.

Aproximație

Altitudini mici față de raza Pământului

Dacă:

\[ h\ll R, \]

se poate utiliza dezvoltarea aproximativă prezentată în Compendiu.

\[ \boxed{ g_h \simeq g_0 \left( 1-\frac{2h}{R} \right) } \]

Pentru înălțimi mici în raport cu raza Pământului, variația lui \(g\) este suficient de mică pentru ca accelerația gravitației să poată fi considerată aproximativ constantă.

Exemplul din Compendiu

Altitudinea de \(1\,\mathrm{km}\)

Pentru:

\[ h=1\,\mathrm{km}, \qquad R\simeq6400\,\mathrm{km}, \]

relația aproximativă devine:

\[ g_h = g_0 \left( 1-\frac{2}{6400} \right) \]
\[ g_h = g_0 \left( 1-\frac{1}{3200} \right) \]

Diferența față de \(g_0\) este suficient de mică pentru a considera accelerația gravitației practic constantă pe această diferență de altitudine.

Câmp de forțe

Acțiunea într-o regiune a spațiului

Câmp de forțe

Dacă în fiecare punct al unei anumite regiuni a spațiului se exercită o forță, în regiunea respectivă există un câmp de forțe.

Câmp gravitațional

Câmpul produs de o masă

Forța de atracție a Pământului se exercită în punctele spațiului din jurul său.

Câmp gravitațional sau câmp gravific

Câmpul de forțe produs de atracția gravitațională a unui corp.

Deoarece toate corpurile se atrag reciproc, fiecare corp dă naștere unui câmp gravitațional în spațiul din jurul său.

Masa exprimă astfel atât proprietățile inerțiale ale corpului, cât și proprietățile sale gravifice.

Intensitatea câmpului

Mărime caracteristică a câmpului

Forța gravitațională care acționează asupra unui corp depinde atât de corpul care produce câmpul, cât și de masa corpului aflat în acel câmp.

Pentru caracterizarea câmpului independent de masa corpului de probă se introduce intensitatea câmpului gravitațional.

Intensitatea câmpului gravitațional

Forța exercitată de câmp asupra unității de masă.

\[ \boxed{ \vec{\Gamma} = \frac{\vec F}{m} } \]
Expresia intensității

Câmpul produs de Pământ

Pentru Pământ, folosind legea atracției universale:

\[ \boxed{ \vec{\Gamma} = -K \frac{ M_P }{ r^3 } \vec r } \]

Modulul intensității este:

\[ \boxed{ \Gamma = K \frac{ M_P }{ r^2 } } \]

Cu cât intensitatea câmpului este mai mare, cu atât acțiunea asupra unei mase aflate în câmp este mai puternică.

Intensitate și accelerație

Aceeași expresie matematică

Intensitatea câmpului gravitațional are aceeași expresie matematică precum accelerația gravitației.

Semnificația introdusă în Compendiu pentru intensitatea câmpului este însă aceea de forță care acționează asupra unității de masă.

\[ \vec{\Gamma} = \frac{\vec F}{m} \]
Simetria câmpului

Câmp gravitațional cu simetrie sferică

Intensitatea câmpului gravitațional al Pământului are același modul în punctele situate la aceeași distanță de centrul Pământului.

Aceste puncte se găsesc pe suprafața unei sfere cu centrul în centrul Pământului.

Simetrie sferică

Modulul intensității câmpului este același în toate punctele egal depărtate de centrul corpului care produce câmpul.

Titularizare

Precizări pentru examen

Această secțiune este separată de conținutul §3.11 al Compendiului. Ea este raportată la programa oficială pentru Titularizare Fizică 2026.

Cerință explicită în programa 2026

Programa cuprinde distinct:

Mișcarea în câmp central (cazul forțelor atractive). Legea atracției universale. Legile lui Kepler.

§3.11 este, prin urmare, direct relevant pentru programa de concurs.

Trebuie stăpânite:

caracterul central al forței: \[ \vec F \parallel \vec r \] legea atracției universale: \[ \boxed{ F = K \frac{ m_1m_2 }{ r^2 } } \] momentul nul al forței centrale: \[ \vec M=0 \] conservarea momentului cinetic: \[ \boxed{ \vec L=\text{constant} } \] viteza areolară constantă: \[ \boxed{ \frac{dS}{dt} = \text{constant} } \] și cele trei legi ale lui Kepler.
Legătura logică importantă pentru examen:

\[ \text{forță centrală} \Longrightarrow \vec M=0 \Longrightarrow \vec L=\text{constant} \Longrightarrow \frac{dS}{dt}=\text{constant} \] Aceasta este legătura dintre forța centrală și legea a II-a a lui Kepler.
Pentru orbita circulară:

\[ K \frac{ Mm }{ R^2 } = \frac{ mv^2 }{ R } \] sau: \[ K \frac{ Mm }{ R^2 } = m\omega^2R. \] Aceste egalități leagă gravitația de dinamica mișcării circulare.
Atenție la notația Compendiului: în corpul lecției a fost păstrat simbolul \(K\) utilizat în Compendiu pentru constanta atracției universale. La rezolvarea unei probleme trebuie urmărită notația precizată în enunț.
Valoarea numerică: valoarea \(K=6{,}66\cdot10^{-11}\) este cea tipărită în Compendiul din 1972. Pentru un subiect actual, dacă valoarea constantei este furnizată în enunț, se utilizează valoarea din subiect.
