3.8 Greutatea corpurilor

Greutatea, accelerația gravitației, căderea liberă și mișcarea corpurilor aruncate în câmpul gravitațional terestru.

3.8 Greutatea corpurilor
Pagini: 76–79
Greutatea

Căderea corpurilor spre Pământ

Orice corp care nu este susținut se mișcă spre Pământ.

Căderea liberă

Mișcarea spre Pământ a unui corp nesusținut, atunci când se neglijează rezistența aerului.

Forța care produce căderea corpului este greutatea sa.

\[ \vec G \]
Direcția greutății

Verticala locului

Direcția greutății este dată de dreapta după care se efectuează căderea liberă.

Verticala locului

Direcția după care se efectuează căderea liberă a corpurilor.

Verticala locului poate fi determinată cu ajutorul firului cu plumb.

În prezentarea din Compendiu, aceasta este dirijată după raza Pământului.

Latitudinea geografică

Unghiul dintre verticale

Se consideră verticala unui punct de pe suprafața Pământului și verticala unui punct de pe ecuator, aflat pe același cerc meridian.

Unghiul \(\alpha\) dintre cele două verticale reprezintă latitudinea geografică a locului considerat.

\[ \alpha = \text{latitudinea geografică} \]
Punct de aplicație

Centrul de greutate

Centrul de greutate

Punctul de aplicație al forței de greutate a unui corp.

Experiență

Tubul lui Newton

Căderea liberă poate fi studiată într-un tub din care aerul a fost evacuat.

În asemenea condiții se constată că toate corpurile capătă aceeași viteză și aceeași accelerație.

Neglijând rezistența aerului, căderea corpurilor nu depinde de:

  • forma corpului;
  • dimensiunile corpului;
  • natura corpului.
Accelerația gravitației

Relația dintre greutate și masă

Accelerația gravitației

Accelerația pe care o capătă corpurile datorită greutății lor.

Accelerația gravitației este notată cu \(g\).

Aplicând principiul al doilea al mecanicii:

\[ \boxed{ G=mg } \]

În formă vectorială:

\[ \boxed{ \vec G=m\vec g } \]
Determinarea lui \(g\)

Planul înclinat

În căderea liberă viteza crește rapid, ceea ce îngreunează măsurătorile.

Pentru reducerea accelerației măsurate, Galileo Galilei a utilizat planul înclinat.

Pe direcția planului acționează componenta greutății:

\[ G_{\parallel} = mg\sin\alpha \]

Accelerația corpului este:

\[ \boxed{ a=g\sin\alpha } \]

și este mai mică decât accelerația căderii libere:

\[ a
Geometria planului

Determinarea accelerației gravitației

Dacă \(h\) este înălțimea planului înclinat și \(l\) lungimea acestuia:

\[ \sin\alpha = \frac{h}{l} \]

atunci:

\[ a = g\frac{h}{l} \]

de unde:

\[ \boxed{ g = a\frac{l}{h} } \]
Determinarea lui \(g\)

Mașina Atwood

Un alt dispozitiv prezentat pentru determinarea accelerației gravitației este mașina Atwood.

Ea este formată din două corpuri identice, fiecare de masă \(M\), suspendate la capetele unui fir care trece peste un scripete fix.

Se neglijează frecările dintre fir și scripete și rezistența aerului.

Uneia dintre mase i se adaugă o masă suplimentară \(m\).

Masa totală a sistemului devine:

\[ 2M+m \]

Forța care pune sistemul în mișcare este greutatea masei suplimentare:

\[ mg \]
Ecuația mișcării

Accelerația mașinii Atwood

Mișcarea sistemului este uniform accelerată.

Aplicând principiul al doilea al mecanicii întregului sistem:

\[ \boxed{ mg = (2M+m)a } \]

După măsurarea accelerației \(a\), se poate calcula accelerația gravitației:

\[ \boxed{ g = \frac{2M+m}{m}\,a } \]
Cădere liberă

Corp lăsat fără viteză inițială

Se consideră un corp care cade liber de la înălțimea \(h\), fără viteză inițială.

Mișcarea este uniform accelerată, cu accelerația \(g\).

\[ \boxed{ h = \frac{gt^2}{2} } \]

Viteza corpului după timpul \(t\) este:

\[ \boxed{ v=gt } \]
Eliminarea timpului

Viteza la atingerea solului

Eliminând timpul dintre relațiile:

\[ h=\frac{gt^2}{2} \]

și:

\[ v=gt, \]

se obține:

\[ \boxed{ v=\sqrt{2gh} } \]
Timpul de cădere

Coborârea de la înălțimea \(h\)

Din ecuația căderii libere:

\[ h=\frac{gt^2}{2}, \]

rezultă timpul de cădere:

\[ \boxed{ t = \sqrt{ \frac{2h}{g} } } \]
a) Aruncarea pe verticală

Corp aruncat vertical în sus

Se consideră un corp aruncat vertical în sus cu viteza inițială \(v_0\).

În timpul urcării, corpul execută o mișcare uniform încetinită.

După timpul \(t\), viteza sa este:

\[ \boxed{ v=v_0-gt } \]
Punctul cel mai înalt

Timpul de urcare

La înălțimea maximă viteza corpului devine nulă:

\[ v=0 \]

Din:

\[ 0=v_0-gt_{\mathrm{urc}} \]

rezultă:

\[ \boxed{ t_{\mathrm{urc}} = \frac{v_0}{g} } \]
Înălțimea maximă

Ridicarea corpului

Înălțimea maximă atinsă de corp este:

\[ \boxed{ h_{\max} = \frac{v_0^2}{2g} } \]

După atingerea înălțimii maxime, corpul începe să cadă liber.

Pentru revenirea la același nivel de la care a fost lansat, viteza finală are aceeași mărime ca viteza inițială, iar timpul de coborâre este egal cu timpul de urcare.

\[ t_{\mathrm{cob}} = t_{\mathrm{urc}} \]
b) Aruncarea sub un unghi dat

Proiectil lansat oblic

Se consideră un corp lansat cu viteza inițială \(v_0\), care formează unghiul \(\alpha\) cu orizontala.

Se neglijează rezistența aerului, iar singura forță considerată este greutatea.

Viteza inițială se descompune după două direcții perpendiculare.

\[ v_{0x} = v_0\cos\alpha \]
\[ v_{0y} = v_0\sin\alpha \]
Ecuațiile mișcării

Componentele mișcării

După direcția orizontală, mișcarea este uniformă.

După direcția verticală, în timpul urcării, mișcarea este uniform încetinită.

\[ \boxed{ x = v_0\cos\alpha\,t } \]
\[ \boxed{ y = v_0\sin\alpha\,t - \frac{gt^2}{2} } \]
Înălțimea maximă

Aruncarea oblică

Înălțimea maximă atinsă de corp este:

\[ \boxed{ y_{\max} = \frac{ v_0^2\sin^2\alpha }{ 2g } } \]
Bătaia

Distanța maximă pe orizontală

Distanța parcursă pe orizontală până la revenirea corpului la nivelul de lansare este:

\[ \boxed{ x_{\max} = \frac{ v_0^2\sin2\alpha }{ g } } \]
Durata mișcării

Urcarea și coborârea

Timpul de urcare este:

\[ \boxed{ t_{\mathrm{urc}} = \frac{ v_0\sin\alpha }{ g } } \]

Pentru revenirea la nivelul de lansare:

\[ t_{\mathrm{cob}} = t_{\mathrm{urc}} \]

Timpul total al mișcării este:

\[ \boxed{ t = \frac{ 2v_0\sin\alpha }{ g } } \]
Traiectoria

Ecuația parabolei

Eliminând timpul dintre ecuațiile:

\[ x=v_0\cos\alpha\,t \]

și:

\[ y = v_0\sin\alpha\,t - \frac{gt^2}{2}, \]

se obține:

\[ \boxed{ y = x\tan\alpha - \frac{ gx^2 }{ 2v_0^2\cos^2\alpha } } \]

Traiectoria este o parabolă.

c) Aruncarea pe orizontală

Corp lansat de la înălțimea \(h\)

Se consideră un corp lansat de la înălțimea \(h\) față de sol, cu viteza inițială \(v_0\) orientată orizontal.

Mișcarea poate fi considerată rezultatul compunerii:

  • unei mișcări rectilinii uniforme după direcția \(Ox\);
  • unei mișcări uniform accelerate, fără viteză inițială, după direcția verticală.
Ecuațiile mișcării

Mișcarea pe cele două axe

La momentul inițial corpul se găsește în punctul:

\[ A(0,h) \]

Ecuațiile mișcării sunt:

\[ \boxed{ x=v_0t } \]
\[ \boxed{ y = h-\frac{gt^2}{2} } \]
Traiectoria

Eliminarea timpului

Din:

\[ t=\frac{x}{v_0} \]

și ecuația verticală rezultă:

\[ \boxed{ y = h - \frac{ gx^2 }{ 2v_0^2 } } \]

Și în acest caz traiectoria este o parabolă.

Atingerea solului

Timpul de cădere

Corpul atinge solul când:

\[ y=0 \]

astfel încât:

\[ \boxed{ t_{\mathrm{cob}} = \sqrt{ \frac{2h}{g} } } \]
Distanța maximă

Deplasarea pe orizontală

În timpul căderii, corpul se deplasează pe orizontală cu viteza constantă \(v_0\).

Distanța parcursă pe orizontală până la atingerea solului este:

\[ \boxed{ x_{\max} = v_0 \sqrt{ \frac{2h}{g} } } \]
Sinteză

De reținut din §3.8

Greutatea

\[ \boxed{ \vec G=m\vec g } \]

Căderea liberă

\[ h=\frac{gt^2}{2} \]
\[ v=gt \]
\[ \boxed{ v=\sqrt{2gh} } \]
\[ \boxed{ t=\sqrt{\frac{2h}{g}} } \]

Aruncarea verticală

\[ v=v_0-gt \]
\[ t_{\mathrm{urc}} = \frac{v_0}{g} \]
\[ h_{\max} = \frac{v_0^2}{2g} \]

Aruncarea oblică

\[ x = v_0\cos\alpha\,t \]
\[ y = v_0\sin\alpha\,t - \frac{gt^2}{2} \]
\[ y_{\max} = \frac{ v_0^2\sin^2\alpha }{ 2g } \]
\[ x_{\max} = \frac{ v_0^2\sin2\alpha }{ g } \]
\[ t = \frac{ 2v_0\sin\alpha }{ g } \]

Aruncarea orizontală

\[ x=v_0t \]
\[ y = h-\frac{gt^2}{2} \]
\[ y = h - \frac{ gx^2 }{ 2v_0^2 } \]
\[ x_{\max} = v_0 \sqrt{ \frac{2h}{g} } \]
Titularizare

Precizări pentru examen

Această secțiune nu face parte din §3.8 al Compendiului. Ea este raportată separat la programa oficială pentru Titularizare Fizică 2026.

Încadrarea în programa 2026

„Greutatea corpurilor” și „aruncarea corpurilor” nu sunt nominalizate ca puncte separate în lista tematicii științifice.

Conținutul se leagă însă direct de:

  • principiile mecanicii newtoniene;
  • mișcarea rectilinie uniform variată;
  • cinematica mișcării curbilinii;
  • mișcarea în câmp central;
  • legea atracției universale.
Pentru această lecție trebuie fixate în special:

relația dintre greutate și masă: \[ \boxed{ \vec G=m\vec g } \] căderea liberă: \[ h=\frac{gt^2}{2}, \qquad v=gt \] aruncarea verticală;
descompunerea mișcării în cazul aruncării oblice;
ecuația traiectoriei parabolice;
compunerea mișcării uniforme pe orizontală cu mișcarea uniform accelerată pe verticală.
Condiția fizică esențială: formulele pentru aruncarea verticală, oblică și orizontală din această lecție sunt scrise în condițiile în care rezistența aerului este neglijată.
Titularizare 2027: programa oficială pentru sesiunea 2027 trebuie reverificată după publicare.
