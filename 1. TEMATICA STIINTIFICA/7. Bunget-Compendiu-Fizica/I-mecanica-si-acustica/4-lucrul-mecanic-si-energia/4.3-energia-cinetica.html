4.3 Energia cinetică

Legătura dintre lucrul mecanic al forței rezultante și modificarea stării de mișcare a corpului.

Ion Bunget Compendiu de Fizică §4.3

4.3 Energia cinetică
Pagini: 127–128
Punct material

O forță modifică viteza corpului

Se consideră un corp asimilat unui punct material, asupra căruia acționează o forță constantă \(\vec F\).

Sub acțiunea acestei forțe, viteza corpului se modifică conform legilor mișcării uniform variate.

Compendiul urmărește să stabilească legătura dintre modificarea vitezei corpului și lucrul mecanic efectuat de forță.

Condițiile inițiale

Forța și viteza sunt paralele

La momentul inițial \(t_0\), punctul material are viteza:

\[ \vec v_0 \]

iar forța \(\vec F\) începe să acționeze asupra lui.

În demonstrația inițială, vectorii \(\vec F\) și \(\vec v_0\) sunt considerați paraleli.

La un moment ulterior \(t_1\), corpul are viteza:

\[ \vec v_1 \]

cu aceeași direcție, dar cu o altă valoare.

Lucrul mecanic

Forța constantă

În intervalul:

\[ \Delta t = t_1-t_0, \]

corpul parcurge distanța \(s\).

Deoarece forța are aceeași direcție cu deplasarea, lucrul mecanic este:

\[ \boxed{ L=Fs } \]

Din principiul al doilea al mecanicii:

\[ F=ma. \]

Prin urmare:

\[ \boxed{ L=mas } \]
Cinematică

Ecuațiile mișcării uniform variate

Pentru intervalul \(t_1-t_0\), spațiul parcurs este:

\[ \boxed{ s = v_0(t_1-t_0) + \frac{a}{2} (t_1-t_0)^2 } \]

Viteza la momentul \(t_1\) este:

\[ \boxed{ v_1 = v_0 + a(t_1-t_0) } \]

Din ultima relație:

\[ a(t_1-t_0) = v_1-v_0. \]
Calcul

Produsul \(as\)

Înmulțind expresia spațiului parcurs cu accelerația:

\[ as = av_0(t_1-t_0) + \frac{a^2}{2} (t_1-t_0)^2. \]

Folosind:

\[ a(t_1-t_0) = v_1-v_0, \]

se obține:

\[ as = v_0(v_1-v_0) + \frac12 (v_1-v_0)^2. \]

După efectuarea calculelor:

\[ \boxed{ as = \frac12 \left( v_1^2-v_0^2 \right) } \]
Rezultatul

Legătura dintre lucru și viteze

Deoarece:

\[ L=mas, \]

folosind rezultatul precedent se obține:

\[ \boxed{ L = \frac{m}{2} \left( v_1^2-v_0^2 \right) } \]

sau:

\[ \boxed{ L = \frac{mv_1^2}{2} - \frac{mv_0^2}{2} } \]
Definiție

Energia cinetică

Relația precedentă arată că lucrului mecanic îi corespunde variația mărimii:

\[ \boxed{ W_c = \frac{mv^2}{2} } \]
Energia cinetică

Mărimea fizică asociată mișcării corpului, definită în Compendiu prin:

\[ W_c = \frac{mv^2}{2} \]

Energia cinetică depinde de masa corpului și de pătratul vitezei sale.

Relația fundamentală

Lucrul mecanic și variația energiei cinetice

Notând cu:

\[ W_{c0} = \frac{mv_0^2}{2} \]

energia cinetică inițială și cu:

\[ W_{c1} = \frac{mv_1^2}{2} \]

energia cinetică finală, relația obținută devine:

\[ \boxed{ L = W_{c1}-W_{c0} } \]

sau:

\[ \boxed{ L=\Delta W_c } \]
\(L>0\)

Creșterea energiei cinetice

Dacă lucrul mecanic efectuat asupra corpului este pozitiv:

\[ L>0, \]

atunci:

\[ W_{c1}>W_{c0}. \]

Energia cinetică a corpului crește.

\[ \boxed{ L>0 \quad\Longrightarrow\quad \Delta W_c>0 } \]

Pentru situația inițială studiată de Compendiu, aceasta corespunde mișcării uniform accelerate.

\(L=0\)

Energia cinetică nu se modifică

Dacă lucrul mecanic este nul:

\[ L=0, \]

atunci:

\[ \boxed{ W_{c1}=W_{c0} } \]

Energia cinetică rămâne neschimbată.

\[ \Delta W_c=0 \]
\(L<0\)

Scăderea energiei cinetice

Dacă asupra corpului acționează o forță care se opune mișcării, lucrul său mecanic este negativ.

\[ L<0 \]

și energia cinetică scade:

\[ \boxed{ L<0 \quad\Longrightarrow\quad W_{c1}

Energia cinetică poate scădea până la zero.

Această situație corespunde opririi corpului.

Exemplu

Oprirea unui corp prin frecare

Se consideră un corp care are viteza inițială \(v_0\).

Asupra lui acționează o forță de frecare constantă \(F_f\), orientată în sens opus mișcării.

Lucrul mecanic al forței de frecare pe distanța \(s\) este:

\[ \boxed{ L_f=-F_fs } \]

Conform relației dintre lucru și variația energiei cinetice:

\[ -F_fs = \frac{mv^2}{2} - \frac{mv_0^2}{2}. \]
Oprirea

Distanța parcursă până la oprire

La oprire:

\[ v=0. \]

Relația precedentă devine:

\[ -F_fs = -\frac{mv_0^2}{2}. \]

sau:

\[ \boxed{ F_fs = \frac{mv_0^2}{2} } \]

Rezultă distanța parcursă până la oprire:

\[ \boxed{ s = \frac{ mv_0^2 }{ 2F_f } } \]
Interpretare

Lucrul necesar opririi

Compendiul subliniază că valoarea absolută a lucrului mecanic negativ necesar opririi corpului este egală cu energia cinetică pe care acesta o avea inițial.

\[ \boxed{ |L_f| = \frac{mv_0^2}{2} = W_{c0} } \]
Accelerația

Forma cinematică a distanței de oprire

Dacă \(a_f\) reprezintă modulul accelerației constante produsă de forța de frecare:

\[ F_f=ma_f, \]

relația distanței de oprire poate fi scrisă:

\[ \boxed{ s = \frac{ v_0^2 }{ 2a_f } } \]

Același rezultat poate fi obținut direct din legile mișcării uniform variate.

Generalizare

Forță variabilă și traiectorie curbilinie

Relația dintre lucrul mecanic și variația energiei cinetice a fost obținută inițial pentru o forță constantă și pentru mișcare rectilinie.

Compendiul precizează însă că rezultatul rămâne valabil și atunci când forța nu este constantă și traiectoria nu este rectilinie.

În acest caz lucrul mecanic trebuie calculat prin relația generală stabilită în §4.1:

\[ \boxed{ L_{A\to B} = \int_A^B \vec F\cdot d\vec r } \]

iar relația energetică rămâne:

\[ \boxed{ L_{A\to B} = W_c(B)-W_c(A) } \]
Legătura logică

Forță → lucru mecanic → energie cinetică

Principiul al doilea

\[ F=ma \]

Lucrul mecanic

\[ L=Fs \]

Cinematica

\[ v_1^2-v_0^2 = 2as \]

Rezultatul

\[ L = \frac{m}{2} \left( v_1^2-v_0^2 \right) \]

Energia cinetică

\[ \boxed{ W_c = \frac{mv^2}{2} } \]

Relația fundamentală

\[ \boxed{ L=\Delta W_c } \]
Sinteză

De reținut din §4.3

Energia cinetică

\[ \boxed{ W_c = \frac{mv^2}{2} } \]

Teorema energiei cinetice

\[ \boxed{ L = W_{c1}-W_{c0} = \Delta W_c } \]

Lucru pozitiv

\[ L>0 \quad\Longrightarrow\quad W_{c1}>W_{c0} \]

Lucru nul

\[ L=0 \quad\Longrightarrow\quad W_{c1}=W_{c0} \]

Lucru negativ

\[ L<0 \quad\Longrightarrow\quad W_{c1}

Oprire prin frecare

\[ \boxed{ F_fs = \frac{mv_0^2}{2} } \]
\[ \boxed{ s = \frac{ mv_0^2 }{ 2F_f } } \]
\[ \boxed{ s = \frac{ v_0^2 }{ 2a_f } } \]

Caz general

\[ \boxed{ \int_A^B \vec F\cdot d\vec r = W_c(B)-W_c(A) } \]
Titularizare

Precizări pentru examen

Această secțiune este separată de conținutul §4.3 al Compendiului. Ea este raportată la programa oficială pentru Titularizare Fizică 2026.

Cerință explicită în programa 2026

Energia cinetică este menționată explicit la punctul 5:

Teoremele mecanicii clasice (energie cinetică, impuls, moment cinetic). Legi de conservare.

Notație actuală uzuală: în Compendiu este utilizat simbolul \(W_c\). În multe formulări actuale energia cinetică este notată \(E_c\): \[ \boxed{ E_c = \frac12mv^2 } \] Cele două notații reprezintă aceeași mărime fizică.
Teorema variației energiei cinetice: lucrul mecanic al rezultantei forțelor care acționează asupra punctului material este egal cu variația energiei sale cinetice: \[ \boxed{ L_{\mathrm{rez}} = \Delta E_c = E_{c,f}-E_{c,i} } \]
Forma explicită: \[ \boxed{ L_{\mathrm{rez}} = \frac12mv_f^2 - \frac12mv_i^2 } \]
Greșeală frecventă: în teorema energiei cinetice trebuie folosit lucrul mecanic al rezultantei forțelor sau, echivalent, suma lucrurilor tuturor forțelor: \[ L_{\mathrm{rez}} = \sum_i L_i. \] Nu se ia în calcul arbitrar numai una dintre forțe.
Atenție la semn: dacă: \[ L_{\mathrm{rez}}>0, \] energia cinetică crește; dacă: \[ L_{\mathrm{rez}}<0, \] energia cinetică scade; iar dacă: \[ L_{\mathrm{rez}}=0, \] energia cinetică rămâne constantă.
Energie cinetică constantă nu înseamnă neapărat viteză vectorială constantă. Energia cinetică depinde de modulul vitezei: \[ E_c=\frac12mv^2. \] De exemplu, în mișcarea circulară uniformă direcția lui \(\vec v\) se modifică, dar modulul vitezei și energia cinetică rămân constante.
Unitatea SI: \[ [E_c]_{\mathrm{SI}} = \mathrm J. \] Verificare dimensională: \[ [E_c] = \mathrm{kg} \cdot \frac{\mathrm{m^2}}{\mathrm{s^2}} = \mathrm J. \]
Metoda de lucru într-o problemă:

1. alegi corpul sau sistemul studiat;
2. identifici toate forțele care efectuează lucru mecanic;
3. calculezi lucrul total;
4. scrii: \[ L_{\mathrm{rez}} = \Delta E_c; \] 5. introduci: \[ E_c=\frac12mv^2; \] 6. verifici semnul lucrului, unitățile și sensul fizic al rezultatului.
Legătura cu lecția următoare: în §4.4 va fi introdusă energia potențială pentru forțele conservative. Ulterior: \[ E_c+E_p \] va conduce la energia mecanică totală și la legea conservării energiei mecanice.
