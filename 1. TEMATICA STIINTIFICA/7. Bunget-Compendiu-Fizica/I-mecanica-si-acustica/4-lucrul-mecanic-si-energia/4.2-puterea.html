4.2 Puterea

Puterea caracterizează rapiditatea cu care este efectuat lucrul mecanic. Pentru o mișcare oarecare, puterea instantanee depinde de forță, de viteza corpului și de unghiul dintre acestea.

Ideea fizică

Același lucru mecanic poate fi efectuat în timpuri diferite

Mărimea lucrului mecanic efectuat de o forță depinde de deplasarea punctului său de aplicație.

Pe măsură ce timpul de acțiune crește, poate crește și deplasarea, deci și lucrul mecanic efectuat.

Pentru a compara acțiunile mecanice ale unor forțe trebuie să se țină seama nu numai de lucrul mecanic, ci și de timpul în care acesta este efectuat.

Definiție

Puterea

Puterea

Puterea este egală cu lucrul mecanic efectuat în unitatea de timp.

\[ \boxed{ P=\frac{L}{t} } \]

În această relație:

\(P\) — puterea;

\(L\) — lucrul mecanic efectuat;

\(t\) — intervalul de timp.

Puterea în timp

Lucrul mecanic nu se efectuează întotdeauna uniform

În general, în intervale egale de timp nu se efectuează neapărat lucruri mecanice egale.

Din acest motiv, pentru caracterizarea acțiunii mecanice la un anumit moment se consideră un interval de timp foarte mic:

\[ \Delta t \]

în care se efectuează lucrul mecanic:

\[ \Delta L. \]
Puterea instantanee

Limita pentru \(\Delta t\to0\)

Puterea instantanee se obține trecând la limita în care intervalul de timp tinde către zero:

\[ \boxed{ P = \lim_{\Delta t\to0} \frac{\Delta L}{\Delta t} } \]

În notație diferențială:

\[ \boxed{ P = \frac{dL}{dt} } \]
Lucrul elementar

Legătura dintre putere, forță și mișcare

Din definiția lucrului mecanic, pe o deplasare foarte mică \(\Delta s\):

\[ \Delta L = F_s\Delta s, \]

unde \(F_s\) reprezintă componenta forței pe direcția mișcării.

Introducând această relație în expresia puterii:

\[ P = \lim_{\Delta t\to0} F_s \frac{\Delta s}{\Delta t}. \]
Viteza instantanee

Limita raportului \(\Delta s/\Delta t\)

Pentru:

\[ \Delta t\to0, \]

raportul:

\[ \frac{\Delta s}{\Delta t} \]

tinde către viteza instantanee:

\[ v = \lim_{\Delta t\to0} \frac{\Delta s}{\Delta t}. \]

Se obține astfel:

\[ \boxed{ P=F_s\,v } \]
Componenta tangențială

\(F_s=F\cos\alpha\)

Dacă \(\alpha\) este unghiul dintre forță și direcția vitezei:

\[ F_s = F\cos\alpha. \]

Prin urmare:

\[ \boxed{ P = Fv\cos\alpha } \]

Aceeași relație poate fi scrisă folosind produsul scalar:

\[ \boxed{ P = \vec F\cdot\vec v } \]
Interpretare

Ce determină puterea instantanee

Puterea la un moment dat este determinată de componenta forței în direcția mișcării și de viteza corpului la acel moment.

\[ \boxed{ P=F_s v } \]

O componentă a forței perpendiculară pe direcția vitezei nu contribuie la putere.

Caz particular

Forța și viteza au același sens

Dacă:

\[ \alpha=0, \]

atunci:

\[ \cos\alpha=1. \]

Relația puterii devine:

\[ \boxed{ P=Fv } \]
Caz particular

Forța perpendiculară pe viteză

Dacă:

\[ \alpha=\frac{\pi}{2}, \]

atunci componenta forței pe direcția mișcării este nulă:

\[ F_s=0. \]

Rezultă:

\[ \boxed{ P=0 } \]
Unitate de măsură

Watt

Unitatea de putere în Sistemul Internațional este wattul, cu simbolul:

\[ \mathrm W \]
Watt

Un watt corespunde unei puteri pentru care se efectuează lucrul mecanic de un joule într-o secundă.

\[ \boxed{ 1\,\mathrm W = 1\,\mathrm{\frac{J}{s}} } \]
Relația unităților

Wattul în unități mecanice

Deoarece:

\[ 1\,\mathrm J = 1\,\mathrm{N\,m}, \]

rezultă:

\[ \boxed{ 1\,\mathrm W = 1\,\mathrm{ \frac{N\,m}{s} } } \]
Multiplu

Kilowatt

În practică se utilizează frecvent kilowattul.

\[ \boxed{ 1\,\mathrm{kW} = 10^3\,\mathrm W } \]
Energie

Kilowatt-oră

Compendiul prezintă și kilowatt-ora.

Aceasta reprezintă energia corespunzătoare unei puteri constante de \(1\,\mathrm{kW}\) dezvoltate timp de o oră.

\[ 1\,\mathrm{kWh} = 1\,\mathrm{kW} \cdot 1\,\mathrm h \]

Deoarece:

\[ 1\,\mathrm{kW} = 10^3\,\mathrm W \]

și:

\[ 1\,\mathrm h = 3600\,\mathrm s, \]

rezultă:

\[ \boxed{ 1\,\mathrm{kWh} = 3{,}6 \cdot 10^6\,\mathrm J } \]
Observație: kilowatt-ora este o unitate de energie, nu o unitate de putere.
Unitate istorică

Sistemul CGS

În sistemul CGS, Compendiul exprimă puterea prin:

\[ \boxed{ 1\,\mathrm{ \frac{erg}{s} } } \]

Această unitate nu primește o denumire specială.

Sistemul tehnic

Kilogram-forță-metru pe secundă

În sistemul tehnic, unitatea de putere este exprimată prin:

\[ 1\,\mathrm{ \frac{kgf\,m}{s} } \]

Compendiul indică relația:

\[ \boxed{ 1\,\mathrm{ \frac{kgf\,m}{s} } = 9{,}8\,\mathrm W } \]
Unitate tehnică

Calul-putere

Compendiul prezintă și calul-putere, simbolizat:

\[ \mathrm{CP} \]

Relația indicată este:

\[ \boxed{ 1\,\mathrm{CP} = 75\,\mathrm{ \frac{kgf\,m}{s} } \simeq 736\,\mathrm W } \]
Legătura logică

Lucru mecanic → timp → putere

Lucru mecanic

\[ L = \vec F\cdot\vec s \]

Puterea pentru un interval

\[ \boxed{ P = \frac{L}{t} } \]

Puterea instantanee

\[ \boxed{ P = \frac{dL}{dt} } \]

Legătura cu viteza

\[ \boxed{ P = F_s v = Fv\cos\alpha = \vec F\cdot\vec v } \]

Unitatea SI

\[ \boxed{ 1\,\mathrm W = 1\,\mathrm{J/s} } \]
Sinteză

De reținut din §4.2

Definiția puterii

\[ \boxed{ P = \frac{L}{t} } \]

Puterea instantanee

\[ \boxed{ P = \frac{dL}{dt} } \]

Puterea mecanică instantanee

\[ \boxed{ P = \vec F\cdot\vec v } \]
\[ \boxed{ P = Fv\cos\alpha } \]

Forță paralelă cu viteza

\[ \boxed{ P=Fv } \]

Unitatea SI

\[ \boxed{ 1\,\mathrm W = 1\,\mathrm{\frac Js} } \]

Kilowatt

\[ \boxed{ 1\,\mathrm{kW} = 10^3\,\mathrm W } \]

Kilowatt-oră

\[ \boxed{ 1\,\mathrm{kWh} = 3{,}6 \cdot 10^6\,\mathrm J } \]

Cal-putere

\[ \boxed{ 1\,\mathrm{CP} \simeq 736\,\mathrm W } \]
Titularizare

Precizări pentru examen

Această secțiune este separată de conținutul §4.2 al Compendiului. Ea se raportează la programa oficială pentru Titularizare Fizică 2026.

Statut în programa 2026

Puterea mecanică nu apare ca temă numerotată distinct în secțiunea de mecanică a programei 2026.

Ea este însă strâns legată de lucrul mecanic și de teorema energiei cinetice, necesare pentru punctul 5:

Teoremele mecanicii clasice — energie cinetică, impuls, moment cinetic — și legile de conservare.

Relațiile care trebuie stăpânite: \[ \boxed{ P_{\mathrm{med}} = \frac{\Delta L}{\Delta t} } \] și: \[ \boxed{ P = \frac{dL}{dt} = \vec F\cdot\vec v = Fv\cos\alpha } \]
Nu confunda puterea cu energia: \[ [P]_{\mathrm{SI}} = \mathrm W \] în timp ce: \[ [L]_{\mathrm{SI}} = [E]_{\mathrm{SI}} = \mathrm J. \] În particular: \[ \mathrm{kW} \] este unitate de putere, iar: \[ \mathrm{kWh} \] este unitate de energie.
Verificare dimensională: \[ [P] = \frac{[L]}{[t]} = \frac{\mathrm J}{\mathrm s} = \mathrm W \] și: \[ [Fv] = \mathrm N \cdot \frac{\mathrm m}{\mathrm s} = \frac{\mathrm{N\,m}}{\mathrm s} = \mathrm W. \]
Condiție importantă: relația: \[ P=Fv \] nu este formula generală. Ea este valabilă când forța și viteza sunt coliniare și au același sens. În general: \[ \boxed{ P = Fv\cos\alpha } \]
Legătura cu lecția următoare: §4.3 va arăta că lucrul mecanic al rezultantei forțelor este egal cu variația energiei cinetice: \[ L_{\mathrm{rez}} = \Delta E_c. \] Combinând această teoremă cu definiția puterii se obține o legătură directă între putere și ritmul de variație al energiei cinetice.
Titularizare 2027: nu presupunem modificări față de programa 2026. Programa oficială pentru 2027 trebuie reverificată după publicare.
