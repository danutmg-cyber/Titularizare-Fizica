Aplicația 1

Corp aruncat vertical

Compendiul consideră mai întâi un corp aruncat după verticala locului cu viteza inițială \(v_0\).

Se alege convențional energia potențială gravitațională egală cu zero la suprafața Pământului.

\[ W_p(0)=0 \]

În momentul lansării, energia mecanică totală este deci egală cu energia cinetică inițială.

\[ \boxed{ W = \frac12mv_0^2 } \]
Conservarea energiei

Corpul la înălțimea \(h\)

La înălțimea \(h\), corpul are viteza \(v\).

Energia cinetică este:

\[ W_c = \frac12mv^2 \]

iar energia potențială:

\[ W_p=mgh. \]

Conservarea energiei mecanice conduce la:

\[ \boxed{ \frac12mv_0^2 = \frac12mv^2 + mgh } \]

Aceasta este relația (4.37) utilizată de Compendiu.

Consecință

Viteza la înălțimea \(h\)

Simplificând masa și rearanjând:

\[ v_0^2 = v^2+2gh. \]

Rezultă:

\[ \boxed{ v^2 = v_0^2-2gh } \]

Creșterea energiei potențiale este însoțită de scăderea energiei cinetice.

Înălțimea maximă

Punctul în care viteza se anulează

În punctul cel mai înalt:

\[ v=0. \]

Energia cinetică este nulă, iar energia mecanică se găsește integral sub formă de energie potențială.

\[ \frac12mv_0^2 = mgh_{\max} \]

de unde:

\[ \boxed{ h_{\max} = \frac{v_0^2}{2g} } \]

În acel punct:

\[ \boxed{ W_{p,\max} = W = \frac12mv_0^2 } \]
Reprezentare energetică

Graficul \(W_p=mgh\)

Compendiul reprezintă energia potențială ca funcție de înălțime.

\[ W_p(h)=mgh. \]

Graficul este o dreaptă care trece prin origine.

Panta sa este:

\[ \boxed{ \frac{dW_p}{dh} = mg } \]

Energia mecanică totală:

\[ W = \frac12mv_0^2 \]

este constantă și este reprezentată printr-o dreaptă orizontală.

Interpretarea graficului

Energia cinetică este diferența

La orice înălțime accesibilă corpului:

\[ \boxed{ W_c = W-W_p } \]

Deoarece energia cinetică nu poate fi negativă:

\[ W_c\geq0, \]

trebuie să fie îndeplinită condiția:

\[ \boxed{ W_p\leq W } \]

Din:

\[ mgh \leq \frac12mv_0^2 \]

rezultă din nou:

\[ h\leq h_{\max}. \]
Aplicația 2

Pendulul matematic

Compendiul aplică apoi aceeași metodă energetică pendulului matematic în cazul micilor oscilații.

Se notează cu \(O\) poziția de echilibru și cu \(s\) deplasarea față de această poziție.

Pentru micile oscilații, componenta tangențială a greutății are forma:

\[ \boxed{ G_t = -\frac{mg}{l}s } \]
Analogie

Pendulul se comportă ca un oscilator elastic

Relația:

\[ G_t = -\frac{mg}{l}s \]

are aceeași formă cu legea forței elastice:

\[ F=-ks. \]

Se poate identifica:

\[ \boxed{ k = \frac{mg}{l} } \]
Energia potențială

Energia pendulului pentru micile oscilații

Energia potențială asociată forței de revenire este:

\[ W_p = \frac12ks^2. \]

Folosind:

\[ k=\frac{mg}{l}, \]

Compendiul obține relația (4.38):

\[ \boxed{ W_p(s) = \frac{mg}{2l}s^2 } \]

Energia potențială este aleasă zero în poziția de echilibru:

\[ W_p(0)=0. \]
Conservarea energiei

Pendulul trece prin poziția de echilibru

Se notează cu \(v_0\) viteza pendulului când acesta trece prin poziția de echilibru \(O\).

În \(O\):

\[ s=0, \qquad W_p=0. \]

Energia mecanică totală este:

\[ \boxed{ W = \frac12mv_0^2 } \]
Relația (4.39)

Energia la distanța \(s\)

Dacă la distanța \(s\) față de poziția de echilibru pendulul are viteza \(v\):

\[ \boxed{ \frac12mv_0^2 = \frac12mv^2 + \frac{mg}{2l}s^2 } \]

Energia cinetică scade pe măsură ce pendulul se îndepărtează de poziția de echilibru.

În același timp, energia potențială crește.

Depărtarea maximă

Punctele de întoarcere

La depărtarea maximă față de poziția de echilibru:

\[ v=0. \]

Din conservarea energiei:

\[ \frac12mv_0^2 = \frac{mg}{2l}s_{\max}^2. \]

Rezultă:

\[ \boxed{ s_{\max}^2 = \frac{v_0^2l}{g} } \]

sau:

\[ \boxed{ s_{\max} = v_0 \sqrt{ \frac{l}{g} } } \]
Reprezentare energetică

Parabola energiei potențiale

Deoarece:

\[ W_p(s) = \frac{mg}{2l}s^2, \]

graficul energiei potențiale în funcție de \(s\) este o parabolă cu vârful în origine.

Energia mecanică totală este reprezentată printr-o dreaptă orizontală:

\[ W = \frac12mv_0^2. \]

Intersecțiile dintre această dreaptă și parabola \(W_p(s)\) determină cele două poziții extreme.

\[ \boxed{ s=-s_{\max} \qquad\text{și}\qquad s=+s_{\max} } \]
Aplicația 3

Mișcarea într-un câmp gravitațional

Compendiul trece apoi la mișcarea unui corp de masă \(m\) în câmpul gravitațional creat de o masă \(M\).

Se utilizează energia potențială gravitațională stabilită în §4.4, cu originea aleasă la infinit.

\[ \boxed{ W_p(r) = -K \frac{Mm}{r} } \]

Pentru orice distanță finită:

\[ W_p<0. \]
Grafic energetic

Energia potențială gravitațională

Graficul:

\[ W_p(r) = -K\frac{Mm}{r} \]

este o ramură de hiperbolă situată sub axa corespunzătoare energiei nule.

Pentru:

\[ r\rightarrow\infty, \]

energia potențială tinde către:

\[ W_p\rightarrow0. \]
Energia mecanică

Energia totală în câmp central

Energia mecanică totală este:

\[ \boxed{ W = W_c+W_p = \frac12mv^2 - K\frac{Mm}{r} } \]

Compendiul analizează mișcarea în funcție de semnul acestei energii totale.

Cazul \(W<0\)

Mișcare într-o regiune finită

Dacă energia cinetică este mai mică decât modulul energiei potențiale:

\[ W_c<|W_p|, \]

atunci energia mecanică totală este negativă:

\[ \boxed{ W<0 } \]

În construcția energetică prezentată de Compendiu, corpul nu poate ajunge la distanțe arbitrar de mari față de centrul de forțe.

Mișcarea este limitată la o regiune finită a spațiului.

Orbită legată

Traiectoria eliptică

Compendiul precizează că pentru energia mecanică totală negativă, traiectoria corespunzătoare mișcării gravitaționale este o elipsă.

\[ \boxed{ W<0 \quad\Longrightarrow\quad \text{orbită legată} } \]

Planetele constituie exemplul menționat în text.

Energia lor mecanică totală este negativă, iar mișcarea în jurul Soarelui are loc pe orbite eliptice.

Cazul \(W=0\)

Traiectoria parabolică

Dacă energia cinetică este egală cu modulul energiei potențiale:

\[ W_c=|W_p|, \]

energia totală este nulă:

\[ \boxed{ W=0 } \]

Corpul poate ajunge până la distanțe oricât de mari.

Compendiul precizează că traiectoria corespunzătoare este o parabolă.

\[ \boxed{ W=0 \quad\Longrightarrow\quad \text{parabolă} } \]
Cazul \(W>0\)

Traiectoria hiperbolică

Dacă:

\[ W_c>|W_p|, \]

energia mecanică totală este pozitivă:

\[ \boxed{ W>0 } \]

Corpul nu rămâne legat de centrul de forțe.

Traiectoria indicată de Compendiu este o hiperbolă.

\[ \boxed{ W>0 \quad\Longrightarrow\quad \text{hiperbolă} } \]
Clasificare energetică

Semnul energiei mecanice

Energie negativă

\[ W<0 \]

mișcare legată; traiectorie eliptică.

Energie nulă

\[ W=0 \]

cazul limită al desprinderii; traiectorie parabolică.

Energie pozitivă

\[ W>0 \]

mișcare nelegată; traiectorie hiperbolică.

Satelit artificial

Orbită circulară în apropierea Pământului

Compendiul reia cazul unui satelit artificial aflat pe o orbită circulară în imediata apropiere a suprafeței Pământului.

Raza orbitei este aproximativ:

\[ r\simeq R, \]

unde \(R\) este raza Pământului.

Prima viteză cosmică

Condiția orbitei circulare

Pentru orbita circulară, accelerația centripetă este produsă de gravitație.

\[ \frac{v_1^2}{R} = g_0. \]

Rezultă:

\[ \boxed{ v_1 = \sqrt{g_0R} } \]

Compendiul indică valoarea:

\[ \boxed{ v_1 \simeq 7{,}9\,\mathrm{km/s} } \]

Aceasta este numită prima viteză cosmică.

Energia satelitului

Energia totală pe orbita circulară

Energia mecanică totală este:

\[ W = \frac12mv_1^2 - K\frac{M_Pm}{R}, \]

unde \(M_P\) este masa Pământului.

Din:

\[ g_0 = K \frac{M_P}{R^2}, \]

rezultă:

\[ K\frac{M_Pm}{R} = mg_0R. \]

Deoarece:

\[ v_1^2=g_0R, \]

se obține:

\[ \boxed{ W = -\frac12mg_0R <0 } \]
Interpretare

Orbita circulară este legată

Energia mecanică totală a satelitului circular este negativă.

Acest rezultat este în acord cu faptul că traiectoria este finită.

Compendiul amintește că cercul reprezintă un caz particular de elipsă.

Creșterea vitezei

De la cerc la elipsă

Compendiul consideră apoi lansarea cu o viteză mai mare decât prima viteză cosmică.

\[ v_0>v_1. \]

Cât timp energia mecanică totală rămâne negativă, traiectoria rămâne legată și este eliptică.

Pe măsură ce viteza inițială crește, elipsa devine mai alungită.

Condiția energetică

Limita superioară a vitezei

Pentru ca energia totală la suprafața Pământului să rămână negativă:

\[ \frac12mv_0^2 < K\frac{M_Pm}{R}. \]

Folosind:

\[ K\frac{M_P}{R} = g_0R, \]

rezultă:

\[ \boxed{ v_0 < \sqrt{2g_0R} } \]
Domeniul discutat de Compendiu

Orbite eliptice

Pentru lansarea analizată în text:

\[ \boxed{ \sqrt{g_0R} \leq v_0 < \sqrt{2g_0R} } \]

energia totală este negativă, iar traiectoria este eliptică.

Pentru:

\[ v_0=\sqrt{g_0R}, \]

elipsa se reduce la cercul de rază \(R\).

A doua viteză cosmică

Condiția \(W=0\)

Cazul limită dintre o mișcare legată și una nelegată corespunde energiei mecanice totale nule.

\[ \boxed{ W=0 } \]

La suprafața Pământului:

\[ \frac12mv_2^2 - K\frac{M_Pm}{R} = 0. \]

De aici:

\[ \frac12mv_2^2 = K\frac{M_Pm}{R}. \]
Deducere

Formula vitezei de desprindere

După simplificarea masei:

\[ v_2^2 = \frac{2KM_P}{R}. \]

Deoarece:

\[ g_0 = K \frac{M_P}{R^2}, \]

rezultă:

\[ \boxed{ v_2 = \sqrt{2g_0R} } \]

Comparând cu prima viteză cosmică:

\[ v_1=\sqrt{g_0R}, \]

obținem:

\[ \boxed{ v_2 = \sqrt2\,v_1 } \]
Valoare numerică

Pentru Pământ

Utilizând în Compendiu:

\[ g_0 = 9{,}81\,\mathrm{m/s^2} \]

și:

\[ R = 6400\,\mathrm{km}, \]

se obține aproximativ:

\[ \boxed{ v_2 \simeq 11{,}2\,\mathrm{km/s} } \]
A doua viteză cosmică

Viteza corespunzătoare cazului limită \(W=0\) pentru desprinderea corpului din câmpul gravitațional terestru în modelul analizat.

Traiectoria limită

La a doua viteză cosmică

Pentru:

\[ v_0=v_2, \]

energia mecanică totală este nulă:

\[ W=0. \]

În modelul gravitațional analizat de Compendiu, traiectoria este parabolică.

\[ \boxed{ v_0=v_2 \quad\Longrightarrow\quad \text{parabolă} } \]
Peste viteza de desprindere

Energia mecanică pozitivă

Pentru o viteză inițială mai mare decât valoarea limită:

\[ v_0>v_2, \]

energia mecanică totală devine pozitivă:

\[ W>0. \]

În problema idealizată a atracției gravitaționale produse numai de Pământ, corpul nu mai rămâne gravitațional legat de acesta.

\[ \boxed{ v_0>v_2 \quad\Longrightarrow\quad W>0 } \]
Observația Compendiului

Influența Soarelui

Compendiul precizează că, în realitate, un corp care se îndepărtează de Pământ nu se află numai sub acțiunea gravitației terestre.

Atracția Soarelui trebuie de asemenea luată în considerare.

Textul descrie corpul care părăsește influența terestră ca putând deveni un satelit artificial al Soarelui, adică o planetă artificială.

Exemplu final

Nava cosmică la revenirea spre Pământ

Finalul §4.6 discută calitativ revenirea unei nave cosmice dinspre Lună către Pământ.

Compendiul subliniază rolul rezistenței aerului în reducerea energiei mecanice și a vitezei navei în apropierea Pământului.

Exemplul leagă astfel analiza ideală bazată pe conservarea energiei mecanice de situația în care apar forțe disipative.

Legătura logică

Aceeași lege, trei aplicații

Aruncare verticală

\[ \boxed{ \frac12mv_0^2 = \frac12mv^2 + mgh } \]
\[ \boxed{ h_{\max} = \frac{v_0^2}{2g} } \]

Pendul matematic

\[ W_p = \frac{mg}{2l}s^2 \]
\[ \boxed{ \frac12mv_0^2 = \frac12mv^2 + \frac{mg}{2l}s^2 } \]
\[ \boxed{ s_{\max} = v_0 \sqrt{ \frac{l}{g} } } \]

Câmp gravitațional central

\[ \boxed{ W = \frac12mv^2 - K\frac{Mm}{r} } \]

Orbită legată

\[ W<0 \]

Limită de desprindere

\[ W=0 \]

Mișcare nelegată

\[ W>0 \]

Prima viteză cosmică

\[ \boxed{ v_1 = \sqrt{g_0R} \simeq 7{,}9\,\mathrm{km/s} } \]

A doua viteză cosmică

\[ \boxed{ v_2 = \sqrt{2g_0R} = \sqrt2\,v_1 \simeq 11{,}2\,\mathrm{km/s} } \]
Sinteză

De reținut din §4.6

Legea utilizată

\[ \boxed{ W = W_c+W_p = \text{constant} } \]

Aruncare verticală

\[ \boxed{ \frac12mv_0^2 = \frac12mv^2+mgh } \]
\[ \boxed{ h_{\max} = \frac{v_0^2}{2g} } \]

Pendul matematic, mici oscilații

\[ \boxed{ W_p = \frac{mg}{2l}s^2 } \]
\[ \boxed{ s_{\max} = v_0 \sqrt{\frac{l}{g}} } \]

Câmp gravitațional

\[ \boxed{ W_p = -K\frac{Mm}{r} } \]
\[ \boxed{ W = \frac12mv^2 - K\frac{Mm}{r} } \]

Semnul energiei

\[ W<0 \Rightarrow \text{mișcare legată} \]
\[ W=0 \Rightarrow \text{parabolă} \]
\[ W>0 \Rightarrow \text{hiperbolă} \]

\[ \boxed{ v_1=\sqrt{g_0R} } \]
\[ \boxed{ v_2 = \sqrt{2g_0R} = \sqrt2\,v_1 } \]

Legătura directă cu programa 2026

§4.6 reunește aplicații care se leagă direct de două puncte ale tematicii științifice.

5. Teoremele mecanicii clasice — energie cinetică, impuls, moment cinetic. Legi de conservare.

8. Mișcarea în câmp central în cazul forțelor atractive. Legea atracției universale. Legile lui Kepler.

Notația actuală uzuală: Compendiul folosește: \[ W_c,\quad W_p,\quad W. \] În rezolvările actuale sunt frecvente notațiile: \[ E_c,\quad E_p,\quad E_m. \] Astfel: \[ \boxed{ E_m = E_c+E_p } \]
În câmpul gravitațional central: folosind notația actuală uzuală \(G\) pentru constanta gravitațională: \[ \boxed{ E_p(r) = -G\frac{Mm}{r} } \] și: \[ \boxed{ E = \frac12mv^2 - G\frac{Mm}{r} } \] pentru convenția: \[ E_p(\infty)=0. \]
Clasificarea energetică importantă: \[ \boxed{ E<0 \Rightarrow \text{orbită legată} } \] \[ \boxed{ E=0 \Rightarrow \text{caz parabolic} } \] \[ \boxed{ E>0 \Rightarrow \text{caz hiperbolic} } \] pentru problema Kepler idealizată a unei forțe atractive de tip \(1/r^2\).
Precizare importantă: energia totală este esențială pentru stabilirea caracterului legat sau nelegat al mișcării, dar pentru caracterizarea completă a orbitei trebuie ținut seama și de momentul cinetic. Programa 2026 cere explicit și momentul cinetic la punctul 5.
Prima viteză cosmică: pentru un satelit pe orbită circulară de rază \(R\): \[ G\frac{Mm}{R^2} = m\frac{v_1^2}{R} \] de unde: \[ \boxed{ v_1 = \sqrt{ \frac{GM}{R} } } \] iar la suprafața Pământului: \[ g_0 = \frac{GM}{R^2}, \] deci: \[ \boxed{ v_1 = \sqrt{g_0R} } \]
Energia unui satelit pe orbită circulară: din: \[ v^2=\frac{GM}{r} \] rezultă: \[ E_c = \frac12 \frac{GMm}{r}, \] \[ E_p = -\frac{GMm}{r}, \] și deci: \[ \boxed{ E = -\frac{GMm}{2r} } \] Energia totală este negativă.
A doua viteză cosmică: pentru desprinderea din câmpul gravitațional, în modelul idealizat, se impune condiția limită: \[ E=0. \] La suprafața Pământului: \[ \frac12mv_2^2 - \frac{GMm}{R} = 0, \] deci: \[ \boxed{ v_2 = \sqrt{ \frac{2GM}{R} } = \sqrt{2g_0R} } \] și: \[ \boxed{ v_2=\sqrt2\,v_1 } \]
Condițiile formulelor pentru vitezele cosmice: relațiile de mai sus sunt pentru modelul gravitațional idealizat. Pentru valorile de la suprafața Pământului se neglijează, în această aproximație:

rezistența atmosferei;
rotația Pământului;
acțiunea altor corpuri cerești;
variațiile locale ale câmpului gravitațional.
Atenție la \(mgh\): relația: \[ E_p=mgh \] este utilizată când câmpul gravitațional poate fi considerat aproximativ uniform. Pentru distanțe comparabile cu raza Pământului se folosește: \[ \boxed{ E_p = -G\frac{Mm}{r} } \]
Atenție la pendul: relația: \[ W_p = \frac{mg}{2l}s^2 \] rezultă aici din aproximația micilor oscilații. Ea provine din: \[ G_t \simeq -\frac{mg}{l}s. \] Nu trebuie utilizată fără condiția de unghi mic atunci când se cere o demonstrație riguroasă.
Exemplul final din Compendiul din 1972: discuția despre revenirea unei nave cosmice dinspre Lună trebuie privită în contextul prezentării calitative a sursei. Pentru o problemă actuală de mecanică orbitală trebuie utilizate condițiile și datele precizate explicit în enunț, fără generalizarea automată a acelui exemplu.
Schema de rezolvare recomandată:

1. alegi sistemul;
2. precizezi starea inițială și starea finală;
3. verifici dacă energia mecanică se conservă;
4. alegi originea energiei potențiale;
5. scrii: \[ E_{c,i}+E_{p,i} = E_{c,f}+E_{p,f}; \]
6. calculezi mai întâi simbolic;
7. introduci numeric valorile în unități SI;
8. verifici semnul energiei și sensul fizic al rezultatului.
