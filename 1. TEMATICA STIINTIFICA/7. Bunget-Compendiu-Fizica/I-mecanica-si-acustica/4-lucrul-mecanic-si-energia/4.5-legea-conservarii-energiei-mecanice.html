4.5 Legea conservării energiei mecanice

Energia cinetică și energia potențială se pot transforma reciproc. Atunci când asupra sistemului acționează numai forțe conservative, suma lor rămâne constantă.

Ion Bunget Compendiu de Fizică §4.5

Punct de plecare

Mișcare sub acțiunea forțelor conservative

Se consideră un punct material de masă \(m\), care se deplasează din punctul \(A\) în punctul \(B\).

În punctul \(A\), corpul are viteza \(v_A\), iar în punctul \(B\) are viteza \(v_B\).

Asupra lui acționează numai forțe conservative.

poziția inițială: \(A\);

viteza inițială: \(v_A\);

poziția finală: \(B\);

viteza finală: \(v_B\).

Energia cinetică

Lucrul mecanic și variația energiei cinetice

Din §4.3, lucrul mecanic total efectuat asupra punctului material este egal cu variația energiei sale cinetice.

\[ \boxed{ L_{A\to B} = W_c(B)-W_c(A) } \]

Energia cinetică în cele două puncte este:

\[ W_c(A) = \frac12mv_A^2 \]
\[ W_c(B) = \frac12mv_B^2 \]
Energia potențială

Lucrul unei forțe conservative

Din definiția energiei potențiale stabilită în §4.4, pentru o forță conservativă:

\[ \boxed{ L_{A\to B} = W_p(A)-W_p(B) } \]

Echivalent:

\[ L_{A\to B} = -\Delta W_p. \]
Combinarea relațiilor

Energia cinetică și energia potențială

Pentru aceeași deplasare de la \(A\) la \(B\):

\[ L_{A\to B} = W_c(B)-W_c(A) \]

și:

\[ L_{A\to B} = W_p(A)-W_p(B). \]

Egalând cele două expresii:

\[ \boxed{ W_c(B)-W_c(A) = W_p(A)-W_p(B) } \]
Rearanjare

Suma energiilor

Trecând termenii corespunzători în aceiași membri ai egalității:

\[ \boxed{ W_c(B)+W_p(B) = W_c(A)+W_p(A) } \]

Suma dintre energia cinetică și energia potențială are aceeași valoare în punctele \(A\) și \(B\).

Definiție

Energia mecanică totală

Energia mecanică totală

Suma dintre energia cinetică și energia potențială a punctului material.

\[ \boxed{ W = W_c+W_p } \]

În punctul \(A\):

\[ W(A) = W_c(A)+W_p(A) \]

iar în punctul \(B\):

\[ W(B) = W_c(B)+W_p(B). \]
Conservare

Energia mecanică rămâne constantă

Din relațiile precedente rezultă:

\[ \boxed{ W(B)=W(A) } \]

Deoarece punctele \(A\) și \(B\) pot fi două puncte oarecare ale mișcării, energia mecanică totală rămâne constantă în timpul mișcării.

\[ \boxed{ W = W_c+W_p = \text{constant} } \]
Legea

Legea conservării energiei mecanice

Legea conservării energiei mecanice

Energia mecanică totală a unui punct material asupra căruia acționează numai forțe conservative rămâne constantă în timpul mișcării.

\[ \boxed{ W_c+W_p = \text{constant} } \]

Între două poziții:

\[ \boxed{ W_{cA}+W_{pA} = W_{cB}+W_{pB} } \]
Generalitate

Punct material, sistem și corp material

Compendiul precizează că legea nu este limitată la un singur punct material.

Ea este aplicabilă și:

  • sistemelor de puncte materiale;
  • corpurilor materiale;

atunci când asupra sistemului considerat acționează numai forțe conservative.

Transformarea energiei

Energie cinetică ↔ energie potențială

Conservarea energiei mecanice nu înseamnă că energia cinetică și energia potențială rămân fiecare constante.

Ele se pot modifica în timpul mișcării.

O scădere a energiei cinetice este însoțită de o creștere corespunzătoare a energiei potențiale.

Invers, o scădere a energiei potențiale este însoțită de creșterea energiei cinetice.

\[ \boxed{ \Delta W_c = -\Delta W_p } \]
Consecință

Variații egale și opuse

Deoarece:

\[ W=W_c+W_p \]

și:

\[ W=\text{constant}, \]

rezultă:

\[ \Delta W=0. \]

Prin urmare:

\[ \boxed{ \Delta W_c+\Delta W_p=0 } \]

sau:

\[ \boxed{ \Delta W_c=-\Delta W_p } \]
Valori extreme

Repartizarea energiei mecanice

În prezentarea din Compendiu, energia mecanică totală este repartizată între componenta cinetică și cea potențială.

Într-un punct în care energia cinetică devine nulă:

\[ W_c=0, \]

întreaga energie mecanică se găsește sub forma energiei potențiale:

\[ \boxed{ W_p=W } \]

Analog, dacă pentru alegerea originii utilizate energia potențială este nulă:

\[ W_p=0, \]

atunci:

\[ \boxed{ W_c=W } \]
Forțe neconservative

Ce se întâmplă în prezența frecării

Compendiul examinează apoi situația în care, pe lângă forțele conservative, asupra corpului acționează și forțe neconservative.

Exemplul considerat este forța de frecare.

Forța de frecare

Nu este o forță conservativă, deoarece lucrul său mecanic depinde de drumul parcurs și nu este nul pe un drum închis.

Lucrul mecanic total

Separarea contribuțiilor

Lucrul mecanic total este suma dintre lucrul forțelor conservative și lucrul forțelor de frecare.

\[ \boxed{ L_{A\to B} = L_{\mathrm{cons}} + L_f } \]

Conform teoremei energiei cinetice:

\[ L_{A\to B} = W_c(B)-W_c(A). \]
Forțele conservative

Legătura cu energia potențială

Numai lucrul forțelor conservative poate fi scris prin diferența energiilor potențiale:

\[ \boxed{ L_{\mathrm{cons}} = W_p(A)-W_p(B) } \]

Introducând această relație în teorema energiei cinetice:

\[ W_c(B)-W_c(A) = W_p(A)-W_p(B) + L_f. \]
Rezultatul

Variația energiei mecanice

Rearanjând termenii:

\[ W_c(B)+W_p(B) - W_c(A)-W_p(A) = L_f. \]

Deoarece:

\[ W=W_c+W_p, \]

se obține:

\[ \boxed{ W(B)-W(A) = L_f } \]

Echivalent:

\[ \boxed{ \Delta W=L_f } \]
Frecare

Energia mecanică scade

Forța de frecare se opune mișcării, iar lucrul său mecanic este negativ:

\[ L_f<0. \]

Din:

\[ W(B)-W(A)=L_f \]

rezultă:

\[ \boxed{ W(B)

În prezența frecării, energia mecanică totală nu se conservă.

Disiparea energiei

Energia mecanică nu dispare

Scăderea energiei mecanice în prezența frecării nu înseamnă dispariția energiei.

Compendiul observă că suprafețele între care apare frecarea se încălzesc.

Energia mecanică pierdută de mișcarea macroscopică se transformă în energia mișcării interne a particulelor corpului.

Această transformare se manifestă sub formă de încălzire.

Disiparea energiei mecanice

Transformarea unei părți a energiei mecanice în energie termică datorită forțelor de frecare.

Energie termică

Conservarea energiei totale

Compendiul arată că energia mecanică transformată prin frecare nu este pierdută.

Dacă se ia în considerare și energia termică, energia totală se conservă.

\[ \boxed{ E_{\mathrm{total}} = W_{\mathrm{mec}} + E_{\mathrm{term}} } \]

În procesul cu frecare, scăderea energiei mecanice este însoțită de creșterea energiei termice.

Limita tratării mecanice

Formularea folosită în mecanică

Compendiul precizează că analiza detaliată a creșterii temperaturii și a producerii căldurii depășește cadrul capitolului de mecanică.

În mecanică se spune simplu că, datorită frecării, o parte din energia mecanică este disipată sub formă de căldură.

Cantitatea de energie mecanică disipată este legată de lucrul mecanic al forței de frecare.

Comparație

Cu și fără forțe neconservative

Numai forțe conservative

\[ \boxed{ W_c+W_p = \text{constant} } \]
\[ \boxed{ W(B)=W(A) } \]

În prezența frecării

\[ \boxed{ W(B)-W(A) = L_f } \]

Deoarece:

\[ L_f<0, \]

energia mecanică scade.

Legătura logică

Cum se deduce legea

Teorema energiei cinetice

\[ L = \Delta W_c \]

Forță conservativă

\[ L = -\Delta W_p \]

Egalăm

\[ \Delta W_c = -\Delta W_p \]

Rezultă

\[ \Delta W_c+\Delta W_p=0 \]

Energia mecanică

\[ W=W_c+W_p \]

Conservarea

\[ \boxed{ W = \text{constant} } \]
Sinteză

De reținut din §4.5

Energia cinetică

\[ W_c = \frac12mv^2 \]

Lucrul forțelor conservative

\[ \boxed{ L_{\mathrm{cons}} = -\Delta W_p } \]

Energia mecanică

\[ \boxed{ W=W_c+W_p } \]

Numai forțe conservative

\[ \boxed{ W_A=W_B } \]
\[ \boxed{ W_c+W_p = \text{constant} } \]

Transformarea reciprocă

\[ \boxed{ \Delta W_c = -\Delta W_p } \]

Cu frecare

\[ \boxed{ \Delta W = L_f } \]

iar pentru:

\[ L_f<0, \]

energia mecanică scade.

Energia disipată

Energia mecanică pierdută prin frecare se transformă în energie termică.

Cerință explicită în programa 2026

Punctul 5 al tematicii științifice cere:

Teoremele mecanicii clasice (energie cinetică, impuls, moment cinetic). Legi de conservare.

Notație actuală uzuală: Compendiul folosește: \[ W_c,\qquad W_p,\qquad W. \] În rezolvările actuale se întâlnesc frecvent: \[ E_c,\qquad E_p,\qquad E_m. \] Astfel: \[ \boxed{ E_m=E_c+E_p } \]
Condiția de conservare: dacă asupra sistemului efectuează lucru numai forțe conservative: \[ \boxed{ E_{m,i}=E_{m,f} } \] adică: \[ \boxed{ E_{c,i}+E_{p,i} = E_{c,f}+E_{p,f} } \]
Nu aplica automat conservarea energiei mecanice. Înainte de a scrie: \[ E_{m,i}=E_{m,f}, \] trebuie verificat dacă există forțe neconservative care efectuează lucru mecanic, de exemplu frecarea.
Forma generală când există forțe neconservative: \[ \boxed{ \Delta E_m = L_{\mathrm{necons}} } \] sau: \[ \boxed{ E_{m,f}-E_{m,i} = L_{\mathrm{necons}} } \] Pentru frecare: \[ L_f<0 \quad\Longrightarrow\quad E_{m,f}
Două legi diferite: conservarea energiei mecanice \[ E_m=\text{constant} \] este valabilă în condițiile precizate mai sus. Conservarea energiei totale este un principiu mai general: energia mecanică se poate transforma în alte forme de energie fără ca energia totală să dispară.
Pentru o problemă de Titularizare:

1. alegi sistemul fizic;
2. stabilești stările inițială și finală;
3. identifici forțele conservative și neconservative;
4. alegi originea energiei potențiale;
5. scrii expresiile energiilor;
6. alegi relația: \[ E_{m,i}=E_{m,f} \] sau: \[ E_{m,f}-E_{m,i} = L_{\mathrm{necons}}; \]
7. verifici unitățile și sensul fizic al rezultatului.
Relații care trebuie recunoscute imediat: \[ E_c=\frac12mv^2 \] \[ E_{p,g}=mgh \] pentru câmp gravitațional aproximativ uniform, \[ E_{p,g} = -G\frac{Mm}{r} \] pentru câmp gravitațional radial cu \(E_p(\infty)=0\), și: \[ E_{p,e} = \frac12kx^2. \]
Greșeală frecventă: energia mecanică nu înseamnă numai energie cinetică. \[ \boxed{ E_m=E_c+E_p } \] iar conservarea ei permite transformarea reciprocă dintre \(E_c\) și \(E_p\).
Altă greșeală frecventă: dacă există frecare nu se „șterge” pur și simplu energia. Lucrul negativ al frecării determină scăderea energiei mecanice: \[ \Delta E_m=L_f<0, \] iar energia corespunzătoare este transferată către forme interne de energie.
