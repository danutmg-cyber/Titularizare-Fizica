4. Lucrul mecanic și energia
4.1 Definirea lucrului mecanic
Pagini: 121–126
Introducere

Acțiunea unei forțe

Se consideră un corp \(C\) asupra căruia acționează, într-un interval de timp \(\Delta t\), o forță constantă \(\vec F\).

Sub acțiunea acestei forțe, corpul se deplasează din punctul \(A\) în punctul \(B\).

Deplasarea punctului de aplicație al forței este descrisă prin vectorul:

\[ \vec s \]

Direcția deplasării nu trebuie să coincidă cu direcția forței.

Compendiul folosește exemplul unui vagonet care se deplasează pe șine și este tras cu un lanț într-o direcție oblică față de șine.

Mărime fizică

Necesitatea definirii lucrului mecanic

Aceeași forță poate produce efecte mecanice diferite, în funcție de deplasarea punctului său de aplicație și de orientarea forței față de deplasare.

Pentru caracterizarea acestei acțiuni mecanice se introduce mărimea fizică numită lucru mecanic.

Definiție

Lucrul mecanic al unei forțe constante

Se notează cu \(F_s\) componenta forței pe direcția deplasării.

\[ F_s=F\cos\alpha \]

unde \(\alpha\) este unghiul dintre vectorii \(\vec F\) și \(\vec s\).

Lucrul mecanic

Lucrul mecanic efectuat de o forță constantă este egal cu produsul dintre deplasarea punctului de aplicație și componenta forței pe direcția deplasării.

\[ \boxed{ L=F_s\,s } \]

Folosind:

\[ F_s=F\cos\alpha, \]

rezultă:

\[ \boxed{ L = Fs\cos\alpha = \vec F\cdot\vec s } \]
Produs scalar

Caracterul scalar al lucrului mecanic

Relația:

\[ L=\vec F\cdot\vec s \]

exprimă lucrul mecanic prin produsul scalar dintre forță și deplasare.

Prin urmare, lucrul mecanic este o mărime scalară.

Caz particular

Forța are sensul deplasării

Dacă:

\[ \alpha=0, \]

atunci:

\[ \cos\alpha=1. \]

Lucrul mecanic are valoarea:

\[ \boxed{ L=Fs } \]

Pentru valori date ale lui \(F\) și \(s\), aceasta este valoarea maximă pozitivă a lucrului mecanic.

Caz particular

Forța este perpendiculară pe deplasare

Pentru:

\[ \alpha=\frac{\pi}{2}, \]

avem:

\[ \cos\frac{\pi}{2}=0. \]

Prin urmare:

\[ \boxed{ L=0 } \]

O forță perpendiculară pe deplasarea punctului său de aplicație nu efectuează lucru mecanic.

Semnul lucrului mecanic

Forța se opune deplasării

Dacă unghiul dintre forță și deplasare este obtuz:

\[ \frac{\pi}{2} < \alpha \leq \pi, \]

atunci:

\[ \cos\alpha<0. \]

Rezultă:

\[ \boxed{ L<0 } \]

În această situație, componenta forței pe direcția mișcării are sens opus deplasării.

Exemplu

Lucrul mecanic al forței de frecare

Forța de frecare are sens opus mișcării corpului.

Unghiul dintre forța de frecare și deplasare este:

\[ \alpha=\pi. \]

Deoarece:

\[ \cos\pi=-1, \]

lucrul mecanic al forței de frecare este:

\[ \boxed{ L_f=-F_fs } \]
Forță activă

Lucrul mecanic transmis corpului

Se presupune că mișcarea este produsă de o forță \(\vec F\), iar corpul este supus și forței de frecare \(F_f\).

Lucrul mecanic total primit de corp este suma dintre lucrul forței \(\vec F\) și lucrul forței de frecare.

\[ \boxed{ L_{\mathrm{corp}} = Fs\cos\alpha - F_fs } \]

Forța \(\vec F\), care întreține deplasarea corpului, este numită de Compendiu forță activă.

Forțe rezistente

Forțe care se opun mișcării

Forțe rezistente sau pasive

Forțele care se opun deplasării corpului.

Lucrul mecanic al unei asemenea forțe este negativ.

Pentru ca mișcarea să se poată produce, trebuie să existe un lucru mecanic pozitiv care să compenseze efectul forțelor rezistente.

Deplasare coliniară

Forța activă și frecarea

Dacă forța activă are aceeași direcție și același sens cu deplasarea:

\[ \alpha=0, \]

atunci:

\[ \boxed{ L_{\mathrm{corp}} = (F-F_f)s } \]

Pentru deplasarea corpului în sensul forței active este necesar:

\[ \boxed{ F>F_f } \]
Lucru util

Lucru mecanic util și consumat

Compendiul numește lucrul mecanic primit de corp:

Lucru mecanic util

Lucrul mecanic transmis efectiv corpului.

Lucrul mecanic efectuat de forța activă este numit:

Lucru mecanic consumat

Lucrul mecanic furnizat de forța activă.

Randament

Raportul dintre lucrul util și cel consumat

Randamentul

Raportul dintre lucrul mecanic util și lucrul mecanic consumat.

\[ \boxed{ \eta = \frac{ L_{\mathrm{util}} }{ L_{\mathrm{consumat}} } } \]

În situația analizată:

\[ L_{\mathrm{util}} = Fs\cos\alpha-F_fs \]
\[ L_{\mathrm{consumat}} = Fs\cos\alpha \]

astfel încât:

\[ \boxed{ \eta = 1- \frac{ F_f }{ F\cos\alpha } } \]

Pentru \(\alpha=0\):

\[ \boxed{ \eta = 1- \frac{F_f}{F} } \]
Forța de greutate

Corp în cădere

Se consideră un corp de masă \(m\), care cade între două puncte \(A\) și \(B\).

Diferența de nivel este suficient de mică pentru ca forța de greutate să poată fi considerată constantă.

Dacă:

\[ h_{AB} = h_A-h_B, \]

atunci greutatea și deplasarea au același sens.

\[ \boxed{ L_{A\to B}^{(G)} = Gh_{AB} = mg(h_A-h_B) >0 } \]
Plan înclinat

Același rezultat pe alt drum

Corpul poate ajunge la același nivel inferior și deplasându-se fără frecare pe un plan înclinat.

Dacă planul face unghiul \(\beta\) cu orizontala, componenta greutății în direcția deplasării produce lucrul:

\[ L = Gs\sin\beta. \]

Deoarece:

\[ s\sin\beta=h_{AB}, \]

rezultă:

\[ \boxed{ L = Gh_{AB} = mg(h_A-h_B) } \]
Concluzie

Lucrul greutății și forma drumului

Pentru situația analizată, lucrul mecanic efectuat de forța de greutate nu depinde de forma drumului urmat de corp.

El depinde numai de diferența de nivel dintre poziția inițială și poziția finală.

\[ \boxed{ L_{A\to B}^{(G)} = mg(h_A-h_B) } \]
Ridicarea corpului

Lucrul greutății este negativ

Dacă același corp este ridicat de la \(B\) la \(A\), greutatea are sens opus deplasării.

\[ \boxed{ L_{B\to A}^{(G)} = -mgh_{AB} } \]

Forța de greutate se comportă în acest caz ca o forță rezistentă.

Pentru ridicarea corpului trebuie aplicată o forță exterioară care să compenseze efectul greutății.

Caz limită

Lucrul minim pentru ridicare

Dacă forța exterioară este verticală și corpul este ridicat fără variație a energiei cinetice, valoarea minimă a forței este:

\[ F=G. \]

Lucrul mecanic minim al acestei forțe este:

\[ \boxed{ L_{\min}=mgh } \]
Contur închis

Lucrul total al greutății

Dacă un corp revine în punctul din care a plecat, lucrul efectuat de greutate pe drumul de coborâre este opus lucrului efectuat pe drumul de urcare.

\[ L_{A\to B}^{(G)} + L_{B\to A}^{(G)} = 0 \]

Prin urmare, pe un contur închis:

\[ \boxed{ L_{\mathrm{închis}}^{(G)} = 0 } \]
Forțe conservative

Definiție

Forță conservativă

Forță al cărei lucru mecanic pe un contur închis este nul.

\[ \boxed{ \oint \vec F\cdot d\vec r = 0 } \]

Forța gravitațională și forța elastică vor constitui exemple importante în continuarea capitolului.

Forță variabilă

Mișcare rectilinie

Se consideră acum o forță care nu este constantă, în timp ce corpul se deplasează după o dreaptă între punctele \(A\) și \(B\).

Drumul este împărțit în intervale suficient de mici \(\Delta y\).

Pe un asemenea interval, componenta \(F_y\) poate fi considerată aproximativ constantă.

\[ \Delta L = F_y\,\Delta y \]
Limită

Calculul lucrului mecanic

Lucrul total este obținut prin însumarea contribuțiilor tuturor intervalelor:

\[ L_{AB} \simeq \sum_i F_{y,i}\Delta y_i. \]

La limita în care lungimea intervalelor tinde la zero, suma devine integrală.

\[ \boxed{ L_{AB} = \int_{y_A}^{y_B} F_y\,dy } \]
Aplicație

Lucrul mecanic al forței elastice

Pentru un resort elastic:

\[ F_y=-ky. \]

Lucrul forței elastice la deplasarea de la \(y_A\) la \(y_B\) este:

\[ L_{AB}^{(e)} = -k \int_{y_A}^{y_B} y\,dy. \]

Rezultă:

\[ \boxed{ L_{AB}^{(e)} = \frac{k}{2} \left( y_A^2-y_B^2 \right) } \]
Caz particular

Îndepărtarea de poziția de echilibru

Dacă punctul inițial este poziția de echilibru:

\[ y_A=0, \]

atunci:

\[ \boxed{ L_{O\to B}^{(e)} = -\frac12ky_B^2 } \]

Lucrul este negativ deoarece forța elastică se opune îndepărtării corpului de poziția de echilibru.

Pentru deplasarea inversă:

\[ L_{B\to O}^{(e)} = -L_{O\to B}^{(e)}. \]
Aplicație

Lucrul forței de atracție universală

Se consideră masa \(M\) în punctul \(O\) și masa \(m\) situată la distanța \(r\).

Forța de atracție este orientată către \(O\).

\[ \boxed{ F_r = -K \frac{Mm}{r^2} } \]

Lucrul mecanic între distanțele \(r_A\) și \(r_B\) este:

\[ L_{AB}^{(g)} = \int_{r_A}^{r_B} F_r\,dr. \]

Rezultă:

\[ \boxed{ L_{AB}^{(g)} = KMm \left( \frac{1}{r_B} - \frac{1}{r_A} \right) } \]
Îndepărtarea maselor

Lucru mecanic negativ

Dacă:

\[ r_B>r_A, \]

atunci:

\[ \frac{1}{r_B} < \frac{1}{r_A}. \]

Prin urmare:

\[ \boxed{ L_{AB}^{(g)}<0 } \]

Forța de atracție se opune îndepărtării masei \(m\) de centrul de atracție.

La infinit

Deplasarea din \(A\) până la infinit

Pentru:

\[ r_B\rightarrow\infty, \]

avem:

\[ \frac{1}{r_B}\rightarrow0. \]

Lucrul forței de atracție este:

\[ \boxed{ L_{A\to\infty}^{(g)} = -K \frac{Mm}{r_A} } \]

Pentru deplasarea inversă, de la infinit până în \(A\):

\[ \boxed{ L_{\infty\to A}^{(g)} = K \frac{Mm}{r_A} } \]
Caz general

Forță variabilă și drum curbiliniu

Compendiul consideră apoi situația generală în care forța este variabilă, iar corpul se deplasează pe o curbă între \(A\) și \(B\).

Drumul este împărțit în arce foarte mici \(\Delta s\).

Pe fiecare arc se consideră componenta tangențială \(F_s\) a forței.

\[ \Delta L = F_s\Delta s. \]

Lucrul total este limita sumei acestor contribuții.

\[ \boxed{ L_{AB} = \int_A^B \vec F\cdot d\vec r } \]
Exemplu

Mișcarea circulară uniformă

Se consideră un corp aflat în mișcare circulară uniformă.

Forța centripetă este orientată radial, către centrul cercului.

Deplasarea elementară este tangentă la traiectorie.

\[ \vec F_c \perp d\vec r. \]

Componenta tangențială a forței este nulă.

\[ F_s=0. \]

Prin urmare:

\[ \boxed{ L_{AB}^{(F_c)}=0 } \]

Forța centripetă nu efectuează lucru mecanic în mișcarea circulară uniformă.

Unitate de măsură

Joule

Din relația:

\[ L=Fs, \]

unitatea de lucru mecanic în Sistemul Internațional este joule-ul.

Joule

Un joule reprezintă lucrul mecanic efectuat de o forță de \(1\,\mathrm N\), când punctul său de aplicație se deplasează cu \(1\,\mathrm m\) în direcția și sensul forței.

\[ \boxed{ 1\,\mathrm J = 1\,\mathrm{N\,m} } \]
Unități prezentate în Compendiu

CGS și sistemul tehnic

Compendiul prezintă și unități aparținând altor sisteme de unități folosite la data publicării.

Erg

\[ 1\,\mathrm{erg} = 1\,\mathrm{dyn\,cm} \]
\[ \boxed{ 1\,\mathrm J = 10^7\,\mathrm{erg} } \]

Kilogram-forță-metru

\[ 1\,\mathrm{kgf\,m} \simeq 9{,}8\,\mathrm J \]

Titularizare

Precizări pentru examen

Această secțiune este separată de conținutul §4.1 al Compendiului. Ea se raportează la programa oficială pentru Titularizare Fizică 2026.

Încadrarea în programa 2026

„Lucrul mecanic” nu apare ca punct numerotat separat în tematica științifică.

El este însă instrumentul matematic necesar pentru punctul 5 al programei:

Teoremele mecanicii clasice — energie cinetică, impuls, moment cinetic — și legile de conservare.

Relația de bază: \[ \boxed{ L = \vec F\cdot\vec s = Fs\cos\alpha } \] pentru o forță constantă.
În cazul general: \[ \boxed{ L_{A\to B} = \int_A^B \vec F\cdot d\vec r } \] Această relație va fi utilizată imediat în demonstrarea teoremei variației energiei cinetice.
Greșeală frecventă: lucrul mecanic nu este în general \[ Fs. \] Această formă este valabilă numai când forța este constantă și paralelă cu deplasarea, în același sens. Formula generală pentru forța constantă este: \[ \boxed{ L=Fs\cos\alpha } \]
Semnul nu se introduce separat: el rezultă din: \[ \cos\alpha. \] De exemplu, pentru frecare: \[ \alpha=\pi \quad\Rightarrow\quad L_f=-F_fs. \]
Unități SI: \[ [F]=\mathrm N, \] \[ [s]=\mathrm m, \] \[ \boxed{ [L] = \mathrm J = \mathrm{N\,m} } \]
Atenție la unitățile istorice: ergul și kilogram-forță-metrul apar în Compendiul istoric. Pentru rezolvările actuale se lucrează în Sistemul Internațional, dacă enunțul nu precizează altfel.
Legătura esențială pentru lecțiile următoare:

\[ \text{forță} \longrightarrow \text{lucru mecanic} \longrightarrow \text{energie cinetică} \] iar pentru forțele conservative: \[ \text{lucru mecanic} \longleftrightarrow \text{energie potențială}. \]
Titularizare 2027: nu presupunem modificări ale tematicii. Programa oficială pentru 2027 trebuie reverificată după publicare.
