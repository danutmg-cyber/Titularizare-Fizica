4.7 Ciocniri elastice și inelastice

Conservarea impulsului în procesul de ciocnire, ciocniri centrale, conservarea energiei cinetice la impactul elastic și pierderea de energie mecanică în cazul inelastic tratat de Compendiu.

Ion Bunget Compendiu de Fizică §4.7
Sursa

Compendiu de Fizică

Partea I. Mecanică și acustică
4. Lucrul mecanic și energia
4.7 Ciocniri elastice și inelastice
Pagini: 137–139
Sistemul analizat

Două sfere care se ciocnesc

Se consideră două sfere de mase \(m_1\) și \(m_2\).

Înainte de ciocnire, vitezele lor sunt:

\[ \vec v_1, \qquad \vec v_2. \]

După ciocnire, vitezele devin:

\[ \vec v_1', \qquad \vec v_2'. \]

\(m_1\) — masa primei sfere;

\(m_2\) — masa celei de-a doua sfere;

\(\vec v_1,\vec v_2\) — vitezele înainte de ciocnire;

\(\vec v_1',\vec v_2'\) — vitezele după ciocnire.

Conservarea impulsului

Impulsul total înainte și după ciocnire

Pentru sistemul alcătuit din cele două sfere, Compendiul aplică legea conservării impulsului.

\[ \boxed{ m_1\vec v_1 + m_2\vec v_2 = m_1\vec v_1' + m_2\vec v_2' } \]

Membrul stâng reprezintă impulsul total înainte de ciocnire.

Membrul drept reprezintă impulsul total după ciocnire.

Geometria ciocnirii

Ciocnirea centrală

Compendiul restrânge analiza următoare la cazul în care toate vitezele implicate sunt orientate de-a lungul aceleiași drepte.

Ciocnire centrală

Ciocnire în care vitezele corpurilor înainte și după impact sunt orientate pe aceeași direcție.

Problema vectorială se reduce astfel la o problemă unidimensională.

Convenția de semn

Vitezele ca proiecții pe axa \(Ox\)

Se alege o axă \(Ox\) pe direcția comună a mișcării.

Dacă ambele sfere se deplasează în același sens, proiecțiile vitezelor pot fi luate ambele pozitive.

Dacă sferele se deplasează una spre cealaltă, vitezele au semne opuse.

Semnul vitezei conține deja informația despre sensul mișcării.
Forma scalară

Conservarea impulsului în ciocnirea centrală

Pentru mișcarea pe aceeași dreaptă, relația vectorială devine:

\[ \boxed{ m_1v_1 + m_2v_2 = m_1v_1' + m_2v_2' } \]

Aceasta este relația (4.43) din Compendiu.

Ciocnire elastică

Conservarea energiei cinetice

Compendiul presupune că sferele nu interacționează între ele decât în timpul procesului de ciocnire.

Ciocnire elastică

Ciocnire în care energia cinetică totală a sistemului după ciocnire este egală cu energia cinetică totală înainte de ciocnire.

\[ \boxed{ \frac12m_1v_1^2 + \frac12m_2v_2^2 = \frac12m_1{v_1'}^2 + \frac12m_2{v_2'}^2 } \]

Aceasta este relația (4.44).

Sistem de ecuații

Impuls + energie cinetică

Pentru ciocnirea elastică centrală există două relații de conservare.

Conservarea impulsului

\[ m_1v_1+m_2v_2 = m_1v_1'+m_2v_2' \]

Conservarea energiei cinetice

\[ \frac12m_1v_1^2 + \frac12m_2v_2^2 = \frac12m_1{v_1'}^2 + \frac12m_2{v_2'}^2 \]

Necunoscutele sunt vitezele finale \(v_1'\) și \(v_2'\).

Prelucrare

Relația dintre vitezele relative

Din conservarea impulsului:

\[ m_1(v_1-v_1') = m_2(v_2'-v_2). \]

Din conservarea energiei cinetice:

\[ m_1 \left( v_1^2-{v_1'}^2 \right) = m_2 \left( {v_2'}^2-v_2^2 \right). \]

Factorizând:

\[ m_1 (v_1-v_1') (v_1+v_1') = m_2 (v_2'-v_2) (v_2'+v_2). \]

Compararea cu ecuația impulsului conduce la:

\[ v_1+v_1' = v_2'+v_2. \]

Echivalent:

\[ \boxed{ v_1-v_2 = v_2'-v_1' } \]

Pentru ciocnirea elastică centrală, viteza relativă de apropiere este astfel egală ca modul cu viteza relativă de îndepărtare.

Rezultatul

Viteza finală a primei sfere

Rezolvând sistemul format din conservarea impulsului și conservarea energiei cinetice, Compendiul obține:

\[ \boxed{ v_1' = \frac{ (m_1-m_2)v_1 + 2m_2v_2 }{ m_1+m_2 } } \]
Rezultatul

Viteza finală a celei de-a doua sfere

\[ \boxed{ v_2' = \frac{ 2m_1v_1 + (m_2-m_1)v_2 }{ m_1+m_2 } } \]

Cele două relații constituie formulele (4.45) pentru ciocnirea elastică centrală.

Verificare

Impulsul total se păstrează

Vitezele finale trebuie să satisfacă relația:

\[ \boxed{ m_1v_1+m_2v_2 = m_1v_1'+m_2v_2' } \]

Aceasta constituie o verificare imediată a rezultatului.

Verificare

Energia cinetică totală se păstrează

Pentru ciocnirea elastică:

\[ \boxed{ E_{c,i}=E_{c,f} } \]

adică:

\[ \frac12m_1v_1^2 + \frac12m_2v_2^2 = \frac12m_1{v_1'}^2 + \frac12m_2{v_2'}^2. \]
Consecință a formulelor

Sfere cu mase egale

Pentru:

\[ m_1=m_2, \]

formulele vitezelor finale se reduc la:

\[ \boxed{ v_1'=v_2 } \]
\[ \boxed{ v_2'=v_1 } \]

În acest caz, cele două sfere își schimbă între ele vitezele.

Caz particular

A doua sferă este inițial în repaus

Dacă:

\[ v_2=0, \]

atunci formulele generale devin:

\[ \boxed{ v_1' = \frac{ m_1-m_2 }{ m_1+m_2 } v_1 } \]
\[ \boxed{ v_2' = \frac{ 2m_1 }{ m_1+m_2 } v_1 } \]
Caz particular

Mase egale, a doua sferă în repaus

Pentru:

\[ m_1=m_2 \]

și:

\[ v_2=0, \]

rezultă:

\[ \boxed{ v_1'=0 } \]
\[ \boxed{ v_2'=v_1 } \]

Prima sferă se oprește, iar cea de-a doua preia viteza ei inițială.

Ciocnire inelastică

Aceeași viteză după impact

Compendiul consideră apoi cazul în care, după ciocnire, vitezele celor două sfere sunt egale.

\[ \boxed{ v_1'=v_2'=v' } \]

În text, acest caz este numit ciocnire inelastică centrală.

Cele două sfere continuă mișcarea cu aceeași viteză după ciocnire.

Conservarea impulsului

Ecuația ciocnirii inelastice

Legea conservării impulsului se scrie:

\[ \boxed{ m_1v_1+m_2v_2 = (m_1+m_2)v' } \]

Aceasta este relația (4.46).

Viteza comună

Rezultatul după ciocnire

Din conservarea impulsului:

\[ \boxed{ v' = \frac{ m_1v_1+m_2v_2 }{ m_1+m_2 } } \]

Aceasta este relația (4.47) din Compendiu.

Energia cinetică

Înainte de ciocnire

Energia cinetică totală inițială este:

\[ \boxed{ E_{c,i} = \frac12m_1v_1^2 + \frac12m_2v_2^2 } \]
Energia cinetică

După ciocnire

Deoarece ambele corpuri au viteza comună \(v'\):

\[ \boxed{ E_{c,f} = \frac12 (m_1+m_2) {v'}^2 } \]

Introducând expresia vitezei comune:

\[ E_{c,f} = \frac{ (m_1v_1+m_2v_2)^2 }{ 2(m_1+m_2) }. \]
Variația energiei

Energia cinetică nu se conservă

Se definește:

\[ \Delta E_c = E_{c,f}-E_{c,i}. \]

După introducerea vitezei comune și simplificarea expresiei, rezultă:

\[ \boxed{ \Delta E_c = - \frac{ m_1m_2 }{ 2(m_1+m_2) } (v_1-v_2)^2 } \]

Aceasta corespunde relației (4.48) din Compendiu.

Consecință

Scăderea energiei cinetice

Deoarece:

\[ m_1>0, \qquad m_2>0 \]

și:

\[ (v_1-v_2)^2\geq0, \]

rezultă:

\[ \boxed{ \Delta E_c\leq0 } \]

Pentru o ciocnire efectivă cu viteze inițiale diferite:

\[ \boxed{ \Delta E_c<0 } \]

Energia cinetică totală scade.

Energia transformată

Modulul scăderii energiei cinetice

Valoarea energiei cinetice care nu mai apare sub forma mișcării macroscopice este:

\[ \boxed{ E_{c,i}-E_{c,f} = \frac{ m_1m_2 }{ 2(m_1+m_2) } (v_1-v_2)^2 } \]
Explicația fizică

Deformații inelastice

Compendiul explică scăderea energiei cinetice prin deformările inelastice produse în timpul impactului.

Pentru realizarea acestor deformări se efectuează lucru mecanic.

O parte a energiei mecanice este transferată către energia internă a corpurilor.

Transformarea energiei

Încălzirea corpurilor

Compendiul leagă deformările inelastice de încălzirea sferelor.

Energia cinetică care dispare din mișcarea macroscopică nu reprezintă o dispariție a energiei totale.

Ea se transformă în alte forme de energie, asociate în special deformării și încălzirii corpurilor.

Legătura logică

Ce se conservă la ciocnire?

Impuls

Pentru sistemul mecanic izolat:

\[ \boxed{ m_1v_1+m_2v_2 = m_1v_1'+m_2v_2' } \]

Energie cinetică

Se conservă numai în ciocnirea elastică:

\[ \boxed{ E_{c,i}=E_{c,f} } \]

În cazul inelastic din §4.7

Impulsul se conservă, dar energia cinetică totală scade:

\[ \boxed{ \Delta E_c<0 } \]
Sinteză

De reținut din §4.7

Conservarea impulsului

\[ \boxed{ m_1v_1+m_2v_2 = m_1v_1'+m_2v_2' } \]

Ciocnire elastică

\[ \boxed{ \frac12m_1v_1^2 + \frac12m_2v_2^2 = \frac12m_1{v_1'}^2 + \frac12m_2{v_2'}^2 } \]

Viteza relativă

\[ \boxed{ v_1-v_2 = v_2'-v_1' } \]

Vitezele după impact elastic

\[ \boxed{ v_1' = \frac{ (m_1-m_2)v_1 + 2m_2v_2 }{ m_1+m_2 } } \]
\[ \boxed{ v_2' = \frac{ 2m_1v_1 + (m_2-m_1)v_2 }{ m_1+m_2 } } \]

\[ \boxed{ v_1'=v_2'=v' } \]

Titularizare

Precizări pentru examen

Această secțiune este separată de conținutul §4.7 al Compendiului. Ea se raportează la programa oficială pentru Titularizare Fizică 2026.

Cerință explicită în programa 2026

Punctul 7 al tematicii științifice este:

Ciocniri elastice și inelastice.

Prin urmare, §4.7 este direct și explicit relevant pentru concurs.

El trebuie corelat și cu punctul 5 al programei, care cere impulsul, energia cinetică și legile de conservare.
Legea care se verifică prima: pentru un sistem izolat: \[ \boxed{ \vec p_i=\vec p_f } \] adică: \[ \boxed{ m_1\vec v_1 + m_2\vec v_2 = m_1\vec v_1' + m_2\vec v_2' } \]
Condiția „sistem izolat” este importantă: conservarea impulsului total se aplică atunci când impulsul forțelor exterioare este nul sau neglijabil în intervalul foarte scurt al ciocnirii.
Ciocnire perfect elastică: se conservă simultan: \[ \boxed{ \vec p_i=\vec p_f } \] și: \[ \boxed{ E_{c,i}=E_{c,f} } \]
Precizare terminologică actuală: cazul numit de Bunget „ciocnire inelastică” în această secțiune este cazul în care: \[ v_1'=v_2'. \] În terminologia actuală, acesta este cazul perfect inelastic , în care corpurile continuă împreună cu aceeași viteză.
Pentru ciocnirea perfect inelastică: \[ \boxed{ v' = \frac{ m_1v_1+m_2v_2 }{ m_1+m_2 } } \] iar energia cinetică nu se conservă.
Energia cinetică transformată în cazul perfect inelastic: \[ \boxed{ E_{c,i}-E_{c,f} = \frac{ m_1m_2 }{ 2(m_1+m_2) } (v_1-v_2)^2 } \] pentru viteze algebrice măsurate pe aceeași axă.
Nu spune că „energia nu se conservă”. Într-o ciocnire inelastică nu se conservă energia cinetică . Energia totală se conservă, dar o parte din energia cinetică este transformată în energie internă, deformare, încălzire etc.
Greșeală foarte frecventă: conservarea impulsului și conservarea energiei cinetice nu sunt aceeași lege.

La ciocnire elastică: \[ p=\text{constant}, \qquad E_c=\text{constant}. \] La ciocnire inelastică: \[ p=\text{constant} \] pentru sistemul izolat, dar: \[ E_{c,f}
Atenție la semnele vitezelor: într-o problemă unidimensională trebuie aleasă mai întâi axa și sensul pozitiv. Dacă un corp se deplasează în sens opus axei: \[ v<0. \] Nu se introduc numai modulele vitezelor în conservarea impulsului.
Verificare foarte utilă pentru impactul elastic central: \[ \boxed{ v_1-v_2 = -(v_1'-v_2') } \] sau echivalent: \[ \boxed{ v_1-v_2 = v_2'-v_1' } \] Viteza relativă de apropiere este egală cu viteza relativă de separare, cu sensurile tratate algebric.
Caz de recunoscut imediat: pentru: \[ m_1=m_2 \] într-o ciocnire elastică centrală: \[ \boxed{ v_1'=v_2, \qquad v_2'=v_1 } \] Corpurile își schimbă vitezele.
Schema de rezolvare la examen:

1. alegi sistemul format din corpurile care se ciocnesc;
2. alegi axa și sensul pozitiv;
3. scrii toate vitezele cu semn;
4. scrii conservarea impulsului;
5. identifici tipul ciocnirii;
6. pentru ciocnirea elastică adaugi conservarea energiei cinetice;
7. pentru cazul perfect inelastic folosești viteza finală comună;
8. verifici impulsul, energia și unitățile rezultatului.
Unități SI: impuls: \[ \boxed{ [p] = \mathrm{kg\,m/s} } \] energie cinetică: \[ \boxed{ [E_c] = \mathrm J } \] viteză: \[ \boxed{ [v] = \mathrm{m/s} } \]
