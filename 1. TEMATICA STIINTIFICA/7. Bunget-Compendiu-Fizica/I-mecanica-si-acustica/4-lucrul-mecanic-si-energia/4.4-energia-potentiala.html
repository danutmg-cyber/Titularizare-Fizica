4.4 Energia potențială
Pagini: 129–131
Punct de plecare

Lucrul mecanic al forței gravitaționale

În §4.1 s-a arătat că, atunci când forța gravitațională poate fi considerată constantă, lucrul mecanic efectuat între două puncte nu depinde de forma sau lungimea drumului.

El depinde numai de pozițiile inițială și finală, respectiv de diferența dintre altitudinile acestora.

\[ \boxed{ L_{A\to B}^{(G)} = mg(h_A-h_B) } \]
Generalizare

Traiectorie curbilinie

Rezultatul nu este limitat la deplasările rectilinii.

Compendiul precizează că și atunci când corpul se deplasează între două puncte pe o traiectorie curbilinie, lucrul forței gravitaționale depinde numai de extremitățile drumului.

Această concluzie rămâne valabilă și dacă variația forței gravitaționale cu altitudinea nu mai poate fi neglijată.

Gravitație

Deplasări la altitudini mari

Se consideră Pământul de masă \(M\) și rază \(R\).

Corpul de masă \(m\) este deplasat între suprafața Pământului și un punct situat la altitudinea \(h\).

Distanțele față de centrul Pământului sunt:

\[ r_A=R \]

și:

\[ r_B=R+h. \]
Lucrul gravitațional

Ridicarea corpului

Folosind expresia stabilită anterior pentru lucrul forței de atracție universală, lucrul gravitațional la deplasarea corpului de la suprafața Pământului spre altitudinea \(h\) este:

\[ \boxed{ L_{A\to B}^{(g)} = KMm \left( \frac{1}{R+h} - \frac{1}{R} \right) } \]

Echivalent:

\[ \boxed{ L_{A\to B}^{(g)} = - \frac{ KMmh }{ R(R+h) } <0 } \]

Lucrul este negativ deoarece deplasarea se face împotriva atracției gravitaționale.

Proprietate

Independența de drum

Valoarea lucrului mecanic gravitațional este aceeași indiferent de drumul urmat între aceleași două puncte.

De exemplu, corpul poate fi ridicat după direcția razei Pământului sau după o altă traiectorie care unește aceleași puncte.

Lucrul forței gravitaționale are aceeași valoare.

Contur închis

Lucrul gravitațional total

Lucrul efectuat pentru deplasarea de la \(A\) la \(B\) este opus celui efectuat la deplasarea inversă.

\[ L_{A\to B}^{(g)} = - L_{B\to A}^{(g)} \]

Prin urmare:

\[ \boxed{ L_{A\to B}^{(g)} + L_{B\to A}^{(g)} = 0 } \]

Lucrul forței gravitaționale pe un drum închis este nul.

Ridicarea corpului

Lucrul forței exterioare

Compendiul arată că lucrul mecanic efectuat de o forță exterioară pentru a ridica un corp este egal ca valoare cu lucrul efectuat de forța gravitațională la coborârea aceluiași corp între aceleași puncte.

Forțe conservative

Proprietatea fundamentală

Proprietatea întâlnită la forța gravitațională nu este unică.

Există și alte forțe al căror lucru mecanic între două puncte depinde numai de pozițiile inițială și finală, nu de forma traiectoriei.

Forță conservativă

Forță al cărei lucru mecanic între două puncte depinde numai de pozițiile inițială și finală.

Compendiul menționează ca exemple:

  • forța gravitațională;
  • forța elastică.
Definiție

Energia potențială

Pentru o forță conservativă, lucrul mecanic efectuat la deplasarea corpului din punctul \(A\) în punctul \(B\) poate fi caracterizat prin introducerea unei mărimi numite energie potențială.

Energia potențială

Mărimea definită pentru un câmp de forțe conservative astfel încât lucrul mecanic al forței conservative între două puncte să fie egal cu diferența dintre energiile potențiale în punctul inițial și punctul final.

\[ \boxed{ L_{A\to B} = W_p(A)-W_p(B) } \]
Variația energiei potențiale

Relația cu lucrul mecanic

Definind variația energiei potențiale prin:

\[ \Delta W_p = W_p(B)-W_p(A), \]

relația precedentă poate fi scrisă:

\[ \boxed{ L_{A\to B} = -\Delta W_p } \]

Lucrul mecanic al unei forțe conservative este opus variației energiei potențiale.

Semnul lucrului

Lucru mecanic pozitiv

Dacă forța conservativă efectuează lucru mecanic pozitiv:

\[ L_{A\to B}>0, \]

atunci:

\[ W_p(A)>W_p(B). \]

Energia potențială scade.

\[ \boxed{ L>0 \quad\Longrightarrow\quad \Delta W_p<0 } \]
Semnul lucrului

Lucru mecanic negativ

Dacă:

\[ L_{A\to B}<0, \]

atunci:

\[ W_p(A)

Energia potențială crește.

\[ \boxed{ L<0 \quad\Longrightarrow\quad \Delta W_p>0 } \]
Originea energiei

Valoarea zero este convențională

Relația:

\[ L_{A\to B} = W_p(A)-W_p(B) \]

permite determinarea diferenței dintre energiile potențiale, nu a unei valori absolute impuse în mod unic.

Pentru a atribui o valoare energiei potențiale într-un anumit punct, trebuie ales convențional un punct în care energia potențială este considerată egală cu zero.

Constantă arbitrară

Energia potențială până la o constantă

Energia potențială poate fi modificată prin adăugarea aceleiași constante \(C\) în toate punctele fără ca lucrul mecanic să se modifice.

\[ W_p(A) = W_p^{\,0}(A)+C \]
\[ W_p(B) = W_p^{\,0}(B)+C \]

În diferență, constanta se simplifică.

\[ \boxed{ W_p(A)-W_p(B) } \]

are aceeași valoare indiferent de alegerea constantei \(C\).

Compendiul subliniază astfel că semnificație fizică au diferențele de energie potențială.

Câmp gravitațional uniform

Energia potențială \(mgh\)

Pentru deplasări suficient de mici pe verticală, greutatea poate fi considerată constantă.

Lucrul gravitațional între punctele \(A\) și \(B\) este:

\[ L_{A\to B}^{(G)} = mg(h_A-h_B). \]

Comparând cu:

\[ L_{A\to B} = W_p(A)-W_p(B), \]

se poate scrie:

\[ W_p(A) = mgh_A+C \]

și:

\[ W_p(B) = mgh_B+C. \]
Alegerea originii

Energia potențială zero la sol

Se alege convențional energia potențială egală cu zero la suprafața Pământului.

\[ h=0 \quad\Longrightarrow\quad W_p=0. \]

În această convenție:

\[ \boxed{ W_p=mgh } \]

Relația este utilizată pentru situația în care variația lui \(g\) cu altitudinea poate fi neglijată.

Interpretare

Dependența de înălțime

Pentru aceeași alegere a nivelului de referință, energia potențială gravitațională crește odată cu înălțimea.

\[ W_p = mgh \]

Pentru un corp coborât de la o înălțime mai mare la una mai mică, energia potențială scade, iar forța gravitațională efectuează lucru pozitiv.

Câmp gravitațional radial

Variația greutății cu altitudinea

Pentru deplasări la distanțe la care variația forței gravitaționale nu poate fi neglijată, relația \(mgh\) nu mai este forma utilizată de Compendiu.

Lucrul forței gravitaționale între două puncte situate la distanțele \(r_A\) și \(r_B\) față de centrul Pământului este:

\[ \boxed{ L_{A\to B}^{(g)} = KMm \left( \frac{1}{r_B} - \frac{1}{r_A} \right) } \]
Energia potențială gravitațională

Forma generală

Comparând expresia lucrului cu definiția energiei potențiale, se obține:

\[ W_p(A) = - K\frac{Mm}{r_A} + C \]

și:

\[ W_p(B) = - K\frac{Mm}{r_B} + C. \]

Prin urmare, într-un punct situat la distanța \(r\):

\[ \boxed{ W_p(r) = - K\frac{Mm}{r} + C } \]
Convenție

Energia potențială zero la infinit

Pentru câmpul gravitațional radial, Compendiul consideră un punct aflat la infinit.

Dacă:

\[ r\rightarrow\infty, \]

atunci:

\[ W_p(\infty)=C. \]

Alegând convențional:

\[ W_p(\infty)=0, \]

rezultă:

\[ C=0. \]

Energia potențială gravitațională devine:

\[ \boxed{ W_p(r) = - K \frac{Mm}{r} } \]
Semnul energiei

De ce energia este negativă

Cu alegerea:

\[ W_p(\infty)=0, \]

energia potențială gravitațională la o distanță finită de centrul de atracție este negativă:

\[ \boxed{ W_p(r)<0 } \]

pentru:

\[ r<\infty. \]
Suprafața Pământului

\(r=R\)

Pentru un corp situat la suprafața Pământului:

\[ r=R. \]

Cu energia potențială aleasă zero la infinit:

\[ \boxed{ W_p(R) = - K \frac{Mm}{R} } \]
Convenții

Două alegeri diferite ale originii

Pentru câmpul gravitațional apar în Compendiu două alegeri ale originii energiei potențiale.

Câmp aproximativ uniform

Dacă nivelul de referință este suprafața Pământului:

\[ W_p(0)=0 \]

și:

\[ \boxed{ W_p=mgh } \]

Câmp gravitațional radial

Dacă energia potențială este aleasă zero la infinit:

\[ W_p(\infty)=0 \]

și:

\[ \boxed{ W_p(r) = - K\frac{Mm}{r} } \]
Observație

Valoarea depinde de originea aleasă

Cele două expresii nu reprezintă o contradicție.

Energia potențială este definită până la o constantă aditivă.

Alegerea originii energiei este diferită în cele două cazuri.

Mărimea cu semnificație independentă de această alegere este diferența dintre energiile potențiale.

\[ \boxed{ \Delta W_p = W_p(B)-W_p(A) } \]
Forța elastică

Energia potențială elastică

Forța elastică este, de asemenea, o forță conservativă.

Pentru o deformare descrisă prin coordonata \(y\):

\[ F_y=-ky. \]

În §4.1 s-a obținut lucrul forței elastice:

\[ \boxed{ L_{A\to B}^{(e)} = \frac{k}{2} \left( y_A^2-y_B^2 \right) } \]
Compararea relațiilor

Forma energiei potențiale elastice

Din definiția:

\[ L_{A\to B} = W_p(A)-W_p(B) \]

și din expresia lucrului forței elastice rezultă:

\[ W_p(A) = \frac12ky_A^2+C \]

și:

\[ W_p(B) = \frac12ky_B^2+C. \]

Într-o poziție oarecare:

\[ \boxed{ W_p(y) = \frac12ky^2+C } \]
Originea elastică

Poziția în care forța elastică este nulă

Compendiul alege energia potențială egală cu zero în poziția:

\[ y=0, \]

unde și forța elastică se anulează.

\[ W_p(0)=0. \]

Rezultă:

\[ C=0. \]

Energia potențială elastică este:

\[ \boxed{ W_p = \frac12ky^2 } \]

Aici \(y\) reprezintă distanța până la poziția în care forța elastică se anulează.

Forță conservativă → lucru → energie potențială

Titularizare

Precizări pentru examen

Această secțiune este separată de conținutul §4.4 al Compendiului. Ea se raportează la programa oficială pentru Titularizare Fizică 2026.

Cerință explicită în programa 2026

La punctul 9, programa include explicit:

Deformări elastice izotrope. Legea lui Hooke. Energia potențială elastică.

Energia potențială elastică trebuie cunoscută explicit: \[ \boxed{ E_{p,e} = \frac12kx^2 } \] pentru alegerea: \[ E_{p,e}(0)=0. \] În Compendiu este utilizată notația \(W_p\).
Relația fundamentală pentru o forță conservativă: \[ \boxed{ L_c = -\Delta E_p } \] adică: \[ \boxed{ L_{A\to B}^{(c)} = E_p(A)-E_p(B) } \]
Greșeală de semn foarte frecventă: nu se scrie: \[ L_c=\Delta E_p. \] Pentru o forță conservativă: \[ \boxed{ L_c=-\Delta E_p } \] Dacă forța conservativă efectuează lucru pozitiv, energia potențială scade.
Nu confunda cele două formule gravitaționale: aproape de suprafața Pământului, când \(g\) poate fi considerat constant și nivelul zero este ales convenabil: \[ \boxed{ E_p=mgh } \] În câmpul gravitațional al unei mase punctiforme sau sferic simetrice, cu originea energiei aleasă la infinit: \[ \boxed{ E_p(r) = -G\frac{Mm}{r} } \]
Notație: Compendiul folosește \(K\) pentru constanta atracției universale: \[ W_p(r) = -K\frac{Mm}{r}. \] În notația actuală frecventă se utilizează \(G\): \[ E_p(r) = -G\frac{Mm}{r}. \]
Energia potențială nu are o origine absolută: poți adăuga aceeași constantă \(C\) tuturor valorilor: \[ E_p'=E_p+C \] fără să modifici diferențele: \[ \Delta E_p. \] În probleme trebuie observat sau declarat nivelul de referință.
Legătura cu punctul 5 din programa 2026: programa cere teoremele mecanicii clasice și legile de conservare. Energia potențială este necesară pentru formularea energiei mecanice: \[ E_m=E_c+E_p, \] care va fi tratată în lecția următoare.
Unitatea SI: \[ \boxed{ [E_p]_{\mathrm{SI}} = \mathrm J } \] Pentru energia elastică: \[ \left[ \frac12kx^2 \right] = \frac{\mathrm N}{\mathrm m} \cdot \mathrm{m^2} = \mathrm{N\,m} = \mathrm J. \]
Titularizare 2027: nu presupunem că programa 2027 este identică celei din 2026. Cerințele trebuie reverificate în documentul oficial pentru sesiunea 2027 după publicare.
