2.8 Compunerea mișcărilor oscilatorii

Mișcarea rezultată prin compunerea a două mișcări oscilatorii armonice desfășurate pe aceeași direcție sau pe direcții perpendiculare.

2.8 Compunerea mișcărilor oscilatorii
Pagini: 50–58
Compunerea oscilațiilor

Mișcarea rezultantă

În practică se întâlnesc situații în care un mobil este supus concomitent mai multor mișcări oscilatorii.

Mișcările componente pot avea loc pe aceeași direcție sau pe direcții diferite.

Se urmărește determinarea mișcării rezultante obținute prin compunerea acestor mișcări oscilatorii.

a) Aceeași dreaptă

Compunerea a două mișcări oscilatorii pe aceeași direcție

Se consideră mai întâi două mișcări oscilatorii care au loc pe aceeași direcție.

Cele două mișcări au aceeași perioadă, dar amplitudinile și fazele lor pot fi diferite.

Elongațiile celor două mișcări sunt:

\[ y_1 = A_1 \sin(\omega t+\varphi_1) \]
\[ y_2 = A_2 \sin(\omega t+\varphi_2) \]

Elongația mișcării rezultante este suma elongațiilor celor două mișcări:

\[ y=y_1+y_2 \]
\[ y = A_1\sin(\omega t+\varphi_1) + A_2\sin(\omega t+\varphi_2) \]
Vectori rotitori

Reprezentarea mișcărilor componente

Pentru determinarea mișcării rezultante se folosește reprezentarea mișcărilor oscilatorii prin vectori rotitori.

Vectorii de module \(A_1\) și \(A_2\) corespund celor două oscilații.

Deoarece cele două mișcări au aceeași pulsație \(\omega\), cei doi vectori se rotesc cu aceeași viteză unghiulară.

Diferența de fază:

\[ \Delta\varphi = \varphi_2-\varphi_1 \]

rămâne constantă în timp.

Vectorul rezultant este suma vectorială:

\[ \vec A = \vec A_1+\vec A_2 \]

El se rotește cu aceeași pulsație \(\omega\).

Mișcarea rezultantă este deci tot o mișcare oscilatorie armonică:

\[ y = A\sin(\omega t+\varphi) \]
Faza rezultantă

Determinarea fazei inițiale

Din proiecțiile vectorilor rotitori rezultă:

\[ A\cos\varphi = A_1\cos\varphi_1 + A_2\cos\varphi_2 \]
\[ A\sin\varphi = A_1\sin\varphi_1 + A_2\sin\varphi_2 \]

Prin împărțirea celor două relații se obține:

\[ \tan\varphi = \frac{ A_1\sin\varphi_1 + A_2\sin\varphi_2 }{ A_1\cos\varphi_1 + A_2\cos\varphi_2 } \]
Amplitudinea rezultantă

Dependența de diferența de fază

Modulul vectorului rezultant este amplitudinea oscilației compuse.

\[ A^2 = A_1^2 + A_2^2 + 2A_1A_2 \cos(\varphi_2-\varphi_1) \]

Amplitudinea rezultantă depinde de diferența de fază dintre cele două mișcări componente.

Valorile posibile ale amplitudinii sunt cuprinse între:

\[ |A_1-A_2| \leq A \leq A_1+A_2 \]
Caz particular

Oscilații în fază

Dacă diferența de fază este nulă:

\[ \Delta\varphi=0 \]

atunci:

\[ A=A_1+A_2 \]

Amplitudinea rezultantă are valoarea maximă.

Caz particular

Oscilații în opoziție de fază

Pentru:

\[ \Delta\varphi=\pi \]

amplitudinea rezultantă devine:

\[ A=|A_1-A_2| \]

Dacă amplitudinile celor două mișcări sunt egale:

\[ A_1=A_2 \]

rezultă:

\[ A=0 \]

Mișcarea rezultantă dispare.

Pulsații diferite

Două oscilații cu pulsații apropiate

Se consideră acum două oscilații de pulsații diferite:

\[ \omega_1\neq\omega_2 \]

Pentru simplificare, fazele inițiale se aleg egale:

\[ \varphi_1=\varphi_2=\varphi \]

iar amplitudinile sunt considerate egale:

\[ A_1=A_2=A_0 \]

Elongațiile sunt:

\[ y_1 = A_0 \sin(\omega_1t+\varphi) \]
\[ y_2 = A_0 \sin(\omega_2t+\varphi) \]
Mișcarea rezultantă

Amplitudine variabilă în timp

Pentru pulsații apropiate, elongația rezultantă poate fi scrisă:

\[ y = 2A_0 \cos \left( \frac{\omega_2-\omega_1}{2}t \right) \sin \left[ \frac{\omega_1+\omega_2}{2}t + \varphi \right] \]

Amplitudinea mișcării rezultante variază periodic în timp:

\[ A(t) = 2A_0 \left| \cos \left( \frac{\omega_2-\omega_1}{2}t \right) \right| \]

Mișcarea rezultantă poate fi considerată o oscilație cu pulsația:

\[ \omega = \frac{\omega_1+\omega_2}{2} \]

a cărei amplitudine variază lent în timp.

Bătăi

Fenomenul de bătăi

Bătăile

Fenomenul obținut prin compunerea a două oscilații de frecvențe apropiate, când amplitudinea mișcării rezultante variază periodic și lent în timp.

Frecvența variației amplitudinii este egală cu diferența dintre frecvențele oscilațiilor componente:

\[ \nu_b = |\nu_2-\nu_1| \]

Perioada bătăilor este:

\[ T_b = \frac{1}{ |\nu_2-\nu_1| } \]

Folosind pulsațiile:

\[ T_b = \frac{2\pi}{ |\omega_2-\omega_1| } \]
b) Direcții perpendiculare

Compunerea a două mișcări oscilatorii perpendiculare

Se consideră un mobil supus simultan la două mișcări oscilatorii de perioade egale, perpendiculare între ele.

Direcțiile celor două oscilații sunt alese în lungul axelor \(Ox\) și \(Oy\).

Ecuațiile elongațiilor sunt:

\[ x = A_1 \sin(\omega t+\varphi_1) \]
\[ y = A_2 \sin(\omega t+\varphi_2) \]

Traiectoria se obține prin eliminarea timpului dintre cele două ecuații.

Traiectoria

Ecuația generală

Notând diferența de fază:

\[ \Delta\varphi = \varphi_2-\varphi_1 \]

prin eliminarea timpului rezultă:

\[ \frac{x^2}{A_1^2} + \frac{y^2}{A_2^2} - \frac{2xy}{A_1A_2} \cos\Delta\varphi = \sin^2\Delta\varphi \]

Curba descrisă de această ecuație este, în general, o elipsă.

Forma și orientarea acesteia depind de diferența de fază dintre cele două oscilații componente.

Caz particular

Oscilații perpendiculare în fază

Dacă:

\[ \Delta\varphi=0 \]

sau diferența de fază este un multiplu de \(2\pi\), ecuația traiectoriei devine:

\[ y = \frac{A_2}{A_1}x \]

Mișcarea rezultantă are loc pe o dreaptă care trece prin origine.

Amplitudinea mișcării liniare rezultate este:

\[ A = \sqrt{ A_1^2+A_2^2 } \]
Caz particular

Diferență de fază egală cu \(\pi\)

Dacă:

\[ \Delta\varphi=\pi \]

traiectoria este din nou o dreaptă:

\[ y = -\frac{A_2}{A_1}x \]

Mobilul execută o mișcare oscilatorie armonică liniară.

Amplitudinea mișcării rezultate este:

\[ A = \sqrt{ A_1^2+A_2^2 } \]
Caz particular

Oscilații în cuadratură

Pentru o diferență de fază:

\[ \Delta\varphi = \frac{\pi}{2} \]

sau:

\[ \Delta\varphi = \frac{3\pi}{2}, \]

ecuația traiectoriei devine:

\[ \frac{x^2}{A_1^2} + \frac{y^2}{A_2^2} = 1 \]

Traiectoria este o elipsă cu semiaxele \(A_1\) și \(A_2\).

Amplitudini egale

Traiectoria circulară

Dacă, în cazul oscilațiilor în cuadratură:

\[ A_1=A_2=A, \]

ecuația devine:

\[ x^2+y^2=A^2 \]

Traiectoria rezultantă este un cerc de rază \(A\).

Cele două valori ale diferenței de fază, \(\pi/2\) și \(3\pi/2\), corespund unor sensuri opuse de parcurgere a cercului.

Alte diferențe de fază

Traiectorii eliptice

Pentru celelalte valori ale diferenței de fază se obțin tot traiectorii eliptice.

Axele acestor elipse nu mai sunt, în general, orientate în lungul axelor de coordonate.

Pentru diferențe de fază complementare corespunzătoare, se obțin elipse cu aceleași semiaxe, dar parcurse în sensuri opuse.

Pulsații neegale

Oscilații perpendiculare cu pulsații diferite

În cazul mai general în care cele două oscilații perpendiculare au pulsații diferite, traiectoriile obținute sunt mai complicate.

În general, acestea nu sunt curbe închise.

Pentru ca traiectoria să fie o curbă închisă, raportul pulsațiilor trebuie să fie un număr rațional:

\[ \frac{\omega_2}{\omega_1} = \frac{m}{n}, \qquad m,n\in\mathbb{N} \]
Figurile Lissajous

Traiectorii închise

Figurile Lissajous

Curbele închise obținute prin compunerea a două mișcări oscilatorii armonice perpendiculare cu pulsații al căror raport este un număr rațional.

Forma figurii depinde de raportul pulsațiilor și de diferența de fază dintre oscilațiile componente.

Dacă raportul pulsațiilor nu este rațional, traiectoria nu se închide.

Mobilul nu mai trece exact prin aceeași poziție după un timp finit, dar după un timp suficient de lung poate trece oricât de aproape de o poziție ocupată anterior.

Sinteză

De reținut din §2.8

Oscilații pe aceeași direcție, cu aceeași pulsație

\[ y=y_1+y_2 \]
\[ y = A\sin(\omega t+\varphi) \]
\[ A^2 = A_1^2+A_2^2 + 2A_1A_2 \cos(\varphi_2-\varphi_1) \]
\[ \tan\varphi = \frac{ A_1\sin\varphi_1 + A_2\sin\varphi_2 }{ A_1\cos\varphi_1 + A_2\cos\varphi_2 } \]

Limitele amplitudinii

\[ |A_1-A_2| \leq A \leq A_1+A_2 \]

Bătăi

\[ \nu_b = |\nu_2-\nu_1| \]
\[ T_b = \frac{1}{ |\nu_2-\nu_1| } \]

Oscilații perpendiculare de aceeași pulsație

\[ x = A_1\sin(\omega t+\varphi_1) \]
\[ y = A_2\sin(\omega t+\varphi_2) \]
\[ \frac{x^2}{A_1^2} + \frac{y^2}{A_2^2} - \frac{2xy}{A_1A_2} \cos\Delta\varphi = \sin^2\Delta\varphi \]

Cazuri particulare

\(\Delta\varphi=0\): traiectorie rectilinie.

\(\Delta\varphi=\pi\): traiectorie rectilinie.

\(\Delta\varphi=\pi/2\) sau \(3\pi/2\): traiectorie eliptică.

Pentru amplitudini egale și oscilații în cuadratură: traiectorie circulară.

Figuri Lissajous

\[ \frac{\omega_2}{\omega_1} = \frac{m}{n} \]

Pentru un raport rațional al pulsațiilor, traiectoria este închisă.

Titularizare

Precizări pentru examen

Această secțiune nu face parte din §2.8 al Compendiului. Ea este raportată separat la programa oficială pentru Titularizare Fizică 2026.

Programa oficială 2026

Tematica științifică prevede:

Oscilatorul armonic liniar — oscilații libere, amortizate și forțate; rezonanță și factorul de calitate.

În legătură cu §2.8: compunerea mișcărilor oscilatorii nu apare ca punct separat în tematica științifică 2026. Ea face însă parte din conținutul Compendiului studiat aici.
Din această lecție trebuie cunoscute în special:

compunerea a două oscilații armonice coliniare cu aceeași pulsație;
dependența amplitudinii rezultante de diferența de fază;
fenomenul de bătăi pentru frecvențe apropiate;
compunerea oscilațiilor perpendiculare;
cazurile de traiectorie rectilinie, eliptică și circulară;
condiția de apariție a figurilor Lissajous.
Pentru pregătirea completă conform programei 2026: conținutul Compendiului trebuie completat separat cu oscilațiile libere, amortizate și forțate, rezonanța și factorul de calitate.
Titularizare 2027: programa oficială pentru sesiunea 2027 trebuie reverificată după publicare.
