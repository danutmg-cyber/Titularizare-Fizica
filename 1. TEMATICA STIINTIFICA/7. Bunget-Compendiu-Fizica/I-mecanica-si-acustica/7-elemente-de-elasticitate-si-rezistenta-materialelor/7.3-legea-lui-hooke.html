7.3 Legea lui Hooke

Întinderea și compresiunea unei bare elastice, modulul lui Young, alungirea specifică, contracția transversală, coeficientul lui Poisson și energia potențială elastică.

Ion Bunget Compendiu de Fizică §7.3

7.3 Legea lui Hooke
Pagini: 172–173
Model experimental

Bara supusă la întindere

Compendiul consideră o bară de lungime inițială \(l_0\) și secțiune normală de arie \(S\).

Bara este supusă unei solicitări de întindere prin aplicarea unei forțe \(F\) în lungul axei sale.

\[ F \parallel \text{axa barei} \]

Piesa utilizată pentru încercările experimentale este numită:

Epruvetă

Corp de formă și dimensiuni determinate utilizat pentru încercarea experimentală a materialului.

Lungimea inițială \(l_0\) este măsurată între două repere ale epruvetei.

Domeniul elastic

Forța nu trebuie să depășească o anumită valoare

Bunget precizează că, dacă forța aplicată nu depășește o anumită valoare caracteristică materialului, deformarea este elastică.

În domeniul analizat experimental, alungirea barei depinde de forța aplicată, de lungimea inițială și de aria secțiunii.

Rezultat experimental

De ce depinde alungirea

Alungirea:

\[ \Delta l \]

este direct proporțională cu modulul forței aplicate:

\[ \Delta l\sim F, \]

direct proporțională cu lungimea inițială:

\[ \Delta l\sim l_0, \]

și invers proporțională cu aria secțiunii normale:

\[ \Delta l\sim\frac1S. \]
Relația (7.2)

Alungirea barei

Combinând dependențele experimentale, relația poate fi scrisă:

\[ \boxed{ \Delta l = \frac{ F l_0 }{ ES } } \]

Factorul \(E\) caracterizează materialul barei.

Constantă elastică

Modulul lui Young

Modulul de elasticitate sau modulul lui Young

Mărimea \(E\) care intervine în relația dintre solicitarea axială și deformarea longitudinală a barei.

\[ \boxed{ E } \]
Relația (7.3)

Forma Legii lui Hooke

Relația pentru alungire poate fi rearanjată:

\[ \boxed{ \frac{\Delta l}{l_0} = \frac1E \frac{F}{S} } \]

Această relație exprimă legea lui Hooke pentru solicitarea axială analizată.

Deformare relativă

Alungirea specifică

Raportul:

\[ \boxed{ \frac{\Delta l}{l_0} } \]

este numit în Compendiu alungire relativă sau alungire specifică.

El reprezintă alungirea corespunzătoare unității de lungime inițială a barei.

Efort unitar

Raportul \(F/S\)

Compendiul identifică:

\[ \boxed{ \sigma = \frac{F}{S} } \]

ca efort unitar normal.

Notație compactă

Deformația longitudinală relativă

Notând:

\[ \varepsilon = \frac{\Delta l}{l_0}, \]

Legea lui Hooke capătă forma:

\[ \boxed{ \sigma=E\varepsilon } \]
Constanta unei bare

Legătura cu resortul

Bunget introduce pentru bara dată mărimea:

\[ \boxed{ k = \frac{ES}{l_0} } \]

Cu această notație, relația pentru întindere devine:

\[ \boxed{ F=k\Delta l } \]

Compendiul face astfel legătura cu relația utilizată anterior pentru resort.

Interpretare

Forțele interioare sunt elastice

Forța care tinde să readucă bara la lungimea inițială este proporțională cu deformarea.

Bunget folosește acest rezultat pentru a caracteriza forțele interioare care apar în timpul deformării elastice drept forțe elastice.

Compresiune

Aceleași relații pentru scurtare

Compendiul precizează că relațiile precedente sunt valabile și pentru solicitarea de compresiune.

În acest caz, \(F\) reprezintă forța axială care comprimă bara.

\(\Delta l\) reprezintă scurtarea, iar:

\[ \boxed{ \frac{\Delta l}{l_0} } \]

este scurtarea specifică.

Modulul de elasticitate

Aceeași valoare a lui \(E\)

Pentru bara confecționată din același material, Compendiul consideră aceeași valoare a modulului de elasticitate \(E\) atât la întindere, cât și la compresiune.

Deformare transversală

Contracția transversală

Experiența arată că întinderea longitudinală este însoțită de o micșorare a dimensiunilor transversale ale barei.

Contracție transversală

Micșorarea dimensiunilor secțiunii transversale care însoțește întinderea longitudinală.

La compresiune, Compendiul indică fenomenul invers: secțiunea transversală se mărește.

Relația (7.4)

Coeficientul lui Poisson

Dacă \(d_0\) este diametrul inițial, iar \(\Delta d\) reprezintă micșorarea diametrului la întindere, Compendiul introduce coeficientul:

\[ \boxed{ \frac{\Delta d}{d_0} = \mu \frac{\sigma}{E} } \]
Coeficientul lui Poisson

Mărimea \(\mu\), denumită în Compendiu și coeficient de contracție transversală.

Dimensiunea longitudinală

Lungimea după deformare

Din Legea lui Hooke:

\[ \frac{\Delta l}{l_0} = \frac{\sigma}{E}. \]

Lungimea după întindere poate fi scrisă:

\[ \boxed{ l = l_0 \left( 1+ \frac{\sigma}{E} \right) } \]
Dimensiunea transversală

Diametrul după deformare

Deoarece diametrul se micșorează la întindere:

\[ d=d_0-\Delta d. \]

Folosind coeficientul lui Poisson:

\[ \boxed{ d = d_0 \left( 1- \mu \frac{\sigma}{E} \right) } \]
Volumul barei

Modificarea volumului

Bunget analizează apoi modificarea volumului unei bare cilindrice supuse la întindere.

Pentru deformații mici, după neglijarea termenilor de ordin superior, relația conduce la:

\[ \boxed{ V \approx V_0 \left[ 1+ (1-2\mu) \frac{\sigma}{E} \right] } \]
Variația volumului

\(\Delta V\)

Echivalent:

\[ \boxed{ \Delta V \approx (1-2\mu) \frac{\sigma}{E} V_0 } \]

Compendiul examinează consecințele acestei relații pentru coeficientul lui Poisson.

Caz particular

\(\mu=0{,}5\)

Dacă:

\[ \mu=0{,}5, \]

atunci:

\[ \boxed{ \Delta V=0 } \]

adică deformarea s-ar produce fără modificarea volumului.

Observație experimentală

Valoarea coeficientului lui Poisson

Compendiul menționează că, la întinderea materialelor analizate, volumul crește:

\[ \Delta V>0. \]

Din relația precedentă rezultă în modelul prezentat:

\[ \mu<0{,}5. \]

Bunget indică pentru numeroase metale o valoare experimentală de ordinul:

\[ \boxed{ \mu\simeq0{,}3 } \]
Lucru mecanic

Alungirea barei necesită lucru

Pentru alungirea barei de la \(l_0\) la \(l_0+\Delta l\) este efectuat un lucru mecanic.

Forța crește liniar de la zero la valoarea finală \(F\).

Valoarea medie este:

\[ \boxed{ F_m=\frac F2 } \]
Lucrul mecanic

Expresia lucrului

Rezultă:

\[ L = F_m\Delta l. \]
\[ \boxed{ L = \frac12F\Delta l } \]
Folosirea Legii lui Hooke

Lucrul exprimat prin caracteristicile barei

Din:

\[ F = \frac{ES}{l_0} \Delta l, \]

se obține:

\[ \boxed{ L = \frac{ES}{2l_0} (\Delta l)^2 } \]
Energia elastică

Lucrul se înmagazinează în bara deformată

Compendiul arată că lucrul mecanic efectuat pentru deformare se înmagazinează în bara elastică sub forma energiei potențiale.

\[ \boxed{ W_p = \frac{ES}{2l_0} (\Delta l)^2 } \]
Legătura cu resortul

Forma cunoscută a energiei elastice

Folosind notațiile:

\[ k=\frac{ES}{l_0} \]

și:

\[ x=\Delta l, \]

relația devine:

\[ \boxed{ W_p = \frac12kx^2 } \]

Compendiul observă că aceasta coincide cu expresia energiei potențiale asociate unei forțe elastice proporționale cu deformarea.

Legătura logică

De la întinderea barei la energia elastică

Solicitare axială

\[ F \]

Efort unitar

\[ \boxed{ \sigma=\frac FS } \]

Deformare longitudinală

\[ \boxed{ \varepsilon = \frac{\Delta l}{l_0} } \]

Legea lui Hooke

\[ \boxed{ \sigma=E\varepsilon } \]

Constanta barei

\[ \boxed{ k=\frac{ES}{l_0} } \]

Relația forță–deformare

\[ \boxed{ F=k\Delta l } \]

Energia potențială

\[ \boxed{ W_p = \frac12k(\Delta l)^2 } \]
Sinteză

De reținut din §7.3

Alungirea barei

\[ \boxed{ \Delta l = \frac{ Fl_0 }{ ES } } \]

Efort unitar

\[ \boxed{ \sigma=\frac FS } \]

Deformare specifică

\[ \boxed{ \varepsilon = \frac{\Delta l}{l_0} } \]

Legea lui Hooke

\[ \boxed{ \sigma=E\varepsilon } \]

Constanta elastică a barei

\[ \boxed{ k = \frac{ES}{l_0} } \]

Coeficientul lui Poisson

\[ \boxed{ \frac{\Delta d}{d_0} = \mu \frac{\sigma}{E} } \]

Lucrul de deformare

\[ \boxed{ L = \frac12F\Delta l } \]

Energia potențială elastică

\[ \boxed{ W_p = \frac{ES}{2l_0} (\Delta l)^2 } \]
\[ \boxed{ W_p = \frac12kx^2 } \]

Prioritate explicită în programa 2026

Punctul 9 al tematicii științifice cere explicit:

Deformări elastice izotrope. Legea lui Hooke. Energia potențială elastică.

§7.3 acoperă direct două dintre elementele centrale ale acestei cerințe: Legea lui Hooke și energia potențială elastică.

Mărimile de bază:

forța axială: \[ F \] aria secțiunii: \[ S \] lungimea inițială: \[ l_0 \] variația lungimii: \[ \Delta l \] tensiunea normală: \[ \sigma \] deformația longitudinală: \[ \varepsilon \] modulul lui Young: \[ E. \]
Unități SI: \[ [F]=\mathrm N \] \[ [S]=\mathrm{m^2} \] \[ [l_0] = [\Delta l] = \mathrm m \] \[ \boxed{ [\sigma] = [E] = \mathrm{Pa} } \] \[ \boxed{ [\varepsilon]=1 } \]
Forma de bază pentru întindere axială uniformă: \[ \boxed{ \sigma = \frac FS } \] \[ \boxed{ \varepsilon = \frac{\Delta l}{l_0} } \] și: \[ \boxed{ \sigma = E\varepsilon } \]
Rezultă imediat: \[ \boxed{ \Delta l = \frac{ Fl_0 }{ ES } } \]
Greșeală frecventă: \(E\) și \(k\) nu sunt aceeași mărime. Modulul lui Young: \[ \boxed{ E } \] caracterizează materialul în modelul elastic considerat. Constanta: \[ \boxed{ k=\frac{ES}{l_0} } \] caracterizează bara concretă și depinde și de geometria ei.
Unitățile confirmă diferența: \[ \boxed{ [E]=\mathrm{Pa} } \] dar: \[ \boxed{ [k]=\mathrm{\frac Nm} } \]
Legea lui Hooke nu este o relație universală pentru orice deformare. Forma liniară: \[ \sigma=E\varepsilon \] se utilizează în domeniul în care solicitarea și deformarea sunt proporționale. Limitele acestui domeniu sunt discutate de Bunget în §7.4.
Elastic nu înseamnă obligatoriu liniar. În §7.4 va apărea distincția dintre limita de proporționalitate și limita de elasticitate. Pentru Legea lui Hooke liniară trebuie respectat domeniul de proporționalitate.
Forța elastică și semnul: relația: \[ F=kx \] exprimă modulele. Dacă scriem forța de revenire pe o axă: \[ \boxed{ F_e=-kx } \] semnul minus indică faptul că forța elastică este orientată în sens opus deplasării față de poziția de echilibru.
Energia potențială elastică: \[ \boxed{ E_{p,\mathrm{el}} = \frac12F\Delta l } \] și folosind Legea lui Hooke: \[ \boxed{ E_{p,\mathrm{el}} = \frac{ES}{2l_0} (\Delta l)^2 } \]
Forme echivalente utile: \[ \boxed{ E_{p,\mathrm{el}} = \frac12k(\Delta l)^2 } \] și: \[ \boxed{ E_{p,\mathrm{el}} = \frac{ F^2l_0 }{ 2ES } } \]
Densitatea energiei elastice: pentru solicitarea axială liniar-elastică uniformă: \[ u = \frac{ E_{p,\mathrm{el}} }{ V }. \] Cum: \[ V=Sl_0, \] rezultă: \[ \boxed{ u = \frac12 \sigma\varepsilon } \] și: \[ \boxed{ u = \frac{\sigma^2}{2E} = \frac12E\varepsilon^2 } \]
Coeficientul lui Poisson — notație actuală: este utilizat frecvent simbolul: \[ \nu. \] Pentru întindere: \[ \varepsilon_{\parallel}>0, \] iar deformația transversală este negativă: \[ \varepsilon_{\perp}<0. \] Convenția modernă este: \[ \boxed{ \nu = - \frac{ \varepsilon_{\perp} }{ \varepsilon_{\parallel} } } \]
Diferență de notație față de Compendiu: Bunget utilizează \(\mu\) și exprimă contracția transversală prin modulul micșorării. În formularea actuală este frecvent: \[ \nu = - \frac{ \Delta d/d_0 }{ \Delta l/l_0 } \] dacă variațiile sunt introduse cu semn.
„Izotrop”: pentru cerința din programă, un material elastic izotrop este modelat ca având aceleași proprietăți elastice indiferent de direcția în care este analizat.
Nu confunda izotropia cu omogenitatea. Omogenitatea se referă la variația proprietăților de la un punct la altul. Izotropia se referă la dependența proprietăților de direcție.
Altă eroare frecventă: la calculul: \[ \sigma=\frac FS \] aria trebuie introdusă în unități SI. De exemplu: \[ 1\,\mathrm{mm^2} = 10^{-6}\,\mathrm{m^2}. \]
Verificare dimensională pentru alungire: \[ \Delta l = \frac{ Fl_0 }{ ES }. \] Deoarece: \[ [ES] = \frac{\mathrm N}{\mathrm{m^2}} \cdot \mathrm{m^2} = \mathrm N, \] rezultă: \[ [\Delta l] = \frac{ \mathrm{N\,m} }{ \mathrm N } = \boxed{ \mathrm m }. \]
Verificare dimensională pentru energia elastică: \[ E_p = \frac12F\Delta l. \] Prin urmare: \[ [E_p] = \mathrm{N\,m} = \boxed{ \mathrm J }. \]
Metodă de rezolvare pentru o bară întinsă:

1. transformă toate datele în SI;
2. identifică \(F\), \(l_0\), \(S\), \(E\);
3. verifică modelul: solicitare axială și domeniu elastic liniar;
4. calculează: \[ \sigma=\frac FS; \]
5. aplică: \[ \varepsilon=\frac{\sigma}{E}; \]
6. determină: \[ \Delta l = \varepsilon l_0; \]
7. dacă este cerută energia: \[ E_p = \frac12F\Delta l; \]
8. verifică unitățile și ordinul de mărime.
Relația-cheie de reconstruit, nu doar de memorat: \[ \sigma = E\varepsilon \] împreună cu: \[ \sigma=\frac FS \] și: \[ \varepsilon = \frac{\Delta l}{l_0} \] conduce imediat la: \[ \boxed{ \Delta l = \frac{ Fl_0 }{ ES } } \]
Prioritate mare pentru concurs: trebuie să poți trece fără ezitare între: \[ \boxed{ \sigma=E\varepsilon } \] \[ \boxed{ \Delta l = \frac{Fl_0}{ES} } \] \[ \boxed{ k=\frac{ES}{l_0} } \] și: \[ \boxed{ E_{p,\mathrm{el}} = \frac12kx^2 } \]
