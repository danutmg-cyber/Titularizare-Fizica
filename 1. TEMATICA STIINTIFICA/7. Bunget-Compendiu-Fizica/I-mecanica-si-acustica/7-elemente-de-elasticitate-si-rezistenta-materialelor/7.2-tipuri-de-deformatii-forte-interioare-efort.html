Compendiul

Deformații elastice și permanente

Sub acțiunea forțelor exterioare, un corp își poate modifica forma. Dacă după încetarea acțiunii forțelor corpul revine la forma inițială, deformarea este elastică. Dacă modificarea rămâne, deformarea este permanentă.

Deformare elastică

Dispare după îndepărtarea solicitării.

Deformare permanentă

Nu dispare complet după încetarea solicitării.

Forțe interioare

Răspunsul interior al corpului

Când forțele exterioare deformează corpul, în interior apar forțe care se opun deformării. Pentru deformările elastice, acestea sunt forțe elastice.

Forțele interioare exprimă acțiunea unei părți a corpului asupra celeilalte.

Metoda secțiunilor

Punerea în evidență a forțelor interioare

Bunget imaginează secționarea corpului în două părți. Pentru ca fiecare parte izolată să rămână în echilibru, pe suprafața secțiunii trebuie introduse acțiunile pe care cealaltă parte le exercita înainte de secționare.

\[ \boxed{ \text{secționare} \longrightarrow \text{eforturi interioare} } \]
Reducerea eforturilor

Rezultantă și moment rezultant

În cazul general, acțiunile interioare dintr-o secțiune sunt reprezentate convențional printr-o rezultantă \(\vec R\) și un moment rezultant \(\vec M\), aplicate în centrul secțiunii.

\[ \boxed{ \vec R,\qquad \vec M } \]
Solicitări simple

Cele patru cazuri prezentate

Întindere / compresiune

Este produsă de componenta normală \(N\).

Forfecare

Este produsă de forța tăietoare \(T\).

Torsiune

Este produsă de componenta de moment care răsucește bara în jurul axei sale.

Încovoiere

Este produsă de momentul care curbează bara.

Distribuția interioară

Eforturile nu acționează într-un singur punct

Reprezentarea prin \(\vec R\) și \(\vec M\) este convențională. În realitate, acțiunile interioare sunt distribuite pe suprafața secțiunii.

Efort unitar

Acțiunea pe unitatea de suprafață

Bunget introduce apoi efortul unitar, numit și tensiune, pornind de la forța interioară distribuită pe un element mic de suprafață.

Formula din scanul/transcrierea disponibilă este deteriorată. Sensul relației este raportarea forței interioare distribuite la elementul de suprafață.

Efortul unitar este descompus într-o componentă normală și una tangențială.

Observația finală

Caracter macroscopic

Paragraful se limitează la descrierea macroscopică a comportării mecanice. Bunget nu dezvoltă aici mecanismul microscopic dintre structura materialului și proprietățile sale mecanice.

Titularizare

Completare pentru examen

Această secțiune este separată de corpul §7.2 al Compendiului. Reperul oficial este programa Titularizare Fizică 2026.

Cerință explicită

Punctul 9 al tematicii științifice cere:

Deformări elastice izotrope. Legea lui Hooke. Energia potențială elastică.

§7.2 oferă baza conceptuală, iar relațiile cantitative esențiale continuă în §7.3.

Deformare elastică: corpul revine la configurația inițială după îndepărtarea solicitării, în limitele modelului elastic.
Deformare permanentă sau plastică: după îndepărtarea solicitării rămâne o deformare reziduală.
Nu confunda: „elastic” nu înseamnă automat „legea lui Hooke”. Un material poate avea comportare elastică fără ca relația solicitare–deformare să fie liniară pe întregul domeniu elastic.
Corp elastic izotrop: în modelul izotrop, proprietățile elastice sunt aceleași în toate direcțiile materialului.
„Izotrop” și „omogen” nu sunt sinonime. Omogenitatea se referă la faptul că proprietățile nu depind de poziție. Izotropia se referă la independența lor față de direcție.
Metoda secțiunilor:

1. alegi o secțiune;
2. separi imaginar corpul;
3. păstrezi una dintre părți;
4. înlocuiești partea eliminată prin acțiunile interioare din secțiune;
5. aplici ecuațiile de echilibru.
Rezultantele interioare uzuale pentru o bară:

\(N\) — forță normală;
\(T\) — forță tăietoare;
\(M_t\) — moment de torsiune;
\(M_f\) — moment de încovoiere.
Solicitarea axială: dacă forța normală este orientată astfel încât să îndepărteze cele două părți ale barei: \[ \boxed{ \text{întindere} } \] iar dacă le apropie: \[ \boxed{ \text{compresiune} } \]
Solicitarea de forfecare: este asociată unei acțiuni tangențiale în secțiune. Rezultanta corespunzătoare este forța tăietoare: \[ \boxed{ T } \]
Torsiunea: corespunde unui moment care tinde să răsucească bara în jurul axei sale. \[ \boxed{ M_t } \]
Încovoierea: este asociată unui moment încovoietor: \[ \boxed{ M_f } \]
Tensiunea mecanică normală în cazul simplu uniform: \[ \boxed{ \sigma = \frac{N}{S} } \] unde:

\(N\) — forța normală;
\(S\) — aria secțiunii.
Tensiunea tangențială medie în cazul simplu: \[ \boxed{ \tau = \frac{T}{S} } \]
Unitatea SI pentru tensiunea mecanică: \[ \boxed{ [\sigma] = [\tau] = \mathrm{Pa} } \] deoarece: \[ 1\,\mathrm{Pa} = 1\,\mathrm{\frac{N}{m^2}}. \]
Greșeală frecventă: tensiunea mecanică nu este o forță. Forța se măsoară în: \[ \mathrm N, \] iar tensiunea mecanică în: \[ \mathrm{Pa}. \]
Pentru o distribuție neuniformă: relația: \[ \sigma=\frac{N}{S} \] reprezintă numai valoarea medie dacă tensiunea nu este uniformă. Local trebuie analizată distribuția tensiunilor în secțiune.
Formulare locală: pentru un element foarte mic de suprafață: \[ \boxed{ \vec t = \frac{d\vec F}{dS} } \] vectorul \(\vec t\) poate fi descompus într-o componentă normală și una tangențială.
Precizare de nivel superior: starea de tensiune într-un punct nu este descrisă în general de un singur vector. Ea este reprezentată prin tensorul tensiunilor. Bunget menționează explicit caracterul tensorial, fără să dezvolte teoria tensorilor în §7.2.
De ce depinde vectorul tensiunii pe o suprafață? Nu numai de punctul considerat, ci și de orientarea planului secțiunii. În notație modernă: \[ \boxed{ \vec t(\vec n) = \boldsymbol{\sigma} \cdot \vec n } \] unde \(\vec n\) este normala la suprafață.
Pentru Titularizare: nu transforma această relație tensorială într-o prioritate de memorare dacă problema nu o cere. Prioritatea este să stăpânești clar:

solicitarea;
deformarea;
tensiunea mecanică;
legea lui Hooke;
energia elastică.
Legătura directă cu §7.3: pentru întinderea axială uniformă vom avea: \[ \sigma=\frac{F}{S}, \] iar deformația longitudinală relativă: \[ \varepsilon = \frac{\Delta l}{l_0}. \] În domeniul liniar elastic, acestea vor fi legate prin legea lui Hooke.
Atenție la simbolul \(\varepsilon\): aici el este folosit frecvent pentru deformația specifică. În capitolul despre rotație, Bunget folosea \(\varepsilon\) pentru accelerația unghiulară. Sensul simbolului trebuie stabilit din context.
Deformația longitudinală relativă: \[ \boxed{ \varepsilon = \frac{\Delta l}{l_0} } \] este adimensională: \[ \boxed{ [\varepsilon]=1 } \]
Ordinea corectă pentru o problemă de elasticitate:

1. identifici solicitarea;
2. stabilești secțiunea;
3. determini eforturile interioare;
4. calculezi tensiunea;
5. aplici legea constitutivă adecvată;
6. determini deformarea;
7. verifici domeniul de valabilitate.
