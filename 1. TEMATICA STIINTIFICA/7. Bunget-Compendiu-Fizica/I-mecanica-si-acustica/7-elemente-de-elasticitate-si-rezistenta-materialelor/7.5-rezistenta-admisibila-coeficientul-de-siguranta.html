7.5 Rezistența admisibilă. Coeficientul de siguranță

Stabilirea solicitării maxime admisibile a unei piese, coeficientul de siguranță, dimensionarea barelor solicitate la întindere, influența greutății proprii și bara de egală rezistență.

7. Elemente de elasticitate și rezistența materialelor
7.5 Rezistența admisibilă. Coeficientul de siguranță
Pagini: 177–178
Punct de plecare

Piesa trebuie să funcționeze fără rupere sau deformare permanentă

Bunget pornește de la curba caracteristică analizată în §7.4.

Cunoscând comportarea materialului, trebuie stabilit până la ce valoare a efortului unitar poate fi solicitată o piesă fără să se rupă și fără să sufere deformări permanente.

\[ \boxed{ \text{solicitare de lucru} < \text{valoare limită a materialului} } \]
Condiție de proiectare

Solicitarea se menține sub limitele periculoase

Compendiul arată că piesele sunt dimensionate astfel încât eforturile unitare care apar în timpul funcționării să nu ajungă la valori care produc deformarea permanentă sau ruperea.

În practică, valoarea folosită la dimensionare este aleasă mai mică decât valorile-limită indicate de curba caracteristică.

Motivul marjei

Forțele reale nu sunt cunoscute întotdeauna exact

Bunget justifică folosirea unei marje de siguranță prin faptul că valorile forțelor luate în calcul pot fi numai aproximative.

În condițiile reale de funcționare, solicitarea poate deveni mai mare decât cea estimată inițial.

\[ \boxed{ \text{incertitudini} \longrightarrow \text{marjă de siguranță} } \]
Definiție

Rezistența admisibilă

Rezistență admisibilă

Valoarea convențională aleasă în calcul pentru efortul unitar maxim care poate apărea într-o piesă realizată dintr-un anumit material și supusă unei solicitări determinate.

În notația Compendiului, apar simboluri de forma:

\[ \boxed{ \sigma_a \qquad\text{sau}\qquad \tau_a } \]

în funcție de natura solicitării considerate.

Curba caracteristică

Alegerea valorii admisibile

Rezistența admisibilă este legată de valorile caracteristice obținute din curba materialului.

Alegerea diferă în funcție de comportarea materialului înainte de rupere.

Materiale tenace

Raportarea la limita de curgere

Pentru materialele tenace, la care poate fi determinată o limită de curgere, Compendiul raportează rezistența admisibilă la această valoare-limită.

\[ \boxed{ \sigma_a = \frac{\sigma_c}{c_c} } \]

unde \(c_c\) este coeficientul de siguranță asociat limitei de curgere.

Materiale fragile

Raportarea la limita de rupere

Pentru materialele fragile, pentru care ruperea este criteriul relevant în prezentarea Compendiului, se utilizează limita de rupere.

\[ \boxed{ \sigma_a = \frac{\sigma_r}{c_r} } \]

unde \(c_r\) este coeficientul de siguranță asociat rezistenței de rupere.

Definiție

Coeficientul de siguranță

Coeficient de siguranță

Factorul prin care o valoare-limită caracteristică materialului este redusă pentru stabilirea valorii admisibile folosite în calcul.

\[ \boxed{ c>1 } \]

în situațiile obișnuite descrise de această definiție.

Alegerea coeficientului

Factorii menționați de Bunget

Compendiul precizează că valorile coeficienților de siguranță depind de condițiile concrete în care funcționează piesa.

omogenitatea materialului;

natura solicitării;

temperatura;

durata solicitării;

condițiile de funcționare.

Ediția Compendiului face referire la valorile prevăzute în standardele tehnice ale epocii.

Figura I.7.8 a

Bară solicitată la întindere

Pentru ilustrarea modului de dimensionare, Bunget consideră o bară încastrată, de lungime \(l\), solicitată axial printr-o forță \(F\).

Se urmărește determinarea secțiunii necesare astfel încât bara să reziste solicitării.

Efort unitar

Condiția de rezistență

Pentru o bară de secțiune constantă \(S\), neglijând pentru moment greutatea proprie:

\[ \boxed{ \sigma = \frac{F}{S} } \]

Pentru ca solicitarea să nu depășească rezistența admisibilă:

\[ \boxed{ \sigma \leq \sigma_a } \]
Dimensionare

Secțiunea necesară

La dimensionarea-limită:

\[ \frac{F}{S_{\mathrm{nec}}} = \sigma_a. \]

Prin urmare:

\[ \boxed{ S_{\mathrm{nec}} = \frac{F}{\sigma_a} } \]
Al doilea caz

Bară verticală de lungime mare

Pentru o bară verticală suficient de lungă, Bunget arată că nu mai poate fi neglijată greutatea proprie.

Bara este supusă simultan:

forței exterioare \(F\);

greutății proprii a porțiunilor aflate sub secțiunea analizată.

Secțiune oarecare

Secțiunea aflată la distanța \(x\)

Se consideră o secțiune transversală aflată la distanța \(x\) de capătul inferior al barei.

Dacă bara are secțiunea constantă \(S\) și densitatea \(\rho\), masa porțiunii de lungime \(x\) este:

\[ m_x = \rho Sx. \]
Greutatea proprie

Greutatea porțiunii inferioare

Greutatea porțiunii de bară situate sub secțiunea considerată este:

\[ \boxed{ G_x = \rho g x S } \]
Solicitarea secțiunii

Forța totală transmisă prin secțiune

Secțiunea trebuie să suporte atât forța exterioară \(F\), cât și greutatea porțiunii inferioare.

\[ \boxed{ N(x) = F+\rho gxS } \]
Efort unitar

Variația în lungul barei

Efortul unitar în secțiunea respectivă este:

\[ \sigma_x = \frac{ F+\rho gxS }{ S }. \]

Deci:

\[ \boxed{ \sigma_x = \frac FS + \rho gx } \]
Consecință

Efortul crește liniar de jos în sus

Pentru bara cu secțiune constantă, relația:

\[ \sigma_x = \frac FS + \rho gx \]

arată că efortul unitar crește liniar cu distanța \(x\).

\[ \boxed{ \sigma_x \sim x } \]
Capătul inferior

Efortul minim

Pentru:

\[ x=0, \]

rezultă:

\[ \boxed{ \sigma_{\min} = \frac FS } \]
Capătul superior

Efortul maxim

La capătul superior:

\[ x=l. \]

Prin urmare:

\[ \boxed{ \sigma_{\max} = \frac FS + \rho gl } \]
Figura I.7.8

Secțiunea periculoasă

Deoarece efortul unitar este maxim la capătul superior al barei, Bunget identifică secțiunea de acolo drept:

Secțiune periculoasă

Secțiunea în care solicitarea atinge valoarea maximă și în care condiția de rezistență trebuie verificată cu prioritate.

În figura Compendiului, aceasta este secțiunea \(BB'\).

Condiția de rezistență

Dimensionarea barei verticale

Pentru ca bara să reziste:

\[ \boxed{ \sigma_{\max} \leq \sigma_a } \]

La dimensionarea-limită:

\[ \frac{F}{S_{\mathrm{nec}}} + \rho gl = \sigma_a. \]
Rezultatul dimensionării

Secțiunea necesară când contează greutatea proprie

Din relația precedentă rezultă:

\[ \boxed{ S_{\mathrm{nec}} = \frac{ F }{ \sigma_a-\rho gl } } \]

Secțiunea necesară crește odată cu lungimea barei.

Consecință

Limita impusă de greutatea proprie

Relația de dimensionare conține diferența:

\[ \sigma_a-\rho gl. \]

Dacă lungimea crește, această diferență devine din ce în ce mai mică.

În cazul-limită:

\[ \boxed{ \rho gl = \sigma_a } \]

formula ar necesita o secțiune infinit de mare.

Interpretare fizică

Bara se poate rupe sub propria greutate

Compendiul atrage atenția că pentru lungimi suficient de mari, contribuția greutății proprii poate atinge singură nivelul rezistenței admisibile.

\[ \boxed{ \rho gl \rightarrow \sigma_a } \]

Rezultă că o bară foarte lungă poate ajunge într-o situație critică numai datorită propriei greutăți.

Utilizarea materialului

De ce secțiunea constantă este neeconomică

La bara verticală de secțiune constantă, efortul unitar nu este același în toate secțiunile.

Secțiunea superioară este cea mai solicitată, iar secțiunile inferioare sunt solicitate mai puțin.

\[ \sigma_{\min} < \sigma_x < \sigma_{\max} \]

Materialul nu este, prin urmare, utilizat uniform pe întreaga lungime.

Soluția teoretică

Bară cu secțiune variabilă

Pentru o utilizare mai bună a materialului, Compendiul propune o bară a cărei secțiune transversală crește de la capătul inferior către cel superior.

\[ \boxed{ S(x) \text{ crește cu }x } \]
Definiție

Bara de egală rezistență la întindere

Bară de egală rezistență

Bară cu secțiune variabilă, dimensionată astfel încât solicitarea să fie repartizată mai uniform pe lungimea ei.

Compendiul precizează că variația optimă a secțiunii este de tip exponențial.

\[ \boxed{ S(x) \sim e^{kx} } \]
Precizare asupra sursei

Formula tipărită pentru bara de egală rezistență

Relația exponențială din scanul/transcrierea disponibilă este deteriorată. Din textul sursei se poate stabili sigur faptul că secțiunea barei de egală rezistență variază exponențial. Forma exactă este reconstruită separat în secțiunea „Titularizare”, prin calcul.
Limită practică

Forma continuu variabilă este greu de realizat

Bunget observă că o bară cu secțiune variabilă continuu, după legea exponențială, este dificil de executat.

Din acest motiv, soluția practică descrisă în Compendiu utilizează secțiuni care se modifică în trepte.

Titularizare

Precizări pentru examen

Această secțiune este separată de corpul §7.5 al Compendiului. Reperul oficial utilizat este programa Titularizare Fizică 2026.

Statut în programa 2026

„Rezistența admisibilă” și „coeficientul de siguranță” nu sunt enumerate ca teme științifice autonome.

Punctul 9 cere explicit:

Deformări elastice izotrope. Legea lui Hooke. Energia potențială elastică.

§7.5 completează util această zonă, dar are prioritate mai mică decât §7.3 pentru cerința explicită din programă.

Notație actuală utilă: rezistența admisibilă se notează frecvent: \[ \boxed{ \sigma_{\mathrm{adm}} } \] pentru tensiuni normale, și: \[ \boxed{ \tau_{\mathrm{adm}} } \] pentru tensiuni tangențiale.
Unitatea SI: rezistența admisibilă are aceeași unitate ca tensiunea mecanică: \[ \boxed{ [\sigma_{\mathrm{adm}}] = \mathrm{Pa} } \] În practică apar frecvent: \[ \mathrm{MPa}. \]
Nu confunda termenul „rezistență admisibilă” cu rezistența electrică. Aici este vorba despre o tensiune mecanică admisibilă, cu dimensiunea: \[ \boxed{ \mathrm{\frac{N}{m^2}} } \]
Condiția generală de verificare: \[ \boxed{ \sigma_{\mathrm{ef}} \leq \sigma_{\mathrm{adm}} } \] unde \(\sigma_{\mathrm{ef}}\) este tensiunea mecanică efectivă calculată în secțiunea verificată.
Dimensionarea: dacă bara este solicitată axial uniform și greutatea proprie poate fi neglijată: \[ \sigma = \frac FS. \] La limită: \[ \sigma = \sigma_{\mathrm{adm}}, \] deci: \[ \boxed{ S_{\mathrm{nec}} = \frac{ F }{ \sigma_{\mathrm{adm}} } } \]
Verificare versus dimensionare: sunt două sarcini diferite.

Dacă \(S\) este cunoscut, faci: verificarea \[ \sigma = \frac FS \leq \sigma_{\mathrm{adm}}. \]

Dacă \(S\) este necunoscut, faci: dimensionarea \[ S_{\mathrm{nec}} = \frac F{ \sigma_{\mathrm{adm}} }. \]
Coeficientul de siguranță: nu folosi o valoare numerică inventată. Dacă problema oferă coeficientul \(c\) și o tensiune-limită \(\sigma_{\mathrm{lim}}\), relația de tipul: \[ \boxed{ \sigma_{\mathrm{adm}} = \frac{ \sigma_{\mathrm{lim}} }{ c } } \] trebuie aplicată folosind exact criteriul specificat în problemă.
Valorile standardizate menționate de Bunget: trimit la standardele tehnice ale epocii Compendiului. Pentru o problemă actuală de proiectare tehnică, nu folosi automat acele valori istorice. Se utilizează normele actuale aplicabile problemei concrete.
Greutatea proprie a barei verticale: pentru secțiune constantă: \[ \boxed{ \sigma(x) = \frac FS + \rho gx } \] unde:

\(\rho\) — densitatea materialului, \[ [\rho] = \mathrm{kg/m^3}; \]
\(g\) — accelerația gravitațională, \[ [g] = \mathrm{m/s^2}; \]
\(x\) — distanța măsurată de la capătul inferior.
Verificare dimensională: \[ [\rho gx] = \frac{\mathrm{kg}}{\mathrm{m^3}} \cdot \frac{\mathrm m}{\mathrm{s^2}} \cdot \mathrm m \] \[ = \frac{ \mathrm{kg} }{ \mathrm{m\,s^2} } \] \[ = \boxed{ \mathrm{Pa} } \] deci termenul \(\rho gx\) poate fi adunat corect cu \(F/S\).
Secțiunea cea mai solicitată: pentru bara verticală suspendată de capătul superior și încărcată la capătul inferior: \[ \boxed{ x=l } \] și: \[ \boxed{ \sigma_{\max} = \frac FS + \rho gl } \]
Greșeală frecventă: greutatea întregii bare nu trebuie adăugată în orice secțiune. O secțiune aflată la poziția \(x\) suportă numai greutatea porțiunii de bară aflate sub ea, în configurația analizată.
La capătul superior: secțiunea suportă întreaga greutate a barei: \[ G_{\mathrm{bară}} = \rho Slg. \] Astfel: \[ \sigma_{\max} = \frac{ F+\rho Slg }{ S }. \] Prin simplificare: \[ \boxed{ \sigma_{\max} = \frac FS + \rho gl } \]
Dimensionarea cu greutate proprie: din condiția: \[ \frac FS + \rho gl \leq \sigma_{\mathrm{adm}}, \] rezultă: \[ \boxed{ S \geq \frac{ F }{ \sigma_{\mathrm{adm}} - \rho gl } } \] cu condiția: \[ \boxed{ \sigma_{\mathrm{adm}} - \rho gl > 0 } \]
Condiția de existență a soluției: \[ \sigma_{\mathrm{adm}} > \rho gl. \] Dacă: \[ \rho gl \geq \sigma_{\mathrm{adm}}, \] simpla creștere a unei secțiuni constante nu mai rezolvă modelul de dimensionare prezentat.
Bara de egală rezistență — reconstrucție modernă a relației: impunem ca tensiunea să fie aceeași în fiecare secțiune: \[ \boxed{ \sigma(x) = \sigma_{\mathrm{adm}} } \]
Dacă \(N(x)\) este forța axială: \[ N(x) = \sigma_{\mathrm{adm}} S(x). \] Greutatea elementului \(dx\) produce creșterea: \[ dN = \rho gS(x)\,dx. \] Deci: \[ \sigma_{\mathrm{adm}} dS = \rho gS\,dx. \]
Separând variabilele: \[ \frac{dS}{S} = \frac{ \rho g }{ \sigma_{\mathrm{adm}} } dx. \] Prin integrare: \[ \ln \frac{S(x)}{S_0} = \frac{ \rho gx }{ \sigma_{\mathrm{adm}} }. \]
Rezultă variația exponențială: \[ \boxed{ S(x) = S_0 e^{ \frac{ \rho gx }{ \sigma_{\mathrm{adm}} } } } \] iar la capătul inferior: \[ S_0 = \frac{ F }{ \sigma_{\mathrm{adm}} }. \] Prin urmare: \[ \boxed{ S(x) = \frac{ F }{ \sigma_{\mathrm{adm}} } e^{ \frac{ \rho gx }{ \sigma_{\mathrm{adm}} } } } \]
Delimitare de sursă: Compendiul afirmă explicit că legea variației secțiunii este exponențială. Forma de mai sus a fost reconstruită prin calcul deoarece formula tipărită este deteriorată în transcrierea disponibilă.
Sens fizic: bara trebuie să fie mai groasă spre partea superioară deoarece fiecare secțiune superioară susține atât sarcina exterioară, cât și o cantitate mai mare din greutatea proprie a barei.
Schema pentru probleme:

1. identifici solicitarea;
2. alegi secțiunea periculoasă;
3. determini forța interioară \(N\);
4. calculezi: \[ \sigma = \frac NS; \]
5. stabilești rezistența admisibilă;
6. impui: \[ \sigma_{\max} \leq \sigma_{\mathrm{adm}}; \]
7. dimensionezi sau verifici secțiunea;
8. verifici unitățile și condițiile de aplicare.
Prioritate pentru Titularizare: din capitolul 7, pentru cerința explicită a programei trebuie stăpânite înainte de toate: \[ \boxed{ \sigma = \frac FS } \] \[ \boxed{ \varepsilon = \frac{\Delta l}{l_0} } \] \[ \boxed{ \sigma = E\varepsilon } \] și: \[ \boxed{ E_{p,\mathrm{el}} = \frac12kx^2 } \] Rezistența admisibilă și dimensionarea barelor sunt o extensie utilă, dar nu sunt formulate ca punct separat în programa 2026.
