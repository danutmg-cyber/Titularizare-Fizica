12.6 Surse sonore

Coarde vibrante, moduri proprii și armonice, influența punctului de excitare, tuburi sonore, rezonanța coloanei de aer, tuburi deschise și închise și corecția de capăt.

Ion Bunget Compendiu de Fizică §12.6

12.6 Surse sonore

Pagini: 254–257.
§12.7 Ultrasunetele începe la p. 258.
Ideea centrală

Corpul care vibrează ca sursă sonoră

Compendiul pornește de la corpurile materiale puse în vibrație, care generează unde elastice în mediul din jur. Sunt amintite coardele, tuburile sonore, vergile, diapazoanele, membranele și plăcile.

a) Coarde

Unde staționare pe coarda fixată la capete

Reflexiile succesive la cele două capete produc unde staționare, cu noduri în punctele de fixare.

\[ \boxed{ l = n\frac{\lambda_n}{2}, \qquad n=1,2,3,\ldots } \]
\[ \boxed{ \lambda_n = \frac{2l}{n} } \]
\[ \boxed{ \nu_n = n\frac{v}{2l} } \]
Relația (12.7)

Fundamentală și armonice

Fundamentală

\[ \boxed{ \nu_1 = \frac{v}{2l} } \]

Armonica a doua

\[ \nu_2 = 2\nu_1 \]

Armonica a treia

\[ \nu_3 = 3\nu_1 \]

Bunget leagă și timbrul de intensitățile relative ale acestor componente. Poziția în care coarda este ciupită modifică armonicele excitate.

Punctul de excitare

Unele armonice pot lipsi

Coarda ciupită la mijloc

Armonicele pare sunt suprimate în modelul descris.

Coarda ciupită la o treime

Modurile cu \(n=3,6,9,\ldots\) nu sunt excitate.

b) Tuburi sonore

Coloana de aer și rezonanța

Tubul sonor conține o sursă de vibrații și o coloană de aer care selectează prin rezonanță anumite frecvențe. Compendiul ilustrează fenomenul și cu o coloană de aer de lungime variabilă, excitată de un diapazon.

Un capăt închis

Condiția de rezonanță

\[ \boxed{ l = (2n+1) \frac{\lambda}{4}, \qquad n=0,1,2,\ldots } \]

În modelul sursei, la capătul închis apare un nod de deplasare, iar la capătul deschis un ventru.

Relația (12.8)

Tub deschis la ambele capete

\[ \boxed{ l = n\frac{\lambda_n}{2}, \qquad n=1,2,3,\ldots } \]
\[ \boxed{ \nu_n = n\frac{v}{2l} } \]

Fundamentală:

\[ \boxed{ \nu_1 = \frac{v}{2l} } \]
Relația (12.9)

Tub închis la un capăt

\[ \boxed{ l = (2n+1) \frac{\lambda_n}{4}, \qquad n=0,1,2,\ldots } \]
\[ \boxed{ \nu_n = (2n+1) \frac{v}{4l} } \]

Fundamentală:

\[ \boxed{ \nu_0 = \frac{v}{4l} } \]

Față de un tub deschis de aceeași lungime, frecvența fundamentală este în modelul ideal de două ori mai mică.

Corecția de capăt

Lungimea acustică diferă de lungimea geometrică

Compendiul arată că reflexia la capăt nu se produce exact în planul geometric al deschiderii. Pentru modelul citat al unui tub deschis circular introduce:

\[ \boxed{ \Delta l = 0{,}41d } \]
\[ \boxed{ l' = l+\Delta l } \]
Alte surse

Vergi, diapazoane, membrane și plăci

Bunget încheie §12.6 observând că aceste sisteme au moduri de vibrație mai complicate, fără a le dezvolta matematic în acest paragraf.

Sinteză

De reținut din §12.6

Coardă fix–fix

\[ \boxed{ \nu_n = n\frac{v}{2l} } \]

Tub deschis–deschis

\[ \boxed{ \nu_n = n\frac{v}{2l} } \]

Tub închis–deschis

\[ \boxed{ \nu_n = (2n+1) \frac{v}{4l} } \]

Rezonanță

Sunt amplificate numai modurile compatibile cu condițiile la limită.

Titularizare

Precizări pentru examen

Această secțiune este separată de corpul §12.6 al Compendiului. Reperul oficial utilizat este programa Titularizare Fizică 2026.

Statut în programa 2026

„Sursele sonore”, coardele muzicale și tuburile sonore nu sunt enumerate ca teme științifice autonome.

Conținutul este însă direct legat de:

punctul 10 — oscilatorul armonic, oscilații forțate, rezonanță și factor de calitate;

și de:

punctul 11 — unde elastice plane în medii omogene și izotrope, unde longitudinale și transversale, viteza undelor și ecuația undei plane.

Coarda ideală: viteza undelor transversale este: \[ \boxed{ v = \sqrt{ \frac{F_T}{\mu} } } \] unde: \[ F_T = \text{tensiunea mecanică} \] și: \[ \mu = \frac{m}{l} \] este densitatea liniară.
Unități SI: \[ [F_T] = \mathrm N, \] \[ [\mu] = \mathrm{kg/m}, \] \[ [v] = \mathrm{m/s}. \]
Verificarea dimensională: \[ \left[ \frac{F_T}{\mu} \right] = \frac{ \mathrm{kg\,m/s^2} }{ \mathrm{kg/m} } \] \[ = \frac{ \mathrm{m^2} }{ \mathrm{s^2} }. \] Prin urmare: \[ \left[ \sqrt{ \frac{F_T}{\mu} } \right] = \mathrm{m/s}. \]
Pentru coarda fixată la ambele capete: condițiile la limită sunt: \[ \boxed{ y(0,t)=0 } \] și: \[ \boxed{ y(l,t)=0 } \] deoarece capetele nu se pot deplasa transversal.
Aceste condiții conduc la: \[ \boxed{ k_n = \frac{n\pi}{l} } \] și: \[ \boxed{ \lambda_n = \frac{2l}{n} } \]
Frecvențele proprii: \[ \nu_n = \frac{v}{\lambda_n}. \] Deci: \[ \boxed{ \nu_n = n\frac{v}{2l} } \] iar cu viteza pe coardă: \[ \boxed{ \nu_n = \frac{n}{2l} \sqrt{ \frac{F_T}{\mu} } } \]
Fundamentală: \[ \boxed{ \nu_1 = \frac{1}{2l} \sqrt{ \frac{F_T}{\mu} } } \]
Cum modifici înălțimea sunetului unei corzi? Din relație rezultă: \[ \boxed{ \nu \propto \frac{1}{l} } \] \[ \boxed{ \nu \propto \sqrt{F_T} } \] \[ \boxed{ \nu \propto \frac{1}{\sqrt{\mu}} } \]
Deci: coardă mai scurtă \(\Rightarrow\) frecvență mai mare;

tensiune mai mare \(\Rightarrow\) frecvență mai mare;

densitate liniară mai mare \(\Rightarrow\) frecvență mai mică.
De ce contează locul în care ciupești coarda? Modul propriu \(n\) are dependență spațială de forma: \[ \boxed{ X_n(x) \propto \sin \left( \frac{n\pi x}{l} \right) } \]
Dacă punctul de excitare coincide cu un nod al unui anumit mod, acel mod este slab excitat sau poate lipsi în modelul ideal.
La mijlocul corzii: \[ x = \frac{l}{2}. \] Pentru armonicele pare: \[ n=2m, \] avem: \[ \sin \left( \frac{ 2m\pi }{ 2 } \right) = \sin(m\pi) = 0. \] Deci: \[ \boxed{ \text{modurile pare nu sunt excitate ideal} } \]
Într-un instrument real, coarda nu este perfect flexibilă, excitarea nu este punctuală, amortizarea nu este nulă, iar corpul instrumentului interacționează cu coarda. Relațiile Bunget sunt un model idealizat.
Rezonanța: o oscilație forțată are amplitudine mare când frecvența excitatoare se află în apropierea unei frecvențe proprii a sistemului. Schema este: \[ \boxed{ \nu_{\mathrm{exc}} \approx \nu_{\mathrm{proprie}} \Rightarrow \text{rezonanță} } \]
Nu spune că tubul „creează” frecvențele. Sursa poate furniza un spectru de frecvențe, iar rezonatorul amplifică selectiv componentele apropiate de modurile sale proprii.
Atenție la mărimea care formează nodul: într-o coloană de aer trebuie diferențiate:

deplasarea / viteza particulelor aerului;
variația presiunii acustice.
Capăt închis ideal: particulele nu pot oscila longitudinal prin perete. Pentru deplasare: \[ \boxed{ \text{nod} } \] Pentru presiune: \[ \boxed{ \text{ventru} } \]
Capăt deschis ideal: pentru deplasare: \[ \boxed{ \text{ventru} } \] iar pentru variația de presiune: \[ \boxed{ \text{nod} } \]
Eroare foarte frecventă: „la capătul închis avem întotdeauna nod”. Incomplet. Trebuie precizat pentru ce mărime:

nod de deplasare;
ventru de presiune.
Tub deschis la ambele capete: pentru deplasarea aerului avem ventre la ambele capete. Condiția ideală este: \[ \boxed{ l = n \frac{\lambda_n}{2} } \]
De aici: \[ \boxed{ \lambda_n = \frac{2l}{n} } \] și: \[ \boxed{ \nu_n = n\frac{v}{2l} } \]
Seria armonică: \[ \boxed{ \nu_1, \ 2\nu_1, \ 3\nu_1, \ 4\nu_1, \ldots } \] în modelul ideal.
Tub închis la un capăt: deplasarea are:

nod la capătul închis;
ventru la capătul deschis. Condiția este: \[ \boxed{ l = (2n+1) \frac{\lambda_n}{4} } \]
Rezultă: \[ \boxed{ \lambda_n = \frac{ 4l }{ 2n+1 } } \] și: \[ \boxed{ \nu_n = (2n+1) \frac{v}{4l} } \]
Frecvențele ideale sunt: \[ \boxed{ \nu_0, \ 3\nu_0, \ 5\nu_0, \ 7\nu_0, \ldots } \] adică apar numai armonicile impare ale fundamentalei în modelul ideal închis–deschis.
Comparație pentru aceeași lungime \(l\): tub deschis: \[ \nu_{\mathrm{deschis}} = \frac{v}{2l}; \] tub închis: \[ \nu_{\mathrm{închis}} = \frac{v}{4l}. \] Prin urmare: \[ \boxed{ \nu_{\mathrm{închis}} = \frac{1}{2} \nu_{\mathrm{deschis}} } \]
Corecția de capăt: nodul sau ventrul ideal nu este localizat exact în planul geometric al deschiderii. De aceea se folosește o lungime efectivă: \[ \boxed{ l_{\mathrm{ef}} = l+\Delta l } \]
Valoarea: \[ \Delta l = 0{,}41d \] este cea menționată de Compendiu pentru configurația discutată. Nu o trata ca pe o constantă universală. Corecția reală depinde de geometria capătului, de flanșare, de raza tubului și de configurația experimentală.
Dacă: \[ l_{\mathrm{ef}}>l, \] atunci pentru fundamentală: \[ \nu = \frac{v}{ 2l_{\mathrm{ef}} } \] este mai mică decât valoarea calculată cu lungimea geometrică.
În tuburile cu aer: \[ v = v_{\mathrm{sunet}} \] și depinde de proprietățile gazului, în special de temperatură.
Afirmația istorică potrivit căreia frecvența ar depinde numai de lungimea tubului este o aproximație pentru tubul ideal. Într-un sistem real contează și:

viteza sunetului;
temperatura;
geometria capetelor;
corecția de capăt;
pierderile;
diametrul, dacă aproximația de tub subțire nu mai este suficientă.
Schema pentru probleme cu o coardă:

1. datele în SI;
2. identifică: \[ l,\quad F_T,\quad \mu; \]
3. calculează: \[ v = \sqrt{ \frac{F_T}{\mu} }; \]
4. stabilește modul \(n\);
5. folosește: \[ \nu_n = n \frac{v}{2l}; \]
6. verifică unitățile și sensul variațiilor.
Schema pentru probleme cu tuburi:

1. identifică tipul capetelor;
2. stabilește nodurile și ventrele;
3. scrie condiția geometrică;
4. determină \(\lambda\);
5. folosește: \[ \boxed{ v=\lambda\nu } \]
6. aplică o corecție de capăt numai dacă problema o cere sau o definește.
Activitate experimentală foarte potrivită: rezonanța unei coloane de aer cu lungime variabilă. Elevii pot modifica lungimea coloanei și identifica pozițiile pentru care sunetul este amplificat.
Din două rezonanțe consecutive ale aceluiași tip de coloană ideală, diferența de lungime este: \[ \boxed{ \Delta l = \frac{\lambda}{2} } \] astfel încât: \[ \boxed{ \lambda = 2\Delta l } \]
Dacă frecvența diapazonului este cunoscută: \[ \boxed{ v = 2\nu\Delta l } \] în modelul ideal.
Avantaj didactic: experimentul permite legarea directă dintre: \[ \boxed{ \text{rezonanță} \leftrightarrow \text{undă staționară} \leftrightarrow \lambda \leftrightarrow v } \]
Șase erori de evitat:

1. folosirea: \[ \nu_n = n\frac{v}{2l} \] pentru orice tub;

2. afirmarea că un tub închis–deschis are toate armonicele;

3. confundarea nodului de deplasare cu nodul de presiune;

4. uitarea condițiilor la limită;

5. confundarea vitezei de propagare pe coardă cu viteza de oscilație a punctelor coardei;

6. folosirea corecției \(0{,}41d\) ca relație universală.
Nucleul de memorat: coardă: \[ \boxed{ v = \sqrt{ \frac{F_T}{\mu} } } \] \[ \boxed{ \nu_n = \frac{n}{2l} \sqrt{ \frac{F_T}{\mu} } } \] tub deschis: \[ \boxed{ \nu_n = n\frac{v}{2l} } \] tub închis: \[ \boxed{ \nu_n = (2n+1) \frac{v}{4l} } \] relația undei: \[ \boxed{ v=\lambda\nu } \] lungime efectivă: \[ \boxed{ l_{\mathrm{ef}} = l+\Delta l } \]
Prioritate pentru concurs: nu trata §12.6 ca temă autonomă obligatorie după programa 2026. Pentru examen, partea cu cea mai mare valoare este legătura cu:

oscilațiile forțate și rezonanța;
undele staționare;
viteza de propagare;
relația: \[ v=\lambda\nu; \]
condițiile la limită.
