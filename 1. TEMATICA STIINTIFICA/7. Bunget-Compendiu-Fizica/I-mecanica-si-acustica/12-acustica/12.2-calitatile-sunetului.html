12.2 Calitățile sunetului

Înălțimea sunetului, frecvența fundamentală și armonicele, intensitatea undei sonore, transportul de energie, dependența de amplitudine și frecvență, propagarea sferică și timbrul.

Ion Bunget Compendiu de Fizică §12.2

Compendiu de Fizică

Pagini: 247–248.
§12.3 Perceperea sunetelor începe la p. 249.
Clasificare

Cele trei calități principale

Bunget caracterizează sunetele prin trei calități principale:

1. Înălțimea

legată de frecvență;

2. Intensitatea

legată de energia transportată de undă;

3. Timbrul

permite deosebirea sunetelor produse de surse diferite.

a) Înălțimea

Frecvența și înălțimea sunetului

Înălțimea exprimă caracterul mai grav sau mai acut al unui sunet.

Experimental, Compendiul leagă înălțimea de frecvența oscilațiilor sonore.

\[ \boxed{ \nu\uparrow \Rightarrow \text{sunet mai acut} } \]
\[ \boxed{ \nu\downarrow \Rightarrow \text{sunet mai grav} } \]

Două sunete cu aceeași frecvență sunt considerate de aceeași înălțime.

Spectrul sursei

Sunet fundamental și armonice superioare

Bunget observă că un corp material poate avea mai multe frecvențe proprii de vibrație.

Sunet fundamental

Componenta cu frecvența cea mai mică dintre cele produse de corpul care vibrează.

Armonice superioare

Componente ale căror frecvențe sunt multipli întregi ai frecvenței fundamentale, în situația descrisă de Compendiu.

\[ \boxed{ \nu_n=n\nu_1, \qquad n=1,2,3,\ldots } \]

Sunetele naturale sunt, de regulă, compuse din mai multe componente de frecvențe diferite.

b) Intensitatea

Energia transportată prin unitatea de suprafață

Bunget definește intensitatea într-un punct prin energia transportată de unda sonoră în unitatea de timp, prin unitatea de suprafață perpendiculară pe direcția de propagare.

Intensitatea sunetului

Puterea transportată de unda sonoră prin unitatea de suprafață perpendiculară pe propagare.

\[ \boxed{ I = \frac{W}{ \Delta S\,T } } \]
Relația (12.3)

Energia traversată într-o perioadă

Compendiul consideră un paralelipiped cu secțiunea transversală \(\Delta S\) și lungimea:

\[ vT. \]

Volumul corespunzător este:

\[ \Delta V = \Delta S\,vT. \]

Dacă \(\overline{w}\) este densitatea medie de energie din §11.7, energia din acest volum este:

\[ \boxed{ W = \overline{w}\, \Delta S\,vT } \]
Relația (12.4)

Intensitatea undei plane

Din definiția intensității:

\[ I = \frac{W}{ \Delta S\,T }, \]

și din relația precedentă, rezultă:

\[ I = \overline{w}\,v. \]

Folosind:

\[ \overline{w} = \frac{1}{2} \rho A^2\omega^2, \]

se obține:

\[ \boxed{ I = \frac{1}{2} \rho vA^2\omega^2 } \]

iar cu:

\[ \omega=2\pi\nu, \]

forma echivalentă este:

\[ \boxed{ I = 2\pi^2 \rho vA^2\nu^2 } \]
Consecințe

De ce depinde intensitatea

Relația arată că intensitatea depinde atât de caracteristicile oscilației, cât și de mediul prin care se propagă unda.

Amplitudine

\[ \boxed{ I\propto A^2 } \]

Frecvență

\[ \boxed{ I\propto\nu^2 } \]

Densitatea mediului

apare prin \(\rho\);

Viteza de propagare

apare prin \(v\).

Propagare sferică

Dependența de distanță

Pentru o undă sferică într-un mediu omogen și fără absorbție, energia transportată se distribuie pe suprafețe sferice din ce în ce mai mari.

Din conservarea fluxului energetic, Compendiul ajunge la:

\[ \boxed{ A(r) = \frac{A_0}{r} } \]

și, deoarece:

\[ I\propto A^2, \]

rezultă:

\[ \boxed{ I(r) = \frac{I_0}{r^2} } \]
Notă asupra sursei: în transcriere apare înaintea demonstrației o propoziție care atribuie amplitudinii o dependență invers proporțională cu pătratul distanței. Formula dedusă imediat în continuare este însă: \[ A=\frac{A_0}{r}, \] iar intensitatea: \[ I\propto\frac{1}{r^2}. \] Am urmat relațiile matematice explicite ale paragrafului.
c) Timbrul

De ce două instrumente nu sună la fel

Două surse pot emite sunete cu aceeași înălțime și aceeași intensitate, dar pot fi deosebite auditiv.

Timbrul

Calitatea prin care sunt diferențiate sunete de aceeași înălțime și intensitate produse de surse diferite.

Bunget leagă timbrul de componentele superioare care însoțesc sunetul fundamental.

\[ \boxed{ \text{sunet} = \text{fundamentală} + \text{componente superioare} } \]

În prezentarea sursei, timbrul depinde de:

numărul componentelor superioare;

frecvențele lor;

intensitățile lor relative.

Compendiul afirmă că diferențele de fază dintre aceste componente nu determină timbrul în modelul prezentat.

Sinteză

De reținut din §12.2

Înălțime

\[ \boxed{ \text{înălțimea} \leftrightarrow \nu } \]

Armonice

\[ \boxed{ \nu_n=n\nu_1 } \]

Intensitate

\[ \boxed{ I = \frac{1}{2} \rho vA^2\omega^2 } \]
\[ \boxed{ I = 2\pi^2 \rho vA^2\nu^2 } \]

Undă sferică

\[ \boxed{ A\propto\frac{1}{r} } \]
\[ \boxed{ I\propto\frac{1}{r^2} } \]

Timbru

Este legat de structura spectrală a sunetului.

Titularizare

Precizări pentru examen

Această secțiune este separată de corpul §12.2 al Compendiului. Reperul oficial utilizat este programa Titularizare Fizică 2026.

Statut în programa 2026

„Calitățile sunetului” nu apar ca temă științifică autonomă.

Legătura directă rămâne punctul 11:

Unde elastice plane în medii omogene și izotrope: unde longitudinale și transversale, viteza undelor. Ecuația undei plane.

§12.2 este o aplicație acustică a formalismului undelor elastice.

1. Înălțimea sunetului: mărimea fizică direct asociată este frecvența fundamentală: \[ \boxed{ [\nu]=\mathrm{Hz} } \] Frecvență mai mare corespunde, în condiții obișnuite, unei percepții mai acute.
Înălțimea percepută și frecvența nu sunt termeni identici. Frecvența este o mărime fizică măsurabilă. Înălțimea este o caracteristică perceptivă, corelată în principal cu frecvența.
2. Intensitatea fizică: \[ \boxed{ I = \frac{P}{S} } \] pentru flux uniform printr-o suprafață perpendiculară pe propagare. Unitatea SI este: \[ \boxed{ [I] = \mathrm{W/m^2} } \]
Pentru unda plană armonică din modelul Compendiului: \[ \boxed{ I = \frac{1}{2} \rho v \omega^2A^2 } \] unde: \[ [\rho] = \mathrm{kg/m^3}, \] \[ [v] = \mathrm{m/s}, \] \[ [A] = \mathrm m. \]
Verificare dimensională: \[ [I] = \frac{\mathrm{kg}}{\mathrm{m^3}} \cdot \frac{\mathrm m}{\mathrm s} \cdot \frac{1}{\mathrm{s^2}} \cdot \mathrm{m^2} \] \[ = \frac{ \mathrm{kg} }{ \mathrm{s^3} } = \boxed{ \mathrm{W/m^2} }. \]
Intensitatea fizică nu este același lucru cu „tăria” percepută. Intensitatea \(I\) este mărime fizică. Senzația auditivă depinde și de frecvență și de sensibilitatea sistemului auditiv. Această distincție este dezvoltată în §12.3.
Dependența de amplitudine: \[ \boxed{ I\propto A^2 } \] Dacă amplitudinea se dublează: \[ A_2=2A_1, \] atunci: \[ \boxed{ I_2=4I_1 } \] pentru celelalte mărimi neschimbate.
Propagare sferică ideală: pentru o sursă care emite aceeași putere acustică \(P\) uniform în toate direcțiile: \[ \boxed{ I(r) = \frac{P}{ 4\pi r^2 } } \] în absența absorbției.
De aici: \[ \boxed{ I\propto\frac{1}{r^2} } \] iar pentru amplitudinea unei unde sferice ideale: \[ \boxed{ A\propto\frac{1}{r} } \]
Nu confunda răspândirea geometrică cu absorbția. Scăderea: \[ I\propto\frac{1}{r^2} \] poate exista chiar într-un mediu fără absorbție. Absorbția introduce o scădere suplimentară prin disiparea energiei în mediu.
3. Timbrul — formulare modernă: timbrul este legat de structura spectrală și temporală a sunetului. Sunt importante:

frecvența fundamentală;
frecvențele componentelor superioare;
amplitudinile lor relative;
evoluția temporală a sunetului.
Precizare modernă față de afirmația istorică din Bunget: nu este sigur să afirmăm în general că fazele componentelor spectrale nu influențează niciodată timbrul. Pentru forme de undă complexe și mai ales pentru fenomene tranzitorii, relațiile de fază pot modifica forma temporală a semnalului și pot avea efect perceptibil.
Sunet pur: idealizat printr-o singură componentă sinusoidală: \[ \boxed{ y(t) = A\sin( \omega t+\varphi ) } \] cu o singură frecvență.
Sunet complex periodic: poate fi reprezentat printr-o sumă de componente armonice: \[ \boxed{ y(t) = \sum_{n} A_n \sin( \omega_n t+\varphi_n ) } \] Aceasta este o formulare modernă pentru ideea spectrală pe care Bunget o descrie prin fundamentală și armonice.
Armonică și componentă spectrală nu sunt întotdeauna sinonime. O armonică are frecvența: \[ \boxed{ \nu_n=n\nu_1 } \] O componentă spectrală poate avea și o frecvență care nu este multiplu întreg al fundamentalei.
Verificare rapidă într-o problemă: dacă: \[ A_2=3A_1, \] pentru același mediu și aceeași frecvență: \[ \frac{I_2}{I_1} = \left( \frac{A_2}{A_1} \right)^2 \] \[ \boxed{ \frac{I_2}{I_1}=9 } \]
Patru erori de evitat:

1. frecvență mare = intensitate mare;

2. intensitatea este proporțională cu amplitudinea;

3. amplitudinea unei unde sferice scade ca \(1/r^2\);

4. timbrul este determinat numai de frecvența fundamentală.
Nucleul de memorat: înălțime: \[ \boxed{ \text{corelată cu }\nu } \] armonice: \[ \boxed{ \nu_n=n\nu_1 } \] intensitate: \[ \boxed{ I = \frac{1}{2} \rho vA^2\omega^2 } \] undă sferică: \[ \boxed{ A\propto\frac{1}{r} } \] \[ \boxed{ I\propto\frac{1}{r^2} } \] timbru: \[ \boxed{ \text{structura spectrală și temporală} } \]
Prioritate pentru concurs: §12.2 nu este o temă autonomă în programa 2026. Pentru pregătirea de Titularizare păstrează prioritatea pe punctul 11:

unde elastice plane;
unde longitudinale și transversale;
viteza undelor;
ecuația undei plane. Relațiile energetice și acustice din §12.2 sunt aprofundări utile.
