12.3 Perceperea sunetelor

Limitele de audibilitate, infrasunete și ultrasunete, pragul de audibilitate, pragul durerii, nivelul intensității sonore, decibelul, condiția de durată, sunete muzicale, zgomote, intervale și scara muzicală.

Percepția auditivă

De la vibrație la senzație

Bunget menționează că vibrațiile sonore, transmise prin ureche, pun în mișcare structurile receptoare ale organului auditiv. Excitația este apoi transmisă prin nervul auditiv.

Limite de frecvență

Domeniul audibil din sursă

\[ \boxed{ 16\,\mathrm{Hz} \lesssim \nu \lesssim 20\,000\,\mathrm{Hz} } \]

Infrasunete

\[ \nu<16\,\mathrm{Hz} \]

Ultrasunete

\[ \nu>20\,000\,\mathrm{Hz} \]

Limitele sunt prezentate ca aproximative și variabile de la persoană la persoană și cu vârsta.

Limite de intensitate

Pragul de audibilitate și pragul durerii

Prag de audibilitate

Intensitatea minimă care produce senzație auditivă.

Prag tactil / prag al durerii

Limita superioară la care senzația auditivă este însoțită de presiune și durere.

Compendiul subliniază că aceste praguri depind de frecvență.

Figura I.12.3

Sensibilitatea urechii nu este uniformă

În prezentarea sursei, sensibilitatea este maximă aproximativ în domeniul:

\[ \boxed{ 1000\,\mathrm{Hz} \text{ – } 3000\,\mathrm{Hz} } \]

Regiunea dintre pragul de audibilitate și pragul durerii formează domeniul intensităților perceptibile.

Distincție

Intensitate fizică și senzație auditivă

Compendiul distinge intensitatea fizică a undei sonore de intensitatea subiectivă a senzației.

\[ \boxed{ \text{intensitate fizică} \neq \text{senzație auditivă} } \]
Legea Weber–Fechner

Dependența logaritmică

Bunget prezintă aproximația psihofizică:

\[ \boxed{ S_2-S_1 = K \log \left( \frac{I_2}{I_1} \right) } \]
Relația (12.5)

Nivelul intensității sonore

Luând drept referință intensitatea \(I_0\), sursa scrie:

\[ \boxed{ S = K \log \left( \frac{I}{I_0} \right) } \]

Valoarea de referință folosită este:

\[ \boxed{ I_0 = 10^{-16} \,\mathrm{W/cm^2} } \]

Pentru scara în decibeli, sursa utilizează factorul \(K=10\).

Exemple din sursă

Raport de intensități și nivel sonor

Intensitate Nivel
\(I=10I_0\) \(10\,\mathrm{dB}\)
\(I=100I_0\) \(20\,\mathrm{dB}\)
\(I\approx10^{14}I_0\) \(\approx140\,\mathrm{dB}\)
A treia condiție

Durata sunetului

Pe lângă frecvență și intensitate, Bunget introduce și o condiție de durată.

\[ \boxed{ \Delta t \approx 10^{-2}\,\mathrm s } \]

Sursa dă ca exemple aproximativ 5 oscilații la \(500\,\mathrm{Hz}\) și 10 oscilații la \(1000\,\mathrm{Hz}\).

Zgomote

Pocnete

asociate unei variații bruște și scurte a presiunii aerului.

Titularizare

Precizări pentru examen

Această secțiune este separată de corpul §12.3 al Compendiului. Reperul curricular utilizat este programa oficială Titularizare Fizică 2026.

Statut în programa 2026

„Perceperea sunetelor” și nivelul sonor în decibeli nu sunt enumerate ca teme științifice autonome.

Legătura directă cu tematica oficială este punctul 11:

unde elastice plane în medii omogene și izotrope, unde longitudinale și transversale, viteza undelor și ecuația undei plane.

Convenția modernă uzuală pentru domeniul auditiv: în manuale se utilizează frecvent aproximativ: \[ \boxed{ 20\,\mathrm{Hz} \text{ – } 20\,\mathrm{kHz} } \] pentru un auz uman tânăr, cu precizarea că limitele diferă între persoane.
Bunget folosește: \[ 16\,\mathrm{Hz} \text{ – } 20\,000\,\mathrm{Hz}. \] Nu trebuie să modificăm retrospectiv textul sursei. Într-o rezolvare actuală, folosește valorile definite în enunț sau convenția cerută de materialul curricular.
Conversia referinței Bunget în SI: \[ I_0 = 10^{-16} \,\mathrm{W/cm^2}. \] Cum: \[ 1\,\mathrm{cm^2} = 10^{-4}\,\mathrm{m^2}, \] rezultă: \[ \boxed{ I_0 = 10^{-12} \,\mathrm{W/m^2} } \]
Notația modernă pentru nivelul intensității: \[ \boxed{ L_I = 10 \log_{10} \left( \frac{I}{I_0} \right) \mathrm{dB} } \] cu: \[ I_0 = 10^{-12} \,\mathrm{W/m^2}. \]
\(I_0\) este o intensitate de referință. Nu trebuie interpretată ca prag auditiv exact pentru orice frecvență. Sensibilitatea urechii depinde puternic de frecvență.
Regula de calcul: dacă: \[ \frac{I_2}{I_1}=10, \] atunci: \[ \boxed{ L_2-L_1 = 10\,\mathrm{dB} } \]
Dacă intensitatea crește de 100 de ori: \[ \frac{I_2}{I_1}=100, \] rezultă: \[ \boxed{ \Delta L = 20\,\mathrm{dB} } \]
Pentru dublarea intensității: \[ \Delta L = 10\log_{10}2 \] \[ \boxed{ \Delta L \approx 3{,}0\,\mathrm{dB} } \]
Decibelii nu se adună direct ca intensitățile. Mai întâi trebuie să lucrezi cu raporturile sau cu intensitățile fizice.
Nivelul presiunii sonore — extensie modernă: pentru presiunea acustică eficace: \[ \boxed{ L_p = 20 \log_{10} \left( \frac{p_{\mathrm{rms}}}{p_0} \right) \mathrm{dB} } \] unde, în aer, se folosește uzual: \[ \boxed{ p_0 = 20\,\mu\mathrm{Pa} } \]
De ce apare 20 și nu 10? Deoarece, în aceleași condiții: \[ I\propto p_{\mathrm{rms}}^2. \] Astfel: \[ 10\log(p^2) = 20\log p. \]
Intensitate fizică și tărie percepută nu sunt aceeași mărime. \[ I \quad [\mathrm{W/m^2}] \] este o mărime fizică. Percepția auditivă este dependentă și de frecvență, durată și caracteristicile sistemului auditiv.
Legea Weber–Fechner din Compendiu este un model psihofizic aproximativ. Nu trebuie prezentată drept o lege exactă universală a auzului. Pentru problemele de fizică, relația logaritmică a nivelului sonor rămâne însă esențială.
Condiția de durată: percepția corectă a înălțimii nu depinde numai de frecvență. Un semnal extrem de scurt nu conține suficient timp pentru o apreciere stabilă a periodicității.
Interval muzical: matematic, acesta este legat de raportul frecvențelor: \[ \boxed{ q = \frac{\nu_2}{\nu_1} } \] De exemplu, octava satisface: \[ \boxed{ \nu_2=2\nu_1 } \]
Precizare modernă privind tabelul Bunget: raporturile precum: \[ \frac{5}{4}, \qquad \frac{3}{2} \] descriu o acordare prin rapoarte simple. În temperamentul egal, semitonurile sunt construite prin raportul constant: \[ \boxed{ 2^{1/12} } \]
După \(n\) semitonuri în temperament egal: \[ \boxed{ \frac{\nu_2}{\nu_1} = 2^{n/12} } \] iar pentru 12 semitonuri: \[ 2^{12/12}=2, \] deci obținem o octavă.
Reper de frecvență: valoarea: \[ \boxed{ 440\,\mathrm{Hz} } \] pentru nota „la” este utilă ca reper de acordaj și apare și în Compendiu.
Tip de exercițiu foarte probabil ca metodă: dacă sunt date două intensități: \[ I_1,\qquad I_2, \] nu calcula separat nivelurile dacă nu este necesar. Folosește direct: \[ \boxed{ \Delta L = 10 \log_{10} \left( \frac{I_2}{I_1} \right) } \]
Verificare dimensională: argumentul logaritmului trebuie să fie adimensional: \[ \boxed{ \frac{I}{I_0} } \] este un raport între două intensități exprimate în aceleași unități.
Cinci erori de evitat:

1. confundarea intensității \(I\) cu nivelul \(L_I\);

2. exprimarea intensității în decibeli;

3. folosirea logaritmului fără raportul \(I/I_0\);

4. afirmația că urechea are aceeași sensibilitate la toate frecvențele;

5. prezentarea limitelor 16 Hz sau 20 Hz ca prag biologic universal și exact.
Nucleul de memorat: intensitate de referință: \[ \boxed{ I_0 = 10^{-12} \,\mathrm{W/m^2} } \] nivel de intensitate: \[ \boxed{ L_I = 10 \log_{10} \left( \frac{I}{I_0} \right) \mathrm{dB} } \] diferență de nivel: \[ \boxed{ \Delta L = 10 \log_{10} \left( \frac{I_2}{I_1} \right) } \] octavă: \[ \boxed{ \frac{\nu_2}{\nu_1}=2 } \]
Prioritate pentru concurs: §12.3 este conținut de aprofundare acustică. Programa oficială 2026 nu nominalizează separat perceperea sunetelor sau scara decibelilor. Pentru această zonă, prioritatea curriculară rămâne punctul 11 despre undele elastice.
Titularizare 2027: această încadrare este făcută pe baza programei oficiale 2026. Programa oficială 2027 trebuie reverificată după publicare.
