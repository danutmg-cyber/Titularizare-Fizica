12.5 Interferența sunetelor

Interferența undelor sonore, diferența de drum, maxime și minime de intensitate, aparatul lui Quincke, determinarea lungimii de undă, tubul lui Kundt, unde staționare și determinarea vitezei sunetului.

Fenomen ondulatoriu

Interferența undelor sonore

Bunget aplică sunetelor fenomenul de interferență discutat anterior pentru undele elastice.

Dacă două unde sonore ajung în același punct după ce au parcurs drumuri diferite, amplitudinea rezultantă depinde de diferența dintre aceste drumuri.

\[ \boxed{ \Delta d = |d_1-d_2| } \]
Figura I.12.4

Aparatul lui Quincke

Pentru evidențierea interferenței, Compendiul prezintă un aparat format din două ramuri tubulare în formă de U.

Una dintre părți poate culisa, astfel încât lungimea unuia dintre drumurile parcurse de sunet poate fi modificată.

Sunetul produs în pâlnia \(S\) ajunge la observatorul \(O\) pe două căi:

\[ SAO \qquad\text{și}\qquad SBO. \]

În punctul \(O\), cele două unde se suprapun.

Interferență constructivă

Condiția de maxim

Dacă diferența de drum este egală cu un număr par de semiunde, amplitudinea rezultantă este maximă.

\[ |d_1-d_2| = 2k \frac{\lambda}{2}. \]

Echivalent:

\[ \boxed{ |d_1-d_2| = k\lambda } \]

În această situație, intensitatea sunetului perceput de observator este maximă.

Interferență destructivă

Condiția de minim

Dacă diferența de drum este un număr impar de semiunde, amplitudinea rezultantă este minimă.

\[ \boxed{ |d_1-d_2| = (2k+1) \frac{\lambda}{2} } \]

Intensitatea percepută este atunci minimă.

\[ \boxed{ \text{maxim} \longleftrightarrow \text{sunet mai intens} } \]
\[ \boxed{ \text{minim} \longleftrightarrow \text{sunet mai slab} } \]
Observație experimentală

Alternanța maximelor și minimelor

Prin deplasarea părții mobile a aparatului lui Quincke, diferența dintre cele două drumuri se modifică.

Observatorul aude alternativ un sunet mai intens și unul mai slab.

\[ \boxed{ \Delta d \text{ variabil} \Rightarrow I_{\max}, I_{\min}, I_{\max}, \ldots } \]
Determinare experimentală

Lungimea de undă cu aparatul lui Quincke

Aparatul poate fi folosit pentru determinarea lungimii de undă.

Se măsoară deplasarea \(x\) a părții mobile dintre două poziții succesive pentru care intensitatea este maximă.

Deoarece deplasarea modifică două porțiuni ale drumului sonor, variația diferenței de drum este:

\[ \Delta(\Delta d) = 2x. \]

Două maxime succesive corespund unei variații a diferenței de drum cu o lungime de undă.

\[ \boxed{ \lambda=2x } \]
În transcrierea OCR, simbolul deplasării apare neuniform. În această pagină folosim consecvent \(x\), păstrând relația explicită a sursei: \[ \lambda=2x. \]
Figura I.12.5

Tubul lui Kundt

A doua experiență prezentată de Bunget folosește interferența undei sonore directe cu unda reflectată.

În acest fel se formează unde staționare.

Dispozitivul conține:

un tub \(AB\);

un piston mobil \(C\);

o cameră \(CD\) cu pulbere fină de plută;

o vergea metalică \(DE\), fixată la mijloc;

un disc aflat la capătul vergelei.

Excitarea vibrațiilor

Vibrațiile longitudinale ale vergelei

Prin frecarea longitudinală a vergelei, aceasta este pusă în vibrație.

În vergea se stabilește o undă staționară, cu un nod în punctul de fixare și ventre la capete, în configurația descrisă de Compendiu.

Discul de la capăt transmite apoi vibrațiile aerului sau gazului din tub.

Unda din tub

Unda directă și unda reflectată

Unda sonoră produsă de discul \(D\) se propagă spre pistonul \(C\).

La piston, unda se reflectă și se întoarce.

Pentru o lungime potrivită a camerei, unda directă și cea reflectată formează o undă staționară.

\[ \boxed{ \text{undă directă} + \text{undă reflectată} \Rightarrow \text{undă staționară} } \]
Evidențierea nodurilor

Rolul pulberii de plută

Pulberea fină face vizibilă distribuția undei staționare.

În descrierea Compendiului, pulberea este îndepărtată din regiunile de ventru și se acumulează în noduri.

\[ \boxed{ \text{pulbere acumulată} \longrightarrow \text{noduri} } \]

Distanța dintre două noduri consecutive este:

\[ \boxed{ l_g = \frac{\lambda_g}{2} } \]
Relația (12.6)

Compararea vitezelor în vergea și în gaz

Simbolurile relației (12.6) sunt puternic degradate în OCR. Pentru transcriere clară, folosim indicii:

\(s\) — solid / vergea;
\(g\) — gaz.

Vergeaua fixată la mijloc are, în configurația sursei:

\[ l = \frac{\lambda_s}{2}. \]

Cum:

\[ \lambda_s=v_sT, \]

rezultă:

\[ \boxed{ l = \frac{v_sT}{2} } \]

Pentru gaz, distanța \(l_g\) dintre două noduri consecutive este:

\[ l_g = \frac{\lambda_g}{2} = \frac{v_gT}{2}. \]

Perioada este aceeași, deoarece oscilația gazului este produsă de vergea.

Făcând raportul:

\[ \boxed{ \frac{v_s}{v_g} = \frac{l}{l_g} } \]

Astfel, dacă una dintre viteze este cunoscută, cealaltă poate fi determinată prin măsurarea lungimilor.

Sinteză

De reținut din §12.5

Minim de interferență

\[ \boxed{ \Delta d = (2k+1) \frac{\lambda}{2} } \]

Aparatul lui Quincke

\[ \boxed{ \lambda=2x } \]

Undă staționară

Apare prin interferența undei directe cu unda reflectată.

Noduri consecutive

\[ \boxed{ l_g = \frac{\lambda_g}{2} } \]

Tubul lui Kundt

\[ \boxed{ \frac{v_s}{v_g} = \frac{l}{l_g} } \]
Titularizare

Precizări pentru examen

Această secțiune este separată de corpul §12.5 al Compendiului. Reperul oficial utilizat este programa Titularizare Fizică 2026.

Statut în programa 2026

Interferența sunetelor și tuburile Quincke/Kundt nu sunt nominalizate ca teme științifice autonome.

Legătura directă este cu punctul 11:

Unde elastice plane în medii omogene și izotrope: unde longitudinale și transversale, viteza undelor. Ecuația undei plane.

§12.5 este o aplicație experimentală foarte utilă a interferenței, reflexiei și undelor staționare.

Diferența de drum: \[ \boxed{ \delta = |d_1-d_2| } \] cu: \[ [\delta] = \mathrm m. \]
Pentru două unde coerente emise în fază: maxim: \[ \boxed{ \delta=k\lambda } \] minim: \[ \boxed{ \delta = (2k+1) \frac{\lambda}{2} } \] unde: \[ k=0,1,2,\ldots \]
Condițiile de mai sus presupun că sursele sunt în fază. Dacă există o diferență de fază inițială \(\Delta\varphi_0\), trebuie utilizată diferența totală de fază.
Relația generală dintre diferența de drum și fază: \[ \boxed{ \Delta\varphi = \Delta\varphi_0 + \frac{ 2\pi\Delta d }{ \lambda } } \] cu semnul termenului spațial stabilit după convenția de fază utilizată.
Metoda Quincke: între două maxime succesive: \[ \Delta(\Delta d) = \lambda. \] Dacă deplasarea ramurii mobile este \(x\) și geometria modifică două segmente egale: \[ \Delta(\Delta d)=2x. \] Prin urmare: \[ \boxed{ \lambda=2x } \]
După determinarea lungimii de undă: dacă frecvența sursei este cunoscută: \[ \boxed{ v=\lambda\nu } \] permite determinarea vitezei sunetului.
Eroare experimentală frecventă: dacă ramura mobilă se deplasează cu \(x\), diferența de drum nu se modifică numai cu \(x\). În montajul Quincke descris de Bunget: \[ \boxed{ \Delta(\Delta d)=2x } \]
Unda staționară: pentru două unde de aceeași frecvență și amplitudine, propagate în sensuri opuse: \[ y_1 = A\sin(\omega t-kx), \] \[ y_2 = A\sin(\omega t+kx). \] Prin superpoziție: \[ \boxed{ y = 2A \sin(\omega t) \cos(kx) } \] pentru alegerea de fază de mai sus.
Distanțe caracteristice: două noduri consecutive: \[ \boxed{ d_{NN} = \frac{\lambda}{2} } \] două ventre consecutive: \[ \boxed{ d_{VV} = \frac{\lambda}{2} } \] un nod și ventrul vecin: \[ \boxed{ d_{NV} = \frac{\lambda}{4} } \]
Metoda Kundt — ideea de măsurare: aceeași frecvență se transmite de la vergea la gaz: \[ \boxed{ \nu_s=\nu_g } \] deci perioadele sunt egale: \[ \boxed{ T_s=T_g=T } \]
Dacă: \[ l = \frac{\lambda_s}{2} \] pentru modul de vibrație al vergelei analizat, iar: \[ l_g = \frac{\lambda_g}{2} \] este distanța dintre două noduri succesive în gaz, atunci: \[ \frac{l}{l_g} = \frac{\lambda_s}{\lambda_g}. \]
Cum: \[ v_s=\lambda_s\nu \] și: \[ v_g=\lambda_g\nu, \] rezultă: \[ \boxed{ \frac{v_s}{v_g} = \frac{l}{l_g} } \]
Nu folosi relația \(l=\lambda_s/2\) pentru orice vergea care vibrează. Ea corespunde modului de vibrație și condițiilor la limită ale configurației descrise în §12.5.
Condițiile la limită trebuie tratate fizic. Un capăt rigid, un capăt liber și un capăt antrenat de un vibrator nu impun automat aceeași condiție de nod sau ventru. Formulările istorice simplificate din Compendiu nu trebuie generalizate fără verificarea mișcării reale a mediului.
Pulberea din tubul Kundt: în modelul descris, mișcarea gazului este foarte redusă în nodurile de deplasare. Pulberea este îndepărtată din zonele cu mișcare mai intensă și se poate acumula în regiunile nodale.
Nod de deplasare și nod de presiune nu sunt același lucru. Pentru o undă acustică staționară într-un tub: un nod al deplasării particulelor corespunde unui maxim al variației de presiune, și invers, în modelul ideal.
Activitate experimentală potrivită didactic: interferența poate fi investigată prin două căi acustice de lungimi variabile. Elevii pot:

identifica maximele și minimele;
măsura distanța dintre două maxime;
deduce \(\lambda\);
calcula: \[ v=\lambda\nu; \]
compara rezultatul cu valoarea așteptată.
Schema de rezolvare — Quincke:

1. identifică două maxime consecutive;
2. măsoară deplasarea \(x\);
3. stabilește variația diferenței de drum: \[ 2x; \]
4. folosește: \[ 2x=\lambda; \]
5. dacă se cunoaște frecvența: \[ v=\lambda\nu; \]
6. verifică unitățile.
Schema de rezolvare — Kundt:

1. măsoară distanța dintre două noduri;
2. folosește: \[ \lambda_g=2l_g; \]
3. determină frecvența sau viteza cunoscută;
4. aplică: \[ v=\lambda\nu; \]
5. pentru compararea solid–gaz, folosește relația corespunzătoare modului de vibrație al vergelei.
Cinci erori de evitat:

1. confundarea maximului cu minimul de interferență;

2. uitarea factorului 2 în aparatul lui Quincke;

3. folosirea: \[ d_{NN}=\lambda \] în loc de: \[ d_{NN}=\frac{\lambda}{2}; \]

4. presupunerea că frecvența se schimbă la trecerea vibrației din vergea în gaz;

5. aplicarea condițiilor nod/ventru fără analiza condițiilor la limită.
Nucleul de memorat: maxim: \[ \boxed{ \delta=k\lambda } \] minim: \[ \boxed{ \delta = (2k+1) \frac{\lambda}{2} } \] Quincke: \[ \boxed{ \lambda=2x } \] nod–nod: \[ \boxed{ d_{NN} = \frac{\lambda}{2} } \] relația undei: \[ \boxed{ v=\lambda\nu } \] Kundt, pentru configurația sursei: \[ \boxed{ \frac{v_s}{v_g} = \frac{l}{l_g} } \]
Prioritate pentru concurs: interferența sunetelor și aparatele Quincke/Kundt nu sunt nominalizate separat în programa 2026. Prioritatea explicită rămâne punctul 11:

unde elastice plane;
unde longitudinale și transversale;
viteza undelor;
ecuația undei plane. §12.5 este însă foarte valoros pentru înțelegerea experimentală a acestor noțiuni.
