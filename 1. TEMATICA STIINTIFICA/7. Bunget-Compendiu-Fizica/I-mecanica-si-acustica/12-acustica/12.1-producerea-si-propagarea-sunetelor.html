Acustica

Sunetul și vibrațiile

Compendiul leagă sunetul de vibrațiile corpurilor materiale care se propagă printr-un mediu și pot produce senzație auditivă.

Acustica include și vibrații care nu sunt percepute de ureche, cum sunt ultrasunetele.

Propagare

Undele sonore

Vibrația se transmite din aproape în aproape. În gaze și lichide, undele discutate sunt longitudinale.

\[ \boxed{ \text{sunet} \longrightarrow \text{undă elastică} } \]

Fiind necesar un mediu material, sunetul nu se propagă în vid.

Relația (12.1)

Viteza sunetului într-un gaz

Pentru gaz, Bunget folosește formula lui Laplace:

\[ \boxed{ v = \sqrt{ \frac{ \gamma RT }{ M } } } \]

\(T\) — temperatura absolută;

\(R\) — constanta gazelor;

\(M\) — masa molară;

\(\gamma=C_p/C_v\).

\[ \boxed{ v\propto\sqrt{T} } \]

Titularizare

Precizări pentru examen

Această secțiune este separată de corpul §12.1 al Compendiului. Reperul oficial utilizat este programa Titularizare Fizică 2026.

Statut în programa 2026

„Acustica”, „producerea sunetelor” și „undele de șoc” nu sunt enumerate ca teme științifice autonome.

Legătura directă este cu punctul 11:

Unde elastice plane în medii omogene și izotrope: unde longitudinale și transversale, viteza undelor. Ecuația undei plane.

Capitolul de acustică trebuie privit în primul rând ca aplicație și aprofundare a undelor elastice.

Definiție fizică modernă: o undă sonoră este o perturbație mecanică ce se propagă printr-un mediu material. În gaze și lichide, undele sonore de volum sunt în mod obișnuit longitudinale.
Nu formula: „sunetul este transport de aer”. Particulele mediului oscilează local. Perturbația și energia se propagă.
Vid: \[ \boxed{ \text{sunetul nu se propagă în vid} } \] deoarece o undă mecanică necesită particule care să transmită perturbația.
Viteza sunetului într-un gaz ideal: \[ \boxed{ c = \sqrt{ \frac{ \gamma p }{ \rho } } } \] iar folosind: \[ p = \frac{ \rho RT }{ M }, \] rezultă: \[ \boxed{ c = \sqrt{ \frac{ \gamma RT }{ M } } } \]
Mărimi și unități SI: \[ [c] = \mathrm{m/s}, \] \[ [T] = \mathrm K, \] \[ [M] = \mathrm{kg/mol}, \] \[ [R] = \mathrm{ J/(mol\,K) }. \] Coeficientul: \[ \gamma = \frac{C_p}{C_v} \] este adimensional.
Verificare dimensională: \[ \left[ \frac{RT}{M} \right] = \frac{ \mathrm{J/mol} }{ \mathrm{kg/mol} } \] \[ = \frac{ \mathrm{m^2} }{ \mathrm{s^2} }. \] Prin urmare: \[ \boxed{ [c] = \mathrm{m/s} } \]
„Viteza nu depinde de presiune” are condiții. Pentru un gaz ideal cu aceeași temperatură și aceeași compoziție: \[ \frac{p}{\rho} = \frac{RT}{M}, \] astfel încât presiunea nu apare independent în formula finală.
Nu generaliza această concluzie oricărui mediu. Viteza undelor mecanice depinde de proprietățile elastice și inerțiale ale mediului.
Temperatura: pentru același gaz ideal: \[ \boxed{ c\propto\sqrt{T} } \] Deci: \[ \boxed{ \frac{c_2}{c_1} = \sqrt{ \frac{T_2}{T_1} } } \]
Temperatura trebuie introdusă în kelvini. Nu utiliza direct temperatura în grade Celsius în relația: \[ c = \sqrt{ \frac{ \gamma RT }{ M } }. \]
Aproximație practică pentru aer, în apropierea temperaturilor obișnuite: \[ c \approx 331\,\mathrm{m/s} + 0{,}6 \frac{\mathrm{m/s}}{^\circ\mathrm C} \,\theta, \] unde \(\theta\) este temperatura în grade Celsius.
Aceasta este o aproximație locală, nu legea fundamentală. Formula cu temperatura absolută este baza teoretică pentru gazul ideal.
Precizare modernă față de textul istoric: în acustica liniară, pentru unde sonore de amplitudine mică, viteza de propagare nu depinde în mod semnificativ de intensitatea sunetului. Efecte dependente de amplitudine apar în regimul neliniar, la perturbații suficient de puternice.
Sursă punctuală în repaus: într-un mediu omogen și izotrop: \[ \boxed{ R=ct } \] pentru fronturile sferice ideale, măsurând timpul de la emisie.
Numărul Mach: pentru un corp sau o sursă cu viteza \(u\): \[ \boxed{ \mathrm{Ma} = \frac{u}{c} } \] Este o mărime adimensională.
Regimuri: subsonic: \[ \boxed{ \mathrm{Ma}<1 } \] sonic: \[ \boxed{ \mathrm{Ma}=1 } \] supersonic: \[ \boxed{ \mathrm{Ma}>1 } \]
Conul Mach: pentru o sursă punctuală idealizată care se deplasează uniform cu: \[ u>c, \] geometria fronturilor conduce la: \[ \boxed{ \sin\mu = \frac{c}{u} = \frac{1}{\mathrm{Ma}} } \]
Nu confunda unghiul Mach cu un unghi de reflexie sau refracție. El descrie geometria înfășurătorii fronturilor emise succesiv de sursa supersonică.
Interpretarea geometrică: într-un interval \(\Delta t\): unda avansează: \[ c\Delta t, \] iar sursa: \[ u\Delta t. \] De aici: \[ \sin\mu = \frac{ c\Delta t }{ u\Delta t } = \frac{c}{u}. \]
Unda de șoc: când perturbațiile se acumulează într-un front foarte abrupt, apare o variație rapidă a presiunii, densității și temperaturii. Acesta este un regim neliniar al curgerii compresibile.
„Bubuitura sonică” nu este produsă numai în clipa în care avionul trece de Mach 1. Un corp supersonic generează un sistem de unde de șoc cât timp se menține regimul corespunzător. Observatorul aude efectul când frontul de șoc îl traversează.
Legătura cu Doppler: dacă: \[ u
La: \[ u\rightarrow c, \] formula Doppler elementară pentru o sursă subsonică nu trebuie interpretată ca o divergență fizică nelimitată. Aproape de regimul sonic devin importante efectele neliniare și formarea undelor de șoc.
În solide: pot exista mai multe moduri de propagare elastică, inclusiv longitudinale și transversale. Vitezele lor pot fi diferite.
Prin urmare, valoarea „vitezei sunetului într-un solid” trebuie legată de tipul undei, direcția de propagare și proprietățile materialului. În materiale anizotrope, viteza poate depinde și de direcție.
Fenomene sonore care derivă din caracterul ondulatoriu: reflexie;
refracție;
interferență;
difracție.
Legătura logică pentru concurs: \[ \boxed{ \text{oscilație} \rightarrow \text{undă elastică} \rightarrow \text{undă sonoră} } \] Acustica aplică formalismul undelor elastice unor perturbații mecanice detectabile sau analizabile ca sunet.
Cinci erori de evitat:

1. afirmația că sunetul se propagă în vid;

2. confundarea vitezei sunetului cu viteza particulelor mediului;

3. folosirea temperaturii în grade Celsius în formula lui Laplace;

4. confundarea regimului sonic cu cel supersonic;

5. folosirea relației \(\sin\mu=c/u\) pentru: \[ u
Nucleul de memorat: gaz ideal: \[ \boxed{ c = \sqrt{ \frac{ \gamma RT }{ M } } } \] relația undei: \[ \boxed{ c=\lambda\nu } \] număr Mach: \[ \boxed{ \mathrm{Ma} = \frac{u}{c} } \] con Mach: \[ \boxed{ \sin\mu = \frac{1}{\mathrm{Ma}} } \] condiție supersonică: \[ \boxed{ \mathrm{Ma}>1 } \]
