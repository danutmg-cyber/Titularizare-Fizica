1. Mecanică 10 p

Date:
m = 400 g = 0,400 kg
v = 10 m/s
t = 20 min = 1200 s

Forța de frecare reprezintă 15% din greutatea corpului:

Ff = 0,15G

Mișcarea este rectilinie uniformă.

Observație privind enunțul: în fotografia subiectului nu este precizată valoarea accelerației gravitaționale. Pentru calculul numeric vom utiliza convenția școlară uzuală g = 10 m/s² = 10 N/kg.

a) Reprezentarea forțelor și calculul valorilor lor

Asupra corpului acționează patru forțe:

  • greutatea G, vertical în jos;
  • reacțiunea normală N a suprafeței, vertical în sus;
  • forța de frecare Ff, orizontal și opus sensului mișcării;
  • forța motoare F, orizontal și în sensul mișcării.

Greutatea

G = mg
G = 0,4 kg · 10 m/s²
G = 4 N

Reacțiunea normală

Pe verticală nu există accelerație:

N - G = 0
N = G = 4 N

Forța de frecare

Ff = 15% · G
Ff = 0,15 · 4 N
Ff = 0,6 N

Forța motoare

Corpul se deplasează uniform, deci:

a = 0

Din principiul fundamental al dinamicii:

ΣF⃗ = ma⃗ = 0

Pe direcția orizontală:

F - Ff = 0
F = Ff = 0,6 N

Schema forțelor

Răspuns a):
G = 4 N;
N = 4 N;
Ff = 0,6 N;
F = 0,6 N.

b) Lucrul mecanic total

Pasul 1. Distanța parcursă

Mișcarea este uniformă:

s = vt
s = 10 m/s · 1200 s
s = 12 000 m

Lucrul mecanic al forței motoare

Forța motoare are același sens cu deplasarea:

LF = Fs cos 0°
LF = Fs
LF = 0,6 N · 12 000 m
LF = 7200 J

Lucrul mecanic al forței de frecare

Frecarea este opusă deplasării:

Lf = Ffs cos 180°
Lf = -Ffs
Lf = -7200 J

Lucrul greutății și al reacțiunii normale

G și N sunt perpendiculare pe deplasare:

LG = 0
LN = 0

Lucrul mecanic al rezultantei tuturor forțelor

Ltot = LF + Lf + LG + LN
Ltot = 7200 - 7200 + 0 + 0
Ltot = 0 J

Rezultatul este în acord cu teorema variației energiei cinetice:

Ltot = ΔEc

Deoarece viteza este constantă:

ΔEc = 0
Răspuns b):
dacă prin „lucrul mecanic total” se înțelege lucrul mecanic al rezultantei tuturor forțelor, atunci:
Ltot = 0 J
Lucrul mecanic pozitiv efectuat de forța motoare este:
LF = 7200 J
Observație privind formularea enunțului: sintagma „lucrul mecanic total” poate crea ambiguitate. Fizic, suma lucrurilor tuturor forțelor este 0 J deoarece corpul se deplasează uniform. Dacă autorul urmărește lucrul mecanic efectuat de forța motoare pentru învingerea frecării, valoarea este 7200 J.

c) Puterea mecanică produsă

Puterea mecanică medie asociată forței motoare este:

P = LF/t
P = 7200 J / 1200 s
P = 6 W

Se poate calcula și direct:

P = Fv
P = 0,6 N · 10 m/s
P = 6 W
Răspuns c): puterea mecanică a forței motoare este P = 6 W.

Puterea rezultantei tuturor forțelor este 0 W, deoarece rezultanta este nulă. Valoarea de 6 W este puterea necesară pentru compensarea frecării și menținerea mișcării uniforme.

d) Energia cinetică a corpului

Energia cinetică:

Ec = mv²/2
Ec = 0,4 kg · (10 m/s)² / 2
Ec = 0,4 · 100 / 2 J
Ec = 20 J
Răspuns d): energia cinetică a corpului este Ec = 20 J.

Deoarece viteza este constantă, energia cinetică rămâne constantă pe toată durata mișcării.

2. Calorimetrie 10 p

Date:
Q = 9660 J
t1 = 22°C
t2 = 32°C
cFe = 460 J/(kg·K)

Se cere masa corpului de fier:

m = ?

1. Variația temperaturii

ΔT = t2 - t1
ΔT = 32°C - 22°C
ΔT = 10°C = 10 K

2. Ecuația calorimetrică

Căldura necesară pentru modificarea temperaturii unui corp fără schimbarea stării de agregare este:
Q = mcΔT

Rezolvăm în raport cu masa:

m = Q/(cΔT)

3. Calcul numeric

m = 9660 J / [460 J/(kg·K) · 10 K]
m = 9660 / 4600 kg
m = 2,1 kg

4. Verificarea unităților

[m] = J / [J/(kg·K) · K]
[m] = kg

✓ Unitatea obținută este corectă.

5. Verificarea numerică

Q = 2,1 kg · 460 J/(kg·K) · 10 K
Q = 9660 J

✓ Se reproduce valoarea din enunț.

Răspuns problema 2: masa corpului de fier este m = 2,1 kg.

3. Fir de cupru – tensiunea electrică 10 p

Date:
ρ = 1,68 · 10-8 Ω·m
I = 120 mA
l = 4 m
S = 0,2 mm²

Se cere:

U = ?

1. Transformarea datelor în SI

Intensitatea curentului

I = 120 mA
I = 120 · 10-3 A
I = 0,12 A

Aria secțiunii transversale

Știm că:

1 mm = 10-3 m

Prin urmare:

1 mm² = 10-6 m²
S = 0,2 · 10-6 m²
S = 2 · 10-7 m²

2. Rezistența firului

Rezistența electrică a unui conductor omogen este:
R = ρl/S

Introducem datele:

R = (1,68 · 10-8 Ω·m · 4 m) / (2 · 10-7 m²)
R = 6,72 · 10-8 / 2 · 10-7 Ω
R = 0,336 Ω

3. Aplicarea Legii lui Ohm

Pentru fir:

U = RI

Numeric:

U = 0,336 Ω · 0,12 A
U = 0,04032 V

În milivolți:

0,04032 V = 40,32 mV
Răspuns problema 3: tensiunea la capetele firului este U = 0,04032 V ≈ 40,32 mV.

4. Verificare dimensională

Pentru rezistență:

[R] = (Ω·m) · m / m² = Ω

Pentru tensiune:

[U] = Ω·A = V

✓ Unitățile sunt corecte.
